Anthropic 揭秘科學家用 Claude 都幹啥：大多用來分析數據和寫作

內容機器翻譯自第三方媒體（IT之家 · cnBeta.COM），僅供參考，以原文為準。

正文

11 月 5 日，Anthropic 前 Claude Code 產品負責人 Cat Wu 宣佈加入 OpenAI，負責核心產品團隊的產品管理工作。

這已經不是 Anthropic 近期第一次出現核心成員離職。10 月 24 日，Claude Code 團隊工程師 Thariq Shihipar 宣佈離職。他在 Anthropic 工作了一年多，參與了 Claude Code 的開發。同一天，負責開發 Claude Code 桌面版的 Anthony Morris 也公開了離職消息。11 月初，Cat Wu 又離開了這支團隊。短短十餘天，三位參與 Claude Code 產品開發的重要成員先後告別 Anthropic。

就在 Cat Wu 宣佈新去向的同一天，剛剛離職的 Thariq 參加了由 Sarah 和 Vivian 主持的播客節目《State of the Art Wives》（SOTA Wives），回顧了從創業到加入 Anthropic 的經歷，以及對頂尖 AI 實驗室的反思。

Thariq 自己也曾面臨繼續創業和加入頂尖 AI 實驗室之間的選擇。他曾創辦一家融資千萬美元的遊戲公司，但最終決定關閉公司、轉向 AI 領域。在探索了一段時間後，他選擇加入 Anthropic，成為 Claude Code 團隊的一員。

然而，這位主動加入頂尖實驗室的工程師，在真正進入其中工作之後，卻開始反思外界對這些機構的崇拜。他認為，如今的頂尖 AI 實驗室正在成為巨大的“人才黑洞”，不斷吸引優秀人才加入。但從 MIT、YC 到 Anthropic，他發現，這些機構雖然聚集了大量聰明人，卻並不存在某種讓人突然變成天才的魔法。加入頂尖實驗室，不意味着一個人必然能夠做出優秀成果；離開這些機構，也不意味着失去了創造價值的機會。對那些因為 OpenAI、Anthropic 等巨頭過於強大而猶豫是否創業的人，他尤其想強調一句話：“勇氣比天才更稀缺。”

在加入 Anthropic 之前，Thariq 曾經是一名創業者。2020 年初，他加入了 Y Combinator（YC）冬季創業營，創辦了一家線上遊戲平台，用户可以通過互聯網玩《龍與地下城》之類的桌面角色扮演遊戲。

那是一屆頗為特殊的 YC 創業營。項目剛開始時，新冠疫情尚未對硅谷產生明顯影響，創業者仍然在線下參加活動。但隨着疫情暴發，原本的創業展示和融資活動也被迫改變。Thariq 回憶，那一屆 Demo Day，創業者甚至沒有機會完整展示自己的項目，只能提交一頁幻燈片。感興趣的投資人通過線上點贊或發送消息的方式聯繫創業團隊。

不過，疫情也給遊戲行業帶來了新的機會。居家娛樂需求增長，資本對遊戲行業的投資熱情上升，這也讓 Thariq 的公司獲得了可觀的融資。Thariq 回憶，公司當時賬上大約有 1500 萬美元，但整個團隊只有七八個人。對於一家規模不大的遊戲創業公司而言，這是一筆相當可觀的資金。然而，隨着業務推進，他逐漸意識到，公司獲得的資金已經遠遠超出了實際發展所能支撐的規模。

融資過多還帶來了一個意想不到的問題：退出變得更加困難。如果公司希望通過被收購的方式實現退出，此前較高的融資規模可能讓潛在收購方難以接受相應的交易價格。但 Thariq 認為，更值得警惕的是融資成功對創業者心態的影響。

“融太多錢也會影響心態，讓你以為自己已經做成了什麼，但實際上並沒有。”在他看來，融資成功和真正做出一款有市場需求的產品，是兩件不同的事。他還坦言，在創業過程中，有時候自己甚至覺得只是在“扮演創業者”。他不太認同一種現象：一些人熱衷於研究如何進入 YC、獲得知名機構認可，或者不斷積累看起來亮眼的履歷標籤，卻沒有把全部注意力放在真正做出產品上。最終，Thariq 決定關閉公司，並將剩餘資金退還給投資人。

關閉公司之後，Thariq 並沒有立即加入 Anthropic。事實上，Thariq 很早就對 AI 產生了興趣。從 GPT-2、GPT-3 時期開始，Thariq 就開始嘗試將語言模型應用於遊戲。結束創業之後，他又花了將近一年的時間探索其他方向，他曾在 South Park Commons 活動，與 Goodfire 合作進行 AI 研究，還開發過一個電子表格智能體。這些實踐讓他逐漸轉向 AI，尤其是編程智能體。

隨着 Claude 編程能力不斷提升，Anthropic 開始吸引他的注意。從 Claude 3.5 Sonnet 開始，Thariq 就認為 Anthropic 在編程方面展現出了明顯優勢。他相信，編程將成為 AI 最重要的應用方向之一。最終，在繼續創業與加入頂尖 AI 實驗室之間，他選擇了 Anthropic。後來，Claude Opus 4 的表現也進一步印證了他此前對 AI 編程方向的判斷。

但有意思的是，這位主動選擇加入頂尖實驗室的工程師，後來卻成為反思實驗室光環的人。

Thariq 並不否認 Anthropic 的吸引力。這些實驗室擁有領先的模型能力、優秀的團隊，也讓工程師有機會參與 AI 領域的重要工作。這也讓 OpenAI、Anthropic 等公司成為巨大的“人才黑洞”，吸引越來越多優秀工程師和研究人員。但在 Thariq 看來，外界對這些機構的崇拜已經有些不健康了。

這種對頂尖人才的崇拜，在社交媒體上表現得尤為明顯。Thariq 回憶，自己最初接觸 X 技術圈時，曾經對這裏充滿嚮往。平台上聚集了大量聰明的工程師和研究人員，他們討論前沿技術，參加各種有意思的活動。在當時的 Thariq 看來，這個圈子甚至有些像古雅典，或者文藝復興時期的佛羅倫薩。

但隨着自己在 X 上獲得越來越多關注，他逐漸發現，社交媒體對這些人的呈現往往經過了某種程度的美化。尤其是一些匿名技術賬號，這些賬號可能使用戴着眼鏡的花栗鼠、希臘雕像作為頭像，發佈的技術內容非常出色，擁有大量粉絲，卻很少透露真實身份。Thariq 曾經對這類賬號背後的人充滿好奇。但真正見面之後，他發現，對方往往和自己想象中的神秘天才相差甚遠。他甚至半開玩笑地總結了一條原則：如果你關注的是一個匿名賬號，最好不要去見本人。

這種經歷也讓他逐漸意識到，人們很容易因為一個人的機構背景、社交媒體形象或公眾影響力，給對方賦予過高的期待。頂尖 AI 實驗室的身份光環，在某種程度上也存在類似的現象。“每次進入一個新的機構，無論是 MIT、YC，還是 Anthropic，我都會有這樣的體會： 這些人確實很聰明，但他們也只是普通人 。”

當然，這並不意味着他否認實驗室員工的能力。恰恰相反，Thariq 對 Anthropic 同事的評價很高。他認為，這裏有許多聰明、勤奮、認真而且能力出色的工程師。但優秀的人才聚集在一家機構，並不意味着所有優秀的想法都只能在這裏產生。

他自己的經歷就是一個例子。在加入 Anthropic 之前，Thariq 就已經花了大量時間探索 AI 工具和編程智能體的用法。Claude Opus 4 發佈後，他曾嘗試利用 Claude Code 監控數據庫和事件，構建類似如今人們所説的“軟件工廠”的自動化工作流。他也嘗試過用 Claude Code 製作視頻，並認為自己可能是最早探索這種用法的人之一。早期的實現過程非常繁瑣，需要投入大量時間，但這些實驗讓他逐漸形成了一個判斷：如果一項任務現在已經能夠通過 AI 做出初步雛形，那麼未來六到十二個月，相關能力就可能發展得相當成熟。

後來，他開始將這些探索過程分享到 X 上，逐漸獲得越來越多的關注。但 Thariq 認為，自己對 AI 工具的熟練掌握並不完全來自 Anthropic 的內部資源。事實上，在加入 Anthropic 之前，他就已經積累了豐富的實踐經驗，甚至在提示詞編寫和 AI 工具使用方面，有時比實驗室內部的一些人還要熟練。進入 Anthropic 後，他當然也學到了許多新方法，但同樣會看到一些新加入的工程師帶來此前團隊沒有想到的新思路。

這些經歷也讓 Thariq 更加確信，優秀的想法和實踐能力並不是頂尖實驗室的專屬。進入這些機構，確實能夠接觸到優秀的人才和技術， 但並不存在一種魔法，能讓一個人加入之後就突然成為天才。 一個人真正掌握的能力，終究需要通過實際行動和持續探索來積累。

如今，每當 OpenAI 或 Anthropic 發佈一款新產品，人們就會討論，又有多少初創公司將因此失去生存空間。從資源、人才到算力，初創公司似乎很難與這些巨頭競爭。

在 Thariq 看來，舊金山科技圈從來不缺善於思考和分析問題的人。但對於創業者來説，過度理性有時反而會成為阻礙。如果一個人不斷分析大公司的資金、人才和技術優勢，很容易得出一個看似合理的結論：既然幾乎不可能打敗這些公司，為什麼還要開始？可創業本身就是一個不斷嘗試、尋找產品與市場契合點（PMF）的過程。如果一直停留在分析和推演階段，一些原本可能有價值的想法，最終連驗證的機會都沒有。
