此次GIT Day即以「AI智慧製造 精準量測 × 智能自動化」為主題，規劃趨勢洞察、軟硬整合方案、真實案例分享及實機展示交流等四大亮點，希望提供製造業者可實際落地的經驗與技術參考。

本次論壇議程涵蓋的技術議題，包括「AI伺服器之FBT氣/水冷測試設備及自動化解決方案、車用多媒體系統測試方案、矽光子與光通訊產業中的機器視覺光纖對準技術，以及AI智慧巡檢系統等應用」。其中，隨著AI伺服器持續成長，散熱驗證與測試自動化正成為供應鏈的重要課題；而矽光子技術被視為下一世代高速傳輸的重要發展，也帶動光學精準對位與自動化設備需求快速提升，透過產業案例與分享，可深入瞭解技術在智慧工廠與先進製造的成果。

除了技術論壇外，現場亦規劃Solution Demo展示區，呈現無線通訊測試、車用電子驗證、半導體射頻測試與智慧工廠應用等最新成果。其中，無線通訊展示聚焦WiFi 7/WiFi 8 Non-Signaling PHY Layer Testing，協助開發人員提升高速無線產品驗證效率；半導體測試應用則展出RFIC WiFi 8 PA Front-End Test System，展現射頻元件量產測試能力。

車用電子領域涵蓋AM、FM及BT音頻Audio測試的Car Radio車載主機測試方案。此外，智慧工廠應用展出以AI電腦視覺即時判斷作業員動作、支援遠端監控並透過報表解析生產瓶頸的智慧產線作業行為分析系統，以及透過AI視覺即時判讀、達成精準攔截與製程良率優化的智慧晶圓光學檢測系統。

GIT Day將於12月11日下午1點在「新竹喜來登飯店 - 東館5樓多功能廳」舉行，議程除技術專題演講外，也安排Solution Demo展示及交流時段，讓與會者瞭解智慧製造與AI技術實際應用情境，活動採免費報名制，開放產業界人士事先報名參加，現場將提供交流活動及抽獎機會，期待促進半導體、電子製造相關業者共同探討產業升級與數位轉型新契機。邀請您立即報名 「2026 GIT Day」 。
