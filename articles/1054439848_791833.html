Canvas 能夠將 AI 從單純的對話助手，變成一個可交互的工作空間，讓你能夠可視化信息、探索工作流程，並在複雜任務中直接採取行動。

如今，大多數開發者都已經開始與 AI 智能體協作，或至少已經熟悉這種工作方式。智能體能夠幫助你探索想法，並將其轉化爲實際行動，從項目規劃到工作流自動化，很多時候，一段對話就足以推動工作向前。

但如果遇到那些並不適合通過對話完成的任務呢？

與其不斷在一長串提示詞和回覆之間來回切換，不如使用 Canvas，直接與眼前的信息進行交互。

**使用 Canvas**

這些共享、可交互的界面，是 GitHub Copilot App 中的一項擴展能力，稱爲 Canvas。Canvas 是 GitHub Copilot App 中供開發者與智能體實時協作的交互界面，而這些共享式交互界面則被稱爲 Canvas 擴展。

智能體在工作過程中可以持續更新 Canvas，而你也可以通過點擊、編輯等交互方式直接操作同一個工作空間。這些操作既可以發送回智能體繼續處理，也可以由 Canvas 在本地完成響應。

你還可以持續讓 Copilot 對 Canvas 進行迭代，例如添加新的功能、優化已有能力等，讓 Canvas 隨着你的工作不斷演進。

要創建一個 Canvas，只需在 GitHub Copilot App 的 Agent 會話中輸入 **/create-canvas**，然後描述你希望創建的內容，以及它需要具備哪些能力即可。

由於 Canvas 是根據 Prompt 動態生成，並會隨着工作流程不斷演化，因此它可以呈現出各種不同的形態。有些用於可視化信息，有些幫助你執行操作，還有一些則能以更加有趣的方式幫助你處理繁瑣的待辦事項。

下面是幾個 Canvas 擴展的示例。

**Issue 分類助手**

**目標**：以快速、直觀的方式整理 GitHub Issues。

**Prompt**：

/create-canvas Create an interface that allows me to easily swipe through issues in a repo in card format. Can swipe right to ship, left to reject.

**結果**：

Canvas 會生成一個卡片式界面，每次展示一個 Issue。你可以直接在界面中完成操作：右滑表示接受，左滑表示拒絕。隨着你的操作，Canvas 會實時更新狀態，將 Issue 自動歸類到對應的列表中。

**交互式代碼庫架構圖**

**目標**：可視化項目結構以及各組件之間的關係。

**Prompt**：

/create-canvas Render a colorful, interactive diagram showing how the code in this project is working together, show how things are related, etc.

**結果**：

Canvas 會生成一個動態的代碼架構圖，其中每個節點代表系統中的一個組成部分。你可以通過懸停、拖拽和篩選等方式探索不同層級，從而將原本靜態的代碼結構，變成一個可以自由探索的交互式架構圖。

**Sessions Worktree 视图**

**目標**：可視化所有 GitHub Copilot App 會話及其對應的 Git Worktree，清晰區分哪些仍在使用、哪些已經失效，並支持快速清理。

**Prompt**：

/create-canvas Create a worktree view that will help me see all of my current sessions and whether or not they are active or orphaned. Allow me to clean them up with a few clicks where needed

**結果**：

Canvas 會生成一個可視化視圖，展示所有 Worktree，並清楚標識哪些仍處於活動狀態，哪些已經失效或成爲孤立 Worktree。對於失效的 Worktree，你只需點擊按鈕即可完成清理。

**Agent Prompt 教练**

**目標**：分析歷史 Prompt，幫助提升 Prompt 編寫質量，並給出更清晰、更高效的智能體交互建議。

**Prompt**：

/create-canvas Create an interactive prompt coach that suggests to you how you could have improved your previous prompts in your sessions with skills, mcp servers, etc. Make note of any spelling errors, syntax errors, etc.

**結果**：

Canvas 會展示歷史 Prompt，並逐條分析，指出例如上下文缺失、拼寫錯誤、語法問題等可以改進的地方。藉助這些建議，你可以不斷優化 Prompt，提高表達清晰度，並獲得更加穩定、一致的智能體輸出。

**Knowledge Finder**

**目標**：通過搜索 Slack、Teams、郵件以及文檔，找到對某個文件或主題最瞭解的人。

**Prompt**：

/create-canvas Create a way that I can search across Slack, Teams, Email and docs to find people with knowledge of a specific file or someone that would have more context.

**結果**：

Canvas 會跨多個協作工具進行搜索，找出與指定文件或主題關聯最緊密的人員，並展示他們是誰，以及關聯信息來自哪裏。這樣，你可以快速定位最瞭解相關內容的人，並進一步獲取更多背景信息。

**帶走這些思考**

以上這些示例只是 Canvas 能力的一小部分。Canvas 能夠將 AI 從一個對話工具，升級爲一個可視化工作空間，讓你能夠更直觀地理解信息、探索不同的工作流程，並把原本枯燥的任務變成更有趣、更願意完成的體驗。

Canvas 是一個開發者與智能體共同協作的共享工作空間，你們可以在這裏一起思考、探索，並完成實際工作。
