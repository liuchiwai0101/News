【AI 新戰局】馬斯克轉陣！Grok Bot 棄「全自家製」宣佈整合 Claude 5.5、Midjourney 等頂級 AI 當後台

內容機器翻譯自第三方媒體（PCM），僅供參考，以原文為準。

一直以來，AI 業界的競爭焦點都落在「誰家大模型跑分最高、能力最強」。不過，Elon Musk 日前為市場投下一枚震撼彈：SpaceX 旗下的 AI 代理程式 Grok Bot 將不再侷限於自家模型，而是會按任務需求，自動為用家挑選並切換至「最強外援」，當中更直接點名對手 Anthropic 的 Claude Opus 5.5、Midjourney 及 Suno！這意味著未來的 Grok Bot，將從單一模型進化成一個集百家之大成的「AI 超級入口」。

Important note regarding Grok @Bot:

Going forward, @SpaceX will use the best back end model for any given task, including Claude Opus 5.5, MidJourney, Suno and other leading APIs.

Whatever is most likely to give you the best outcome.

— Elon Musk (@elonmusk) October 7, 2026

任務自動分流：簡單問題用平模，複雜任務叫大模

這次的焦點落在今年 8 月開始試用、現隸屬 SpaceX 旗下（前身為 xAI）的「Grok Bot」身上。有別於大家在 X 平台上常用的聊天機械人 Grok，Grok Bot 是一個在雲端擁有獨立運算資源的 AI 代理程式（AI Agent），專責為用户連續處理多項複雜工作。

Grok @Bot will use whatever achieves the best outcome for users.

Simple questions will route to small, fast models. Questions with complex answers will route to large models. https://t.co/T613EfkcQf

— Elon Musk (@elonmusk) October 7, 2026

yes, bot itself will run on opus 5.5

— lauren (@poteto) October 7, 2026

10 月 7 日，Elon Musk 在 X 發帖明言：「未來 SpaceX 將會為任何特定任務，採用最好的後端模型，包括 Claude Opus 5.5、Midjourney、Suno 及其他領先的 API。總之甚麼能給你最好結果，就用甚麼。」其後他再補充，系統會作出智能分流：簡單任務交由小巧快速的模型處理，而複雜任務才會動用大型模型。Grok Bot 團隊成員 lauren (@poteto) 亦證實，Bot 本體將會運行今年 9 月才推出、擅長寫程式與複雜推理的 Claude Opus 5.5（官方定價約為每百萬 Token 輸入 $4 美元、輸出 $20 美元）。

雖然 Grok 本身的 Imagine 生成工具表現不俗，但 Musk 依然將設計師愛用的 Midjourney 納入「外判」考量。

至於圖像及音樂生成方面，雖然 Grok 本身的 Imagine 生成工具表現不俗，但 Musk 依然將設計師愛用的 Midjourney 納入「外判」考量；而自家缺乏音樂模型的 SpaceX，更直接點名 AI 作曲神器 Suno。不過，由於 Suno 目前暫未提供公開 API，這項整合相信仍需待官方公佈接口後才能真正落地。

佈局解碼：掌控「入口」比死磕「模型」更值錢

過去兩年，AI 廠商都在死磕自家模型的參數，但 Musk 此舉揭示了另一種商業邏輯——爭奪「流量入口」。

只要 Grok Bot 成為用家每天依賴的工作流中心，保存了帳號、文件及使用習慣，背後究竟是哪個模型在發功，對一般用家而言根本不重要。用家「懶得搬家」，換模型的成本低，但換入口的成本高。同時，透過「簡單問題用平模型、難題先買貴模型」的分流策略，平台能有效控制成本，從中賺取差價，利潤空間遠比單靠自家模型更大。

然而，此舉亦帶有隱憂。若 Claude 成為 Grok Bot 的預設大腦，Anthropic 將變相獲得龐大的使用量與數據；一旦對方日後加價、限流或收緊商用條款，SpaceX 隨時面臨「斷糧」風險，甚至可能淪為對手的純分銷渠道。

中國香港用家必讀：使用前要釐清的三大盲點

對於一眾中國香港用家及企業用户，面對 Grok Bot 的策略轉向，有三點切身影響必須注意：

  1. 聊天版與 Bot 版屬兩回事： 目前日常在 X 平台或 grok.com 使用的聊天版 Grok，暫未有消息指會跟隨棄用自家模型。今次受影響的主要是針對代理任務的「Grok Bot」，兩者切勿混淆。
  2. 私隱資料「過境」疑慮（最重要）： 這點對企業用家最為致命。帖文目前並未交代用户輸入的 Prompt、機密檔案或對話紀錄，在交由第三方 API 處理時會否直接送交 Anthropic 等公司，亦未見有明確的「Opt-out（退出）」選項。若你打算用 Bot 處理商業企劃或未公開的客户資料，這點比「哪個模型更勁」更需要優先釐清。
  3. 收費模式仍屬未知數： Musk 暫未提及這項「一條龍」服務會否加價，亦沒要求用家自備各平台的 API Key。預計相關呼叫費用會由平台承擔或直接計入 Grok Bot 的訂閲方案內。在未有正式價目表前，不宜假設「一個訂閲費用就能無限制用盡三家大廠」。

總括而言，「入口比模型值錢」是目前極具潛力的產品方向，但現階段 Midjourney 和 Suno 仍只屬例子，尚未完全上線。大家未來最需要盯緊的，是系統日後會否清楚顯示「這次任務呼叫了誰」，以及用户是否擁有拒絕第三方介入的權利。
