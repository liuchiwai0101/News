Windows 11 改版後反應速度提升 20%　8GB 記憶體電腦表現改善

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

微軟今年較早時公佈一項修正 Windows 11 的計劃，重點放在效能、穩定性及整體作業系統體驗。經過數月修正後，微軟表示現時的 Windows 體驗「反應速度提升最多 20%」，並指多項速度改善來自更聰明的記憶體與電腦資源管理方式。

記憶體管理改善 8GB 電腦表現

微軟已在開始功能表、檔案總管、搜尋、Edge 及其他部分著手改善，令 Windows 11 感覺更快、反應更靈敏。微軟 Windows 體驗企業副總裁 Navjot Virk 表示，這項工作很大部分是更聰明地運用記憶體與系統資源，集團改善了整個 Windows 的記憶體管理與效率，讓更多電腦資源集中在使用者正在進行的操作上。

記憶體管理的改進對只有 8GB 記憶體的電腦帶來「實質分別」。Virk 指出，Windows 現時最多可把額外 2GB 的使用中資料保留在記憶體中，而不再把它移到較慢的儲存裝置；在配備 8GB 或更少記憶體的電腦上，小工具只會在使用者開啟時才載入，從而為應用程式及其他工作釋出超過 200MB 記憶體。

工作列與藍牙等體驗改善

微軟同時令 Windows Update 幹擾更少、整理了小工具區塊，並終於允許把工作列移到螢幕的左右兩側或頂部。Windows Hello 登入速度亦已加快，藍牙配對更可靠，包括 AirPods 配對體驗最多快 15 秒。

全新 Windows Search 體驗

下一步是全新的 Windows Search 體驗，速度明顯更快、功能更強。這項功能目前向 Windows Insiders 提供，微軟表示會在「今年較後時間更廣泛推出」。有試用者形容，這是今年 Windows 11 最出色的新增功能之一。
