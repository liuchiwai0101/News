Argon 擅长在编程、金融、法律、网络安全和科学等领域的复杂现实任务中进行深度工作。在多步任务中展现出的深度和精准度，使得 Argon 在各个领域的基准测试中均优于其他前沿模型，并在衡量金融、编程、法律和税务等关键经济领域模型性能的 Vals 指数中排名第一。

该模型于今日推出，首发体验价²为：每百万输入 token 2 美元，每百万输出 token 10 美元（缓存输入 token 可享 95% 折扣）。

Google 内部团队、各企业以及研究界已经开始使用 Argon，在多个领域取得了重大突破：

在 Google，我们一直在使用 Argon 解决最棘手的工程问题。在过去几周里，软件工程师交付高质量代码的速度比以往任何时候都快。Antigravity 中的 Argon 帮助团队将智能体代码提交量提升了 35% 以上，同时将代码回滚率降低了近三分之一。

理清 Chrome 中的浏览器功能代码： Argon 帮助 Chrome 团队将核心网页处理代码从一个有约 600 万行的历史遗留浏览器功能代码文件夹里分离开，而这些代码被掩码在 Chromium 4000 万行代码库中。通过批量传输多项整洁的代码变更优化，Argon 协助团队完成了涉及数百个文件的架构重构，将原本需要数月的工作缩短至几周内完成。对于全球数十亿 Chrome 用户而言，这将使加载中的网页能够在标签页、侧边栏和悬浮窗口之间流畅移动而无需重新加载，从而解决一整类导致浏览器崩溃的问题。

在数小时内优化生产级 Python 代码库： Antigravity 中的 Argon 正在帮助 Google 开源智能体开发工具包（ADK，一个为企业级智能体提供支持的框架）背后的团队进一步提升其性能。该团队向 Argon 提供了其 .agents/skills 规则手册以及一个简短明确的目标：在不破坏现有应用的前提下消除框架带来的额外开销。Argon 在夜间自主工作，提出了各种优化方案 （现已在 google/adk-python 中上线），使长会话中的内存会话准备时间减少了 40%，并将冷导入速度提高了 21%。

优化量子化学开源包： xTB (Semiempirical Extended Tight-Binding) 是分子领域被引用次数最多的开源量子化学软件包之一。科学家们使用它来预测分子的 3D 结构，以及筛选海量的候选药物和材料。借助 Antigravity 中的 Argon，我们的研究人员将 xTB 预测分子结构的速度提升了 2.3 倍，构象搜索速度提升了 1.8 倍。这些优化更新已贡献给 GitHub 上的 xTB 官方代码库。

将我们的 Gemma 开放模型速度提升近三倍： 借助 Argon，我们在短短几天内就在 A100 上通过 vLLM 实现了 2.85 倍的端到端推理速度提升（将 Gemma 4 E2B 上的吞吐量从每秒约 37,900 个 token 加速到超过 108,000 个），且保证了 100% 输出 token 一致和零质量下降——而这个过程通常需要耗时数月。欢迎查看上游的拉取请求（从注意力机制调优到投机解码的全面优化），了解具体的技术改进细节。

实现复杂的 3D 可视化： 与以往的 Gemini 模型相比，Argon 在空间推理、数学精度和可视化编程方面带来了显著提升。通过使用 /goal 等命令，并在 Antigravity 中结合自定义技能提示词发起多智能体循环，Google 员工正利用 Argon 直接通过原生代码制作复杂的 3D 可视化、高保真游戏和交互式动画原型，这些代码均可直接在浏览器中渲染。

Argon 融合了前沿推理、深度视觉感知、不断扩展的领域知识以及在法律、金融、科学和编程方面更强大的写作能力，以协助处理高风险的专业工作流。它沟通清晰，让您随时掌握最新进展，并且在遵循风格指令方面比我们以往的任何 Gemini 模型都更加可靠。Argon 回答问题更直接、少有模棱两可，不会进行不必要的重复，并在回复中避免使用陈词滥调。

我们早期体验计划中的企业用户和初创公司已经凭借 Argon 取得了显著成果。Argon 运用其高级推理和多模态能力，同时保持严格的事实依据，在深度多模态文档理解、纵向数据分析和交互式分析沙盒方面表现优异。

研究人员、工程师和安全专家已在使用 Argon 拓展网络防御、科学、数学和机器人技术的边界。它正在帮助网络防御者和研究人员验证假设，自主审计关键代码库和形式化证明，并捕捉隐蔽的零日漏洞和逻辑缺陷。

从今天起，我们把“Fairwind 计划”开放给数百个新的合作伙伴。

Wiz 已经将 Argon 用于“Scan for Good”倡议中，旨在免费保护公益领域的关键基础设施。通过抢先体验该模型，Wiz 展示了 Argon 在包括关键医疗基础设施在内的多个高风险领域的实际成效。通过对复杂的漏洞链的分析，该模型帮助团队发现并快速修复了医疗软件中的一处公开文件下载绕过漏洞（该漏洞曾导致医疗软件的主密钥泄露，并使攻击管理员获得权限）。Argon 不仅限于发现漏洞，更主动保护了数十万份私人患者记录。

Argon 已经在科学界产生了实际影响，助力多个领域的科学家和专家实现创新突破。

量子计算： Argon 正在帮助我们的研究人员在量子纠错和算法设计领域加速取得突破。为了让纠错解码器实时跟上量子硬件的步伐，Argon 将我们基于机器学习的量子纠错解码器 AlphaQubit 的内部版本转换为高度优化的硬件内核，使其推理吞吐量几乎翻倍，以便我们能够部署规模更大、能力更强的模型，并扩展到更大规模的量子设备，同时继续满足严格的实时阈值要求。Argon 还降低了量子子程序的时空成本。以近期量子模拟算法中的基础模块 arcsin 为例，由 Argon 编写并在 Lean 中得到形式化验证的实现方案，与已发布的量子 CORDIC 基准方案相比，时空成本降低了 100 倍以上，这是迈向优化量子电路标准库的重要一步。

核聚变： 仿星器 (Stellarators) 是极其复杂的机器，是实现无限清洁聚变能的领先候选方案，但优化其 3D 磁场一直以来都极具挑战性。自 1967 年以来，一个被称为“Grad 猜想” 的长期假设认为，为这些磁场寻找精确数学解是不可能的。直到最近，包括马里兰大学的 Matt Landreman 教授在内的研究人员发现了反例。如今，Google 团队与 Landreman 教授携手，发现了更多关于 Grad 猜想的反例。这些新解为核聚变界提供了可靠的基准，用于测试他们的仿星器模拟代码，这些代码正是未来进行设计的宝贵工具。

罕见病研究： Gamow 实验室的研究人员使用 Argon 分析了患有罕见发育性肺病婴儿的去标识化基因组。在某个案例中，Argon 精确定位了一项常规软件多年来一直漏掉的染色体重排，并解释了它未被检测到的原因。基于真实临床与实验室数据的 Gamow Labs 内部评估显示，Argon 在 RareBench（罕见病诊断辅助方面达到 57%）和 LabBench（湿实验推理方面达到 52.2%）上均位居榜首。这些进展预示着面临罕见疾病的家庭将能更快获得诊断。

酶设计： 设计具有精确反应活性的酶历来耗时漫长，通常需要数月的定制模型微调和候选筛选。丝氨酸酯酶 (Serine esterases) 是一类能切割目标分子上酯键的酶，广泛应用于回收利用以及制药、生物燃料和洗涤剂的制造。我们的科学家与 Argon 合作设计了丝氨酸酯酶，针对基准分子乙酸-4MU (4MU-acetate)进行开发，该分子在酯键被切断后会在紫外光下发出荧光。在短短数小时内，Argon 收集了相关数据，完成了模型微调，并识别出多个基于生物化学原理的筛选规则，最终得出了五个全新的设计组合。随后的实验室测试证实了这些设计均具有强大的催化活性。这种快速且便捷的酶生成设计的成功案例，展示了 Argon 在生物制造、绿色化学和药物开发等领域加速酶工程进程的巨大潜力。
