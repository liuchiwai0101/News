家門前規劃三條路線　原價 US $29.99《Three Routes》終生版限時免費

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

Three Routes: Run Walk Cycle 專為想在家附近跑步、步行或騎單車的人而設，可從家門前規劃三條環迴路線，並以 GPS 記錄訓練。此 App 原價 US $29.99，現時終生版限時免費，適合希望靈活安排路線與訓練的用家。

離線規劃三條環迴路線

可選擇步行、跑步或單車，設定距離或時間後取得三條不同路線，包括返回起點的環迴路線或原路折返。部分地區可下載免費離線地圖，在 iPhone 上直接規劃，無需伺服器或訊號；其他地區由 Apple Maps 規劃。路線會顯示爬升、高度剖面、路面與沿途停靠點，並可預覽 3D Flyover，方便出發前掌握路況。

限時免費領取終生版

Three Routes: Run Walk Cycle 終生版內購限時免費中，用户完成初始化後看到收費牆，Lifetime 價格顯示為$0 即可免費收下。注意，如果看到價格不是 $0 代表限免已完結，請勿按付費確認。
