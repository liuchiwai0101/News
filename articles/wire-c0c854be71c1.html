《Marvel’s Wolverine》PS5模擬器再突破 PC已成功進入遊戲畫面

內容機器翻譯自第三方媒體（GameApps.hk · Unwire.hk · Yahoo 新聞 · 電腦領域HKEPC Hardware 等5家），僅供參考，以原文為準。

正文

你相信在能夠電腦上直接不透過模擬器運行 PS5 遊戲嗎？GitHub 上一個「DeadCells-PS5-Native」專案把《Dead Cells: Return to Castlevania Edition》重新連結成一個獨立的 Windows 執行檔，專案頁面記下的表現是室內場景約 55 到 60 FPS、室外約 30 到 35 FPS，音樂與音效正常。而 DeadCells-PS5-Native 的技術則來自另一個專案 AnyPS5，它的 GitHub 說明只有一行：「把 PS5 執行檔轉換成能在 Linux 與 Windows 原生執行的工具。」專案 2026 年 8 月 3 日建立，作者帳號 boykopovar，GPL-2.0 授權，目前 1,674 顆星、118 個分支、21 個未結議題，而且一個正式版本都沒有發布。

AnyPS5 不做模擬，改成重新連結 傳統遊戲主機模擬器（例如 PS3 的 RPCS3）要用軟體重現主機的硬體與作業系統，每一道指令、每一筆繪圖呼叫都得透過模擬跑一遍，代價是效能。AnyPS5 跳過這一層，理由在硬體：PS5 用的是 AMD Zen 2 的 x86-64 架構，與 PC 相同，CPU 指令不需要翻譯。

實際做法拆成兩塊。專案內含一個 relinker（重新連結器），把 PS5 執行檔轉成目標系統的原生格式，Windows 是 PE、Linux 是 ELF；另一塊是 PRX 系統函式庫的替代實作，讓遊戲照原樣做動態連結就有東西可以呼叫。繪圖端交給 shader recompiler，把主機端著色器重編譯成 Vulkan 使用的 SPIR-V 中介格式。這種作法比較接近 Valve 讓 Windows 遊戲在 LINUX 系統的 Steam Deck 上跑的相容層，而不是模擬器。

第一個原生 Windows 版 PS5 遊戲 這次在 GitHub 發布 DeadCells-PS5-Native 0.1.0，附帶一個 win64 zip 與 SHA256 校驗檔。 專案說明 寫著「以我們所知，這是第一款以完整原生 Windows 程式運作的 PS5 遊戲」，並註明它是靠 AnyPS5 才做得出來，原始 x86-64 程式碼被重新連結成獨立執行檔，沒有模擬器、沒有 CPU 模擬、也沒有額外的執行期行程。

執行條件寫得很細：Windows 10 或 11 64 位元、支援 Vulkan 1.1 且具備 VK_EXT_depth_clip_control、BC 紋理壓縮與緩衝區裝置位址的顯示卡驅動，建議 16GB 記憶體，測試機是 NVIDIA RTX 5070 Ti。玩家要把自己那份解密過的 eboot.elf 與 sce_sys、sce_module、res_pak 等遊戲檔案放進同一個資料夾，執行檔才跑得起來。專案明確表示不包含遊戲、韌體、金鑰或任何 Sony 軟體。

AnyPS5 主專案尚未發布任何版本，第一個有成品展示的是外部開發者，測試範圍僅限《Dead Cells: Return to Castlevania Edition》的特定版本與地區，其他版本、修補檔或重新打包的 dump 都沒測過。

同場的其他 PS5 相容開源專案 KytyPS5 ：走的是模擬器路線，已能讓 PS5 版《GTA V》在高階 PC 上跑到 40 到 60 FPS，但仍屬實驗階段，無法維持穩定可玩的張數。 SharpEmu ：主打準確度與底層架構，曾把《Astro’s Playroom》在 Steam Deck 上開起來，張數約 0.5 到 1 FPS，過不了開頭段落。 AnyPS5 ：這次事件的主角，走重新連結路線，尚未發布版本。

Sony 的態度 AnyPS5 的免責聲明寫明，專案用於互通性、研究、保存與相容性目的，不包含也不散布受著作權保護的軟體、韌體、金鑰或專有函式庫，使用者必須自行確保使用的檔案來源合法。截至今日，Sony 未對該專案發表聲明、發出下架通知或採取法律行動。

結語 AnyPS5 目前的成績單是：沒有可下載的版本、沒跑通一款遊戲、主選單之後會崩潰。成立不到兩個月，星數爬得快，技術路線也確實與既有的 PS5 模擬器不同。而能跑起來的分支：「DeadCells-PS5-Native」是一款 2012 年的橫向動作遊戲，已在 Windows 上原生執行，能玩、有聲音、張數堪用。老實說這比較像技術展示，距離 PS5 被破解，能夠在電腦上玩所有 PS5 遊戲還非常遙遠，想玩遊戲還是買台主機會比較划算。
