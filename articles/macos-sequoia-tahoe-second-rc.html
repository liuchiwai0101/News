macOS Sequoia 與 Tahoe 推出第二個 RC　發行說明僅提安全修正

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

Apple 相隔約一星期，為 macOS Sequoia 15.8.2 及 macOS Tahoe 26.7.2 推出第二個 Release Candidate（RC），再次開放測試。兩個版本的發行説明暫時只提到慣常的「重要安全修正」，未進一步説明涉及哪些漏洞。

未經 Beta 直推第二 RC

Apple 在一星期前才推出 macOS Sequoia 15.8.2 與 macOS Tahoe 26.7.2 的首個 RC，第二個 RC 緊接其後推出，期間並沒有先發布常規 Beta 版本。除了這兩個系統的更新，Apple 同時亦為 macOS 27.2 進行測試，該版本預計在未來數週正式推出。

macOS Sequoia 15.8.2 RC 2 的發行版本編號為 24H225，macOS Tahoe 26.7.2 RC 2 則為 25G325。

發行説明僅提安全修正

目前 Apple 為 macOS Sequoia 15.8.2 及 macOS Tahoe 26.7.2 提供的發行説明，只列出一般性的「重要安全修正」，沒有交代所處理漏洞的其他資料。按照慣例，Apple 會在更新正式推出後才公佈這些修正的更多資訊，有時相關細節更要再過數天才可查閲。
