騰訊混元團隊正式發佈 Hy3 大模型正式版，採用 MoE 架構，總參數 295B、激活參數 21B，支持 256K 上下文窗口，已以 Apache 2.0 協議開源。官方表示，模型在後訓練數據質量與 RL 算力規模上顯著提升，Agent 能力、推理與長上下文表現可比肩參數規模爲其 2–5 倍的更大尺寸旗艦模型。

體驗與性能方面，在內部 270 位專家盲測中得分 2.67/4，優於 GLM5.1；工具調用穩定性、抗幻覺及多輪意圖保持等體驗指標大幅改善，幻覺率從 12.5% 降至 5.4%。目前元寶已接入 Hy3 並免費向用戶提供文件生成、數據分析與網頁製作等功能；騰訊雲 API 定價爲每百萬 tokens 輸入 1 元、輸出 4 元，同時在 OpenRouter、Nous Portal 和 CodeBuddy 等平臺提供兩週限時免費體驗。

美團 LongCat 團隊宣佈 LongCat-2.0 模型以 MIT 許可證全面開源，公開模型權重與推理代碼。該模型採用 1.6T 參數的混合專家（MoE）架構，每次推理激活約 480 億參數，支持最長 100 萬 token 上下文。

模型定位爲 Agent 原生模型，可直接集成 Claude Code、OpenClaw 和 Hermes Agent 等智能體框架。部署層面，官方提供 GPU 和 NPU 平臺的推理支持，並已在國內大規模集羣上完成部署驗證。

SpaceXAI 與 Cursor 聯合訓練並正式發佈 Grok 4.5 模型，採用 MoE 架構，定位爲面向軟件工程、數據科學、金融法律等知識工作的通用智能體模型。模型具備 500k 上下文窗口、80 TPS 推理速度，官方稱其 token 效率兩倍於同類領先模型；Elon Musk 表示其內部評估水平大致與 Claude Opus 4.7 相當且速度更快，預計上下文窗口後續將升級至 1M。

訓練方面，模型納入了萬億級 token 的 Cursor 交互數據，覆蓋代碼庫與軟件工具的用戶交互，並通過真實環境下的強化學習提升工具調用、錯誤修復與結果驗證能力。定價方面，基礎版爲每百萬輸入 token 2 美元、輸出 6 美元，高速版爲每百萬輸入 token 4 美元、輸出 18 美元。目前該模型已在 Grok Build、Cursor 全平臺及 SpaceXAI 控制檯上線，Cursor 訂閱用戶首周可享受雙倍使用額度。官方同時說明，該模型在 CursorBench 上的分數因訓練數據意外包含 Cursor 代碼庫快照已被排除。

Cognition 實驗室發佈 SWE-1.7 模型，爲其目前訓練的最強代碼智能體模型，基於 Kimi K2.7 基座通過大規模強化學習訓練完成。官方稱其在保持前沿性能的同時顯著優化了成本曲線，挑戰了 “後訓練天花板” 的行業認知。

性能表現上，該模型在 FrontierCode 1.1 Main 基準得分爲 42.3%，接近 GPT-5.5 與 Claude Opus 4.8 等頂級閉源模型；在 Terminal-Bench 2.1 得分爲 81.5%，SWE-Bench Multilingual 得分爲 77.8%，均處於行業第一梯隊。技術層面，模型通過 top-p 採樣重放穩定訓練熵值、跨洲多集羣分佈式訓練、高質量數據清洗流水線、自壓縮長上下文四項核心技術實現能力突破，具備更凝練的思維鏈與更全面的代碼庫探查習慣。

目前 SWE-1.7 已在 Devin 全平臺（Web、Desktop、CLI）上線，由 Cerebras 提供 1000 TPS 的高速推理版本。

里約熱內盧市信息技術機構 IplanRIO 發佈的 Rio-3.5-Open-397B 模型，被 Nex-AGI 團隊證實未經過獨立訓練，本質是開源模型 Nex N2 Pro 與 Qwen3.5-397B-A17B 按約 0.6:0.4 比例的逐元素線性權重融合。

驗證證據包含兩方面：一是移除模型硬編碼的 “You are Rio” 系統提示詞後，在 120 次身份提問中模型有 79.2% 自稱爲 “Nex”，0% 自稱爲 “Rio”，甚至能完整複述 Nex-AGI 的機構背景表述；二是張量級數學驗證顯示，模型全層權重與 “Nex+Qwen” 線性融合的餘弦相似度達 0.986–0.993，在高維參數空間中可排除偶然重合的可能。

事件後續，IplanRIO 更新了 HuggingFace 模型說明，稱原計劃發佈經過策略蒸餾的最終版本，因操作失誤上傳了未蒸餾的基礎融合權重，並就混淆致歉。社區同時圍繞公共資金使用產生爭議，相關人士澄清項目未動用公共訓練經費，官方公開表述存在溝通偏差。

字節跳動 Seed 團隊正式發佈多模態圖像創作模型 Seedream 5.0 Pro，在圖文匹配、結構合理性、文字渲染與畫面美感等基礎能力上全面升級，核心突破集中在四個方向：

- **複雜信息可視化**：可將數據、概念與密集文本轉化爲專業排版的信息圖，支持時間軸、圖表、實景等多元素融合，滿足教育、科普、商業海報等高信息密度生產場景；

- **交互式精準編輯**：基於空間位置感知能力，支持點選圈選局部修改、草圖渲染、色彩與材質替換、圖層智能分離、多圖融合等可控編輯操作；

- **真實影像與人像質感**：強化物理光影、材質肌理與皮膚細節還原，支持搖拍等進階攝影效果，兼顧寫實人像與 3A 級遊戲角色創作；

- **原生多語種支持**：支持十餘種常用語言直接輸入與文字渲染，自動適配不同語種的排版規則與文化視覺特徵。

目前模型已上線火山方舟體驗中心，將陸續登陸豆包、即夢平臺。官方表示模型在細粒度文字渲染、像素級編輯一致性上仍有優化空間。

SeFi-Image 團隊正式開源 SeFi-Image 系列文本到圖像基礎模型，核心採用 “語義優先擴散” 架構，將語義結構與紋理細節的生成流分離，使語義潛變量先於紋理完成降噪，爲紋理生成階段提供清晰的結構錨點。

模型系列覆蓋 1B、2B、5B 三種參數規模，每個規模均提供 Base 基礎版、RL 強化對齊版、Turbo 少步蒸餾加速版三類變體；其中 5B 版本僅使用約 125K A800 GPU 小時的訓練資源，在 GenEval、LongTextBench、DPG-Bench 等多項基準測試中取得具備競爭力的表現。官方同步發佈了命令行與 Python API 形式的推理代碼，模型權重與代碼已在 GitHub 與 Hugging Face 開放。

Meta Superintelligence Labs 發佈旗下首個圖像生成模型 Muse Image，同時推出視頻生成模型 Muse Video 預覽版。

Muse Image 採用 Agentic 設計範式，推理過程中可自主調用搜索與代碼工具並進行自我修正，支持精確局部編輯、多參考圖像合成，還能借助 Instagram 公開內容理解社交語境。根據 Arena 排行榜數據，該模型在文本到圖像、單圖像編輯、多圖像編輯三項任務中均位列第二。

落地方面，Muse Image 已在 Meta AI 應用、網頁版、美國地區 Instagram Stories 及部分國家 WhatsApp 上線，後續將拓展至 Facebook；Muse Video 仍處於預覽階段，計劃後續面向創作者與 Meta AI 用戶開放。

SenseNova 團隊正式發佈 SenseNova-Vision 系列，包含 7B-MoT 模型權重、SenseNova-Vision-Corpus-50M 數據集、推理代碼與技術報告。

該模型提出統一多模態生成範式，將異構計算機視覺任務全部轉化爲統一多模態模型的原生文本、圖像或圖文混合生成，無需爲不同任務設計專屬預測頭或架構分支，可同時覆蓋目標檢測、OCR、關鍵點檢測等結構化理解，深度估計、法向量預測等稠密幾何任務，語義 / 引用 / 推理分割，以及多視圖三維重建四大類視覺任務。

性能方面，模型在 COCO 目標檢測、NYUv2 深度估計、RefCOCO 引用分割等主流基準上達到或接近業界最優水平。模型權重基於 CC BY-NC 4.0 許可發佈，僅限非商業用途。官方同時提示，模型並非單項任務最優方案，輸出結果依賴特定解析規則，對提示詞較爲敏感，稠密幾何預測精度需獨立校驗。

螞蟻靈波科技（Robbyant）正式發佈 LingBot-Vision 自監督視覺基礎模型系列，同步推出 LingBot-Depth 2.0 深度補全模型。

LingBot-Vision 採用掩碼邊界建模方法，無需人工標註即可在線學習亞像素邊界，引導密集視覺令牌學習；以 ViT-g/16 爲教師模型，蒸餾出 L、B、S 三個尺寸的學生模型，在 NYUv2 深度估計任務上達到 0.296 RMSE，效果優於 7B 參數的 DINOv3，小尺寸模型同樣保持性能優勢。

LingBot-Depth 2.0 將深度補全建模爲掩碼深度任務，改用 LingBot-Vision 作爲編碼器初始化，在透明、反射表面場景下可重建穩定連續表面，塊掩碼 DIODE-Indoor 數據集上的 RMSE 較前代減半。

所有模型權重已通過 HuggingFace 開源，代碼在 GitHub 以 Apache 2.0 許可發佈，提供 pip 安裝、Python 接口及 PCA 可視化演示。

螞蟻靈波科技發佈並開源首個專爲具身智能設計的 MoE 視頻基礎模型 LingBot-Video，採用單流 DiT 加稀疏 MoE 架構，總參數 30B，推理時僅激活 3B 參數，在 1M token 序列下推理速度約爲同規模稠密模型的 3.18 倍，可滿足機器人實時仿真需求。

訓練方面，模型在大規模互聯網視頻預訓練基礎上，疊加了超過 7 萬小時的具身定向數據，並通過獎勵對齊後訓練優化物理合理性、任務完成度與視覺質感。官方數據顯示，其在 RBench 視頻生成基準上以 0.620 分排名第一，超越 Wan2.6、Seedance 1.5 Pro 等主流模型。

項目基於 Apache 2.0 協議開源，提供 Dense-1.3B、MoE-30B-A3B 及基於 Qwen3.6-27B 的重寫器在內的完整權重與代碼。

螞蟻靈波科技發佈 LingBot-World 2.0 交互式世界模型，主打無限時長的實時可交互開放世界生成。

技術層面，模型通過因果預訓練與少步蒸餾實現小時級無視覺漂移的長時間生成，支持 720p / 60fps 實時流式輸出與亞秒級控制延遲。交互方面引入 Agentic Harness 機制，包含 Pilot Agent（玩家視角）與 Director Agent（導演視角），支持用戶自由探索、近戰 / 遠程攻擊、事件觸發、多人協同操控等多樣化交互模式，可生成自然地貌、人文景觀、戰鬥場景等多元內容。

目前 14B 參數的 causal-fast 版本權重與推理代碼已開放，採用 CC BY-NC-SA 4.0 許可，僅限非商業使用；用戶可通過 Reactor 或 LingGuang 移動端體驗實時版本。官方說明當前公開版本缺失部分功能，完整演示將在 WAIC 2026 上海展會提供，同時模型在長期世界記憶、真實物理理解上仍存在侷限。

Mistral AI 發佈其首款具身導航模型 Robostral Navigate，參數量爲 8B。

模型核心特點是僅需自然語言指令與單顆 RGB 攝像頭輸入，無需深度傳感器或 LiDAR，即可驅動機器人在複雜未知環境中自主導航。其支持輪式、足式及飛行機器人，可跨機器人尺寸與攝像頭內參實現泛化。在 R2R-CE 未見環境基準測試中，模型導航成功率達到 76.6%。目前官方僅提供企業合作聯繫渠道，未開放開源或公開 API。

阿里正式升級實時語音識別大模型 Fun-ASR-Realtime，核心升級點在於首字延遲控制在百毫秒級別，識別準確率接近同系列離線模型，並具備基於上下文的自我糾錯能力。

能力覆蓋上，模型支持 16 種方言與 30 種語言，方言識別字符準確率平均 88.62%，在 12 類方言上領先競品；工業中文與英文場景準確率分別達 88.42% 與 91.58%，泰語等東南亞語言也完成專項優化。其離線版本 Fun-ASR-Flash 在 Artificial Analysis 平臺上以 1.7% 字錯率位居全球第一。

落地方面，該模型已支撐影視颶風 “重返荒島” 100 小時直播，實時生成 132 萬字字幕；目前已在阿里雲百鍊平臺開放體驗。

OpenAI 發佈新一代全雙工語音交互模型系列 GPT-Live，包含 GPT-Live-1 與 GPT-Live-1 mini 兩個版本。

該系列採用全雙工架構，可實現邊聽邊說的自然對話體驗，支持將複雜推理、搜索及 Agent 任務異步委託給 GPT-5.5 處理，保證交互流暢性。目前模型正逐步向 ChatGPT 全球用戶推送，付費用戶默認使用 GPT-Live-1，免費用戶默認使用 GPT-Live-1 mini；開發者與企業可註冊獲取 API 上線通知。

MOSI 官方宣佈開源 MOSS-Transcribe-Diarize 0.9B 端到端音頻理解模型，性能更強的 Pro 版本暫未開源，計劃後續通過 API 提供服務。

模型採用 Whisper-Medium 編碼器 + Qwen3-0.6B 風格解碼器的端到端架構，替代傳統 ASR + 說話人分離的級聯方案，可一次性輸出帶時間戳與說話人標籤的結構化轉錄文本。其支持 128k 長上下文，可處理最長約 90 分鐘的音頻輸入，支持多語言轉錄與熱詞提示。

基準測試中，模型在 AISHELL-4、Alimeeting、Podcast、Movies 等多個多說話人數據集上的字錯率與說話人匹配效果顯著優於主流方案。部署方面，模型支持 vLLM、SGLang Omni 服務化部署，單張 H100 下可實現近百倍實時因子的處理速度；官方同時提供字幕生成 Web 工具，支持 SRT/ASS 導出與視頻燒錄。
