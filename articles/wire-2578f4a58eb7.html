擺脱 Copilot 捷徑的限制　Windows 11 將可把 Copilot 鍵換成其他功能

內容機器翻譯自第三方媒體（Yahoo 新聞），僅供參考，以原文為準。

重點內容

若我們使用近年推出的各品牌 Windows 11 筆電，有機會在鍵盤的右下角找到 Copilot 鍵，專門用來打開 Windows 內的 Copilot。不過問題是，我們未必多用 Copilot，令 Copilot 只變成浪費空間的按鈕。好消息是，微軟已準備提供新設定選項，讓我們可把 Copilot 鍵換成其他功能，令這按鍵變得更實用……

媒體 Windows Latest 指出，微軟於本月的預覽版 Windows 11，終於可以自訂鍵盤上 Copilot 鍵的對應功能。用家於 Windows 的系統設定，可在鍵盤設定中找到自訂功能的選項，把 Copilot 鍵不再定為開啟 Windows 內 Copilot 的捷徑，改為右 Ctrl 鍵或右鍵選單鍵，令鍵盤佈置大致還原成沒有 Copilot 鍵的時代，只是要衡量多出一個 Ctrl 鍵還是重新再有右鍵選單鍵是好。

由於上述的選項已進入預覽版 Windows 11，只要最後測試順利，可望隨 Windows 11 的十月份 Patch Tuesday 更新一併推出，推送予所有 Windows 11 用家，特別有利於鍵盤上設有 Copilot 鍵的 Copilot+ PC 筆電用家。

自前年開始，市面上有售的全新筆電開始於鍵盤上設有 Copilot 鍵，原意是配合微軟的策略，方便用家打開 Windows 內的 Copilot，提高 Copilot 的使用率。不過問題是，鍵盤上多出 Copilot 鍵，卻因鍵盤空間有限，取代了傳統的右 Ctrl 鍵或右鍵選單鍵，反而令不少 Windows 用家因根本不多用 Copilot，最終反而降低工作效率，弄巧反拙。因此微軟到了今年 6 月，終於正式承認 Copilot 鍵可能影響生產力及工作流程，並承諾提供 Right Ctrl 與右鍵選單鍵選項，所以上述變更可算是兑現承諾。

不過要留意的是，上述新設定有一個特殊限制，就是將 Copilot 鍵改為右 Ctrl 鍵後，右 Ctrl+Win 及右 Ctrl+Shift 的組合鍵將無法正常運作，微軟建議改由左 Ctrl 鍵代替。另外，實際效果會因鍵盤佈局、廠商、韌體及硬件設計而有差異，若裝置本身已附設由品牌提供的自訂鍵盤按鍵映射工具，微軟建議用家只使用該工具，或經 Windows 系統設定進行設定已可，不應雙管齊下來設定。

如果大家使用中的 Windows 電腦，鍵盤上正是有 Copilot 鍵，不妨多加留意這一兩個月的 Windows 更新，按需要進行設定。
