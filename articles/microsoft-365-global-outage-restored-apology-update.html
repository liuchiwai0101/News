全球大死機逾一日終修復　Microsoft 發道歉公告：非黑客或 AI 事故

內容機器翻譯自第三方媒體（PCM），僅供參考，以原文為準。

Microsoft 旗下雲端及辦公軟件服務 Microsoft 365 日前發生近年最嚴重的全球大死機，導致數以百萬計企業及個人用户無法正常收發電郵及使用協作工具，波及超過 70 個國家及地區。經過超過一日的緊急搶修後，Microsoft 於今日（11 月 14 日）早上正式發表更新公告，確認所有受影響地區及客户的服務已全面恢復正常，並就事件向全球用户致歉。

Microsoft 365 大死機一日之後，Microsoft 在 X 平台道歉發交代事情。


今次大規模故障始於英國時間星期四（11 月 12 日）傍晚約 6 時，監測網站 Downdetector 在短短一小時內便接獲來自 74 個國家及地區的異常報告，單在美國高峯期便有超過 13 萬名用户回報 Outlook 無法運作。除了 Outlook 電郵服務癱瘓外，包括 Microsoft Teams、AI 助手 Copilot 以至部分依賴相關雲端基建的 AI 聊天平台（如 ChatGPT 及 Claude）亦一度受牽連。

死機期間，全球多個公共機構、醫院、警隊、法院、銀行及商業機構運作大受阻礙。以英國為例，英格蘭及威爾斯警方一度無法接收網上報案；國民保健署（NHS）前線醫護被迫改用紙筆紀錄應急；當地鐵路局亦因乘客無法開啟 Outlook 內的電子車票，需緊急呼籲旅客改用購票網站或 App 登入帳户取票。

事件與網絡攻擊或人工智能無關

Microsoft 在最新的服務狀態頁面（編號 MO1550821）公告中表示，團隊已解決事故的根本原因，並逐步完成對餘下受影響地區的服務恢復及穩定性驗證。官方就今次故障為客户及合作夥伴帶來的不便深表歉意，同時強調今次純屬「技術問題」，與網絡攻擊（黑客入侵）或人工智能（AI / Agents）無關。

針對事故成因，Microsoft 解釋是由於早前進行網絡容量升級期間出現潛在問題，並在近日執行另一項網絡變更時被觸發，導致系統出現持續的流量管理失衡。考慮到全球用户重新連線的需求龐大，工程團隊採取分階段恢復策略以確保系統穩定，因此令整體修復時間較長。Microsoft 承諾在完成全面內部檢討後，將會向公眾發布完整的事故調查報告。

商業用户可主動申請賠償

除了關注服務恢復外，不少受影響的企業亦關心能否獲得賠償。據商業版 Microsoft 365 的企業用户受「服務水平協議」（SLA），若服務正常運作時間未能達到承諾標準（例如 Exchange Online 單月正常運作時間低於 99.9%、99% 或 95%，分別可獲受影響服務費用的 25%、50% 或 100% 服務抵免額），受影響機構可向 Microsoft 申請賬單減免。

商業 Microsoft 365 訂户，可以在 Admin center 中的「Help & support」中，在 Support Assistant 中輸入 ： Request an SLA service credit for a Microsoft 365 outage. 提出索償。

不過，該賠償機制並非自動發放，亦不適用於個人版及家庭版（Personal / Family）或免費 Outlook.com 帳户。受影響的企業 IT 管理員需在該賬單月份結束後的一個月內，主動登入 Microsoft 365 系統管理中心（Admin Center），透過「説明及支援」提交支援要求，並附上受影響時間、人數及相關事故編號（如 MO1550821 或 Exchange 專屬編號 EX1550543）作審核；若是經由雲端解決方案供應商（CSP）或經銷商購買服務，則須聯絡相關供應商代為申請。
