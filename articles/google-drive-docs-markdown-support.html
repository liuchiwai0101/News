Google Drive 與 Docs 原生支援 Markdown　AI 代理可共同編輯

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

Google 宣佈，Google Drive 與 Google Docs 現已加入對 Markdown（.md）檔案的原生支援，用户可直接開啟、編輯及協作，毋須更改檔案格式。Google 表示，這項改動與 Markdown 在 AI 時代日益普及有關；過去數年 Google 一直為 Drive 建立 Markdown 支援，但早前做法主要是把 Markdown 轉換成 Docs 可用的格式。

Docs 原生編輯與即時協作

在新支援下，Google Drive 及其應用程式套件可在 Docs 等應用中開啟、編輯及完整使用 Markdown 檔案，包括即時編輯與留言，並完整渲染 Markdown 文件的格式。

Google 解釋，用户現在可在 Docs 原生處理 Markdown 檔案，開啟、編輯及協作時都毋須更改檔案類型；在 Docs 編輯 Markdown 亦讓用户與代理能夠協作，不必強迫任何人撰寫原始語法、手動轉換檔案，或放棄 Docs 的即時編輯與留言工具。

Google 亦指出，這對 AI 應用情境有幫助，例如讓 AI 代理在文件上協作，甚至與 Gemini Notebook 同步。Google 的 Chandu Thota 稱，Markdown「已成為人類與 AI 代理之間的共同語言」。

Drive 直接檢視渲染效果

Drive 現時亦支援渲染 Markdown，用户可直接在 Drive 內檢視完整排版的文件，連結可以點擊，表格亦有結構。

預設啟用並分批推送

Google Drive 與 Docs 的 Markdown 支援由即日起陸續推送，但所有用户最多或需 15 日才會見到。此功能預設啟用，即使是由管理員控制的帳户也不例外。
