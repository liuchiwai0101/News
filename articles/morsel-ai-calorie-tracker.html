拍照兩秒估算卡路里　原價 US $6.99《Morsel》限時免費

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

Morsel 是一款以照片估算卡路里與營養素的飲食記錄 App，適合想快速記錄飲食、又不想逐項手動輸入的人。它可從餐點照片估算熱量和營養素，原價 US $6.99，現正限時免費。

照片估算卡路里

Morsel 以餐點照片估算熱量與營養素，拍攝後可放下手機，估算會在背景完成，即使關閉 App 或失去訊號亦不影響記錄。用家可連接 OpenRouter，或貼上 OpenRouter、OpenAI、Anthropic 的 API 金鑰，按次向供應商付費，通常每張照片低於一美分；沒有供應商時，餐點會先儲存並等候連接。所有照片與記錄留在 iPhone，亦可選擇以 iCloud 同步及匯出 CSV。

取得免費 API 方式，用户要 App 內選定 Openrouter，然後設定為 Free Model，這樣就能免費使用 AI 偵測卡路里！
