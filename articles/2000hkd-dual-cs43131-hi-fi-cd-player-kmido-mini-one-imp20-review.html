兩千元價位雙 CS43131 Hi-Fi CD 機　KMIDO Mini One (iMP20) 評測

內容機器翻譯自第三方媒體（PCM），僅供參考，以原文為準。

好多人可能同筆者一樣，平時已經習慣用手機串流聽歌，貪其方便快捷；但有時回到家中，總想找回那種「放一張 CD，坐下來聽完」的儀式感。今次送測的 KMIDO Mini One (iMP20) 桌面 Hi-Fi 級 CD 播放器，正好瞄準了這批想重温實體碟温度的用家。KMIDO 承襲了韓國資深音訊技術團隊所創的新品牌，定價 HK$2,680 的新機，到底能否在數位時代重現 90 年代旗艦 CD 機的「潤澤之聲」？

KMIDO Mini One (iMP20) 桌面 Hi-Fi CD 播放器，體積僅 160×160×44.5mm，方形設計小巧卻具備旗艦級音訊規格。

車規級光頭穩定讀碟

對於一部 CD 機而言，讀碟能力與精準度絕對是核心。KMIDO Mini One 沒有採用市面普通的平價機芯，而是用上了 JVC 車規級別光頭，並配搭了物理避震結構。設計令抗震性能大幅提升，當遇到桌面的輕微碰撞，依然能保持流暢播放，避免出現跳線或中斷的情況。配合其內建的三星高階桌上型 CD 機同款伺服電路，廠方強調這能確保循跡與聚焦的精準度，將 CD 數據無損直送解碼。

雙 CS43131 解碼

作為主打 Hi-Fi 級數的播放器，廠方在音訊處理上亦下了重本，機內搭載了兩顆 Cirrus Logic 專業級解碼晶片 CS43131，每顆都內建了高保真耳放。在實際試聽過程中，最明顯的感受是它的調音並非追求現代數碼器材那種極致冰冷的高解析力，而是偏向温暖、飽滿的中頻。聽人聲舊歌時，高頻順滑而不刺耳，的確營造出一種 90 年代經典 CD 機的獨特氛圍。這亦歸功於它配備了兩顆線性獨立穩壓 LDO 供電，令輸出部分的推力十分充沛，推動一般耳機遊刃有餘。

超齊全介面

小巧機身卻配備極齊全的背面介面，包括 4.4mm 平衡輸出、XLR、RCA、同軸及光纖輸出，一機滿足各類音訊系統需要。

以一部體積只有 160×160×44.5mm 的桌面機來説，Mini One 的背面介面豐富得令人驚喜。除了標準的 3.5mm 耳機及 RCA 線性輸出，它更提供了發燒友愛用的 4.4mm 平衡輸出及 XLR 介面，甚至備有同軸與光纖輸出，方便用家接駁更高階的解碼擴大機或主動式音箱。另外，它內置了高通 QCC3095 藍牙 5.4 晶片，目前支援藍牙發射（TX），據悉未來更可透過軟件升級作接收（RX）使用，屆時便可連接手機串流播放，大大提升了日常使用的靈活性。

高性價比之選

首批購買者更獲贈限量試音 CD，方便即時體驗。

KMIDO Mini One (iMP20) 在造工、讀碟穩定性以及聲音調校上，都有著超乎其身價的表現。HK$2,680 的定價，無疑是一個相當容易入門的選擇。如果你正想在書房或辦公桌上添置一部具質素的實體 CD 機，重拾聽歌的純粹感動，這款產品絕對值得列入你的考慮名單。
