GPT‑6.1 Sol、Dots 長駐 Agent　OpenAI DevDay 2026 逾 20 項新品全面睇

內容機器翻譯自第三方媒體（PCM），僅供參考，以原文為準。

OpenAI 舉行 DevDay 2026 開發者大會，一口氣公佈超過 20 項新產品及功能，涵蓋新模型、Codex、API、ChatGPT、Plugins 及企業服務。當中除了推出價格更具競爭力的 GPT‑6.1 Sol，更正式發表可以長時間持續工作的 Dots。綜觀這一系列發表，OpenAI 的發展重心已明顯由「回答問題的 AI」，進一步轉向能夠持續執行任務、操作電腦及連接企業軟件的 Agent 工作平台。

GPT‑6.1 Sol：接近 Astra 智能　Token 價格只需五分之一

模型方面，今次 DevDay 的主角是 GPT‑6.1 Sol。這是 GPT‑6 Sol 的重大升級，OpenAI 特別強調 Agentic Coding、Computer Use 及專業工作能力，並表示其智能已接近旗艦 GPT‑6 Astra，但標準 API Input 及 Output Token 價格只有 Astra 五分之一。

GPT‑6.1 Sol 的 API 標準收費為每 100 萬 Input Token US$2、Cached Input US$0.1、Output Token US$10。Cached Input 比普通 Input 便宜 95%，亦比 GPT‑6 Sol 的 Cached Input 再便宜一半。

GPT-6.1 Sol 具備早前宣佈中止發表的GPT-6.1 Astra 的同級智能，不過成本就低得多。

這種定價對長時間運作的 Agent 尤其重要，因為 Agent 經常需要重複載入程式碼、文件、工具定義及其他 Context，Prompt Cache 成本降低可直接減少持續工作的開支。

GPT‑6.1 Sol 已向所有 API、Plus、Pro、Business、Enterprise 及 Edu 用户提供。

Ultrafast：Codex 最高每秒 300 Token

新的速度等級 Ultrafast 提供最高達 8 倍的 Token 生成速度，但價錢也貴了 6 倍。針對講求速度的工作。

模型變聰明之外，OpenAI 今次亦嘗試解決 Agent 工作時另一個實際問題——速度。新的 Ultrafast 是針對低延遲工作負載而設的尊享速度等級。在 Codex 中，Token 生成速度最高提升 8 倍、達每秒 300 Token；API 則最高提升 6 倍。

GPT‑6 Astra Ultrafast 已經在 API，以及 Pro 500 和 Enterprise 的 ChatGPT Work、Codex 提供；GPT‑6.1 Sol Ultrafast 則即將推出。

對 Coding Agent 或需要連續呼叫大量工具的工作而言，這種改進並非單純令答案「出字快一點」。Agent 一項工作可能需要經歷數十甚至數百個模型推理、工具操作及檢查步驟，降低每一步的等待時間，會直接影響整項工作的完成速度。

Dots：AI 不再等你發問

Dots 是 Always-on Agent，能長時間處理一項工作任務。

如果 GPT‑6.1 Sol 是今次最重要的新模型，Dots 則可能是最能代表 OpenAI 未來方向的新產品。Dots 是 Always-on Agent，重點並非回答一次問題，而是長時間負責一項工作。OpenAI 形容它會逐漸瞭解用户重視甚麼，並持續代表用户工作。例如 Dot 可以長期監察客户意見、發現 Bug 後自行調查並準備修正、研究人員取得新數據後重新執行分析，甚至在項目情況改變後自行更新工作內容。

Dots 已向合資格市場的 Pro 及 Business Premium 用户提供；Enterprise、Edu 及 Healthcare 則可由 Workspace 管理員啟用 Beta，而且預設為關閉。

這種模式與傳統 ChatGPT 最大分別，是工作不再必須由一次 Prompt 開始、一次 Response 結束。AI 開始可以承擔「持續責任」。

Codex 由 Coding Assistant 走向完整開發平台

Codex 亦獲得一系列更新。Codex Cloud 現在加入可重用 Development Environment，團隊可以建立共用、已批准設定及權限的開發環境。Codex CLI 則加入語音控制，以及新的 /agents View，方便開發者分派及追蹤多個 Agent Task。

OpenAI 將全套 Codex 搬雲端，讓長時間的 Agent 任務即使用户關機後仍可繼續。

ChatGPT Desktop App 新增 Code Review 體驗，可以閲讀修改摘要、查看 Diff 及詢問 Codex 潛在問題，再把意見交回 GitHub Pull Request 或 GitLab Merge Request。Automatic Review 更可以讓 Codex 在 Cloud 先進行第一輪審查。

安全方面則新增 Codex Security Cloud，可以按需要或排程掃描整個 GitHub Repository，並持續檢查新的 Commit。Codex 會調查 Finding、排除重複結果，甚至在 Cloud 準備修正方案。

Codex Security Cloud 可以按需要或排程掃描整個 GitHub Repository，並持續檢查新的 Commit，查找程式漏洞。

Agents API 正式加入 Computer Use

OpenAI 同時把更多 Agent 技術交到開發者手上。新版 Agents API 支援 Computer Use，開發者可以建立直接與軟件互動並完成工作的 Agent，同時取得 Codex 的 Multi-agent、Tool Search、Tool Calling 及 Context Compaction 能力，底層 Infrastructure 則交由 OpenAI 管理。

OpenAI 亦與 Amazon 合作推出 Bedrock Managed Agents powered by OpenAI，把 Agents API 的核心能力帶到 AWS，讓企業建立完全在 AWS 運行、並整合 AWS 資源的 OpenAI Agent。

另一項新服務 Decisions API 則針對具有有限預設答案的即時決策工作，利用 Luna 的智能處理內容分類、Request Routing，或者選擇 Agent 下一步行動。服務現時處於 Limited Preview，OpenAI 表示將在未來數日廣泛推出。

Plugins 升級　外部事件亦可主動觸發 ChatGPT

ChatGPT Plugin 平台亦有大幅改動。新的 Plugin Extensions 開放 OpenAI 用來建立 ChatGPT 功能的平台技術。開發者可以讓 Plugin 在 Sidebar 擁有自己的入口、建立 Interactive Panel，甚至為產品支援的檔案格式製作 Viewer。

Plugin Extensions 開放 OpenAI 用來建立 ChatGPT 功能的平台技術。

Plugin Creator、新的提交流程，以及改善後的排行榜和推薦 Plugin，則降低建立及發布 Plugin 的門檻。更重要的是 Plugin Automation 將支援 proposed MCP Events specification。連接的 App 發生事件時，可以主動觸發 Automation。例如 Project Board 出現新工作後，ChatGPT 可以自行讀取相關文件並準備工作，而不需要等待用户再輸入 Prompt。

Space、Pages、Slides　ChatGPT 變成協作 Workspace

ChatGPT 本身亦開始由聊天介面進化成工作空間。新的 ChatGPT Space 讓團隊成員、ChatGPT 和 Dot 在同一空間使用共享知識；Pages 則是一種專門為人類與 Agent 協作而設的文件，可以寫作、研究、建立圖表、生成圖片及製作資料視覺化。

即將推出的 Collaborative Slides 更讓多名團隊成員及 Agent 同時修改簡報及留言，完成後可以直接在 ChatGPT Present，或者輸出至 PowerPoint 和 Google Slides並保留格式。

Business 及 Enterprise 用户亦可以建立 Team，共享 Pages、Slides、Plugins 及 Spreadsheet，並把每週 Project Update 等重複工作交給 Team Task。Task 除了按時間執行，亦可以由新 Email 或 Slack Message 等事件觸發。

此外，Business 及 Enterprise 用户可以直接在 Slack 或 Microsoft Teams 使用 @ChatGPT，讓 ChatGPT 在團隊對話內使用獲授權的工具處理工作。

Meetings、Sign in with ChatGPT 及 Pro 500

今次公佈亦包括多項針對日常工作的功能。

新的 Meetings Plugin 可以替用户記錄會議，並把個人化摘要及 Action Items 儲存在 ChatGPT Space。錄音會在筆記完成後刪除，而且不能重新存取或播放。功能首先以 Beta 形式在 macOS ChatGPT Desktop App 向 Pro 及 Business 用户提供。

Sign in with ChatGPT 則讓用户把 ChatGPT 身份帶到其他服務。Plus 及 Pro 用户更可以在 16 個參與服務使用部分 ChatGPT Plan Allowance。

對重度用户，OpenAI 同時推出 Pro 500。新計劃提供 ChatGPT Plus 25 倍的最高 Usage Allowance，並包括 Ultrafast。

企業市場則新增 OpenAI Marketplace。合資格 Enterprise 客户可以把部分既有 OpenAI Commitment 用於獲批准的合作夥伴軟件；首批共有 32 個合作夥伴，涵蓋創意、客户體驗、法律及網絡安全等範疇。

OpenAI 下一步不是單純賣模型

把今次超過 20 項公佈放在一起，OpenAI 的方向其實相當清楚。

GPT‑6.1 Sol 解決的是人工智能所花的成本問題；Ultrafast 解決時延；Agents API 提供 Agent 執行層；Computer Use 讓 AI 操作傳統軟件；Plugins 與 MCP Events 接通外部服務；Dots 則把這些技術組合成可以持續工作的 Agent。最後再透過 Space、Pages、Slides、Codex 及 Marketplace 建立工作環境和軟件生態。

因此 DevDay 2026 真正值得留意的，未必只是新模型的 Benchmark 又提高多少，而是 OpenAI 正由模型供應商進一步走向完整的 AI 工作平台。

過去 AI 的基本操作是「人提出問題，AI 回答」；現在 OpenAI 描繪的下一階段，則是把工作交給 Agent，讓它在背景持續監察、判斷、操作工具和完成任務，人類主要負責設定目標、權限及最後決策。這可能才是 DevDay 2026 最重要的訊息。
