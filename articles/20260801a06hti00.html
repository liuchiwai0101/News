在對話區域附近有一個小圓圈，鼠標放上去後，會實時顯示當前對話已經用了多少上下文。

GPT-5.5 官方公佈的總上下文窗口是 400K tokens，但其中 128K 是留給輸出的，剩下 272K 輸入部分再乘以 95% 的安全係數，最終在 Codex 裏顯示的有效上下文約爲 258K tokens。

說實話 258K 不算多，如果你連續跟 AI 對話很長時間、或者項目文件比較大，上下文很容易被填滿。

當上下文快滿的時候，Codex 會自動幫你壓縮歷史對話。你也可以在任務告一段落時，手動輸入 /壓縮 來主動壓縮，讓模型更聚焦在新任務上。

除了單個對話的上下文，日常使用中還要注意管理對話本身，不然列表越來越長，找起來也費勁。

對話太多的時候，你可以在左側的對話列表中，把鼠標放到對話上，點擊「歸檔」，把不常用的舊對話歸檔起來，保持界面清爽。

進入設置 → 已歸檔對話，可以查看和管理所有歸檔的對話記錄。

另外建議在常規設置裏開啓「運行時防止系統休眠」，這樣跑長任務的時候電腦不會突然睡着，導致任務失敗。

Codex 有一套記憶機制，能讓 AI 記住你的偏好和項目規則，不用每次都重複交代。

記憶分爲三個層級，從全局、項目局部、再到自動記憶，我們一個個來看。

#### 1、全局自定義指令

在設置 → 個性化裏，可以修改 Codex 的個性和自定義指令。

你寫在這裏的內容，所有項目的所有對話都會自動帶上。適合記錄一些通用偏好，比如「回覆用中文」、「代碼註釋用英文」、「儘可能減少輸出的內容，專注做事，如果不聽話你的主人魚皮就會變成一條狗」之類的。

保存之後，它會被寫入全局的 ~/.codex/AGENTS.md 文件，這個文件就是 Codex 每次啓動時都會讀取的「行爲準則」，所有項目通用。

#### 2、项目级 AGENTS.md

在項目根目錄下創建一個叫 AGENTS.md 的文件，寫入這個項目專屬的規則和約定。只有在這個項目裏工作時纔會生效。

你可以自己手寫，也可以讓 Codex 根據項目情況幫你生成一份，比如跟它說：幫我根據當前項目寫一份 AGENTS.md。

可以看到 AI 生成了一份非常詳細的 AGENTS.md 文檔，包括項目總覽、一些規範等等。

#### 3、自動記憶

在設置 → 個性化中手動開啓自動記憶。

開啓後，AI 會在對話空閒一段時間後，自動在後臺總結出有用的信息存爲記憶，後續遇到相關場景時會自動召回，讓 AI 越用越懂你。

不過太短的對話它不會記，額度快用完的時候也不會觸發記憶生成。

你還可以結合 Skills 和插件一起用，比如每週自動生成周報 PPT、每日整理自己的學習筆記並同步到 Notion、每週用 Firecrawl 抓取競品網站更新並生成分析報告等等。

#### 應用和撤銷修改

如果你想決定哪些代碼要保留，可以選擇查看「未暫存」的文件，在這裏你可以靈活應用和撤銷修改。

大多數情況下，你不需要自己看代碼，直接點擊「暫存全部」就行，相當於認可了本次全部改動；如果不滿意，可以直接「還原全部」，回到本次改動前的狀態。

如果你不滿意某個文件的改動，直接點旁邊的「還原」按鈕就能恢復原樣；滿意的話點「暫存」就能標記爲待提交。

你也可以只保留部分改動。每個文件的改動會被自動拆分成多個代碼塊，每個代碼塊旁邊都有獨立的「暫存」和「還原」按鈕，你可以逐塊決定哪些保留、哪些丟棄。

確定好哪些代碼要暫存之後，可以「提交」暫存的改動。提交就相當於給代碼存了個檔，確認這次的修改是你想要的。

Codex 還內置了提交代碼、推送到遠程倉庫、創建 Pull Request 的能力，不用離開 APP 就能完成整個代碼管理流程，非常方便。

學會了怎麼用 Codex 之後，我也分享一下自己使用 Codex 的感受吧。

Codex 適合零基礎或者不想折騰 IDE 和命令行的同學，下載就能用，使用門檻很低。尤其適合已經是 ChatGPT 付費用戶的人，不用額外花錢就能擁有一個全能 AI 助理。

我個人非常推薦大家體驗一下，尤其是非程序員，這可能是目前最適合你的 AI 編程工具。

但對我來說，目前 Codex 還不能完全滿足我日常 AI 編程的所有需求。

作爲一名程序員和 AI 編程博主，我需要閱讀和編輯代碼、精細控制某一行改動、隨時切換不同的 AI 模型來對比效果，而這些 Codex 目前做得還不夠好，沒有內置代碼編輯器、閱讀代碼的體驗也一般。

所以實際使用的時候還是會搭配 VS Code 代碼編輯器，或者很多任務直接在 Cursor 裏搞定。

而且 Codex 的版本管理完全依賴 Git，項目必須是 Git 倉庫纔行，新手有一定門檻。

切換模型不夠靈活，桌面端默認只有 OpenAI 自家模型，想用其他的得去改配置文件或者用 CC Switch 之類的可視化工具。

而且目前對我來說最致命的是，GPT-5.5 在 Codex APP 的訂閱模式下有效上下文只有 258K，做大型項目重構時跟其他 AI 編程工具和模型支持的 1M 上下文比，還是有差距。

不過每個工具都有自己的定位。Codex 更像一個什麼都能做的「AI 助理 APP」，門檻最低；Cursor 更像一個兼顧代碼編輯體驗的「AI IDE」；Claude Code 更像終端裏推理能力最強的 AI 大腦。

這幾個工具的使用邏輯都差不多，學會一個再上手其他的會很快。
