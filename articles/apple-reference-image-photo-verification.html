Apple 參考影像背後原理　加密簽名證明 iPhone 拍攝真偽

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

Apple 詳細説明 Apple Reference Image(Apple 參考影像) 的運作方式。這項功能為參考影像提供可靠而且可規模化的保證：影像確實是由 iPhone 相機內的真實感測器，在特定時間拍攝的真實照片，為可驗證的數碼攝影訂立新標準。

感測器即時加密簽名

Apple Reference Image 會把相機感測器引導至專用的參考模式。該模式指示感測器在完成拍攝後，立即為像素資料進行加密簽名，感測器韌體亦被禁止修改這些資料。Apple 指出，其他驗證系統要待軟件處理流程結束時才為影像簽名，令影像容易受到篡改攻擊。

安全數碼負片與雲端驗證

Apple Reference Image 同時建立一張「安全數碼負片」，與標準的可編輯照片並存，並且不受軟件入侵影響。負片儲存在裝置內，包含像素資料、感測器中繼資料，以及附有上下限的加密時間戳。當用户決定「沖洗」負片作驗證時，負片會以未經處理的狀態送往 Private Cloud Compute；Private Cloud Compute 在安全、私密而且可驗證的環境中，執行渲染影像所需的步驟。

抗量子防禦與私隱保障

Apple 表示，這項功能可抵禦資料注入攻擊、作業系統被入侵、硬件攻擊及密碼學攻擊，並認為 Apple Reference Image 是唯一具備抗量子防禦能力的影像來源驗證系統。萬一系統被攻破，亦有撤銷選項。Private Cloud Compute 會為每張影像計算可信度評分，若發現欺詐行為，Apple 可以撤銷個別照片，甚至整個感測器。為保障攝影師，Apple Reference Image 不採用公開而明確的攝影師憑證，亦防止外界把同一感測器拍攝的不同照片公開關聯起來；影像的機密性受到保護，即使 Apple 亦無法取得。該功能採用自願啟用方式，並且僅限於主相機感測器。
