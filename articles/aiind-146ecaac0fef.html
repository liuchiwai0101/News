加州起訴OpenAI危害公共安全- 國際

內容機器翻譯自第三方媒體（大公文匯網 · 香港文匯報 · cnBeta.COM），僅供參考，以原文為準。

正文

微軟（Microsoft）週二（11/17）在Ignite 2026大會上宣佈 推出7款自研AI模型 ，涵蓋程式開發、網路安全、影像、語音及模型決策等領域，主打以接近OpenAI與Anthropic頂尖模型的效能，提供更低的使用成本。

這批模型由微軟AI部門（Microsoft AI，MAI）開發，主要針對企業日常工作及需要全天候運作的AI代理人。 微軟AI執行長Mustafa Suleyman表示 ，企業的Token支出正快速攀升，因此微軟不只追求頂尖模型的效能，也要同步最佳化品質與價格。

其中，MAI Code 2是針對企業日常程式開發任務設計的模型，包括程式修改、錯誤修復及前端介面開發等。微軟表示，根據4項基準測試，其效能達OpenAI GPT-6.1 Sol的98%，完成任務的成本約為後者的40%；相較Anthropic Claude Opus 5.5，則達到96%效能，成本僅為後者的5%。

MAI Code 2 Flash主要處理程式解説、修改及日常除錯等大量重複性工作，效能接近GPT-6 Luna及Claude Haiku 5.5，完成任務的成本分別約為後者的65%及20%。

MAI Cyber 2 Flash是用於持續監控、漏洞掃描及修補的網路安全模型。在CyberGymE2E測試中，微軟宣稱其表現與GPT-6 Astra相當，完成相同任務的成本不到後者的2%。相較前代MAI Cyber 1.1 Flash，新模型的輸出Token價格也降低86%。

MAI Image 2.7為一影像生成與編輯模型，在Artificial Analysis影像編輯排行榜位居第一，超越GPT Image 2.6 Sunburst（max），價格僅為後者的1/5。微軟另推出MAI Image 2.7 Flash，針對大量影像生成需求，每1,000張圖片成本約10美元。

MAI Realtime 1是支援低延遲即時語音對話的模型，微軟宣稱在相關測試中超越OpenAI GPT-Realtime 2.1，音訊處理費用每分鐘最低0.01美元。

Dragon Copilot Transcribe是採用MAI-Transcribe-2模型的醫療語音轉錄服務，可將醫師與病患的對話轉換成文字，目前每月處理約1,000萬次醫病互動，並將多語言轉錄的錯誤率降低一半。微軟表示，全美約1/3的醫師已使用這項技術。

Decision 1.1是模型路由系統，可依任務需求決定使用哪個AI模型，避免所有工作都交由昂貴的大型模型處理。微軟表示，該模型已有4,000家客户採用，速度比GPT-Sol 6.1快50倍，成本約為後者的1/79。

除了推出新模型，微軟也宣佈MAI模型權重授權服務（MAI Licensed Weights），讓企業取得MAI模型訓練完成後的權重參數，在自己的Azure環境中部署及執行模型，並利用內部資料進行客製化，而不必完全依賴微軟代管的API服務。企業也能自行管理模型存取權限，保有專有資料及客製化成果的控制權。
