一句話結論

LangChain 將 Deep Agents 的生產基礎設施（持久化執行、記憶、沙箱、通道、評估）封裝爲託管服務，開發者專注於智能體行爲，一條命令完成從原型到上線。

核心功能

Managed Deep Agents 解決了智能體從原型到生產的核心工程難題。開發者可以用 Python 或 TypeScript 編寫 Deep Agent，在本地測試後通過 mda deploy 一鍵部署到 LangSmith 託管運行時。

該服務提供以下生產級能力：

- **持久化執行（Durable Execution）**：長時間運行的智能體可暫停、重試、恢復，不丟失工作進度

- **流式輸出（Streaming）**：用戶可實時看到智能體工作進展

- **狀態持久化（Persistence）**：線程狀態在多輪對話、重啓和故障中保持

- **沙箱（Sandboxes）**：智能體可在隔離環境中操作文件、運行代碼、使用 CLI

- **評估（Evals）**：基於 Harbor 框架，驗證智能體的工具調用、文件編輯和狀態變更

- **通道（Channels）**：智能體可直接接入 Slack、GitHub 等工具

- **記憶（Memory）**：跨對話保持持久化偏好和上下文

- **身份認證（Identity）**：基於 OIDC 的多用戶線程隔離和作用域記憶

技術架構

Managed Deep Agent 是一個代碼優先的項目，採用目錄結構組織智能體的所有組件：

my-agent/
  agent.py | agent.ts | agent.tsx    # 智能体主文件
  instructions.md                      # 提示词同步到 Context Hub
  identity.py | identity.ts            # 认证、线程作用域、记忆作用域
  memory.py | memory.ts                # 记忆定义
  tools/                               # 自定义工具
  channels/                            # 接入入口（Slack、GitHub 等）
  middleware/                          # 自定义中间件
  schedules/                           # 托管定时任务
  skills/                              # 技能同步到 Context Hub
  sandbox/                             # 沙箱配置
  evals/                               # 智能体评估

部署時，mda deploy 會編譯項目、同步上下文到 LangSmith Context Hub、上傳構建產物並創建託管部署。

沙箱與評估

沙箱基於 LangSmith Sandboxes，每個持久化線程默認獲得獨立沙箱。開發者只需幾行代碼即可配置：

from managed_deepagents import define_sandbox
sandbox = define_sandbox(
    provider="langsmith",
    scope="thread",
)

評估系統基於 Harbor 框架，通過 mda evals init 和 mda evals compile 自動打包智能體爲 Harbor 可運行的測試工件。生產環境中的每次運行都會被追蹤，失敗案例可轉化爲未來測試用例。

適用場景

適合需要以下能力的團隊：

- 基於開源 Deep Agents 框架構建智能體

- 保持對模型、提示詞、工具、中間件和業務邏輯的完全控制

- 無需從零搭建智能體基礎設施即可部署到生產

- 需要持久化線程、記憶、沙箱、通道、定時任務和評估

當前公開測試版僅支持 LangSmith Cloud 美國區域，採用 CLI 優先方式，後續將增加更多區域和部署方式。
