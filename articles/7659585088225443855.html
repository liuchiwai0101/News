euv 框架入門指南

euv 是什麼？

euv 是一個基於 **Rust** 和 **WebAssembly (WASM)** 的現代前端 UI 框架。它將 Rust 的高性能和類型安全性帶入瀏覽器，使開發者能夠構建快速、可靠的 Web 應用。euv 的核心採用了**虛擬 DOM** 來實現高效的 UI 更新，並使用**響應式信號**進行狀態管理——在理念上類似於 React 和 Solid 等框架，但具有 Rust 生態系統的獨特優勢。

#### 核心特性

- **Rust + WASM**：用 Rust 編寫前端代碼，編譯爲 WebAssembly，在瀏覽器中獲得接近原生的性能。

- **虛擬 DOM**：高效的 DOM diffing 和 patching，最小化昂貴的瀏覽器操作。

- **響應式信號**：細粒度的響應式系統，自動追蹤依賴關係，只更新需要變更的部分。

- **宏驅動 DSL**：- `html!`和- `class!`宏提供了熟悉的 HTML 風格語法，可直接在 Rust 代碼中使用。

- **組件系統**：通過強類型的 Props 構建可複用、可組合的 UI 組件。

- **內置動畫**：開箱即用的 CSS 關鍵幀動畫，如- `euv-spin`、- `euv-fade-in`等。

- **浏览器 API 支持**：一等支持- `Window`、- `Document`、- `Storage`、- `Clipboard`、- `Navigator`等浏览器 API。

- **异步支持**：通过- `spawn_local`实现无缝异步操作，- `JsFuture`、- `Promise`、- `Response`等可通过预lude 获取。

安裝

使用 euv 非常簡單。由於它是一個 Rust crate，你可以通過 Cargo 將其添加到項目中：

cargo add euv

這個命令會將 euv 作爲依賴添加到你的 Cargo.toml 中。請確保你已經設置了一個兼容 WASM 的項目（例如使用 wasm-pack 或 trunk 進行構建和提供服務）。

掛載到不同的選擇器

mount 函數支持多種類型的 CSS 選擇器：

// 挂载到 id="app" 的元素
mount("#app", app);
// 挂载到 <body> 元素
mount("body", app);
// 挂载到 class="root" 的元素
mount(".root", app);
// 挂载到第一个 <main> 元素
mount("main", app);

選擇最適合你項目 HTML 結構的選擇器。最常見的選擇是像 "#app" 這樣的 ID 選擇器。

應用的基本結構

每個 euv 應用都遵循一致的模式：

use euv::*;
// 定义根组件
fn app() -> VirtualNode {
    html! {
        div {
            // 你的 UI 内容
            h1 { "Welcome to euv" }
            p { "Build fast web apps with Rust and WASM." }
        }
    }
}
// 将应用挂载到 DOM
mount("#app", app);

html! 宏是 euv 模板系統的核心。它允許你編寫：

- **嵌套元素**：- `div { p { "text" } }`

- **文本內容**：只需在元素名稱後的花括號內放置字符串

- **属性**：- `input { type: "text", placeholder: "Enter name" }`

- **事件处理器**：- `button { onclick: move |event| { /* handler */ } "Click" }`

- **条件渲染**：- `if { condition } { /* visible */ } else { "" }`

- **列表渲染**：- `for item in { items.get() } { li { item } }`

一個稍微複雜的示例

讓我們看一個更完整的示例，展示狀態和交互功能：

use euv::*;
fn app() -> VirtualNode {
    let count: Signal<i32> = use_signal(|| 0);
    html! {
        div {
            h1 { "My First euv App" }
            p { "The counter will go here" }
            button {
                onclick: move |event: Event| {
                    count.set(count.get() + 1);
                }
                "Increment"
            }
        }
    }
}
mount("#app", app);

在這個示例中：

- 我們使用 `use_signal`創建了一個初始值爲`0`的響應式信號`count`。

- 按鈕有一個 `onclick`事件處理器，通過`count.get()`讀取當前值，並用`count.set(...)`更新它。

- 當信號發生變化時，euv 會自動重新渲染 UI 中受影響的部分。
