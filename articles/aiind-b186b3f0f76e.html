OpenAI 三个神秘模型曝光 10 月 18 日，有开发者发现，OpenAI 的 API 模型列表中突然出现了三个陌生名字：

aurora-red-alpha、aurora-green-alpha、aurora-blue-alpha。三个模型都以 Aurora（极光）命名，分别对应红、绿、蓝三种颜色。但相关条目很快便从模型列表中消失。

此次发现来自第三方维护的 OpenAI 模型列表镜像，并非官方公告。因此，这些模型究竟是什么、是否会正式发布，目前都还是未知数。

有网友推测，这些模型极有可能是 GPT-6 Astra 后续版本的内部检查点，专门对标 Fable 5.5 的强项，创意编码、长程 agent、视觉 / 3D。也有网友推测：三个模型对应 OpenAI 三个图像模型。（消息来源：机器之心）

Anthropic 与法律专家讨论 AI Agent 谈判规则，未来可替用户砍价、处理纠纷 据《金融时报》最新报道，Anthropic 正在与律师事务所及法律专家合作，研究 AI Agent 代表用户进行谈判时应遵循的行为规范。

随着 Agent 逐渐能够独立执行任务，未来可能出现大量 AI 与 AI 之间的商业交互。

例如，消费者让自己的 AI 助手与商家的 AI Agent 讨价还价，员工让 AI 代理参与薪资谈判，或者用户委托 AI 处理服务纠纷。

Anthropic 希望明确几个问题：AI 应该在多大程度上争取用户利益？什么时候需要征求用户确认？面对其他 AI Agent 时，是否应该默认对方存在欺骗或操纵意图？

公司还讨论过一种授权方式：让用户通过签署文件，明确 AI 的代理权限、目标和行为边界。

目前，这仍属于规则研究和产品探索，尚未推出面向公众的自动谈判服务。（消息来源：金融时报）

DeepSeek 正式开放搜索与网页抓取 API，每千次调用收费 5 元 DeepSeek 正式开放 Search 和 Fetch 两项 API，向开发者提供基于自研搜索引擎的网页搜索及内容抓取能力。

其中，Search API 可以根据关键词返回结构化搜索结果，包括网页标题、链接、摘要、发布日期等信息；Fetch API 则可以抓取指定网页，将正文转换为 Markdown 文本。

两项 API 均采用按成功请求次数计费的方式，价格为每千次 5 元。失败、超时或未返回有效结果的请求不收费。

DeepSeek 表示，其自研搜索引擎目前每天在全球范围内处理数亿次请求。（消息来源：DeepSeek 官方公告）

Anthropic 拟设立「公共利益」基金，初始注入 5% 股份 当地时间 10 月 18 日，Anthropic 宣布，在获得股东批准的前提下， 公司计划将 5% 的股份划入新设立的公共利益基金 （Public Benefit Fund）；且随着这家人工智能巨头的估值增长，该基金持有的股份比例未来还可能进一步提升。

该拟议的基金将作为一家全资拥有的有限责任公司设立，经董事会裁量，公司估值每较尚未披露的基准上涨 50%，基金就会获得 Anthropic 额外 2% 的股份。

Anthropic 公共利益基金所支持的项目将涵盖非营利捐赠、向特定群体发放直接资助，以及应对人工智能对就业人员冲击等举措。

该公司表示，该基金所持有的任何股权均不会用于美国国内或海外的政治游说与政治捐赠。

Anthropic 表示，将于未来数月内公布有关该基金治理机制、组织结构以及可能扩大其持股比例的估值门槛的更多细节；此外，公司还计划发布一份公共利益报告，详细披露其实现使命的进展。（消息来源：IT 之家）

苹果首次公布折叠屏 iPhone Duo 电池容量：4883mAh 由两块电池组成 苹果公司近日公布的欧盟产品信息文件揭示了首款折叠屏手机 iPhone Duo 的电池容量。这款设备配备总容量为 4883mAh 的电池，由两块电芯组合而成，容量分别为 2962mAh 和 1921mAh。相关信息此前已在网络上出现，此次欧盟产品信息文件的发布进一步证实了这一数据。

对于一款采用书本式折叠设计的手机而言，4883mAh 的容量反映了苹果在机身厚度、铰链结构、屏幕尺寸和电池空间之间所作的取舍。折叠屏手机需要将内部空间分配给两块显示屏、铰链、主板、摄像头及其他组件，同时还必须在展开和折叠状态下维持合理的机身厚度。与传统直板手机相比，这种结构设计会给电池布局带来更多限制。

iPhone Duo 采用双电池系统，两块电芯分别位于机身的两个部分。苹果此前表示，iOS 会将这两块电池作为一个整体进行管理，而不是让用户分别操作。采用两块电池有助于适应折叠机身的内部空间布局，但这并不意味着两块电池的容量相同，也不能仅凭电芯数量判断整机的续航表现。

苹果公布的续航数据也显示，使用哪块屏幕会显著影响电池表现。根据苹果此前公布的规格，iPhone Duo 在展开状态下使用 7.6 英寸内屏播放视频，最长续航时间为 31 小时；仅使用 5.4 英寸外屏播放视频时，最长可达 44 小时。按照苹果定义的典型使用场景，设备的续航时间最长为 24 小时。该典型使用场景假设用户均衡使用内外两块屏幕，同时进行消息收发、拍照、音乐播放、社交应用、视频流媒体、游戏、网页浏览和导航等操作。( 消息来源：cnBeta)
