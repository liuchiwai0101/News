Parallels Desktop 27 支援 OpenGL 4.3 性能顯著提升

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

近日 Parallels Desktop 27 正式推出，除了支援獲得 macOS Golden Gate 外，它更會進一步提升 macOS 在 Apple Silicon 平台上的虛擬化效能。最新版本引入基於 Metal 的圖形驅動程式，讓 Windows 虛擬機支援 OpenGL 4.3，並顯著加快本地 AI 工作負載處理速度。此外，針對企業 IT 團隊的新功能亦有助簡化管理與部署流程。

OpenGL 4.3 硬體加速支援

Parallels Desktop 27 的核心更新在於新的 Metal 圖形驅動程式，為 Apple Silicon 上的 Windows 虛擬機提供硬體加速的 OpenGL 4.3 支援。這使 ArcGIS Pro、ZWCAD 及 Blender 4.3 等專業軟件能在 macOS 環境中順利運行。官方數據顯示，在 M3 或更新款 Mac 上，OpenGL 圖形性能提升最多達 160%，ArcGIS Pro 中的 3D 渲染速度快最多 35%，整體工作流程時間縮短達 24%。

本地 AI 開發效能提升

在 M4 或更新款 Mac 的 Linux 及 Windows 虛擬機中，Parallels Desktop 27 新增對可擴展矩陣延伸指令集（SME2）的支援。此改進令 AI 和機器學習矩陣運算速度提升最多 7 倍，神經網絡推理速度快最多 1.75 倍。這對於使用 Ollama 和 llama.cpp 等工具的開發者而言，意味著能更有效地在本地構建和測試 AI 模型，無需完全依賴雲端資源。

企業級管理功能增強

Parallels Desktop for Enterprise 版本現允許透過命令列介面判斷授權是由密鑰還是單一登入（SSO）啟動，協助使用 Jamf 的機構建立擴充屬性以進行裝置管理和報告。該產品亦重新獲得 SOC 2 合規認證，並更新了安全黃金映像檔佈署功能，支援透過 Azure Blob Storage 和 SharePoint 等企業儲存方案分發經批准的 VM 映像檔，實現零接觸佈署。
