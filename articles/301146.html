Taro 3.6.33 發佈：BAT 小程序、H5 與 RN 統一端框架

Taro 3.6.33 現已發佈。Taro 是一個開放式跨端跨框架解決方案，支持使用 React/Vue/Nerv 等框架來開發微信 / 京東 / 百度 / 支付寶 / 字節跳動 / QQ 小程序 / H5 等應用。 此版本具體更新內容如下：

小程序

- 修復了因 URL SearchParams 參數不規範而導致的頁面渲染白屏問題 fix #15717

鸿蒙 Hybrid

- 新增了 previewImage 以橋接原生代碼

- 修復了導航欄配置無效和 getLaunchOptionsSync 無返回值的問題

- 修復了 IntersectionObserver 相關的接口無效問題

- 優化了部分不支持的 API，修改爲繼承 H5

- 修復了 clearStorageSync 報錯的問題

- 修復了在 dev 模式下橋接到原生端的同步 API 崩潰的問題

CLI

- 優化了 CLI 模板展示邏輯，以支持自定義模板名稱 - 优化了 taro create 命令，添加 clone 和 sourceRoot 参数
