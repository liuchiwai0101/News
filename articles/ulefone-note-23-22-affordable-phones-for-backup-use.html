【場料】HK$499 起預載 Android 16 Go！Ulefone Note 23 / 22 平價備用雙機登場

內容機器翻譯自第三方媒體（PCM），僅供參考，以原文為準。

針對尋求高性價比備用手機或基本通訊需求的用户，Ulefone 正式在本港推出全新入門手機 Note 23 以及 Note 22，入場費只需 HK$499 起。兩款新機的最大賣點是預載專為入門級硬體優化的 Android 16 (Go edition) 作業系統，確保系統輕巧流暢，同時保留了 3.5mm 耳機孔與 microSD 記憶卡擴充功能，注重日常實用表現。

Ulefone Note 23

定位較高一階的 Ulefone Note 23 定價為 HK$699。機身配備 6.56 吋 90Hz 水滴屏 IPS LCD 顯示屏，解析度為 540 x 1210，最高亮度達 400 nits，面板更具備莫氏硬度 8 級防護等級，提升日常使用的抗刮耐磨能力。機身重量約 192g，提供宇宙橙、深海藍及工藝黑三款配色，並支援 FM 收音機功能。效能方面，Note 23 搭載 Unisoc T7100 八核心處理器，最高時脈達 1.8GHz，搭配 PowerVR GE8322 圖形處理器、3GB RAM（支援動態 RAM 擴充）與 32GB ROM，並可透過 microSD 卡擴充最高 2TB 儲存空間。此外，機身內建 5000mAh 大容量電池，支援 USB Type-C 10W 充電。拍攝方面則由 800 萬像素 f/2.0 主鏡頭與 500 萬像素前鏡頭負責，前後均支援 1080p 30fps 影片錄製。

Ulefone Note 22

同場登場的 Ulefone Note 22 定位更為親民，售價僅 HK$499，主打輕便與基礎應用。機身採用 5.0 吋 60Hz LCD 螢幕（解析度 480 x 854），處理器同為 Unisoc T7100，最高時脈設定為 1.6GHz，同樣配備 3GB RAM 及 32GB ROM。該機特別採用 3,000mAh 可拆卸式電池設計，支援 5W 充電，並配備 200 萬像素主鏡頭與 30 萬像素前置鏡頭。兩款手機均支援 4G 雙卡雙待，為需要長續航或副號碼的用家提供實惠選擇。
