Markdown 即時預覽轉 PDF 圖片　原價 US $0.99《MarkViz》限時免費

MarkViz 是一款把 Markdown 轉成清晰視覺化文件的工具，適合撰寫技術文件、整理流程與規劃專案的使用者。它結合 Markdown 編輯與即時預覽，可在離線狀態下渲染 Mermaid 圖表，並切換思維導圖模式，一眼看清文件結構。原價 US $0.99，現正限時免費。

離線圖表與思維導圖

MarkViz 支援 Markdown 編輯與即時預覽，可匯入 Markdown 及 HTML 文件，並將內容匯出成 PDF 或圖片分享。內建 Mermaid 離線渲染，可繪製流程圖、時序圖、狀態圖、甘特圖、圓餅圖與 ER 圖；由標題與清單自動生成的思維導圖可縮放檢視。程式亦備有收藏、搜尋、文件整理與多款主題。
