Claude Opus 5：“神话”，开始下放了_腾讯新闻

今天凌晨，Anthropic 正式發佈 Claude 。

它在多數評估中都超越了 ，天哪！

能力接近更高一級的 Fable 5，價格只有一半。

標準 API 價格是每百萬輸入 token 5 美元、輸出 token 25 美元，與 Opus 4.8 完全相同，正好是Fable 5的一半。

**神話，開始下放了。**

本次還新增了Fast mode 快速模式，快2.5倍，價格翻倍。

Anthropic 官方对Opus 5 的形容是：**thoughtful （深思熟虑）和 proactive（主动）。**

thoughtful ，不是簡單地回答前多思考幾步，Opus 5 會檢查假設、尋找根因、驗證結果，並在發現問題後繼續迭代。

proactive，不是擅自擴張任務的意思，是在缺少驗證條件時，Opus 5 可以主動搭出一套驗證條件。

比如，給 Opus 5 一張機械零件圖，要求它用代碼把零件重建成三維模型。

但故意不給它直接看圖的能力。

換成以前的模型，很可能會停在“我無法查看圖片”。Opus 5 沒有停下來，而是自己寫了一條計算機視覺處理流程，從圖片的原始像素中提取幾何信息，再完成零件重建。

Anthropic 稱，Opus 5 多次完成了這項任務；相同條件下，其他參測模型連續嘗試五次也沒有成功。

◈編程和複雜任務更強

Opus 5 重點提升了軟件工程和知識工作能力，包括理解大型代碼庫、排查故障、修改多個文件，以及完成分析、表格和自動化任務。

Opus 5 是新的 SOTA，幾乎所有測試都摸到了最前沿的水平。

軟件工程基準 Frontier-Bench 上，超過了所有其他模型，比上一代 Opus 4.8 的成績翻了一倍，但是每個任務的成本反而更低。

（Opus4.8確實草雞，我每天只用Fable 5，眼巴巴等着刷新額度，Opus用不了的話，200美元的訂閱感覺要虧死了）

在 CursorBench 上與 Fable 5 相差不到 0.5%，價格卻只有 Fable 5 的一半。

Opus 5 在代碼審查方面也有明顯升級。官方稱它能在保持較高召回率的同時控制誤報，後續發現的問題大多是真問題，而不是爲了多報數量製造假的正例。即使在較低的effort 下，代碼審查準確度仍能保持得不錯。

不過，如果提示詞寫着“只報告最高嚴重性的問題”或“必須非常保守”，它會非常字面地執行，可能漏掉有價值的問題。官方建議先要求它完整找出問題，再單獨做一次過濾。

◈專業知識工作和電腦操作提升更突出

Opus 5 可能比編程榜單更重要的進步，發生在專業工作和端到端業務流程中。

GDPval-AA 覆蓋44種職業、220項真實工作任務；

AA-Briefcase 偏向專業辦公產物；

AutomationBench 看的是業務流程能否從頭運行到尾；

OSWorld 評估電腦操作能力。

在電腦操作基準 OSWorld 上擊敗 Fable 5，成本僅爲其三分之一多一點，在每一檔成本檔位都贏過所有模型。

◈新問題求解和推理能力

Claude Opus 5 在「人類最後的考試」中排名第一，得分爲 64.7%，以微弱優勢擊敗了得分 64.5% 的 Claude 。

在ARC-AGI 3上，分數是第二名的三倍。之前的最高分數（7.8%）由 GPT-5.6 Sol (Max) 創造。

ARC-AGI-3 是一個抽象推理評測，考察的模型能力是，在沒有現成解題模板、需要臨時理解新規則的問題的推理能力。

而且還發現了一個模型之前未曾展現過的新能力：Opus 5 使用高級邏輯推理將 ARC-AGI-3 佈局轉換爲代數符號。在第 23 步，把場景描述爲"4_center = 2×axis − 5_center"，這是模型第一次明確提出的反射方程。

◈科學研究能力

Anthropic 表示，Opus 5 在內部所有生命科學評測上都超過 Opus 4.8。

其中提升最明顯的是：

- 根據光譜數據推斷有機分子結構：提高10.2個百分點；

- 根據蛋白質序列變異預測功能變化：提高7.7個百分點；

- ArxivMath 2026年6月题集：无工具90.8%，有工具91.3%。

它在結構生物學、有機化學、生物信息學、統計檢驗和交叉驗證方面都有改善。早測用戶特別提到，它會主動選擇統計方法排除混雜因素，並用不同方法交叉檢查結果。

但這部分多數來自 Anthropic 內部評測或早測客戶反饋，不能視爲獨立科學驗證。Opus 5 在長時間自主生物研究上仍有明顯限制，Mythos 5 更強。

至於大家比較關心的，Fable 5 被攔截的部分生物請求，現在會回退到 Opus 5，

◈視覺、網頁和辦公產物

Opus 5 的視覺提升不只是“看圖識字”。

官方提示指南列出的強項包括：

- 圖表、複雜文檔和結構圖理解；

- UI 截圖復刻；

- 前端視覺實現；

- 圖像裁剪、局部分析和反覆視覺驗證；

- 多工作表電子表格；

- 非簡單公式和複雜表格關係；

- 結構完整的演示文稿；

- 動畫、遊戲、3D 和交互式網頁產物。

在網頁任務中，它會主動用瀏覽器檢查桌面和手機尺寸。早測案例中，它發現了移動端首屏以下隱藏的商品，以及跑出屏幕的結賬按鈕，並在交付前自行修復。

官方特別指出：提升視覺任務效果時，給它可迭代操作和檢查的工具，通常比單純提高 thinking effort 更划算。

◈長上下文和多Agent協作

Opus 5 默認就是100萬 token 上下文。Anthropic 稱，它在長上下文中的指令遵循、工具調用和推理一致性都有提升。

ProgramBench 評測中，模型會在多輪任務中繼承之前寫下的代碼：

- 第一輪成功率約83%；

- 第五輪上升到約93%；

- 最終持續性接近 Mythos 5。

**在多Agent協作上，Opus 5 更擅長：**

- writer-verifier 分工；

- 把獨立問題交給不同子Agent；

- 彙總多條研究或實現路徑；

- 減少多個Agent互相覆蓋工作。

不過，它也比以前更愛調用子Agent。小任務如果不限制，可能產生不必要的成本和延遲。官方建議明確規定哪些任務值得委派，並限制最大Agent數量。

除了模型能力外，Opus 5的的成功率降至 ~0。

◈最後：價格

Opus 5 的 API 价格与 Opus 4.8 相同：

- 每百萬輸入 token 5 美元；

- 每百萬輸出 token 25 美元。

Fast mode 的運行速度約爲默認模式的 2.5 倍，價格爲基礎價格的兩倍。

Opus 5 默认开启 adaptive thinking。虽然可以在 high 及以下关闭 thinking。

而且max effort 也不一定是最佳模式，高 effort 下可能陷入反覆檢查、推翻、重新檢查的循環。

Opus 5 發佈時，Anthropic 還推出了兩個測試功能：

- 開發者可以在對話進行到一半時增加、刪除或替換 Claude 可用的工具，而且不會讓 prompt cache 失效。這對長時間Agent很重要。例如任務前半段需要搜索，後半段轉向代碼執行，不必從頭重建上下文和緩存。

- Opus 5 或 Fable 5 觸發安全分類器後，可以由服務器自動把請求路由給適合的替代模型，不必直接終止任務。但開發者需要記錄最終響應來自哪個模型。否則內部評測看起來是在測 Opus 5，實際可能混入 Opus 4.8。

Opus 5 的升級重點很明確：從生成答案，繼續走向完成、檢查並交付複雜任務。

目前這些能力主要來自 Anthropic 和早期合作方的評測與案例。

附上一些Opus 5 的變化：

- 默認回答比舊 Opus 更長；

- Agent 工作時更喜歡彙報接下來要做什麼；

- 寫入文件的報告和文檔也更長；

- 會主動擴大任務範圍；

- 更愛自行驗證；

- 更愛使用子Agent；

- 更常把自己的修正過程告訴用戶；

模型已經正式開放，Max訂閱用戶可以使用了，Pro用戶暫未開放。但能否在不同人的真實工作中穩定復現，還要等待更多外部使用結果。
