利益優先 川普簽命令 豁免對俄製裁

普丁 川普 俄國 ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' 00:00 2026/10/18 08:54:33 中央社 記者侯姿瑩華盛頓17日專電 美國總統川普昨天簽署一項行政命令，暫緩執行針對俄羅斯經濟的大規模新制裁方案，美國兩大黨國會議員齊聲撻伐，批評川普此舉是向非法入侵烏克蘭的俄國獨裁者讓步，還有議員形容，這是俄國總統普丁今年收到的「最佳生日禮物」。

這項法案以已故南卡羅來納州聯邦參議員葛蘭姆（Lindsey Graham）的名字命名，內容包括對俄羅斯出口商品及政治、軍事領袖實施制裁，目的在於打壓俄國經濟並切斷助長對俄烏戰爭的資金流動。該項立法也針對俄羅斯石油或天然氣的前5大進口國加徵關税。

--> 在美國國會兩院通過後，川普上個月將法案簽署立法，不料昨天卻簽署行政命令暫緩執行，並向國會表示，暫緩實施「符合美國國家利益」。但川普在行政命令中並未針對「國家利益」的部分提供進一步説明。

川普此舉招致跨黨派國會議員齊聲批評。與川普同屬共和黨的聯邦參議員柯寧（John Cornyn）今天在X發文寫道，葛蘭姆「一定會感到無比震驚」。

葛蘭姆生前主張美國應對俄羅斯實施更嚴厲的制裁，以作為施壓俄羅斯結束俄烏戰爭的手段。

共和黨聯邦參議員提里斯（Thom Tillis）也發文抨擊，此舉「極不負責」，川普政府向非法入侵烏克蘭、殺害無辜平民的俄羅斯獨裁者讓步，這令人無法接受。「若（川普）總統真的想要降低能源價格，他應該去解決伊朗問題」。

川普2月底和以色列聯手對伊朗開戰，導致全球油價上漲，戰事至今尚未落幕。

另外，民主黨議員同樣反對川普暫緩實施對俄新制裁法案。民主黨籍聯邦眾議員貝耶（Don Beyer）在X發文批評，川普向普丁（Vladimir Putin）妥協，「再次背叛了我們的烏克蘭夥伴」。

參議院民主黨領袖舒默（Chuck Schumer）也在X發文寫道，川普送給了普丁今年能收到的「最佳生日禮物」。

民主黨籍聯邦參議員布魯門塔（RichardBlumenthal）則在臉書貼文直言，川普此舉無關美國國家安全，只是為了奉承討好普丁。

烏克蘭總統澤倫斯基（Volodymyr Zelenskyy）今天在社群發文表示，美國減輕對侵略者的壓力，是對普丁的財務獎勵。「這一切只會鼓勵他繼續發動攻擊」。

川普在簽署這項行政命令之前，上週才宣佈，美國將從俄羅斯進口柴油，以試圖壓低能源價格，儘管此舉恐在俄烏戰爭中對烏克蘭造成不利影響。

隨著美國11月3日的期中選舉將至，「華盛頓郵報」（Washington Post）報導，川普因柴油價格高漲而面臨壓力，生活成本高昂已成為選民關心的核心議題。

川普宣佈和俄羅斯達成柴油協議，不僅引發美國國會跨黨派議員強烈反彈，美國在歐洲的盟友也在這項宣佈後，紛紛強調對澤倫斯基的支持。

華郵指出，這項與俄羅斯的石油協議雖可能稍微緩解美國的油價，但進口量僅佔美國總消耗量的一小部分，預期對價格的實際影響有限。
