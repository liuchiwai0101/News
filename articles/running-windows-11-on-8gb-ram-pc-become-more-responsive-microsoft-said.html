8GB RAM 行 Windows 11 不再痛苦？Microsoft 宣稱反應 +20%、多工 +40%

內容機器翻譯自第三方媒體（PCM），僅供參考，以原文為準。

自去年 AI「盲搶潮」開始，記憶體、SSD、硬碟售價升幅驚人，偏偏 Windows 11 向來以「大食」聞名，即使配備 16GB RAM，流暢度亦未必十分理想。對於預算有限的用家而言，現時想要加 RAM 的話，成本更相當吃力。因此早前 Microsoft 承諾會積極為 Windows 11 進行「輕量化」，務求令 8GB PC 也能重獲順暢體驗。近日官方終於公開具體成果，究竟各項優化是否真有長足進步？

今次 Microsoft 執行副總裁（Windows + Devices）Pavan Davuluri 於官方 Blog 撰文剖析技術細節。是次 Windows 11 優化策略主要聚焦三大方向，包括提高現有記憶體使用率、確保系統在高負載下依然保持即時反應，以及為 Windows 核心應用程式大幅「瘦身」以降低資源佔用。他指出，在 8GB RAM PC 上，更新後的 Windows 11 日常操作反應速度提升高達 20%，而多工作業速度更提升高達 40%。

Microsoft 執行副總裁（Windows + Devices）Pavan Davuluri 於官方 Blog 撰文剖析 Windows 11「輕量化」的技術細節。

改善記憶體壓縮機制

Pavan 將系統記憶體比喻為放滿工作工具的「辦公桌面」，所有物件觸手可及；當桌面放不下時，Windows 就會把部分資料移至「抽屜」，意即速度較慢的 SSD 或硬碟。不少 8GB 機型用家在開啟「工作管理員」時，經常發現記憶體佔用率居高不下，以為電腦「又唔夠 RAM」，但其實這套機制本身是為了預載常用程式與快取資料，確保需要時隨手可得，因此記憶體被善用並不等同系統資源吃緊。

今次 Microsoft 的改進重點，正在於避免系統頻繁動用「抽屜」令流暢度大打折扣。廠方重新調整了 Windows 11「記憶體壓縮」演算法，將暫未活躍的資料先壓縮打包，使其能繼續留在實體記憶體內。團隊特別針對 8GB PC 調校了壓縮比例與調用磁碟分頁的時機，成功將多達 2GB 的活躍資料額外保留在 RAM 當中。如此一來，用家切換視窗或重返分頁時，便能大幅減少「重新載入」情況，整體順暢感會顯著提升。

提高優先權 加快系統反應

Pavan 指出，在介面互動方面，Windows 11 的即時反應表現亦有顯著改善。相比今年 1 月的 Windows 11 版本，如今開啟「開始」功能表、搜尋、點擊右鍵選單、進入「設定」、啟動「剪取工具」以至打開「檔案總管」等日常操作，響應速度提升高達 20%。這是由於 Windows 現在會在用家發出指令時，短暫賦予前台操作最高優先權，並暫緩背景搜尋索引等非必要工作，避免搶佔即時運算資源。

與此同時，系統亦著手消除不必要的重複運算。例如用家點擊網址連結或從「開始」功能表開啟 Microsoft Edge 時，系統會直接連動已在背景待命的處理程序，省去重新檢索與初始化，令啟動速度加快多達 33%。此外，Microsoft Teams 在 8GB PC 上將預設啟用「效率模式」，程式啟動提速 20%。

Windows 11 向來大食，8GB RAM 要應付系統加各類程式，就算只做「文書機」也確實吃力。

大食程式「瘦身」

除了 Windows 11 底層調校外，多個 Windows 原生及 Microsoft 自家「食 RAM 大户」亦同步「瘦身」。Pavan 表示，在多工負載測試中，新版本整體承諾記憶體（Committed Memory）增長量減少了多達 900MB。其中 Microsoft 365（包括 Word、PowerPoint、Excel、Outlook）透過重構記憶體分配機制，成功減省約 360MB；小工具（Widgets）改為點擊開啟時載入，未啟動時可省下約 200MB；Microsoft Edge 閒置分頁自動休眠時間，亦由過往 2 小時大幅收緊至 15 分鐘。官方模擬高負載多工環境作測試，同時開啟 20 個 Edge 分頁、一段 4K 影片、數個大型 Office 檔案、Outlook 及檔案總管，整個作業速度比起今年 1 月 Windows 11 版本提升了 40%。

未來繼續改進不停步

Pavan 透露，是次優化只是改善工程的第一步，未來 Microsoft 將繼續根據用户反饋推進改善計畫。此外，廠方亦會進一步強化記憶體壓縮演算效率；推動系統核心共用架構，例如「搜尋」與「小工具」共用同一個 Web 引擎，以及「OneDrive」與「相片」共用底層模組，避免組件重複佔用記憶體；基於 WinUI 3 架構打造的應用（如記事本、小畫家、檔案總管等）亦會持續進行輕量化改良。

現時 RAM 價高企，不少新推出的 PC 也計畫「縮水」只配 8GB RAM，迫使 Microsoft 必須加大力度將 Windows 11 輕量化，應對當前硬件挑戰。

Microsoft 更計畫與 PC OEM 廠商及晶片夥伴深入合作，將硬件效能進一步優化壓搾，並會聯同第三方開發者改善各類 Windows 軟件資源使用效率，讓主流用家享受更輕快的 PC 日常體驗。話雖如此，大家用 8GB RAM PC 時效能是否真的變得 OK，還真的要實際上手試過先知。
