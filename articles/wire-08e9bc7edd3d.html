多平台版本 Chrome 更新至 153　奠定主要版本更新加速至兩星期一次

內容機器翻譯自第三方媒體（Yahoo 新聞），僅供參考，以原文為準。

重點內容

與眾多應用程式一樣，Google 定期會為 Chrome 進行更新，過往會保持於每月推出一次最新的正式版 Chrome。不過若眾多更新項目都集中於每月一次的更新，加上安全漏洞不時會被找到，一個月才一次更新已未必能配合當前所需。最近 Google 推出最新的版本 153 Chrome，正式把更新週期由四星期一次更新，縮短一半至兩星期一次更新，對 Google 以至廣大用家都有好處。

現時於 Windows、macOS、Android 及 iOS / iPadOS 版 Chrome，全都已更新至版本 153。與過往有點不同的是，由版本 153 開始，Google 會開始把正式版 Chrome 的更新週期，從每四星期縮減一半至兩星期一次。換言之，我們可以預期本月下旬還將會有版本 154 Chrome 可以下載並安裝使用。

在今年較早時候，Google 已經表明會將正式版 Chrome 的發布頻率提高一倍，讓不同新功能、效能改進及錯誤修復可更快送達予全球各用家。當正式版的版本 153 Chrome 已經開始推送，代表他們已經落實計劃。

Google 指出，更為密集的 Chrome 更新不但讓各用家更快獲得更多新功能，更重要的是縮短安全漏洞從程式碼被公開至相關修復送達至用家的時間差。隨著自動化漏洞探測工具及社群回報，產生愈來愈多待處理的修復項目，Google 一直都不能怠慢，需要常常為 Chrome 進行更新，修補安全漏洞，更密集的更新可讓用家盡早獲得更安全的 Chrome，同時因每個正式版 Chrome 之間的改動會比以前少，即使瀏覽器有各式各樣的問題，Google 的工程人員亦可更快找出問題成因，解決問題，對各方而言都是好事。
