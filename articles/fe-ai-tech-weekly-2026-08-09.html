運行時與供應鏈

pnpm 11.20.0

參考來源：pnpm 11.20

8 月 3 日發佈的 pnpm 11.20.0 修復了 11.1.0–11.19.x 在命名 registry 安裝同名同版本包時，鎖文件可能合併不同來源 tarball 的包替換風險。

新鎖文件鍵會攜帶 ，下一次非 frozen 安裝會重寫受影響條目；團隊還需保留全部已引用的 namedRegistries 別名，避免更新後出現 ERR_PNPM_MISSING_NAMED_REGISTRY。使用私有鏡像、GitHub Packages 或多 registry 的項目應統一升級客戶端並提交鎖文件變更，供應鏈風險爲高，建議 **upgrade**。

Node.js 24.19.0 LTS、26.6.0 与 26.7.0 Current

8 月 3 日 Node.js 发布 24.19.0 LTS 与 26.6.0 Current，8 月 5 日再发布 26.7.0 Current；LTS 补充 blob.textStream、稳定的 stream.compose，Current 增加 Perfetto 支持、NSS 根证书和模块钩子释放能力。

測試工具也獲得 context.log()、覆蓋率全量包含等改進，適合排查 CI 與運行時問題；24.x 服務可優先評估兼容性，26.x 使用者應以 26.7.0 爲基線重新跑測試和診斷鏈路，運行時風險爲中，建議 **upgrade**。

構建工具

Rspack 2.1.8

参考来源：Rspack 2.1.8

8 月 4 日的 Rspack 2.1.8 新增 cache.name 与 cache.storage.location，并将 cache.storage.directory 定义为缓存根目录，最终路径默认拼接为 /，以对齐 webpack 的持久缓存语义。

此前把 storage.directory 當作精確緩存路徑的項目，升級後會得到額外一層目錄，舊緩存也不會自動遷移；版本同時讓 HMR 熱清單攜帶更精確的 CSS 變更信息。配置了自定義磁盤緩存的構建團隊需調整目錄字段並清理舊緩存後做冷、熱構建對比，緩存命中風險爲中，建議 **migrate**。

Vite 8.2.1

参考来源：Vite 8.2.1 changelog

8 月 6 日發佈的 Vite 8.2.1 修復了 sharedPlugins: true 時客戶端 chunk import map 失效、bundled dev 中客戶端腳本插入順序不正確，以及 CSS 壓縮重複執行 Lightning CSS visitor 等問題。

該補丁還避免解析 library entry 時修改用戶配置，並改進隨機端口與純 CSS chunk 的處理。使用共享插件、多入口懶加載或嵌入式開發服務器的項目可直接替換補丁版本，再複測生產構建與動態導入，構建迴歸風險爲低，建議 **upgrade**。

Rolldown 1.2.2 与 1.2.3

8 月 3 日的 1.2.2 支持在動態入口中內聯共享依賴，並讓插件時間統計覆蓋用戶回調；8 月 5 日的 1.2.3 修復了 watch 批次註冊失敗、已廢棄的 watch.notify 暴露及部分收尾階段內存分配。

動態 import 較多的應用可能因此改變 chunk 組成和產物體積，依賴自定義插件或 watch API 的工具鏈也應檢查行爲差異。採用 Rolldown 原生構建或通過上層工具接入的團隊應更新後覈對 chunk 圖、熱更新與插件鉤子，兼容性風險爲中，建議 **upgrade**。

代碼質量與組件

Oxlint 1.77.0 与 Oxfmt 0.62.0

参考来源：Oxc apps v1.77.0

8 月 3 日的 Oxlint 1.77.0 增加 file:line:column 形式的 GitHub 註釋，並改善 .gitignore、JavaScript 插件名和多條規則的處理；同批 Oxfmt 0.62.0 支持 Vue 中的 TSX、在 check 模式展示顏色差異，並改用新的 YAML 格式化器。

YAML 輸出與已有格式化基線可能出現差異，而 CI 註釋格式會影響代碼掃描集成。將 Oxc 用於提交檢查或格式化的項目應固定版本、比對 YAML 與 Vue 文件的變更，並確認 GitHub Actions 註釋仍被正確解析，質量門禁風險爲中，建議 **verify**。

ESLint 10.8.1

参考来源：ESLint v10.8.1

8 月 7 日发布的 ESLint 10.8.1 修复了 no-unused-labels 与 no-unused-vars 自动修复可能触发自动分号插入的问题，也降低了 getter-return、accessor-pairs、id-denylist 和 id-match 的误报；官方同时标注 ESLint v9 已于 8 月 6 日结束维护。

仍停留在 v9 的倉庫不再獲得維護修復，應把升級到 v10 與本次補丁合併安排；啓用相關規則的項目需先在全量代碼上運行 --fix-dry-run，再審閱邊界語句和配置兼容性。存量規則集風險爲中，建議 **migrate**。

Ant Design 6.5.4

参考来源：Ant Design 6.5.4

8 月 7 日發佈的 Ant Design 6.5.4 修復了僅傳 onClose 時 Alert 關閉按鈕隱藏、Checkbox.Group 接收空值崩潰、Table 跨頁全選錯誤選中禁用行、Transfer 過濾後取消全選，以及 RangePicker 未透傳語義回調等問題。

該版本還改善了 FloatButton 的減少動態效果和多項圖標、顏色與類型細節。使用批量表格操作、無障礙日曆或動態表單選項的應用，應覆蓋這些交互路徑後更新依賴，組件交互風險爲低，建議 **upgrade**。

文檔解析與 AI 工具

Firecrawl anydoc 与 pdf-inspector

参考来源：anydoc、pdf-inspector

8 月 3 日，Firecrawl 公开 anydoc：这是一个纯 Rust 的文档转换库，可将 Office、OpenDocument、RTF、EPUB、CSV 和文本型 PDF 统一转换为 GitHub Flavored Markdown，并提供 Node.js、Python 与 WebAssembly 绑定；它通过同团队的 pdf-inspector 处理 PDF。

pdf-inspector 會先識別文本型、掃描型、圖像型或混合 PDF，再對有文本層的頁面本地提取並生成 Markdown；掃描頁、加密文件和不受支持格式仍需交由 OCR 或異常處理鏈路。處理多格式附件、RAG 導入或 Agent 文件輸入的團隊，應以真實語料覈對結構保真度、OCR 回退與資源限制，解析質量風險爲中，建議 **verify**。

TanStack Table V9

8 月 4 日，TanStack Table V9 宣佈穩定發佈：核心改爲可 tree-shake 的插件架構，採用 TanStack Store 提供響應式狀態，並提供 10 個框架適配器；官方示例中，百萬行八列數據的堆內存從 2.71 GB 降至 380 MB。
