Anthropic 將 Claude Cowork 與聊天合併為統一的 Claude，並推出 Docs、Slides 等功能

正文

從今天起，Claude Cowork 與聊天功能將合併為一個統一的 Claude。你可以隨手拋出一個簡單問題，也可以把一份中午就要交的報告交給它，Claude 會接手處理，哪怕你已經合上筆記本電腦。未來幾周內，該功能將陸續向 Pro 和 Max 套餐用户推出，後續還會有更多套餐跟進。

Claude 創作的內容也不再需要專屬的存放空間。Claude Docs 和 Claude Slides 於今日推出，Claude Design 現在也能直接在對話中使用。想要一份文檔，你和 Claude 可以一起撰寫。想要一份演示文稿，Claude 會起草幻燈片。你可以直接編輯、從 Claude 中直接演示，或下載為 PowerPoint 或 PDF。這三項功能均處於測試階段，面向付費套餐開放，Enterprise 管理員可自行決定何時啓用。如果你單獨使用 Claude Design，它仍會像以前一樣正常工作。

我們最初把 Cowork 打造為處理更大任務的獨立空間，把 Design 打造為處理視覺工作的獨立空間。人們兩者都會用，並告訴我們，令人頭疼的地方在於判斷一項任務該歸到哪裏。而且，在一個空間裏開始的工作也無法延續到另一個空間。於是我們不再讓你做選擇。Claude 現在能夠判斷一項任務需要什麼，因此 Cowork 和 Design 能做的事，都可以在任意對話中使用，並帶上你已有的上下文、技能和連接器。

“我可以讓 Claude 調出[我的法律研究數據庫]，它會拉取所有案例、逐一閲讀、判斷我還可能需要哪些其他案例、下載它們，並存入一個文件夾供我個人審閲。”——Andrew Keller，高級經濟學家

它是什麼樣的

一份週報中午就要交。出門前，你問 Claude 上週流水線裏有什麼變動，然後補充道：“按我們一貫的寫法來寫，把任何延誤的地方標出來，再把要點做成五頁幻燈片，用於領導會議。”如果有不清楚的地方，Claude 會問你。你可以在去辦公室的路上用手機查看進度。

等你坐到辦公桌前，報告已經作為文檔等着你，裏面還有你同事的批註，幻燈片也已就緒，可以打開、調整並下載為 PowerPoint。兩者都出自同一次對話，所以幻燈片已經和報告內容一致。你自己改了一行，在某一頁幻燈片上給 Claude 留了條評論，然後分享出去。

把它設為每週一自動執行，Claude 就會在無需你開口的情況下開始寫報告。

你用 Claude Design、Slides 或 Docs 製作的任何內容，都存放在一個可分享的鏈接裏，你可以在手機上打開。你可以選中某個元素並移動它，或者直接告訴 Claude 你想改什麼。

你可以選擇 Claude 以何種方式向你彙報進度。默認情況下，Claude 會在執行操作前先詢問你。如果你更希望讓它持續工作、只在需要仔細查看時才來問你，可以開啓這一模式。最終決定權始終在你手裏。

開始使用

如果你主要用聊天，那你不必做任何改變。當你想把更大型的任務交出去時，可以試試下一份你原本要自己動手做的報告或演示文稿。如果你一直在用 Cowork，那麼一切都在你離開時的位置：你的對話、項目、artifacts、連接器和技能。打開應用後，從你上次停下的地方繼續即可。

該功能將率先面向 Pro 和 Max 套餐推出，在未來幾周內通過 Claude 網頁版、桌面端和移動端應用，向這些套餐的現有用户和新用户開放。無需開啓任何設置。Team 和 Free 套餐也將很快跟進，而對於 Enterprise 套餐，在其組織內任何變更生效前，管理員將至少提前 30 天收到我們的通知。

完整的功能列表見 幫助中心。如果你一直攢着一個龐大而雜亂的項目，現在正是時候。
