面向 Vue3 開發者的 React 快速上手系列

這是讓 Vue 開發者最有"親切感"的一篇。React 的**自定義 Hook** 和 Vue 的 **Composables** 是幾乎同一個概念——甚至連命名規範（use 前綴）都一樣！掌握它，你就掌握了 React 邏輯複用的精髓。

一、它們本質是同一個東西

一句話：**自定義 Hook 就是"把用到其他 Hook 的邏輯抽成一個 useXxx 函數"**，和你寫 Composable 的思路完全一致。

二、第一個自定義 Hook：並列對比

// useCounter.js
import { useState } from 'react'
export function useCounter(initial = 0) {
  const [count, setCount] = useState(initial)
  const increment = (setCount(c => c + 1)
  const decrement = (setCount(c => c - 1)
  const reset = (setCount(initial)
  return { count, increment, decrement, reset }

使用起來也幾乎一樣：

// React 组件里
function Counter(const { count, increment, decrement, reset } = useCounter(10)
  return (
    <div>
      <span>{count}</span>
      <button onClick={increment}>+</button>
      <button onClick={decrement}>-</button>
      <button onClick={reset}>重置</button>
    </div>
  )
}

看到沒？結構一模一樣。你寫 Composable 的所有直覺都能平移。

三、自定義 Hook 的規則（"Hook 規則"）

有兩條鐵律，違反會直接報錯（Vue Composable 沒這麼嚴格，需注意）：

- **只在顶层调用 Hook**：不能在- `if`、- `for`、嵌套函数里调用- `useState`/- `useEffect`等。

- **只在 React 函數里調用**：只能在組件或其他自定義 Hook 裏用。

// ❌ 错误：条件里调用
function Bad({ show }) {
  if (show) {
    const [x, setX] = useState(0)   // 报错！
  }
}
// ✅ 正确：顶层调用，条件写在内部
function Good({ show }) {
  const [x, setX] = useState(0)
  if (show) { /* 用 x */ }
}

原因回到第 1 篇：React 靠**調用順序**來對應每個 Hook 的內部存儲，條件調用會打亂順序。這也是爲什麼必須裝 eslint-plugin-react-hooks——它會自動幫你抓違規。

Vue 的 Composable 因为

setup只運行一次，沒有這個順序約束，可以更隨意。這是兩者少數的實質差異之一。

四、幾個實用的自定義 Hook 示例

1. `useToggle`（布尔开关）

import { useState, useCallback } from 'react'
export function useToggle(initial = false) {
  const [value, setValue] = useState(initial)
  const toggle = useCallback(() => setValue(v => !v), [])
  return [value, toggle]
}
// 用法
const [open, toggleOpen] = useToggle()

2. `useLocalStorage`（持久化状态，对标 VueUse 的 useStorage）

import { useState, useEffect } from 'react'
export function useLocalStorage(key, defaultValue) {
  const [value, setValue] = useState(() => {
    const saved = localStorage.getItem(key)
    return saved ? JSON.parse(saved) : defaultValue
  })
  useEffect(() => {
    localStorage.setItem(key, JSON.stringify(value))
  }, [key, value])
  return [value, setValue]
}
// 用法：和 useState 一样，但会自动持久化
const [theme, setTheme] = useLocalStorage('theme', 'light')

3. `useFetch`（数据请求）

import { useState, useEffect } from 'react'
export function useFetch(url) {
  const [data, setData] = useState(null)
  const [loading, setLoading] = useState(true)
  const [error, setError] = useState(null)
  useEffect(() => {
    let cancelled = false
    setLoading(true)
    fetch(url)
      .then(res => res.json())
      .then(json => { if (!cancelled) setData(json) })
      .catch(err => { if (!cancelled) setError(err) })
      .finally(() => { if (!cancelled) setLoading(false) })
    return () => { cancelled = true }
  }, [url])
  return { data, loading, error }
}
// 用法
function UserList(const { data, loading, error } = useFetch('/api/users')
  if (loading) return <Spinner />
  if (error) return <ErrorTip />
  return <ul>{data.map(u => <li key={u.id}>{u.name}</li>)}</ul>
}

4. `useWindowSize`（响应窗口尺寸）

import { useState, useEffect } from 'react'
export function useWindowSize(const [size, setSize] = useState({ width: window.innerWidth, height: window.innerHeight })
  useEffect(() => {
    const handler = (setSize({ width: window.innerWidth, height: window.innerHeight })
    window.addEventListener('resize', handler)
    return () => window.removeEventListener('resize', handler)
  }, [])
  return size
}

五、組合 Hook：Hook 裏調用 Hook

自定義 Hook 可以調用其他 Hook（包括別的自定義 Hook），層層組合，和 Composable 組合思路一致：

export function useUser(userId) {
  const { data, loading } = useFetch(`/api/users/${userId}`)  // 复用 useFetch
  const [isFollowing, toggleFollow] = useToggle(false)         // 复用 useToggle
  return { user: data, loading, isFollowing, toggleFollow }
}

六、开箱即用的 Hook 库：ReactUse / ahooks

Vue 有 **VueUse**（200+ composables），React 也有对应的：

- **ahooks**：阿里出品，中文文檔友好，國內項目常用，涵蓋請求、防抖節流、DOM、生命週期等大量 Hook。

- **ReactUse**：直接對標 VueUse 設計，API 命名都刻意向 VueUse 靠攏，VueUse 用戶上手無縫。

有了它们，useLocalStorage、useDebounce、useRequest 这些常用逻辑不用自己写。就像你在 Vue 里直接 import { useStorage } from '@vueuse/core' 一样。

// ahooks 示例
import { useRequest, useLocalStorageState, useToggle } from 'ahooks'
const { data, loading } = useRequest(fetchUsers)

七、Vue 開發者的心智遷移總結

小結

- 自定義 Hook ≈ Composable，連 `use`前綴命名都相同，是 React 邏輯複用的核心。

- 寫法直覺可從 Composable 直接平移：抽成 `useXxx`函數，內部用其他 Hook，返回狀態和方法。

- **兩條鐵律**：Hook 只在頂層調用、只在 React 函數里調用（裝 ESLint 插件保駕護航）。

- Hook 可組合、可嵌套調用其他 Hook。

- 現成生態：**ahooks / ReactUse**對標 VueUse，別重複造輪子。
