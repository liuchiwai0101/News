《紐約時報》等媒體提交簡要判決動議，援引 OpenAI 與微軟高管內部言論質疑合理使用抗辯

內容機器翻譯自第三方媒體（The Decoder），僅供參考，以原文為準。

AI 導讀

《紐約時報》、Daily News 集團、Ziff Davis 等媒體公司向紐約聯邦法院提交92頁簡要判決動議，就 AI 訓練版權侵權向 OpenAI 和微軟索賠數十億美元，並援引此前未披露的內部郵件和宣誓證詞。

由 THE DECODER 提示的 Nano Banana Pro

要點

  • 包括《紐約時報》在內的多家美國媒體公司正尋求向 OpenAI 和 Microsoft 索賠數十億美元，指控其在 AI 訓練中涉嫌侵犯版權。
  • 原告引用了內部信息和宣誓證詞，其中高管們對自身的合理使用抗辯提出質疑，並將聊天機器人描述為原創新聞業的替代品。
  • 該文件還指控 OpenAI 系統性地繞過付費牆、違反訓練數據的許可條款，並在訴訟提起後部署過濾器以壓制證據。

《紐約時報》及其他原告提交的一份新法庭文件引用了此前未披露的 OpenAI 和 Microsoft 高管內部郵件及宣誓證詞。

《紐約時報》及其他多家媒體公司已在紐約美國聯邦地區法院聯合提交了一份簡易判決書。與《紐約時報》一同加入的還有 Daily News 集團（旗下包括《芝加哥論壇報》和《丹佛郵報》），以及Ziff Davis（旗下擁有 CNET、IGN 和 PCMag）。原告還包括調查報道中心（Mother Jones 的所屬機構）以及The Intercept。

據《金融時報》報道，原告正在尋求數十億美元的損害賠償。這份長達92頁的簡報是合併多地區訴訟的一部分，該訴訟彙集了多起案件，始於2023年12月提起的《紐約時報》訴訟。

高管的內部言論削弱了合理使用抗辯

該簡報援引了在證據開示過程中披露的內部郵件、Slack 消息和宣誓證詞，其中包括削弱 AI 公司合理使用抗辯的言論。

微軟應用科學總監 Brent Hecht 稱這種做法是“一次規模空前的驚人盜竊”，可能是“人類歷史上最大的勞動力盜竊”。他還寫道，合理使用抗辯若獲成功，可以説將“徹底嘲弄‘合理使用’這一概念”。微軟對《金融時報》表示，這些評論“反映了一名員工的個人觀點”，“並非法律分析”。

美國版權局也在2025年5月得出結論，鑑於 AI 公司複製數據的規模之龐大，合理使用無法廣泛適用。負責監督該報告的官員隨後被特朗普政府解僱。

根據該簡報，OpenAI 的 ChatGPT 負責人 Nick Turley 寫道，出版商面臨“生存威脅”。他説，這些產品“在很大程度上具有替代性，就是這樣”，並且“隨着它們變得更好”，將越來越多地取代出版商提供的內容。一位 OpenAI 工程師補充説，“無論我們把鏈接展示得多麼醒目，用户都不會點擊。”

微軟 CEO Satya Nadella 在宣誓後確認，聊天機器人對話已經取代了對原始來源的訪問。在給《金融時報》的一份聲明中，微軟表示他的證詞涉及“廣泛原則以及人們查找和消費信息方式正在發生的變化”。該公司表示，這並不是對本案核心“版權問題的結論”。

一份微軟內部文件描述了一種自我強化的循環，稱之為“末日循環”。

我們的人工智能內容戰略已經啓動了一個“末日循環”，這將同時損害我們模型的性能以及整個網絡：一種終端產品威脅其關鍵供應商的經濟基礎，這是極不尋常的，但這正是我們為 LLM 業務在其“內容供應鏈”方面所創造的處境。

微軟自己的數據顯示，Copilot 上的點擊率遠低於傳統 Bing 搜索。《紐約時報》的點擊率下降了 87% 至 93%，Daily News 集團下降了 83% 至 91%，Ziff Davis 下降了 51% 至 94%。

OpenAI 在內部將本地新聞——Daily News 集團的核心業務——描述為 ChatGPT 中一個“相當常見的查詢”。其他研究也發現，聊天機器人的回答會大幅減少開放網絡的流量。

OpenAI 聯合創始人 Greg Brockman 在一封內部消息中討論了這些模型處理新聞的能力。

順便説一句，我們做新聞非常出色。每次我在《紐約時報》上做任何生成式的東西，它似乎都能相當準確地預測下一句。

付費牆繞過手段和許可限制讓 OpenAI 的辯護變得複雜

原告描述了 OpenAI 如何系統性地繞過付費牆並無視服務條款。當一名員工向 Brockman 提到“一個繞過 nytimes 付費牆的竅門”時，他回覆道“啊，不錯”。大約在 2017 年，Brockman 還寫道，他“被那海量的財富深深驅動”，他希望通過將 OpenAI 的技術商業化來賺取這些財富。

OpenAI 的企業代表作證稱，他不知道有任何方法可以檢測訓練數據中的付費牆內容，也沒有做出任何移除這類內容的努力。該公司的標準爬取流程“不包括審查網站[的]……使用或服務條款”。

Nadella 在宣誓後作證稱，“任何設有付費牆的內容，都應獲得任何想要使用它的人的授權許可。”他表示，如果他當時知道 OpenAI 抓取了付費牆內容並將其用於訓練，他會強制 OpenAI 重新訓練其模型。

OpenAI 還通過第三方獲取了“紐約時報標註語料庫”，這是一個包含 180 萬篇文章的合集。其許可證將使用範圍限制為“非商業性的語言教育、研究與技術開發”。OpenAI 員工知道使用該語料庫訓練模型“並不合適”，但仍然這樣做了。

原告指控 OpenAI 壓制證據，並對全部四項合理使用因素提出質疑

根據該簡報，訴訟提起後，OpenAI 立即構建了一個過濾器，以抑制最有可能來自原告出版物的輸出內容。未提起訴訟的公司的內容則未受影響。原告主張，該過濾器的設計目的並非保護版權，而是阻止他們收集證據。

微軟的 Hecht 曾提出擔憂，認為 OpenAI 可能會部署這樣的過濾器，並稱其為“意外的掩蓋”。他警告説，這將導致“對內容擁有權利的人對訓練所用內容的可見性降低”。即便如此，該簡報仍列舉了大量有問題的輸出示例，ChatGPT 應要求逐字複製並摘要了紐約時報的文章，包括付費牆後的文章。

原告還主張，合理使用抗辯在全部四項法定因素上均不成立。他們稱，該使用是替代性的和商業性的，而非轉換性的，而這些文章是處於版權保護核心的表達性作品。被告還複製了整部作品，儘管他們自己的專家也承認沒有任何單一作品是必需的。

關於市場損害，原告指出了現有的授權市場以及那些有可能切實發展起來的授權市場。OpenAI 和 Microsoft 已與其他出版商簽署了授權協議，Amazon、Google、Meta 和 Perplexity 也是如此。但該簡報辯稱，被告沒有為原告的內容付費，而是免費取用並在彼此之間進行交易。

一個運轉正常的授權市場會讓合理使用抗辯更難成立。當被告已經在為其他出版商的同類內容付費時，他們無法可信地聲稱授權是不可能的。

AI 花 6,800 美元就能生成一百萬篇“粉色黏液”文章

原告還質疑了 AI 模型不與出版商競爭這一論點，進一步削弱了合理使用抗辯。他們主張，OpenAI 的產品讓用户能夠向市場大量傾瀉“粉色黏液”，即低質量、往往抄襲的偽新聞。按照 OpenAI 的 API 價格，生成一百萬篇每篇 500 字的新聞風格文章大約需要 6,800 美元，且無需任何記者參與。該簡報援引了 Prism News 的案例，該公司僅用四名員工就運營了 200 個 AI 生成的出版物，冒充本地新聞編輯室和興趣網站。

OpenAI 在 2024 年宣佈了一款名為“Media Manager”的工具，本應讓出版商可以選擇退出抓取。根據該簡報，該項目此後已被擱置。

原告請求法院認定構成版權侵權並駁回合理使用抗辯。他們還希望在計算任何法定賠償時，將每篇文章視為一件獨立作品。

此前的法院裁決傾向於合理使用，而美國司法部在特朗普政府執政期間也站在了 AI 實驗室一邊。OpenAI 和 Microsoft 很可能很快就會提出自己的主張，重點圍繞合理使用及其工作的變革性。如今已進入公開記錄的內部文件，不會讓這一論點變得更容易成立。
