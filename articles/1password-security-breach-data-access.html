1Password 披露安全漏洞　部分客户姓名及電郵被存取

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

熱門密碼管理應用程式 1Password 表示，本月較早前發生安全漏洞，部分客户姓名及電郵地址被存取，但客户保險庫內容未遭入侵。11 月 19 日，1Password 發現一名員工的 GitHub 帳户有被入侵跡象，並展開調查。

被存取資料與原始碼

1Password 表示，被入侵的 GitHub 帳户曾被用於存取原始碼，並向後端服務推送惡意程式碼，該程式碼下載了部分客户資料。被存取的資料包括客户登入 1Password 時使用的姓名及電郵地址、帳户及用户識別碼、帳户建立時間及最後登入時間、公開金鑰，以及 Secure Remote Password 協定參數；1Password 強調該等參數不能用於存取帳户。

外洩資料亦包括電郵連結中的 Token，涉及邀請、帳户配置及帳户復原；其他與 1Password 內部架構相關的非機密帳户資料，例如版本編號及檔案編號；1Password 的原始碼，該公司稱不包括客户資料或用户機密；以及 1Password 的 CI/CD 系統存取權，1Password 表示該系統載有維持服務運作所需的基礎設施相關機密。

保險庫內容未受影響

1Password 表示，事件未影響其服務、可用性及產品安全。客户保險庫及其中的項目未被存取，保護保險庫的金鑰亦未被存取；攻擊者亦無法存取帳户復原金鑰、1Password 應用程式及瀏覽器擴充功能。1Password 保險庫已加密，並由用户端上的金鑰保護，因此 1Password 或任何入侵其伺服器的人都無法存取內容。

Token 風險與驗證改動

最大風險來自 Token 外洩。Token 可用於帳户復原，但只有在配合 SSO 登入，或配合發送到用户電郵地址的六位數代碼時才有效。相關代碼現已由六位數字改為 10 位英文字母及數字，以提高暴力破解難度。

GitHub 帳户停用與披露爭議

1Password 已停用受影響的 GitHub 帳户，撤銷攻擊者的 Token，並撤銷可能已外洩的內部憑證。內部 GitHub、CI/CD 及端點控制已收緊，並加入針對同類攻擊的新偵測方法。該公司表示，未發現內部證據顯示有用户帳户被接管，或有人利用外洩的帳户配置 Token 造成入侵，並已聘請獨立網絡安全專家驗證其應對措施。

Token 被存取的 1Password 用户已獲通知，但暫不清楚 1Password 是否已向所有用户發出外洩通知。1Password 的網誌以「安全事件更新」為題，但似乎未在六日前首次得悉事件時披露今次外洩。

官方提醒與用户行動

1Password 不會聯絡用户索取帳户密碼或 Secret Key，相關資料只應在官方 1Password 應用程式或官方網站輸入。該公司建議所有用户對提及 1Password 或帳户復原的電郵、短訊及電話等釣魚嘗試保持警覺。用户毋須更新或更改其 1Password 帳户內任何內容。
