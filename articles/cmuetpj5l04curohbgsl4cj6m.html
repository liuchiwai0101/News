推薦理由

原文逐條拆解 Kimi K3 許可證的授權與規模化門檻，並給出 OpenRouter 調用參數和各家定價，讀者可據此決定自部署還是走 API。

正文

Kimi K3 是開放權重，而非開源。Moonshot AI 在 Hugging Face 上以 moonshotai/Kimi-K3 發佈了該 checkpoint，採用 Kimi K3 License，這是一份自定義許可證，沒有 SPDX 標識符，也不在 Open Source Initiative 批准列表中。Hugging Face 模型卡將 license 字段設置為 other，名稱為 kimi-k3。如果你想通過 API 調用該模型，而不是自己運行權重，我們以 moonshotai/kimi-k3 提供該模型。

本文介紹該許可證授予和要求的權利、該 checkpoint 包含的內容，以及如何在 OpenRouter 上調用該模型。

摘要

  • Kimi K3 是開放權重。權重是公開的，但 Kimi K3 License 是 Moonshot AI 自己的文本，並未獲得 OSI 批准。
  • 該許可證默認授予使用、修改、分發和銷售的權利。它在規模化使用時增加了兩個條件：Model as a Service 收入門檻，以及用户界面署名要求。
  • 該 checkpoint 是一個 2.8 萬億參數的混合專家模型，每個 token 激活 1040 億參數，以 MXFP4 存儲。
  • 在 OpenRouter 上，模型 ID 是 moonshotai/kimi-k3。它接受文本、圖像和視頻輸入，擁有 1,048,576 token 的上下文窗口，並支持推理強度、工具調用和結構化輸出。沒有 :free 變體。

開放權重與開源

這兩個術語回答的是不同的問題。

開放權重意味着發佈方公開了訓練好的參數，你可以下載並查看它們。附加在這些參數上的許可證可以是發佈方自行撰寫的任何文本。

開源，按照 Open Source Initiative 對該術語的用法，意味着許可證符合 Open Source Definition 並出現在 OSI approved list 上。像 Apache-2.0 和 MIT 這樣的許可證擁有 SPDX 標識符，並且在該列表上。

Kimi K3 符合第一個定義，但不符合第二個。

Kimi K3 License 授予了什麼

許可證文本將本軟件定義為模型權重、參數、配置文件、推理與訓練代碼以及相關文檔。它免費授予使用、複製、修改、合併、發佈、分發、再許可和銷售本軟件副本的權利，以及運行、部署、微調本軟件並基於其創建衍生作品的權利。

第 1 節設定了兩項基本條件。你必須在軟件的所有副本或實質性部分中包含版權聲明和許可聲明，並且你的使用必須遵守適用的法律法規。

Kimi K3 License 在大規模使用時的要求

在特定閾值之上還適用另外兩項條件。

模型即服務門檻。第 2 條將模型即服務定義為：向第三方提供對語言模型推理或微調的訪問權限，例如通過 API，且其方式使第三方能夠對輸入、參數或訓練數據行使實質性控制。該定義不包括將模型能力嵌入特定功能或框架之中的終端用户產品，也不包括將請求轉發至他人託管的模型。如果你或你的任何關聯方經營模型即服務業務，且你的合計收入在任何連續 12 個月內超過 2000 萬美元，那麼在為任何商業目的使用本軟件或其衍生作品之前，你必須與 Moonshot AI 簽訂單獨協議。

用户界面署名。第 3 條適用於以下情形：本軟件或衍生作品被用於月活躍用户超過 1 億或月收入超過 2000 萬美元的商業產品或服務。在此情況下，該產品必須在其用户界面上顯著展示“Kimi K3”。

豁免。第 4 條將兩種情形豁免於上述兩項條件之外。第一種是內部使用，定義為不向第三方提供本軟件、其輸出或其底層能力的用途。第二種是通過 Moonshot AI 的官方產品或認證推理合作伙伴進行訪問。

第 5 條是保證免責聲明。本軟件及其輸出按現狀提供，不附帶任何形式的保證。

在基於這些權重發布產品之前，請先閲讀許可證。本文描述的是截至 2026-09-11 發佈的文本，不構成法律建議。

模型卡將 Kimi K3 描述為一個原生多模態模型，能夠理解文本、圖像和視頻。模型卡列出思考始終啓用，並帶有一個 reasoning_effort 字段，該字段接受 low、high 和 max，默認為 max。對於多輪對話和工具調用，模型卡指出，API 返回的完整助手消息，包括推理內容和工具調用，必須回傳至 messages。

定價

我們不為該模型設定統一價格。每個提供商端點都會列出自己的提示詞、補全和緩存讀取價格，模型頁面會顯示當前的價格表。2026-09-11 時，目錄中有 19 個端點用於 moonshotai/kimi-k3。提示詞價格從每百萬 token $1.80 到 $6.00 不等，補全價格從每百萬 token $9.01 到 $22.50 不等，緩存讀取價格從每百萬 token $0.21 到 $0.60 不等。Moonshot AI 自己的端點列出的是 $3.00 提示詞、$15.00 補全和 $0.30 緩存讀取。最大輸出長度也因端點而異，從 16,384 token 到 943,718 token 不等。

提供商端點所支持的參數也各不相同。2026-09-11 時，有兩個端點未列出 tools，有兩個未列出 structured_outputs。如果你的請求依賴某個參數，請將 provider.require_parameters 設為 true，這樣我們就只會路由到支持該請求中所有參數的端點。完整的路由控制項請參見 提供商選擇。

推理

Kimi K3 默認返回推理內容。通過我們的 API，你可以使用 reasoning 對象來控制它。reasoning.effort 對該模型接受 low、high 和 max。將 reasoning.exclude 設為 true 會從響應中移除推理文本，而模型仍會進行推理。將 reasoning.enabled 設為 false 會要求端點跳過推理。

我們於 2026-09-11 針對 moonshotai/kimi-k3 將每種配置各運行了一次，使用了一個簡短的算術提示詞。默認請求、low 和 max 請求各自返回了一個 reasoning 字段，以及一條帶有答案的 reasoning_details 條目。exclude 請求返回了答案，但沒有推理字段。enabled: false 請求沒有返回推理字段，而是返回了一個更長的答案，在 content 字段中展示了其推理過程。模型卡稱思考始終處於啓用狀態，而單次調用無法表明該端點究竟是停止了內部推理，還是僅僅停止了返回推理內容。請將 enabled: false 視為對該端點的一項請求，而非一種保證。

對於多輪對話和工具調用，請將完整的 assistant 消息傳回 messages，其中包括 reasoning_details 和 tool_calls。我們的推理指南涵蓋了 跨輪次保留推理。

帶圖片的示例請求

該請求發送一張圖片和一個問題，要求 high 推理強度，並打印答案。它使用 TypeScript SDK。

import { OpenRouter } from '@openrouter/sdk';

const openRouter = new OpenRouter({
  apiKey: process.env.OPENROUTER_API_KEY ?? '',
});

const result = await openRouter.chat.send({
  chatRequest: {
    model: 'moonshotai/kimi-k3',
    messages: [
      {
        role: 'user',
        content: [
          {
            type: 'image_url',
            imageUrl: { url: 'https://example.com/screenshot.png' },
          },
          {
            type: 'text',
            text: 'Summarize this screenshot and list the open questions.',
          },
        ],
      },
    ],
    reasoning: {
      effort: 'high',
    },
    stream: false,
  },
});

if (result instanceof ReadableStream) {
  throw new Error('Expected a non-streaming response');
}

console.log(result.choices[0].message.content);

我們於 2026-09-11 使用一張公開照片運行了一個等效請求。該端點返回了對該圖片的一句話描述、一個 reasoning 字段，以及一個 usage 對象，其中包含 96 個 prompt tokens、119 個 completion tokens 和 87 個 reasoning tokens。圖片輸入在 圖像理解中有所介紹，視頻輸入則在 視頻輸入中有所介紹。

工具調用與結構化輸出

模型記錄列出了 tools、tool_choice、response_format 和 structured_outputs。工具定義遵循 工具調用中的形式。JSON Schema 響應遵循 結構化輸出。由於對這些參數的支持因端點而異，當請求依賴這些參數時，請將 provider.require_parameters 設置為 true。

提示詞緩存

2026-09-11 時，每個 moonshotai/kimi-k3 端點都列出了緩存讀取價格。當請求命中提供商的提示詞緩存時，緩存的提示詞 token 將按該端點的緩存讀取費率計費，而非其提示詞費率，並且響應會在 usage.prompt_tokens_details.cached_tokens 中報告這些 token。關於各提供商的緩存機制，請參見 提示詞緩存。

Kimi 早期版本

Kimi K2 和 Kimi K2.5 採用修改版 MIT 許可證。兩者都在 MIT 基礎上增加了一條條款，要求月活躍用户超過 1 億或月收入超過 2000 萬美元的商業產品，必須在用户界面上顯著展示模型名稱。Kimi K3 許可證保留了該署名條款，並新增了模型即服務收入門檻。

我們的目錄還列出了 moonshotai/kimi-k2.6、moonshotai/kimi-k2.7-code、moonshotai/kimi-k2.5、moonshotai/kimi-k2-thinking 和 moonshotai/kimi-k2。本文僅介紹 Kimi K3。

常見問題

Kimi K3 是開源的嗎？

不是。Kimi K3 是開放權重的。Moonshot AI 在 Hugging Face 上以 Kimi K3 License 發佈了權重，這是一份自定義許可證，不在 Open Source Initiative 批准列表之中。該許可證授予使用、修改、分發和銷售該模型的廣泛權利，但附帶兩項在營收和用户數閾值上生效的條件。

Kimi K3 License 允許什麼？

該許可證授予使用、複製、修改、合併、發佈、分發、再許可和銷售該模型副本的權利，以及運行、部署、微調和創建衍生作品的權利。你必須在該軟件副本中保留版權和許可聲明，並遵守適用法律。

Kimi K3 License 增加了哪些條件？

兩項。如果你或你的關聯方經營 Model as a Service 業務，且在任何連續 12 個月內的合計營收超過 2000 萬美元，則你在商業使用前需要與 Moonshot AI 另行簽訂協議。如果基於該模型構建的商業產品月活躍用户超過 1 億，或月營收超過 2000 萬美元，其用户界面必須顯著展示 Kimi K3。內部使用以及通過 Moonshot AI 官方產品或認證推理合作伙伴進行的訪問，均不受這兩項條件約束。

我可以下載 Kimi K3 的權重嗎？

是的。該 checkpoint 已發佈在 Hugging Face 上的 moonshotai/Kimi-K3。這是一個 2.8 萬億參數的混合專家模型，以 MXFP4 格式存儲，每個 token 激活 1040 億參數。

如何在 OpenRouter 上調用 Kimi K3？

向 https://openrouter.ai/api/v1/chat/completions 發送一個 chat completion 請求，模型 ID 為 moonshotai/kimi-k3。該端點接受文本、圖像和視頻輸入，返回文本，並支持 reasoning、tools 以及結構化輸出參數。

OpenRouter 上有 Kimi K3 的免費版本嗎？

沒有。目錄中列出了 moonshotai/kimi-k3 以及 Batch API 的單獨 moonshotai/kimi-k3:batch 條目。兩者都不是免費的。定價由各提供商設定，因此請查看 模型頁面以瞭解當前費率。
