**詳細解讀**：

**一句话摘要**：CSS-Tricks 报道，`sibling-index()` 和 `sibling-count()` 函数即将纳入 Web Baseline，配合 `@starting-style` 可实现无需 JavaScript 的列表交错入场动画。

**詳細解讀**：

過去實現列表項的交錯動畫（stagger animation），開發者通常需要藉助 JS 給每個元素動態計算 animation-delay，或者使用預處理器生成大量 nth-child 規則。CSS 新增的 sibling-index() 函數可以直接在樣式表中獲取元素在兄弟節點中的位置（從 1 開始計數），徹底簡化這一模式。

li {
  transition: opacity 0.3s ease;
  transition-delay: calc((sibling-index() - 1) * 100ms);
  
  @starting-style {
    opacity: 0;
  }
}

上述代碼即可實現列表項依次淡入的效果，無需任何 JS。sibling-count() 則可獲取兄弟節點總數，常用於計算中間元素的精確居中或對稱佈局。這兩個函數已在穩定版 Chrome 和 Safari 中可用，納入 Baseline 意味着跨瀏覽器支持即將統一。

**開發者建議**：

- 在支持 `sibling-index()`的瀏覽器中，可以逐步替換舊的 JS 交錯動畫方案，減少運行時開銷。

- 配合 `@starting-style`和`transition-behavior: allow-discrete`使用，可以实现`display: none`到`display: block`的平滑过渡——这是 2026 年 CSS 动画最值得掌握的"三件套"。

- 生產環境建議做好 `@supports`回退，或將其作爲漸進增強。
