Anthropic 推出 Claude 背景電腦操作　Mac 用戶實現多工處理

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

Anthropic 今日宣佈，其 AI 助理 Claude 已在 macOS 平台推出背景電腦操作功能。這項更新主要適用於 Claude Code 及 Claude Cowork，並僅向 Pro 和 Max 訂閱客戶開放。雖然桌面版 Claude 的電腦操作功能並非全新技術，但支援在後台執行是一項顯著的改進，讓用戶能更靈活地運用 AI 協助工作。

後台自動化提升效率

用戶可指派任務給 Claude，讓其在後台自動執行點擊、輸入文字及開啟應用程式等操作，同時用戶可繼續處理其他事務。這種模式解決了傳統 AI 代理需佔用滑鼠游標的限制，大幅提升了 Mac 上的多工處理能力。此前，OpenAI 已在其 ChatGPT Mac 應用中引入類似功能，Anthropic 此次跟進顯示出業界對無縫整合人機協作流程的重視。

限定高級訂閱用戶

目前，此背景操作功能僅限於使用 Claude Code 或 Claude Cowork 的高級訂閱者。對於希望在不中斷自身工作流程的情況下，讓 AI 處理重複性或耗時任務的專業人士而言，這提供了更具實用的解決方案。隨著人工智能技術在個人電腦端的滲透，減少用戶對界面的直接干擾將成為未來發展的重要趨勢。
