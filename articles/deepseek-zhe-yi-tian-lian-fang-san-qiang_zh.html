DeepSeek 這一天連放三槍：V4 Flash 開源登頂、Agent 越級，還順手回答了一個敏感問題

7 月 31 日這天，DeepSeek 沒怎麼聲張，但一天之內把三件事都辦了。

第一件，深夜放出 V4 Flash 0731 的模型權重——MIT 協議、隨便商用，在 Artificial Analysis 的智能指數上拿了 50 分，擠進開源模型前三。第二件，V4 Flash 的官方 API 開啓公測，Agent 能力大幅升級，跑分全面超過了自家更重的 V4-Pro-Preview。第三件稍微有點意外：美國一家做金融 AI 的公司 CTGT，用 V4 Flash 當"老師"去蒸餾一個美國開源模型，寫了一份實驗報告，結論是——能力能學過來，但老師那套"審查"行爲，沒跟過來。

三件事單獨拎出來都夠發一條新聞，湊在同一天，值得好好聊聊。

一、開源這一槍：167GB、13B 激活、MIT 協議

先說深夜這條。知名模型評測機構 Artificial Analysis 發推確認：DeepSeek V4 Flash 0731 正式開放權重。

幾個關鍵數字記一下：總參數 284B，激活參數只有 13B；以 FP4/FP8 混合精度發佈，整個文件大約 167GB；在 Artificial Analysis Intelligence Index 上得分 50，位列開放權重模型前三。

這裏有個細節容易被忽略——它落在 Artificial Analysis 評出的"智能指數 vs 總參數"帕累託前沿（Pareto frontier）上。翻譯成人話就是：在同等參數規模下，它的智能水平是目前你能找到的最優解之一，沒有明顯浪費。Artificial Analysis 的原話是"在同體量開放權重模型中，它實現了智能水平的一次顯著飛躍"。

更關鍵的是許可證。MIT，幾乎是最寬鬆的開源協議之一——你可以隨便用、隨便改、隨便拿去賺錢，連署名要求都很低。對於有自己顯卡、想自己部署的團隊來說，這個比"50 分"本身更值錢。

X 上有條熱評挺到位的，來自用戶 Chahat Sharma，大意是：這個 license 纔是真正的故事，而不是那個 50 分。一個 flash 檔位、這麼便宜的模型，還開放權重，等於把"按 token 計費"這個說法對任何有自己硬件的人直接廢掉了。分數只是告訴你，它值得你自己去跑。

另一條來自 @TabDuoBao 的評論抓住了模型的本質：13B 激活纔是重點——13B 的服務成本，前沿的跑分。如果 50 分這個成績在 3-bit、110GB 量化後還能穩住，那真正的競爭維度就不是"誰更強"，而是"每 GB 能換多少智能"。

順便說一句，DeepSeek 官方也出來澄清了一個容易混淆的點：V4 Flash 0731 的模型結構和尺寸，和之前的 V4 Flash 預覽版完全一致，這次只是重新做了後訓練（post-training）。定價也保持不變。

二、API 這一槍：Agent 跑分全面越級

就在同一天白天，DeepSeek-V4-Flash 的官方 API 正式開啓公測，模型名設爲 deepseek-v4-flash 即可調用，調用方式不變。

但真正炸場的是 Agent 能力。DeepSeek 官方說得很直白：基準測試分數"遠超"自家更重的 V4-Pro-Preview。一個 flash（輕量）檔位的模型，跑分壓過了 pro（專業）檔，這本身就是個反直覺的事。

看具體分數更有感覺（來自 DeepSeek 官方 API 文檔）：

- Terminal Bench 2.1：82.7

- NL2Repo：54.2

- Cybergym：76.7

- DeepSWE：54.4

- Toolathlon verified：70.3

- Agent Last Exam：25.2

- Automation Bench（Public）：25.1

- DSBench-FullStack：68.7

- DSBench-Hard：59.6

這裏面 Terminal Bench、DeepSWE、DSBench 都是考覈模型當"代碼 Agent"——也就是能不能自己去操作終端、改代碼、完成多步驟軟件工程任務。V4 Flash 在這些項目上的表現，已經超過了自家定位更高的 V4-Pro 預覽版。

還有一個對開發者很友好的變化：正式版 V4 Flash 原生支持 OpenAI 的 Responses API 格式，並且專門適配了 Codex。這意味着什麼？意味着你原來基於 OpenAI 生態寫的 Agent 代碼、用的 Codex 工作流，可以相對平滑地切到 DeepSeek 上，不用把整套調用邏輯推倒重來。

DeepSeek 也在公告裏留了個尾巴：本次只升級了 V4 Flash 的 API，V4-Pro 的 API 和 App/Web 端模型暫時沒動，V4-Pro 正式版"會盡快發佈"。考慮到連 Flash 都這水平了，V4-Pro 正式版會強成什麼樣，Unsloth 的反應大概能代表不少人的心態——"Flash 都已經這麼強、這麼小了，那 Pro 會是什麼樣？"

三、最有意思的一槍：審查能"教會"學生嗎？

前兩件事是 DeepSeek 自己的官方動作。第三件事來自第三方，但可能爭議最大、信息量也最大。

美國一家專注於金融領域的 AI 公司 CTGT，在 7 月底發表了一篇研究，標題叫《What a Distilled Model Inherits From Its Teacher》（蒸餾模型從它的老師那裏繼承了什麼），作者是 Johnny Yu、Siddarth Mamidanna 和 Cyril Gorlla。

背景是這樣的：中國的前沿模型（包括 DeepSeek 的 R1 和 V3、V4 系列）在涉及中國敏感話題時，會明顯地迴避、改寫，這是各種審計報告早就記錄在案的事。而美國開發者和企業又大量使用這些中國開源模型來蒸餾（distill）——也就是用大模型的輸出去訓練自己的小模型，藉此提升能力。

於是華盛頓和受監管行業一直有個擔憂：如果用中國模型當老師，那老師那套"價值觀"和"審查"會不會順着能力一起，傳染給學生模型？

CTGT 決定在受控條件下認真測一把。他們用的"老師"正是 DeepSeek V4 Flash，"學生"是美國開源模型 GPT-OSS-120B，任務是金融推理。

他們先確認老師確實有審查。方法很巧妙——用"配對"問題（matched pairs）。比如同樣問一場饑荒的成因，問"大躍進"時，模型會搬出"自然災害、農業管理失誤"，拒絕給出死亡人數，還順帶誇一下政府後來的糧食安全承諾；但問發生在蘇聯的"Holodomor"時，它卻能點名斯大林、強制集體化、給出三四百萬死亡的數字。明明兩件事都被廣泛認爲是國家行爲導致的饑荒，前者卻被"洗白"了。

這種配對設計是爲了把"模型對所有敏感話題都回避"和"模型只對一個國家的敏感話題迴避"區分開。他們做了 152 對這樣的問題，每對裏一個是"敏感版"，一個是結構相同但非中國的"對照版"，主題覆蓋：天安門 vs 光州、新疆勞動力轉移 vs 烏茲別克斯坦棉花、中國中國中國中國中國中國中國中國中國中國中國中國中國中國中國中國中國中國中國中國中國中國中國台灣 vs 科索索沃、河南村鎮銀行凍結 vs 塞浦路斯銀行救助等。

打分用的是四個來自四家不同美國前沿實驗室的模型當評委：xAI 的 Grok 4.20、Google 的 Gemini 3.5 Flash、OpenAI 的 GPT-5 Mini、Anthropic 的 Claude Sonnet 4.6。這套評委先跟 96 條人工打分對照校準，皮爾遜相關係數達到 0.948，平均絕對誤差 6.08 分，81.3% 的回答與人工分數相差不到 10 分——可以說比較可信了。

結果很清楚：在 76 對核心政治問題上，DeepSeek V4 Flash 的"審查差值"是 +45.45（敏感版比對照版更傾向審查），87% 的配對都呈正向審查。把 152 對全部加總，差值是 +32.02，正向比例 79%，大約七個標準差，統計上極顯著（p<0.0001）。

那蒸餾之後的學生呢？用 DeepSeek V4 Flash 教出來的 GPT-OSS-120B，審查差值只有 -1.39；自己教自己的版本是 +0.26；連沒動過的原版基礎模型也才 +0.43。三者之間相差不到一個百分點，和原版基線在統計上沒有顯著差異。

換句話說：**政治審查沒有傳遞過來。**

更有意思的是，連"老師"本身可能都不是必需的。他們還做了個對照：讓模型自己給自己當老師（self-distillation）——把模型做錯的題定位到出錯的步驟，在那個位置注入一個簡短提示，讓模型自己繼續往下寫，再用反向 KL 目標訓練。結果自己教自己的版本，成績和 DeepSeek 教出來的版本在每個隨機種子上都沒有顯著差異。

最終交付的那個 120B 模型，在金融推理基準 FinanceReasoning 上（8K token 預算）拿到 83.61%，高於 Kimi K3 的 81.93% 和 Inkling 的 65.13%，而單次查詢成本只有 Inkling 的 1/62、Kimi K3 的 1/160。

CTGT 把整個評測工具包 LineageEval（304 條提示詞、配對構造、評分標準和代碼）、20B 金融模型權重都開源了。當然他們也誠實地說了侷限：這次學生是美國的 GPT-OSS，老師和學生沒有共享初始化，訓練數據裏完全沒有中國敏感內容；而"審查最容易傳遞"的場景——用中國底座（比如 Qwen）去蒸餾中國老師——他們還沒測，那是下一步。

這一天，對開發者意味着什麼

把三件事放一起看，畫面挺有意思。

對普通開發者，最直接的收益是：現在你有一個 13B 激活、MIT 協議、智能指數進開源前三、Agent 能力壓過自家 pro 檔、還原生兼容 OpenAI Responses API 的模型可以用了。要 API 有 API，要自己部署有完整權重，167GB 的體量在量化之後能塞進消費級到企業級的卡里。這種"魚和熊掌"在過去往往是分開賣的。

對做 Agent、做代碼工具的團隊，V4 Flash 這次在 Terminal Bench、DeepSWE、DSBench 這些工程化基準上的表現，說明它已經不是一個"能聊天的模型"，而是一個"能幹活的模型"了。結合 Codex 適配，把它接進現有 OpenAI 生態的成本被壓到了很低。

對那些一直糾結"用中國模型會不會被審查污染"的企業，CTGT 這份報告至少提供了一個有數據支撐的初步答案：在一個受控的金融蒸餾場景裏，老師的政治立場沒有跟着能力一起傳過來。當然，這只是個開頭，不是蓋棺定論——共享初始化的情況、安全訓練（而非政治審查）的傳遞性，都還沒測。但至少，"蒸餾 = 必然被洗腦"這個想當然的結論，現在站不住腳了。

而如果你把 CTGT 那個"自己教自己"的結果也考慮進來，一個更實際的問題浮出水面：在垂直領域，你可能壓根不需要一個前沿老師。一個調教得當的 120B，加上一塊 H100，在受限的 token 預算下，能打過那個會在中途截斷的 2.8 萬億參數巨獸。"按預算算，一個能跑完的 120B，比一個會截斷的巨型模型更值錢"——這句話可能比當天任何一個跑分都更值得記下來。

DeepSeek 沒開發佈會，但這三槍放完，開源社區、API 用戶、還有大洋彼岸那些盯着"模型血統"的監管者，大概都得重新算算賬了。
