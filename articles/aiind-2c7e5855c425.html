傳微軟AI Frontiers部門併回Microsoft AI，主管離職

內容機器翻譯自第三方媒體（iThome · unwire PRO），僅供參考，以原文為準。

正文

Microsoft 據報決定不續簽 2023 年向 Oracle 租用 AI 算力的合約，過去幾個月已逐步關閉部分租用伺服器。據知情人士透露，原因是這批伺服器採用的舊一代 Nvidia GPU，已不符合 Microsoft 改變後的技術規格。對租用算力的企業來説，原本合用的硬件，可能因用户的技術要求改變而不再合適。

Microsoft 不續簽 Oracle 租約：舊 GPU 不合規格 Microsoft 不續簽 Oracle 租約，據 Bloomberg 引述知情人士報道，是因為 Microsoft 的技術要求改變後，Oracle 伺服器使用的舊一代 Nvidia GPU 已不符合其規格，對 Microsoft 的用處愈來愈小。Microsoft 過去幾個月已逐步關閉部分向 Oracle 租用的算力，公司拒絕評論事件。

雙方於 2023 年底公佈原有協議，Oracle 讓 Microsoft 使用其雲端平台 Oracle Cloud Infrastructure 的伺服器，配合 Microsoft 自家的 Azure，支援加入 AI 功能的 Bing 搜尋。當時 AI 算力短缺，外界視這份協議為大型科技公司向對手租用算力的例子；雙方沒有公開合約金額。

Oracle：舊 GPU 需求仍強，續租價高約 20% Oracle 表示市場對其 AI 基礎設施的需求仍然強勁，包括舊一代 GPU。公司早前亦稱，正以比原合約價高約 20% 的價錢，續租已使用約 4 年的 GPU 算力。

舊 GPU 不符合 Microsoft 的規格，未必代表其他用户用不上；不同工作負載對硬件的要求可以不同。Oracle 股價在消息傳出後於美國股市盤中一度跌約 5%。

Microsoft 逾 800 億美元租算力：多項目退出或不擴建 Microsoft 已承諾投入超過 800 億美元（約港幣 6,240 億元），向新興雲端算力服務商 CoreWeave、Nscale 及 Nebius 等租用算力。據報部分高層不滿其中一些合作成本高、交付延誤，Microsoft 已加強監督數據中心項目、退出公司認為風險較高的項目，並在內部討論是否簽訂更多同類合約。

Microsoft 對雲端算力服務商 Nscale 的安排亦有調整：公司沒有行使德州數據中心的擴建選擇權，但現有合約繼續；在西維珍尼亞州，Microsoft 則退出租用 1.35 GW 容量的意向書。公司亦於 10 月退出英國 Loughton 約 30 億美元（約港幣 234 億元）的協議，據報電網方面表示要到 2030 年代才有電力供應；Nscale 表示仍會推進該項目。

Microsoft 財務總監 Amy Hood 曾多次在業績會上提到，第三方算力交付延誤影響公司的資本開支計劃。據報 Microsoft 亦愈來愈傾向派員到合作夥伴的數據中心工地，檢查工程進度及是否符合技術規格和監管要求。

租 GPU 算力：規格、交付及電力都要寫進合約 租用 GPU 算力時，企業除了考慮價格，也可把硬件規格、交付時間及電力供應納入合約安排。Microsoft 不續租 Oracle 算力的個案顯示，硬件是否合用取決於用户的技術要求；企業可在簽約前寫清所需規格，並考慮合約年期與硬件更新週期的配合，以及瞭解合約期內可否升級硬件。

交付方面，企業可訂明時間表和驗收規格，並跟進電力供應安排。至於舊一代 GPU，可按工作負載的要求評估是否繼續使用，而非一律淘汰。

對負責規劃算力的團隊而言，合約需要回答的問題是：當工作負載或硬件要求改變時，現有安排還有多少調整空間。
