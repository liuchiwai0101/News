ChatGPT 現在可生成動態 GIF　GPT Images 2.6 加快圖像生成

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

ChatGPT 現已可將文字提示及照片轉為動態 GIF，這項更新基於 OpenAI 新推出的 Images 2.6 模型，正向所有 ChatGPT 及 Codex 用户推送，涵蓋網頁、桌面及流動應用程式。

文字或照片生成 GIF

用户可從文字提示或上載的照片生成 GIF，再調整動畫速度或編輯個別影格。OpenAI 以「Can you make a gif of a cat dancing?」為例，展示該提示如何產生多個略有差異的角色版本，再以翻頁書方式串連成 GIF。該模型的圖像一致性似乎足以讓角色在每個影格中保持可辨識，而較早的模型可能在影格之間大幅改變外觀，令這種效果難以實現。

圖像生成加速與開發者 API

除了 GIF 功能，Images 2.6 亦旨在加快整體圖像生成速度。OpenAI 同時為開發者發佈 API 模型 GPT-Image-2.6「Flare」，主打高效，以及「Sunburst」，主打更高品質的圖像生成。兩款模型變體最初隨 Image 2.5 推出。OpenAI 表示，用户目前透過 ChatGPT 及 API 每週生成超過 40 億張圖像，較 9 月多 10 億張。
