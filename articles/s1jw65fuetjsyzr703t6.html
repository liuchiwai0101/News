HeroUI v3 正式发布：基于 Tailwind CSS v4 重写

HeroUI（前身爲 NextUI）是一款 React 組件庫，現在已發佈 HeroUI v3 版本。該版本經過了徹底的重寫，開發團隊將其定位爲適用於 Web 和原生應用的統一設計系統。這個於 2026 年 3 月發佈的版本包含超過 75 個 Web 組件（其中 21 個爲新增組件），同時還提供了一個從零開始構建的全新的 React Native 庫，內含 37 個組件。

HeroUI v3 基於 React Aria Components 實現了無障礙功能，並採用 Tailwind CSS v4 進行了樣式設計，同時爲方便自定義，提供了 CSS 變量、OKLCH 顏色和 BEM 修飾符。所有動畫均已遷移至 CSS，不需要 JavaScript 運行時支持。該庫採用了複合組件 API，摒棄了舊版的 provider 包裝器，並且可完美兼容 React 19 和 Next.js 。

這次重寫還大量採用了 AI 輔助開發，並提供了 MCP 服務器、Agent Skills 以及 llms.txt 文件，從而使編碼助手能夠直接讀取組件文檔。此外，本次重寫還提供了一個與組件完全一致的 Figma Kit v3。

目前在 npm 上，核心包 @heroui/react 的每週下載量約爲 341000 次，獨立的 heroui-native 包每週新增下載量約 11000 次，其 GitHub 存儲庫的星標數已接近 27700 個。

自 3.0 版本以來，該組件庫已經發布了多個小版本更新。v3.0.3 版本將 React Aria Components 升級至 1.17.0，並且爲了加快安裝速度，移除了約 90% 的傳遞依賴項，同時還新增了一個排版組件。5 月下旬發佈的 v3.1.0 版本新增了中文文檔，擴展了柔和色彩 Token，引入了可共享的主題滾動條系統，並修復了 useTheme 的 SSR 問題。v3.2.0 版本於 2026 年 6 月 16 日發佈，作爲當前的主線版本，官方承諾將按月發佈小版本。

在 Reddit 上，一位 NextUI 和 v2 的長期用戶發帖稱讚了主題頁面和文檔，但也遺憾地表示，v3 中的輸入標籤動畫、預置單元和自動補全這三項功能“全都不見了”：

我剛剛開始在一個新項目中使用 v3 。主題頁面很漂亮，文檔也一如既往地精準到位，但我總能發現一些我在 v2 中非常喜歡的功能在這個版本中沒有了……輸入框標籤的動畫選項、將單元預置到標籤中的功能、自動補全功能……全都不見了。

在 GitHub 上，開發者們針對路線圖以及導航欄（Navbar）等缺失的功能提出了質疑，其中一位評論者指出：“項目時間表確實缺乏透明度。”

從 v2 遷移的團隊應該仔細規劃，因爲 v2 和 v3 無法在同一個項目中共存。官方遷移指南提供了全量遷移和增量遷移兩種路徑，並由專用的遷移 MCP 服務器提供支持。此外，有些組件（如 Image）已經被完全移除，轉而使用原生元素進行了替代。

HeroUI 是一個由 Junior García 創建、獲得 Y Combinator 支持的、可用於生產環境的開源 React 和 React Native 組件庫，遵循 Apache 2.0 許可。感興趣的讀者可以在 GitHub 上查閱完整的發佈說明。
