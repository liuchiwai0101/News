OpenAI 在 ChatGPT Work 中推出 Data agent

內容機器翻譯自第三方媒體（OpenAI），僅供參考，以原文為準。

AI 導讀

OpenAI 在 ChatGPT Work 中推出新的 Data agent，用户用自然語言即可連接公司數據、分析變化並生成可分享的交互式儀表盤。

推薦理由

官方公佈了數據源和 BI 工具接入範圍及權限管控方式，讀者可據此評估它在自有數據工作流中的落地路徑。

正文

認識一下 ChatGPT Work 中全新的 Data agent：只需提問，就能把公司數據轉化為答案、交互式儀表盤和行動。

各行各業的人都有數據能夠回答的問題。銷售為什麼放緩了？哪裏的支出在上升？哪些問題會威脅到我們最大客户的續約，我們應該優先解決什麼？想要得到這些答案，往往意味着要等一份報告，或者請別人來做分析。

我們推出全新的 ChatGPT Work 中的 Data agent⁠ ，幫助更多人自己回答這些問題。它會連接你的公司數據，調查發生了什麼變化，並構建你可以分享的交互式儀表盤。在一次對話中直接指導並細化分析，無需編寫查詢語句，也無需學習新的分析工具。

連接你的業務所信任的公司數據和上下文

Data agent 可連接已獲批准的數據源，包括 Amazon Redshift、Datadog、Google BigQuery、ClickHouse、Databricks、MongoDB、Snowflake 等。它還能將 Google Drive 和 SharePoint 中的文件和文檔納入分析。

它使用你所在組織的業務術語、指標定義、自定義計算和數據關係來解讀數據。這些上下文來自語義層和可信來源，例如 Databricks Genie Ontology、dbt、GitHub、Snowflake Horizon 和 BI 儀表盤。

把問題轉化為分析與行動

提出後續問題以深入探究結果，並查看每項發現背後的證據。

將分析轉化為帶有內置可視化的交互式儀錶板。你的團隊可以按需編輯、分享和刷新它。分享你的品牌指南，讓輸出契合你所在組織的視覺風格。

Data agent 還可以在 Omni、Oracle BI、Power BI、Sigma、Tableau 和 ThoughtSpot 中構建儀錶板並與之交互。用自然語言在團隊已經在使用的工具中直接下達工作指令。

開始使用 Data agent

你會在 ChatGPT Work 的插件目錄中看到 Data agent 以 Data⁠ 的形式列出。管理員可以通過 Workspace settings > Plugins 將其開放給團隊使用或為團隊安裝。他們還可以啓用並配置相關的數據源插件，例如 Databricks 和 Snowflake，並管理誰可以使用它們。

如果 Data 尚未安裝，請在插件目錄中找到它並選擇 Install plugin，或直接前往 Data 列表頁⁠ 。完成所需的賬户連接步驟，然後與 @Data 開始對話並提出你的業務問題。
