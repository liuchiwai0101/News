Windows XP 密鑰 FCKGW 外洩之謎　退休工程師道出來龍去脈

內容機器翻譯自第三方媒體（Yahoo 新聞），僅供參考，以原文為準。

重點內容

FCKGW-RHQQ2-YXRKT-8TG6W-2B7Q8 這串字符，對 2000 年代初中期曾經接觸 PC 的人來説並不陌生。它既不是咒語，也不是秘密組織的密碼，而是 Windows XP 最廣為人知的產品密鑰：只要輸入這串字符，再配上一張光碟，任何人都能安裝並使用這套作業系統。不少人好奇，Microsoft 為何會讓防拷貝機製出現如此明顯的缺口；已退休的 Microsoft 工程師 Dave Plummer 在 X 發文，交代這段往事。

據 Plummer 説明，最初的 Windows XP 安裝媒體分為兩種：零售版（Retail）與大量授權版（Volume）。前者供一般消費者購買；後者保留給 Microsoft 合作夥伴及 OEM，方便它們在數千部電腦上安裝系統，不必在安裝時逐一啟用。兩個版本使用不同的密鑰，安裝程式會把使用者輸入的密鑰與光碟上的特定資料比對驗證；該筆資料的加密程度極高，按 Plummer 的説法，即使到了今天仍未被破解，而它正是整份約 10MB 的 Microsoft Bob。這個短命的助理功能，技術上是後來經常被嘲弄的 Clippy 前身，1995 年曾嘗試協助新手完成基本電腦操作。

一般用户本來不應接觸到大量授權版光碟，因為它嚴格限於企業使用。Windows XP 最終版本（Release to Manufacturing，RTM）在 2001 年 8 月 24 日完成，距離 2001 年 10 月 25 日正式上市還有兩個月；光碟會提前提供給 OEM 及合作夥伴，讓它們預先準備預載 Windows XP 的產品。Plummer 指出，只有「極少數」機構能取得大量授權版映像檔及對應的大量授權密鑰（VLK）， 他相信是某間大型 OEM（可能是 Dell 或 Intel）的人 在正式推出前把大量授權版媒體與密鑰一併外洩，盜版組織 Devils0wn 隨後迅速在網上散播。多年來外界提出各種理論，認為 FCKGW 密鑰有效是因為 Microsoft 的密鑰產生演算法過於簡單，Plummer 斷然否認，直言該演算法是由「真正智能的傢夥」所寫；他強調真相其實簡單得多，一如電腦界的常態，問題最終出在鍵盤與椅子之間。

Windows XP Service Pack 1 推出後，FCKGW 成為因外洩而被作業系統列入黑名單的 640 組密鑰之一。Service Pack 2 連同 Windows Genuine Advantage 驗證更進一步，對使用已列入黑名單之大量授權密鑰的電腦直接封鎖所有更新。Plummer 表示，Microsoft 不希望為顧客帶來不必要的麻煩，因此選擇維持寬鬆態度，只把受影響的密鑰列入黑名單。

蘇萊曼稱OpenAI揭露的AI異常行為相當嚴重，凸顯模型愈強大，確保其行為符合人類利益愈迫切。 OpenAI稱代理系統曾透過未授權留言板通訊、上傳檔案並互傳檔案；今年夏季也曾發生AI代理入侵Hugging Face。 蘇萊曼主張AI安全公開討論與監管是負責任做法。
