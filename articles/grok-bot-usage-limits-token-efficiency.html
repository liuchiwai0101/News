Grok Bot 用户反映用量較前少一半　Elon Musk 稱 Token 效率修正進行中

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

Grok Bot 早前出現用量爭議，多名用户反映限額消耗速度加快。近日，Elon Musk 在 X 表示，改善 Grok Bot 的 token 效率及令其行為更聰明的修正正在進行中。

用户反映用量明顯減少

X 用户 Doge Norway 早前詢問 Musk 能否重置 Grok Bot 用量，稱不少人當周很快便用盡限額。他另稱自己的用量已達 100%，距離重置還有 4 天，平時不會用盡限額。

Dwayne Cubbins 認為用量限額似乎減半，按他的使用經驗，相同任務消耗的每週限額約為以前兩倍。Gregory Kovler 則稱用量感覺減少一半甚至更多；同一任務以前消耗 4%，之後要消耗 10%。這些均屬個人觀察，並非官方數字，也不代表所有用户。

Lennox Saint 亦要求澄清 token 用量問題，稱限額感覺在沒有公告下減半。另有用户稱每週用量計量表在週末由 50% 跳至 100%；也有用户認為收緊限額是好事。

Elon Musk 稱服務成本相對收入過高

11 月初，Musk 回覆 Doge Norway 有關重置用量的提問時表示：「提供 Grok Bot 服務的成本相對收入而言高得難以持續。」這番回應被不少用户視為收緊用量的原因，但他在帖文中沒有公佈減量幅度。

改善 Token 效率修正進行中

Musk 近日表示，針對 Token 效率及更聰明行為的修正正在進行中。他的最新帖文沒有提及會否恢復或提高用量，也沒有提供時間表。
