蘋果稱下月將推出系統更新　修復 iPhone 18 Pro / Pro Max Face ID 故障重啟問題

內容機器翻譯自第三方媒體（Yahoo 新聞），僅供參考，以原文為準。

重點內容

日前提到，外國有 iPhone 18 Pro / Pro Max 用家發現 Face ID 表現異常，不是像平日般「百發百中」，而是有機會一時未能通過驗證就可能隨即當機，又或明明沒有注視螢幕，都仍奇怪地可通過驗證，明顯不符用家期望。幸好，蘋果已經火速應對問題，並已準備於下週推出 iOS 27 首次小更新，針對解決問題。

媒體 9to5Mac 表示，蘋果已向他們確認，將於下週安排推送系統更新，針對修復 iPhone 18 Pro 及 18 Pro Max 的當機重啟問題。這是指日前外國有 18 Pro / Pro Max 用家發現當 Face ID 驗證失敗後，手機有機會出現畫面凍結繼而重啟的現象。

9to5Mac 舉例指，當用家嘗試以 Face ID 解鎖「密碼」程式時，故意用手遮擋面部進行驗證，結果手機隨即停止回應觸控操作，數秒後就強制重啟。重啟後，系統設定就出現相關的當機記錄。有分析認為，故障可能與 18 Pro 系列今年改用全新的靈動島設計有關。新設計將 Face ID 紅外線鏡頭移至螢幕左上角下方，但這與 iOS 27 之間未得完全協調，就會出問題。

雖然此問題未有影響所有 iPhone 18 Pro / Pro Max，但蘋果難以估算全球究竟有多少用家受影響，而且蘋果可趁機會進行安全更新，修補 iOS 27 已知的安全漏洞，所以他們準備下週進行 iOS 27 更新，可算是令廣大 iPhone 用家，特別是 18 Pro / Pro Max 得益。
