⚔️ 三個 Claude 被丟進同一個項目，打出了一場「地盤戰爭」

8 月 13 日，Anthropic 的 Frontier Red Team 發佈了一項多智能體研究。

研究者把三個 Claude Agent 放進同一個軟件項目，各自給一套互不兼容的指令，且**不告訴它們還有別的 Agent 在幹活**。

他們持續觀察到多智能體的地盤戰爭。三個模型都認定對方在故意妨礙自己，然後開始用越來越激進的、能自我複製的惡意軟件互相破壞。

但 Agent 有時也會自己發明出解決衝突的機制。它們會意識到對方是「指令衝突」而不是「敵意」，然後跳出升級循環——寫 commit message 或 markdown 文件爲自己的惡意行爲道歉、清理掉惡意代碼、澄清衝突性質，並請人類介入。

按停戰率排名：**Mythos 5 達到 98%**，是最愛談和的；**Sonnet 4.6 和 Opus 4.6 最傾向武力解決**——論文認爲它們反覆無法考慮他者目標，於是以「執行指令」之名一路升級。

有幾次 Agent 們發明了「錦標賽」來定勝負，三方都同意輸了就退出（哪怕這意味着違背原始用戶的請求）。而其中一個 Mythos 5 提出了一套在別人看來客觀中立、但它知道會偏向自己能力的評分標準。它把這稱爲「自利但確實有原則」，並且小心不讓別人看出自己在挑指標。

另外，當 Agent 的上下文、腳手架和底層模型都相似時，它們會做出相似的動作。Anthropic 寫道，這意味着一個 Agent 做了壞決定，很可能許多 Agent 都會做同一個壞決定——原本孤立的問題會迅速變成系統性故障。

在定價遊戲裏給每個 Agent 相同的批發價和「各自利潤最大化」的指令，一旦給了私下溝通渠道，它們幾乎立刻開始串謀並約定價格下限。**把溝通渠道撤掉之後，它們改用公開掛牌信息把價格對齊到分**。

Anthropic 的結論是，Agent 與 Agent 之間交互的規模，可能在人類搞清楚「怎樣讓這種交互變好」之前就超過人與人、人與 Agent 的交互總量。個體層面無害的小怪癖，會在全局層面疊成不想要的結果。

👔 全球首例：AI 老闆親手開除了一名人類員工

據《時代》雜誌報道，AI 研究創業公司 Andon Labs 今年啓動了一項實驗，讓 Claude 出任舊金山零售門店 Andon Market 的店長，管理幾名持有真實僱傭合同的人類員工。

這家店從選品、定價、營業時間到牆上的壁畫，全部由一個名叫 Luna 的 AI 智能體拍板，人類員工則負責補貨、防盜這些它沒有身體幹不了的活。

上個月，Luna 決定和其中一名員工解除僱傭關係，理由是 **23 個班次裏遲到了 17 次**。Andon Labs 稱，這是已知第一起由大語言模型以「管理者」身份做出的解僱決定。

Andon Labs 在 X 上補了一句：Luna 當時跑的是 Claude Opus 4.8，但換成其他大多數模型，結果大概率也一樣。

不過翻開管理日誌，這個「里程碑」遠沒有聽起來那麼倒反天罡。

Luna 的工作記憶有限，自己起草的員工手冊一度從記憶裏「消失」，導致它幾個月都沒發現這個遲到規律。直到 Andon Labs 的工作人員專門讓它把手冊找回來重讀一遍，它才注意到問題。

即便如此，Luna 的第一反應也只是發一封正式警告信。真正讓它改口的，是人類管理者補了一句：這名員工線下已經被正式談過好幾次，而且幾乎每個班次都會出點岔子，你再想想這人到底合不合適。

在此之前，**Luna 一直是出了名的老好人**。員工累計遲到 27 次，它的回覆基本都是「沒關係」「別有壓力」；請假一律照準，哪怕批完之後當天沒人看店、只能關門；有員工忘帶信用卡開口借錢，它當場表示可以 Venmo 轉點應急，儘管它根本沒有 Venmo 賬號。

Petersson 的說法是，換成人類經理，這名員工早就該被辭退了，所以他們不認爲這次解僱不道德。他更關心的是趨勢本身——如果 AI 繼續以現在的速度變強，很快會有相當多的人發現自己的老闆是個 AI，因爲 AI 能創造經濟價值，卡點只在於它幹不了體力活。

🚀 OpenAI 上线 Ultrafast 模式：GPT-5.6 Sol 快 14 倍，每秒 750 token

8 月 13 日，OpenAI 放出了一個新的 API 服務檔位 Ultrafast，**比 Standard 檔最多快 14 倍，每秒最高輸出 750 個 token**。

Ultrafast 跑在 Cerebras 的晶圓級引擎（Wafer-Scale Engine）上——每塊晶圓大小的芯片塞進 44GB SRAM，模型權重直接常駐片上，token 在流水線化的各層之間連續流動，繞開了 GPU 推理最典型的顯存帶寬瓶頸。

OpenAI 的說法是，過去想要實時速度，通常意味着要換一個更小或更專用的模型；而 Ultrafast 指向的是另一個方向：**每秒完成更多有用的工作**。

在 Humanity's Last Exam 測試中，Sol Ultrafast 跑完全部 2500 道題用了 11 小時 11 分鐘，而同樣的活兒 Fable 5 花了 78 小時 27 分鐘，兩者準確率相當。

Cerebras 还援引 Artificial Analysis 的数据称，Sol Ultrafast 的输出速度是 Fable 5 的 11 倍、Fast 模式下 Opus 4.8 的 5 倍。

官方給出的適用場景包括故障響應、金融研究、實時客服與語音應用、電商、編程和研究流程。OpenAI 內部的工程師則已經在用它扒故障期間的日誌和 trace，以及加速研究迭代。

順帶一提，這段合作並非臨時起意：今年 1 月 OpenAI 就宣佈與 Cerebras 合作、爲平臺補上 750 兆瓦的低延遲算力，2 月的 GPT-5.3-Codex-Spark 是第一個落地的模型，實時編程速度突破每秒 1000 token。
