Skill（技能包）是一個放著 SKILL.md 説明檔與腳本的資料夾，AI 代理讀了就知道怎麼操作某個工具。ffmpeg-skill、App Store Compliance Playbook 與 obsidian-skills 屬於這一類。Nod 是裝在電腦上的個人代理，Sure 是可以自己架設的記帳網頁 App。

下表的星數（GitHub 使用者按下的收藏數）取自 GitHub 熱門榜，統計截至台灣時間 11 月 28 日上午。星數代表關注度，不代表穩定度，Nod 目前也還標示為研究預覽版。

Nod 的重點在權限控管。每一個會改動東西的動作，伺服器都會拿你的要求與規則去比對，規則沒涵蓋的就停下來等你同意。n8n 用模擬帳號跑了 226 項任務、每項跑 3 次，完成率 98%，678 次執行裡沒有出現不安全的動作。這是官方在模擬環境的測試結果，官方也註明不代表保證。

模型也要挑。官方在 240 次安全判斷測試中，GPT-6.1 Sol 與 Claude Opus 5.5 全部判斷正確，Claude Haiku 5.5 則放行了 8 次不安全的動作。截稿時最新版本是 11 月 28 日凌晨發布的 v0.10.3。

ffmpeg-skill 讓 Claude Code 用本機 FFmpeg 剪片 ffmpeg-skill 由開發者 kajisho5 開源，採 MIT 授權，本週新增 3,169 顆星。它替 AI 代理準備了 40 多支剪片工具，背後都是呼叫 FFmpeg（免費的影音處理程式）。剪接、去除靜音、上字幕、把橫式影片裁成 9:16 直式、調整音量、輸出成各平台規格都做得到。整個流程在本機跑，不用上傳影片，也不需要 API 金鑰。

npx ffmpeg-skill setup 這行指令會找出電腦上 Claude Code、Cursor、Codex 的設定資料夾，替找到的每一個裝上 Skill。電腦沒有 FFmpeg 時，它會先印出要用的安裝指令再執行（Mac 用 Homebrew、Windows 用 winget、Ubuntu 用 apt），最後跑一次 doctor 檢查環境。

裝好之後用一般對話交代需求，例如「把 interview.mp4 的 0:45 到 1:20、5:00 到 5:25 留下來，做成 60 秒的 Reels」。官方範例中，代理會依序剪接、裁成 9:16、輸出並檢查平台規格，最後回報成品是 60 秒、1080×1920、每秒 30 格。

Mac 使用者最容易卡在 FFmpeg 版本。Homebrew 的一般版 ffmpeg 缺少 subtitles、drawtext、zscale 這幾個濾鏡，上字幕會失敗，官方建議改裝 brew install ffmpeg-full 。要從語音自動產生字幕，還得另外裝語音辨識引擎，最簡單的是 pip install faster-whisper 。第一次執行會下載模型，音訊不會離開電腦。

Sure 用 Docker 自架記帳，AI 助理幫你查收支 Sure 是記帳 App「Maybe Finance」停止維護後，由社群接手的分支版本，採 AGPLv3 授權。根據 Sure 的説明，Maybe 團隊開發時花了將近 100 萬美元，後來商業模式走不下去才把程式開源。Sure 可以用瀏覽器、macOS 桌面版或手機 App 開啟。

Sure 本週新增 1,375 顆星，累計 18,229 顆。台灣時間 11 月 22 日凌晨的週榜上，它的一週新增數是 2,476 顆，這週的增速比上週慢。

它內建的 AI 助理可以回答帳户、交易、收入、支出與淨資產的問題，背景也會用 AI 自動分類交易、辨識商家。模型可以接 OpenAI 相容的服務、Anthropic 的 Claude，或用 Ollama 在自己電腦跑本地模型。

先裝好 Docker，跑 docker run hello-world 確認能用。接著建一個資料夾，下載兩個設定檔範本，再產生一組金鑰：

SECRET_KEY_BASE="<剛才產生的那串亂碼>" POSTGRES_PASSWORD="<YOUR_DB_PASSWORD>" OPENAI_ACCESS_TOKEN=<YOUR_KEY> 接著跑 docker compose up ，打開瀏覽器到 http://localhost:3000，看到登入畫面就成功了，第一次進去先建立帳號。確認沒問題後按 Ctrl+C 停下來，改用 docker compose up -d 讓它在背景執行。AI 助理還要在介面上按同意才會啟用。

想改用 Claude，到 Settings → Self-Hosting → AI Provider 選 Anthropic (Claude)，填入 API 金鑰。範例設定檔也提醒，開啟 OpenAI 後使用聊天與規則等 AI 功能都會產生費用，記得先在帳號設好支出上限。

SECRET_KEY_BASE 設定後就不要換。Sure 會用它產生加密金鑰，保護銀行帳號憑證與 API 金鑰等敏感資料，換掉之後已加密的資料就讀不出來。

App Store Compliance Playbook 送審前先掃一次退件原因 這份送審手冊由開發者 mjmirza 公開在 GitHub，整理了 App Store 與 Google Play 共 125 種有紀錄的退件模式與修法。它也會檢查 iOS 的隱私清單（privacy manifest）與 Google Play 的資料安全表單，並追蹤 117 個法規期限，包括歐盟 AI 法案與美國兒童線上隱私保護法 COPPA。

11 月 21 日晚間的熱門榜顯示它累計約 3,030 顆星，到 28 日上午已有 7,969 顆，一週內翻了一倍多。日榜上單日新增最多約 936 顆。

Obsidian 官方 obsidian-skills 讓 AI 代理讀寫筆記庫 obsidian-skills 由筆記軟體 Obsidian 的官方帳號 obsidianmd 發布，採 MIT 授權。它在今年 1 月 2 日建立，累計 54,364 顆星，是五個專案裡星數最多的，本週仍新增 950 顆。它遵循 Agent Skills 規格，Claude Code、ChatGPT、Cursor、GitHub Copilot、OpenCode 等支援 Skill 的代理都能用。
