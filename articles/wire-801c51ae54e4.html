微軟高層稱改良 Windows 11 效能表現有成果　未來可望一開機即進入鎖定螢幕畫面

內容機器翻譯自第三方媒體（Yahoo 新聞），僅供參考，以原文為準。

重點內容

許多人都知道，Windows 電腦有更多的 RAM 總比少的好，不過在現時大家新電腦預算追不上記憶體售價升幅之時，如何令系統、應用程式可在較少可用 RAM 的情況下，仍然保持順暢運作，不但是眾多用家關心的問題，也是微軟關心的問題。因此有微軟高層表明，他們已經為此努力中，並且已經看到成果……

在德國柏林舉行的 IFA 2026，微軟都有參展，並提出他們未來有關 Windows 的發展方向。Windows & Devices 企業副總裁 Mark Linton 在會上表示，Windows 11 已在開機時間、Windows Hello 反應速度等方面取得顯著進步，內部早期測試數據亦顯示系統開機時間有所縮短，用家開機後可幾乎立即看到鎖定畫面，但就未有透露具體有多快。他補充道，團隊會持續改善系統基本表現，並會參考用户意見不斷優化 Windows，相關更新將隨後續版本陸續推出。

媒體 Windows Latest 分析指，Mark Linton 的宣稱暫未出現於預覽版 Windows 11，相信暫時只出現於微軟的內部測試版，外界未有機會體驗得到。

針對記憶體成本上升的問題，微軟早前已表示會著手優化 Windows，令內置 8GB RAM 的裝置重新變得可用，而 Linton 在 IFA 2026，再次重申這方向。他表示，團隊正在優化系統，讓配備 8GB 記憶體的電腦都有良好表現，但同樣未有提供具體數據佐證。

雖然大家都知道 Windows 電腦內置愈多 RAM 愈好，可令系統在不同情況下，都可以順暢運作，特別是執行不同與人工智能有關的工作。不過當現時記憶體市場嚴重供不應求，令眾多新機售價愈來愈貴，不少人惟有退而求其次，選購內置 8GB RAM 而非 16GB RAM 甚至 32GB RAM 的新電腦。因此，如何令 Windows 11 在內置 8GB RAM 的電腦都可有上佳表現，對微軟來説有其重要意義。不過除了作業系統要改善，現時不同應用程式因功能眾多，令需要佔用的 RAM 愈來愈多，不同程式開發商也需努力改善 Windows 版程式的表現，才可以相得益彰。
