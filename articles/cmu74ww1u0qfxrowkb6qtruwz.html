OpenRouter 實測 20 個圖像生成模型的成本、編輯與質量

內容機器翻譯自第三方媒體（OpenRouter），僅供參考，以原文為準。

AI 導讀

OpenRouter 對其路由的 20 個圖像生成模型用相同提示詞實測計費，單張圖片成本在 $0.006 到 $0.134 之間，相差 22 倍。

推薦理由

OpenRouter 用同一提示詞實測 20 個圖像生成模型的真實計費，讀者可以藉此繞開各不相同的計價單位直接比較成本。

正文

我們通過 一個 API 路由了 52 個圖像生成模型。我們用同一個提示詞跑通了其中 20 個，並記錄了每次調用計費了多少、返回了什麼，以及它接受什麼輸入。

成本是最棘手的部分，因為這些模型並非按同一單位計價。FLUX.2 按每兆像素計價。Gemini、OpenAI 和 Microsoft MAI 按 token 計價。Grok、Recraft、Riverflow、Qwen 和 Seedream 按每張圖像計價，費率會隨你所要求的質量和分辨率而變化。每個模型頁面以其自身單位來看都是正確的，所以你無法通過並排閲讀它們的價格來比較其中兩個。

我們把它們放在同一基準上。我們測試的這 20 個模型都收到了相同尺寸的同一提示詞，我們從每個響應中讀取了 usage.cost 字段，也就是我們實際收取的金額。

本頁面上的每一個價格都來自一次真實生成，測量於 2026 年 9 月 11 日。價格和模型經常變化，所以任何超過一個月的數據都應視為參考提示，而非預算條目。你可以用 GET /api/v1/images/models 重新拉取當前接受的參數，用 GET /api/v1/images/models/{model}/endpoints 重新拉取標註了單位的定價。

總結

  • 從 openai/gpt-image-2 開始。它在短提示詞上計費 $0.006，在較長提示詞上計費 $0.0135，這使它成為我們測量到的最便宜的模型，而且它正確地渲染了我們的兩行標籤和參考編輯。
  • 如果圖像很難做對，可以進一步選擇 sourceful/riverflow-v2.5-pro，價格為 $0.064；如果回覆既需要文字也需要圖片，可以選擇 google/gemini-3-pro-image，價格為 $0.134；如果你需要的是可編輯的 SVG 而不是像素圖，可以選擇 recraft/recraft-v4.1-vector，價格為 $0.08。
  • 在我們測量的 20 個模型中，默認設置下生成一張圖片的計費在 $0.006 到 $0.134 之間，相差 22 倍。
  • 每個模型頁面都用自己的單位標價，而實際計費成本可能與標價不同。比較兩個模型的方法是：各生成一張圖片，然後從響應中讀取 usage.cost。
  • 在 OpenAI 模型上，quality 設置讓同一張圖片從 $0.006 變為 $0.211。
  • n，即一次調用返回的圖片數量，在 FLUX.2、Gemini、Grok、Riverflow 和 MAI 上上限為 1。seed 在 Gemini、Grok、OpenAI、Riverflow、Recraft 或 MAI 上不存在。在 FLUX.2 Klein 上存在該設置時，相同的 seed 逐字節復現了同一張圖片。
  • 我們要求生成可讀文本的六個模型中，有五個正確渲染了文本，包括最便宜的那個。
  • 原始 API 返回 data[0].b64_json。TypeScript SDK 返回 data[0].b64Json。

在根據這張表制定預算之前，你需要了解三件事。

  1. 當我們未設置 resolution 時，兩個 Seedream 模型都返回了 2048x2048，而不是 1024x1024。Seedream 5.0 Lite 將 2K 列為它接受的最低分辨率。Seedream 5.0 Pro 接受 1K，但其默認調用返回了 2K，並按 $0.09 的高分辨率費率計費，而不是 $0.045 的基礎費率。Seedream 5.0 Lite 以 $0.035 的價格給你四百萬像素，因此按每像素計算，它比表格看起來的要便宜。
  2. FLUX.2、Grok 和 Seedream 返回了 JPEG。OpenAI、Qwen、Microsoft 和 Krea 返回了 PNG。Sourceful 和 Recraft 返回了 WebP，而 Recraft 的矢量模型返回了 SVG。我們測試的三個 Gemini 模型不接受 output_format，而且它們返回的格式並不全都相同，所以不要硬編碼文件擴展名。在接受該參數的十二個目錄模型上設置 output_format。在不接受該參數的模型上，讀取每個響應都會返回的 media_type 字段。
  3. 兩次使用相同請求體調用 sourceful/riverflow-v2.5-fast，分別計費 $0.017623 和 $0.017639。請根據多次調用的平均值來制定預算，而不是根據單次調用。

質量設置會讓價格變動 35 倍

在 OpenAI 模型上，quality 對你的賬單的影響比任何其他設置都大。我們用相同的提示詞、相同的 1024x1024 尺寸運行了 gpt-image-2，分別將 quality 保持未設置、設置為 low 以及設置為 high。

寬高比對賬單的影響要小得多

在按每兆像素計費的模型上，你請求的畫面尺寸會改變賬單，但變化幅度小於像素數量所暗示的程度。我們用 black-forest-labs/flux.2-klein-4b 跑了兩種形狀。21:9 的調用返回 2400x1024，即 2.46 兆像素，而正方形為 1.05 兆像素。正方形計費 $0.014，寬幅裁剪計費 $0.016。

標價與實際計費可能不同

每個模型都會在其頁面上以及 API 的端點路由中公佈一個費率。這些費率只是一個用於規劃的參考數字，實際響應結果才是你最終支付的費用。2026 年 9 月 11 日，sourceful/riverflow-v2.5-pro 在其默認分辨率下列出的價格為每張圖片 $0.13，而實際向我們計費 $0.064。black-forest-labs/flux.2-flex 列出的是每百萬像素 $0.06，而對一張一百萬像素的圖片向我們計費 $0.05。black-forest-labs/flux.2-max 列出的是 $0.07，並恰好向我們計費 $0.07。krea/krea-2-medium 在其端點上沒有公佈任何定價記錄，並向我們計費 $0.03。

當兩者不一致時，請查看 usage.cost，而不是用列出的費率乘以估算值。

對於已完成的圖片請求，我們全額計費；對於失敗的請求，我們不收取任何費用。Image API 計費文檔 説明了哪些結果會被計費。

參考圖像是你在請求中隨附、供模型據此工作的圖像，既可以是你希望編輯的圖像，也可以是希望模型匹配的風格或產品示例。可發送數量的上限是硬性上限。Grok 接受三張，Gemini 接受十四張，因此一套六張圖的品牌素材包在還沒比較其他任何東西之前就已經把 Grok 排除在外了。

輸出模態這一列是第二個維度。這些模型大多接受文本和圖像輸入，只返回圖像字節。Gemini 圖像模型和 OpenAI 的 gpt-5-image 模型還能在同一次回覆中返回書面文本，如果你想讓模型解釋它生成了什麼，這一點很重要。我們在下文進一步測試了它們這樣做的可靠性。

對任何帶有 GET /api/v1/images/models 的模型重新拉取此表，它會公佈每個模型接受的參數及其範圍。supported_parameters 中未出現的參數，表示該端點不支持。

Seed 在 FLUX.2 Klein 上完全復現了該圖像

seed 是你發送的用於讓結果可復現的數字。在我們目錄中的每個 Gemini、Grok、OpenAI、Riverflow、Recraft 和 MAI 圖像模型上都缺失它。它存在於 FLUX.2、Seedream、Qwen 和 Krea 上。

我們運行了black-forest-labs/flux.2-klein-4b兩次，使用相同的提示詞，以及seed: 424242。兩次響應逐字節完全一致，且均計費 $0.014。我們只測試了 Klein，因此其他支持 seed 的模型應視為未經測試，而不要假設它們的行為相同。作為對比，兩次sourceful/riverflow-v2.5-fast不帶 seed 參數的調用，在相同的請求體下返回了兩張不同的圖像。

排行榜怎麼説

我們在每個模型的頁面上展示 Design Arena 評分。當我們在 2026 年 9 月 11 日通過 benchmarks API 拉取當前評分時，sourceful/riverflow-v2.5-pro 在圖像榜和圖像編輯榜上都獲得了最高評分。微軟的 MAI Image 2.6 模型和 Google 的 Gemini 圖像模型在圖像榜上緊隨其後，而 black-forest-labs/flux.2-klein-4b 在兩個榜單所列模型中評分最低。

這些評分來自模型之間的兩兩對戰投票，Design Arena 將其轉化為 Elo 評分——當模型贏下一場對決時分數上升，輸掉時則下降。

有兩點需要注意。Gemini 的評分基於這些 slug 的 -preview 版本，而非我們在本頁鏈接的正式發佈版本。而且 Elo 告訴你的是投票者在其提示詞上的偏好，而非你的。在我們這次運行中，評分最高的模型每張圖片收費 $0.064，評分最低的模型收費 $0.014。先從榜單中篩選出候選，再根據自己的提示詞做決定。

我們用同一個提示詞測試了六個模型

我們把同一個提示詞發送給了橫跨不同價位的六個模型，並將費用標註在每張圖片下方。我們要求生成一個啞光黑色的咖啡袋，上面印有兩行文字。

提示詞

一張啞光黑色咖啡包裝袋的影棚產品照，置於純白背景之上，採用硬質主光。袋子正面以簡潔的無襯線大寫字母印着 OPENROUTER ROASTERS 字樣，其下方以較小的無襯線大寫字母印着 SINGLE ORIGIN 字樣。

我們選擇可讀的文字，是因為它們容易評分。袋子要麼寫着你要求的內容，要麼沒有。

圖 2. 同一提示詞經由六個模型生成，並附上每次調用的實測成本。

六個中有五個把兩行都印對了。例外是 black-forest-labs/flux.2-klein-4b，它把品牌名渲染正確，卻把第二行拼錯成了 SINGLE ORISION。

最有用的比較，是 Design Arena 榜單上最便宜的模型與最貴的模型之間的對比。openai/gpt-image-2 計費 $0.0135，sourceful/riverflow-v2.5-pro 計費 $0.0654，兩者都生成了正確、可用的商品圖。多花約五倍的錢，換來的是不同的觀感，而不是更好的文字。

這並不意味着 Riverflow 定價過高。它領跑 Design Arena 各榜單，而在更難的圖像、不尋常的構圖或更長的文本串上，差距可能會顯現出來。它真正説明的是，無論是排行榜還是價格欄，都沒能預測出這個提示詞上的結果，只有實際跑一遍提示詞才能知道。

同一次測試還帶出了兩個較小的發現。在按 token 計費的模型上，提示詞長度會改變你的賬單，因為 openai/gpt-image-2 在之前那行單行提示詞上計費 $0.006，而在這個更長的提示詞上計費 $0.0135。另外，每個模型對“studio packshot”的理解都不同，從硬陰影的產品照到柔光的產品照都有，所以構圖是一個需要測試的風格選擇。

按任務挑選

根據對你而言最緊的那項約束來挑選模型。那可能是大批量下的成本、圖像是否必須包含可讀的文字、你需要發送多少張參考圖，或者回復是否需要在圖片之外附帶文字。

大批量、普通提示詞

從 openai/gpt-image-2 開始。在成本表中，它在短提示詞上計費 $0.006，在較長的咖啡袋提示詞上計費 $0.0135，因為它是按 token 計費的，你的提示詞也是賬單的一部分。對於長度相近的產品提示詞，按這個區間做預算。它是我們測過的最便宜的模型，並且以最低的成本正確渲染了我們的文字。

black-forest-labs/flux.2-klein-4b 以 $0.014 成為另一個便宜選項，但有一個實測到的坑。它是六款模型中唯一拼錯標籤的，而且在兩個榜單上都是 Design Arena 評分最低的模型。把它用於畫面中沒有可讀文字的批量工作。當產品名稱必須準確呈現時，不要用它。

OpenAI 的這些數字假設你保持 quality 未設置。把它調到 high 後，我們賬單上那一行變成了 35 倍。Klein 沒有 quality 設置，所以它的成本更容易預測，而且當你需要更好的結果時，也沒有可調高的設置。

在咖啡袋提示詞上，兩者分別為 $0.0135 和 $0.014，也就是一萬張圖片 $135 對 $140。到了這個程度，價格已經不能決定什麼了，所以把你自己的提示詞分別跑一遍，讓輸出結果來決定。

關於 Klein 有一條操作上的説明。Black Forest Labs 在 Hugging Face 上發佈其權重，倉庫名為 black-forest-labs/FLUX.2-klein-4B，而不是使用我們 slug 的大小寫形式。你現在可以通過我們調用它，之後再遷到內部，而無需更換你所圍繞構建的模型家族。

圖片中的文字

當模型把產品名稱弄錯時，包裝、UI 模型圖、幻燈片和海報都會出問題。

我們測試的六個模型中有五個無需任何輔助就能處理兩行標籤，所以可以按成本和風格來挑選，然後拿結果與你自己的文字而非我們的文字進行核對。

black-forest-labs/flux.2-flex 正確渲染了我們的標籤，該圖片計費 $0.05，並且最多接受八張參考圖。如果你已經在使用 FLUX.2 且文字很重要，這就是應該遷移到的 FLUX.2 模型。如果你還沒有鎖定某個模型家族，openai/gpt-image-2 以大約四分之一的價格完成了同樣的工作。

在做決定之前，看看 recraft/recraft-v4.1-vector，它以不同的方式解決了這個問題。它返回的是 SVG 而非像素，其端點接受 style、controls 和 text_layout 作為 provider.options 下的透傳參數。對於需要縮放並保持可編輯的 logo 或標籤，矢量輸出勝過更清晰的位圖，而每張圖片 $0.08 就能得到一個可以在設計工具中打開的文件。

參考一致的品牌作品

在這裏，同一個物體在它出現的所有地方都必須看起來一樣。產品頁面上的瓶子和宣傳圖中的同一個瓶子不應該出現偏差。

我們測試了這一點。我們拿來了openai/gpt-image-2已經做好的咖啡袋，將其作為input_references圖像發回去，並要求四個模型在保持袋子及其印刷標籤完全不變的前提下，將白色背景替換為暖色側光下的深胡桃木枱面。

圖 3. 一張源圖像、一條指令、四個模型，以及每次編輯的實測成本。

四個模型都保留了文字內容和字體。四個模型也都在一定程度上改變了袋子的形狀、比例或光照，且沒有一個能逐像素還原源袋子，因此如果一次營銷活動中的每張圖像都必須與一張主視覺圖保持一致，應將輸出結果與源圖進行對比，而不是僅憑標籤來判斷。

為了公平地比較編輯與生成，我們還使用編輯指令作為提示詞運行了生成一側，因此兩列來自相同的措辭。這一點很重要，因為這些模型中有兩個按 token 計費，更長的提示詞本身就會帶來更高的賬單。

同時包含圖片和文字的回覆

有時用户正在進行一段對話，而回答應當同時包含一張圖片和一段文字説明。我們目錄中 52 個模型裏有九個將文本列為其輸出模態之一，它們就是能夠做到這一點的模型。它們是 Gemini 圖像模型和 OpenAI 的 gpt-5-image 模型。

能夠返回文本和實際做到是兩回事。我們選取了這九個中的四個，通過 chat completions 端點向每個模型發送了相同的請求，並帶上 modalities: ["image", "text"]，要求給出一張圖片外加兩句話的解釋，然後統計我們同時得到兩者的頻率。這些成本高於這些模型在成本表中的數字，因為回覆中帶有文本，而在按 token 計費的模型上，兩者你都要付費。

如果文字是可選的，google/gemini-3.1-flash-image 以 $0.067 的價格可用，你自行處理空返回的情況。如果你的產品缺少文字就無法運行，那麼 google/gemini-3-pro-image 以約 $0.139 的價格是四款模型中唯一在我們的測試中每次都返回文字的模型。

我們建議在新的圖像工作中使用專用的 Image API，而非 chat completions，因為新的圖像模型只會添加到 Image API，而 chat 路由提供的參數更少。openai/gpt-5-image 也是這裏最貴的選項，每次調用 $0.20 到 $0.28，而且它在三次調用中有兩次返回了文本。這些 chat 調用會在圖像之外額外對提示詞和補全 token 計費，因此一段很長的指令和一個很長的回答會比單張圖像的價格更貴。

三項任務，兩個端點

生成、編輯和聊天看起來相似，但它們是不同的請求。生成和編輯使用 images 端點，僅相差一個字段。聊天則改用 chat completions 端點，只有上面九個具備文本能力的模型才能做到。我們的OpenRouter 上的圖像生成模型教程涵蓋了這兩個端點的完整請求和響應契約。

圖 4。生成和編輯是同一個端點，只是請求體不同。聊天則是另一個端點。

生成就是 POST /api/v1/images 加上一個 model 和一個 prompt。你會得到圖像字節作為返回。

編輯是同一個端點加上 input_references，因為你是在修改一張已有的圖像，而不是生成一張新的。

聊天發送一個messages數組到POST /api/v1/chat/completions。文本和圖像輸入，文本和圖像也可以返回。

在 OpenRouter 上調用它

圖像路由是 POST https://openrouter.ai/api/v1/images。唯一必填字段是 model 和 prompt。

curl https://openrouter.ai/api/v1/images \
  -H "Authorization: Bearer $OPENROUTER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "black-forest-labs/flux.2-klein-4b",
    "prompt": "A studio packshot of a glass bottle, hard key light, no text.",
    "aspect_ratio": "1:1"
  }'

響應中包含圖像及其費用。這是我們在 2026 年 9 月 11 日針對該請求收到的響應，已裁剪為本文討論的字段，並移除了圖像字節。

{
  "data": [
    {
      "b64_json": "<base64>",
      "media_type": "image/jpeg"
    }
  ],
  "usage": {
    "prompt_tokens": 16,
    "completion_tokens": 4096,
    "total_tokens": 4112,
    "cost": 0.014,
    "completion_tokens_details": {
      "image_tokens": 4096
    }
  }
}

要改為編輯圖像，請在同一請求體中添加一個 input_references 數組。每個條目都是一個 image_url 對象，攜帶 HTTP(S) URL 或 base64 數據 URL。

{
  "model": "black-forest-labs/flux.2-pro",
  "prompt": "Keep the bag and its printed label exactly as they are. Replace the white background with a dark walnut counter under warm side light.",
  "aspect_ratio": "1:1",
  "input_references": [
    {
      "type": "image_url",
      "image_url": {
        "url": "data:image/png;base64,<base64>"
      }
    }
  ]
}

我們的 TypeScript SDK 封裝了同一路由，並將字段名轉換為駝峯式，因此 b64_json 變為 b64Json，media_type 變為 mediaType，而 aspect_ratio 變為 aspectRatio。generate 方法的返回類型也涵蓋了流式場景，因此在讀取 data 屬性之前，請先對其進行類型收窄。

import { OpenRouter } from '@openrouter/sdk';

const openRouter = new OpenRouter({ apiKey: process.env.OPENROUTER_API_KEY ?? '' });

const result = await openRouter.images.generate({
  imageGenerationRequest: {
    model: 'black-forest-labs/flux.2-klein-4b',
    prompt: 'A studio packshot of a glass bottle, hard key light, no text.',
    aspectRatio: '1:1',
  },
});

if (!('data' in result)) {
  throw new Error('Expected a non-streaming image response');
}

const image = result.data[0]?.b64Json;
const mediaType = result.data[0]?.mediaType;
const cost = result.usage?.cost;

常見問題

2026 年最佳的圖像生成模型是什麼？

沒有單一的最佳模型，所以要按任務來選。在我們 2026 年 9 月 11 日的測試中，openai/gpt-image-2 是我們測到的最便宜的模型，根據提示詞長度不同，每張圖像收費 $0.006 到 $0.0135，並且它正確渲染了兩行標籤和一次參考編輯。sourceful/riverflow-v2.5-pro 在 Design Arena 圖像和圖像編輯榜單上領先，每張圖像收費 $0.064。recraft/recraft-v4.1-vector 以每張圖像 $0.08 的價格返回可編輯的 SVG。

OpenRouter 上最便宜的圖像生成模型是哪個？

在我們以 1024x1024 分辨率、默認設置測量的 20 個模型中，openai/gpt-image-2 收費最低，一行提示詞為 $0.00599。black-forest-labs/flux.2-klein-4b 收費 $0.014，sourceful/riverflow-v2.5-fast 收費 $0.0176。在按 token 計費的模型上，提示詞長度會改變賬單，而在 OpenAI 模型上，quality 設置讓同一張圖像的費用從 $0.006 變為 $0.211。

哪些圖像模型可以編輯現有圖像？

任何端點列出 input_references 的模型都通過 POST /api/v1/images 接受參考圖像。上限因模型而異。在 2026 年 9 月 11 日，OpenAI 圖像模型接受 16 張，Gemini 3.x 圖像模型和 Seedream 5.0 接受 14 張，sourceful/riverflow-v2.5-pro 接受 10 張，FLUX.2 Flex、Pro 和 Max 接受 8 張，FLUX.2 Klein 和 Qwen Image 3 接受 4 張，Grok Imagine 接受 3 張，Recraft、Krea 和 MAI Image 接受 1 張。請閲讀 GET /api/v1/images/models/{model}/endpoints 瞭解當前數值。

哪些圖像模型可以同時回覆文本和圖像？

輸出模態包含文本的模型。在 2026 年 9 月 11 日，我們目錄中的 52 個圖像模型裏有九個屬於此類，即所有 Gemini 圖像模型和 OpenAI gpt-5-image 模型。通過 POST /api/v1/chat/completions 調用它們。在我們的測試中，google/gemini-3-pro-image 在 3 次調用中有 3 次返回了文本，openai/gpt-5-image 在 3 次中有 2 次，google/gemini-3.1-flash-image 在 4 次中有 1 次，google/gemini-3.1-flash-lite-image 在 2 次中有 0 次。

Image API 返回什麼圖像格式？

這取決於模型。在我們的運行中，FLUX.2、Grok 和 Seedream 返回 JPEG，OpenAI、Qwen、Microsoft 和 Krea 返回 PNG，Sourceful 和 Recraft 返回 WebP，而 recraft/recraft-v4.1-vector 返回 SVG。目錄中的 52 個模型裏有十二個接受 output_format 參數。請讀取每個響應上的 media_type 字段，而不要假設文件擴展名。
