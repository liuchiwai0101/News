macOS 27.3 Beta 更新權限管理　防止 AI 應用程式過度存取

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

隨著最新 macOS 27.3 Beta 推出，Apple 為 Mac 用户提供更完善的數據共享與應用程式存取控制機制，特別是針對使用 AI Agent 的應用程式。Apple 已向開發者通知即將實施的「完整磁碟存取」（Full Disk Access）API 及「裝置控制與資料存取」（Device Control and Data Access）API 變更。

細分權限選項與單一授權方式

目前的「裝置控制與資料存取」設定將分為兩個獨立選項，讓用户更清楚瞭解所允許的操作範圍。該設定將改名為「系統與應用保護覆蓋」（System & App Protection Override）及「輔助使用功能」（Accessibility）。此外，授予權限將採用單一方法，用户只需從清單中選擇請求存取的應用程式即可。

鼓勵最小權限原則與透明化提示

Apple 將鼓勵用户僅在必要的工作流程中，授予特定應用程式或特定資料夾（用於完整磁碟存取）的權限，而非無限制的全面存取。系統將提供更詳細資訊，説明若授予完整權限，應用程式將能存取或控制的數據範圍。用户亦可設定應用程式在每次需要存取時重新詢問，以避免一次性給予永久 unrestricted access。當應用程式透過「系統與應用保護覆蓋」控制另一應用程式時，Mac 選單列將顯示透明度指標以提醒用户。

開發者需調整引導流程與現有兼容性

Apple 指出，開發者需調整用户引導（Onboarding）流程，並確保應用程式在使用經過 overhaul 的 API 時，能妥善處理受限的資料夾或應用程式存取情況。對於使用完整磁碟存取進行備份，或使用新輔助使用設定提供輔助技術的應用程式，可申請特殊權限（Entitlements），以便在新安裝時維持與 macOS 27.3 之前相同的體驗。目前已知應用程式在無需額外權限的情況下可保持現有體驗，且在 macOS 27.3 之前已授予的用户權限將繼續有效。用户將在批准新的應用程式權限請求時見到這些變化，相關權限細節將於不久後公佈。
