SWE-2 Flash 對比 DeepSeek V4 Flash：兩個單元，一個差距

內容機器翻譯自第三方媒體（OrcaRouter · 極客公園 · cnBeta.COM），僅供參考，以原文為準。

正文

每一個實際上究竟是什麼，以及檢查點陷阱 價格，以各廠商實際公佈的兩種單位表示 速度：對照量測的重播 唯一一次同表執行，以及是誰執行的 上下文、權重，以及你能打造什麼 路由器改變運算方式的地方 該選哪一個 返回全部文章 當你把 SWE-2 Flash 和 DeepSeek V4 Flash 並排放在一起時，最先崩掉的是單位。 DeepSeek 公佈的是每百萬 token 多少美元，以及一個可下載的檢查點。Cognition 公佈的則是一個分數—— SWE-2 的五分之一——以及 Devin 裡的一個席位。其中一個是你能據以打造的模型；另一個是你能使用的模型。接下來每一項比較都必須經得起這種不對稱，而在發布日流傳的大多數比較都經不起。

那不是跳過比較的理由。那正是這項比較值得仔細做的原因。這兩個模型鎖定的是同一種買家——想要接近前沿的程式設計表現、又不想付前沿價格的團隊——而它們對這位買家希望如何取得這樣的能力，下了相反的賭注。一種賭注是拆分解耦：權重、API、公開的脈絡視窗，以及可預測的帳單。另一種則是整合式：一個針對單一執行框架調校的模型，以另一個模型成本的一小部分出售，而且把服務堆疊一併算進那個數字裡。

每一個實際上究竟是什麼，以及檢查點陷阱 SWE-2 Flash 於 2026 年 11 月 4 日發布。它是基於 Thinking Machines 的 Inkling-Small（總參數 276B、活躍參數 12B 的混合模型）後訓練而成，並可在 Devin Desktop 與 Devin CLI 中使用。在這些產品中，它可免費使用至 11 月 30 日。它沒有 API、沒有公開權重，也沒有公佈上下文視窗。

DeepSeek V4 Flash 是總參數 284B、約 13B 啟用參數的混合專家模型，以 MIT 授權釋出，上下文視窗達 100 萬個 token，輸出上限為 384,000 個 token。它僅支援文字；視覺版本是另一個實驗性 ID。它透過與 OpenAI 相容的 API 提供服務，自春季起即可呼叫，並有一個重新進行後訓練的 0731 檢查點，該檢查點在代理式編碼上發揮了主要作用。

接著是陷阱。DeepSeek 自家的模型與定價頁面（於 2026 年 11 月 5 日查閲）將 deepseek-v4-flash 列為 API 仍接受的舊名稱之一，並表示它現在由 DeepSeek-V4.1-Flash-1017 提供服務。那是另一個且更大的模型：Cognition 的比較表將 V4.1 Flash 1017 列為總參數 763B、啟用參數 16B。因此，「DeepSeek V4 Flash」至少會指向三種東西，取決於説話者是誰——4 月的建置版本、0731 檢查點，或該 ID 現在指向的 10 月 V4.1 檢查點。在 OrcaRouter 上，固定 ID 是各自獨立的路由，這正是比較之所以能重現的唯一原因。

這不是吹毛求疵。這會改變你有資格引用哪一列基準測試數據。「DeepSeek V4 Flash」的公開排行榜數字是在 0731 版本上測得的。Cognition 的表格測得的是 V4.1 Flash 1017。它們並非同一個模型，數字也因而有所不同。

價格，以各廠商實際公佈的兩種單位表示 DeepSeek 的價目表是算術。以 deepseek-flash 這個 ID 目前所服務的模型——頁面明確指名的 DeepSeek-V4.1-Flash-1017——每百萬 token 的價格，於 2026 年 11 月 5 日查得如下：輸入在離峯時段為 $0.15，尖峯時段為 $0.30；輸出在離峯時段為 $0.60，尖峯時段為 $1.20；快取輸入為 $0.003 與 $0.006。尖峯時段為 UTC 週一至週五的 01:00 至 04:00 及 06:00 至 10:00，中國國定假日除外。在上述時段之外，適用較便宜的費率。

固定使用較舊的檢查點，定價並不相同。OrcaRouter 的目錄收錄 deepseek/deepseek-v4-flash，每百萬輸入 token 為 0.22 美元、每百萬輸出 token 為 0.66 美元，採統一費率，沒有尖峯時段分級。這就是可重現性的代價：固定採用四月世系的模型，而非呼叫現行版本，你得多付一些費用，換來的是大多數已發表基準測試列實際上所測量的那個模型。兩種選擇都沒有錯；它們回答的是不同的問題。

Cognition 的宣傳卡是一則比較。「價格是規模大得多的同系列模型的五分之一，速度則是其三倍」就是全部的公開説法，沒有附上任何絕對數字，而且除此之外還可免費用至 11 月 30 日。無法根據公開資訊計算在 SWE-2 Flash 上執行一項任務要花多少成本，因為分母是一個連自身 token 價格也從未公佈過的模型。

由此產生兩個後果，而這兩者都是實務上的，而非學究式的。

• 可預測性 — DeepSeek 每百萬個 token 的成本可以精確到分，包括尖峯時段的倍數。SWE-2 Flash 的成本則只能以某個未公開數字的一個比例來得知，而且還藏在你已經付費的訂閲方案裡。

• 統一報價容易造成誤導——釘選的 V4 Flash 路由採單一均一費率，而供應商目前的價目卡則是雙層級制。因此，單一價格數字在一週當中的部分時段並不正確，而且它所描述的檢查點，與大多數基準測試列所指名的檢查點並不相同。請依供應商價目卡進行規劃；依釘選路由進行重現。

兩者都比表面上看起來更重要。對於一個會執行數千次短呼叫的代理而言，尖峯倍率是你可以透過工程設計因應的排程問題；對於一個只執行少數幾次長時間工作階段的程式設計代理而言，它只是捨入誤差。你屬於哪一種，決定了 DeepSeek 的價目卡上是兩個價格還是一個價格。

速度：對照量測的重播 Cognition 的每秒 200 個 token 並非即時計時。文章對此作出瞭解釋：每個模型各自在 Terminal-Bench 4.0 的 gsea-proteomics 任務上執行，並「以模擬的每秒 200 與 60 個 token 重播」，同時將逐字稿縮短至等長。SWE-2 的 60 tok/s 來自同一次重播。它描述的是 Cognition 所鎖定的服務設定檔，這本身是值得公開的正當資訊，但它並非對兩個端點按下碼錶計時。

Artificial Analysis 在其目前的模型頁面上測得 DeepSeek V4 Flash 的輸出速度為每秒 112 個 token，首個回答 token 的時間為 32.41 秒。這是對運作中 API 的測量，包含供應商所做的任何排隊。這兩個數字不可相比，相減也毫無意義：一個是產品內部的模擬重播，另一個是透過公開端點觀察到的服務速率。

經得起這項保留條件考驗的是方向。如果一個 12B 活躍參數模型真的能在 Devin 內以約 200 tok/s 提供服務，而一個 13B 活躍參數模型在公開 API 上測得 112 tok/s，那麼活躍參數較小的模型未必就明顯較快——服務堆疊所做的工作和架構一樣多。這點支持整合式產品，也反對從參數數量推斷速度。

唯一一次同表執行，以及是誰執行的 Cognition 的發布表格直接收錄了 DeepSeek 的模型。該欄位是 DeepSeek V4.1 Flash 1017——也就是 deepseek-v4-flash 這個 ID 目前所指的檢查點——這使得它成為這對模型唯一在同一屋簷下產生的比較。以下每一項數字都出自 Cognition，採用 Cognition 的基準測試，且未揭露所用的測試框架。

若以差距而非勝場數來衡量這項比較，差距就不再接近。Flash 在 FrontierCode 上確實具競爭力，該基準獎勵依據書面規格提交有限範圍的修補；但它在 Terminal-Bench 4.0 上則遠遠落後，該基準衡量終端代理將任務執行至完成的能力。這也是其餘競爭者拉開差距的同一列： GLM 5.3 Flash 在同一基準上得分 41.8，Claude Haiku 5.5 得分 39.2，而 Flash 為 20.0。

接下來要説的是同樣必須一併提出的注意事項。這是競爭對手的表格。FrontierCode 是 Cognition 自家的工具，而且由 Cognition 評分。這篇貼文未揭露測試框架、推理強度設定與執行次數，因此「同一張表」不等於「相同條件」——這是單一廠商的方法論一致套用，聊勝於無，但不如獨立評測。而且 DeepSeek 欄位是 V4.1 Flash 1017，不是多數公開數據所描述的 0731 版本。

對於工具本身有多大影響，有一項有用的合理性檢查。Artificial Analysis 對 DeepSeek V4 Flash 0731 版本的評估，最後執行於 2026 年 7 月 31 日，在 Terminal-Bench 4.0 上記錄到 12.1%。Cognition 的表格則記錄 V4.1 Flash 1017 檢查點為 42.3%。同一個具名基準上相差三十分。其中一部分來自檢查點——V4.1 是不同且更大的模型——另一部分則來自評測框架，因為一個是標準化的第三方執行，另一個是供應商自己的執行。無論如何，這項比較中沒有任何單一列是僅屬於模型本身的屬性，而兩家供應商分歧最大的那些列，正是最該寬鬆看待的。
