屏幕更大兼有屏下 Face ID？傳 Apple 內部已測試 iPhone Duo 2 原型機

內容機器翻譯自第三方媒體（PCM），僅供參考，以原文為準。

Apple 首款摺疊螢幕手機 iPhone Duo 正式開售，雖然開售初期引來不少話題，但不少用家及果粉最著緊的，莫過於第一代機型因機身極薄而「閹割」了 Face ID，改用側邊電源鍵整合 Touch ID 指紋解鎖。不過，Apple 顯然已經在研究補救方案。

根據彭博通訊社（Bloomberg）執行編輯 Mark Gurman 於最新一集《Power On》Podcast 節目中爆料指出，Apple 內部其實早已展開第二代「iPhone Duo 2」的研發與測試工作。最新傳出的內部原型機（Prototype）顯示，Apple 正全力測試將「屏下 Face ID（Under-display Face ID）」技術引入這款摺機之中。

首代因機身極薄妥協 改用側邊 Touch ID

初代 iPhone Duo 定價達 $1,999 美元（ $17,499 港元），但未有搭載 Apple 近年標配的 Face ID 技術，令不少用家略感遺憾。Gurman 分析指，首代產品之所以改回 Touch ID 設計，主因是折疊機身設計極其纖薄，加上內部需要容納鉸鏈、雙屏幕以及電池等組件，空間堆疊極度緊湊，根本無法放入傳統的 3D 結構的光學 Face ID 模組。

此外，Apple 設計團隊亦考慮到內外雙屏幕操作的體驗一致性，若外屏有 Face ID 而內屏要改用指紋解鎖，體驗會顯得分割，因此最終統一採用側邊電源鍵 Touch ID 解鎖。

屏下 Face ID 隱藏於外屏 兼擬加回「Action Button」

報導提到，現時 Apple 測試中的 iPhone Duo 2 原型機，已嘗試將 Face ID 感測組件隱藏於外屏（Cover Screen）下方。這項技術若能成功量產，除了能為用家帶回最習慣的無感解鎖體驗外，更能避免屏幕被動態島或開孔破壞，保持高屏佔比的視覺效果。

除了屏下 Face ID，Gurman 亦指 Apple 正在探索於 iPhone Duo 2 加回在首代被取消的「動作按鈕（Action Button）」，讓用家可以自行自訂快捷功能。另外，亦有傳聞指 Apple 正評估加大 Duo 2 螢幕尺寸至 8.1 吋的可行性。

正式量產仍有變數 最快明年下半年登場

雖然原型機已在 Apple 內部運作，但 Gurman 強調，屏下 Face ID 技術目前仍處於實驗及測試階段，最終會否順利過渡至量產機型仍未發放定案。消息指，Apple 計劃在未來兩至三年間（即 Duo 2 或 Duo 3）徹底解決這項技術瓶頸。照現時開發進度推算，iPhone Duo 2 最快亦要等到明年（2027 年）秋季才有可能正式登場。
