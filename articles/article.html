刚刚！杭州两大AI巨头发力：DeepSeek V4 Pro正式上线，阿里Qwen3.8首次开源

就在剛剛，國產開源AI大模型——尤其是杭州AI圈兩大山脈迎來“雙響炮”。

**1、DeepSeek V4 Pro 正式版来了。**

**2、阿里** **Qwen 團隊正式開放性能最強的Qwen3.8-2.4T-A95B 模型權重。**

而在海外，剛剛，馬斯克的 SpaceXAI 正式發佈 Grok 4.6，重點提升長時間運行的 Agent，以及更復雜的交互和視覺任務，在 Artificial Analysis Intelligence Index 拿到 61 分，與 GPT-5.6 Sol 持平，僅低於 Fable 5 的 62 分，性能已經追到第一梯隊。

價格方面，Grok 4.6 每百萬輸入、輸出 Token 分別爲 2 美元和 6 美元，與 Grok 4.5 相同。**GPT-5.6 Sol 則是 5 美元和 30 美元，也就是說 Grok 4.6 的輸出價格只有 Sol 的 1/5。官方還提供速度更快的版本，價格翻倍。**

但這個價格還是貴於DeepSeek。

果然還是梁聖！

隨着海外持續進行開源和價格戰，國內開源AI模型這套性價比路線的價值越來越大。

先看DeepSeek。

“DeepSeek V4 Pro 正式版已經更新至 API，調用模型名不變。新版本增強了 Agent 能力，支持 Responses API 和 Codex 接入，歡迎測試和反饋～”

剛剛官方在羣裏就發了這麼一句話，和下面那張圖。

**根據DeepSeek“API文檔”上的“模型&價格”頁面中，模型版本新增了DeepSeek-V4-Pro-0813，其支持非思考與思考模式。**

從目前公佈的信息來看，deepseek-v4-pro 支持 1M 上下文長度，最大輸出長度達到 384K Token，同時支持非思考模式和思考模式，其中思考模式默認開啓，**性能逼近最強的Claude Fable 5，與Opus 5性能相近。**

兩者的併發限制也有所區別。deepseek-v4-flash 的併發限制爲 2500，deepseek-v4-pro 則爲 500。

然而，當前API調用名稱仍是 deepseek-v4-pro，上下文爲 1M，最大輸出 384K，Responses API 現在也已經標爲支持。

價格層面，DeepSeek 此前發佈公告，宣佈計劃近期整體上調 API 服務定價，現在靴子落定。

deepseek-v4-pro正式版當前每百萬 Token 的價格分別爲：緩存命中輸入 0.025 元，緩存未命中輸入 3 元，輸出 6 元，與預覽版幾乎一致。

相比之下，deepseek-v4-flash 分別爲 0.02 元、1 元和 2 元。

**目前來看，DeepSeek-V4-Pro 的價格是V4 Flash正式版的3倍。**

當然，性能上也無法比擬，但這個價格要比Qwen等模型，以及國外的GPT-5.6、Claude系列價格都要略低一些。

除了DeepSeek，杭州另一個兄弟——阿里也開源了。

剛剛，阿里Qwen團隊宣佈， 首次開源 Qwen-Max級別權重。

Qwen3.8-2.4T-A95B 模型總參數爲 2.4T，每個 Token 激活 95B 參數，原生支持 262,144 Token 上下文，並可擴展至 1,010,000 Token。

值得一提的是，Qwen3.8-2.4T-A95B還是一個因果語言模型，模型每個 MoE 層包含 512 個專家，每個 Token 選擇 10 個路由專家，並同時激活 1 個共享專家。

因此，Qwen3.8 延續 Qwen3.5 的混合架構，重點提升編程、辦公、科研和長週期 Agent 任務的端到端完成能力。官方雲端版 Qwen3.8-Max基於該開放權重模型，並加入更多生產環境能力。

官方公佈的評測覆蓋編程 Agent、通用 Agent、專業工作和長上下文等方向。

在官方所列評測中，Qwen3.8-Max 較 Qwen3.7-Max 在多項編程和通用 Agent 任務上提升明顯；與 Opus 4.8、Fable 5 和 GPT 5.6 Sol 等模型相比，不同評測結果互有高低。

以模型卡的結果爲例，Qwen3.8-Max 在 PaperBench 上得分 93.0，Terminal Bench 2.1 爲 86.6，FrontierSWE 爲 73.5，CoWorkBench 爲 74.8。這些數據來自 Qwen 官方測試，且各評測的 Harness、超時時間、採樣參數和上下文長度並不完全一致。

不過，開放版和雲端 Qwen3.8-Max 並不完全一樣。

**官方模型卡寫明，開源版原生支持 262K 上下文，可擴展到約 1M，並支持調節推理強度。當前版本只有文本輸入，而且必須開啓 Thinking。雲端 Qwen3.8-Max 才額外支持視覺輸入、非思考模式、默認 1M 上下文和官方內置工具。**

許可證也不再是 Apache 2.0，而是 Qwen 自定義許可。普通用戶仍可以下載、修改和部署，但部分大規模商業使用需要另行取得授權。

**此前已經有消息指出，阿里計劃開始向 Qwen3.8-Max 的大型商業用戶設置額外收費或授權條件。**

最後總結一下。

Qwen今年的戰略是商業化，所以很多小模型都遲遲不開源。但DeepSeek-V4兩個開源模型持續降價，以及Kimi K3的開源模型能力持續逼近海外水平，這促使阿里希望重啓Qwen模型開源。

如果說 DeepSeek 補齊了商業化服務的短板，那 Qwen3.8-2.4T-A95B 的開源，則是給整個開發者社區扔下重磅紅利。

過去萬億級 MoE 旗艦權重基本閉源鎖死，中小團隊、政企很難本地部署，如今阿里直接放開底層權重，意味着全行業都能基於這套頂尖底座做私有化二次開發，徹底打破高端模型只能雲端調用的壁壘。

**根據預告，Qwen3.8-27B也將會在近期公佈，最快下月公佈開源信息。**

不同於過去只堆參數不顧成本的路線，DeepSeek 這套分層產品體系，證明國產模型已經能精準區分客戶場景，用差異化定價降低企業使用高端算力的門檻，讓百萬字長文檔、複雜邏輯推演不再是巨頭專屬。

這次兩家同步發力，最難得的是路線完全互補，而非同質化內卷。DeepSeek 側重雲端 API 規模化服務，依靠分層定價、高併發承載企業線上生產流量，主打開箱即用的商用推理；Qwen則以開源權重爲核心，也開始慢慢做商業化，否則會持續虧損。

放眼全球，海外巨頭普遍只守閉源路線，極少開放旗艦權重；而國內一邊有創業公司打磨雲端服務，一邊有大廠釋放頂級模型底座，兩條賽道同步成熟，不再單一依賴某一家企業、某一條技術路徑，國產 AI 生態的抗風險能力、創新空間都大幅提升。

縱觀這兩款產品的同步落地，我的核心感受是：國產大模型正在發生黃仁勳所說的 “相變”，不再只是性能上的 “鉅變”，而是底層規則、產業邏輯的徹底重構。

短期來看，兩類產品會持續擠壓海外閉源模型的國內市場空間；長期而言，開放權重以及平價雲端服務的組合，會催生大量行業專屬 AI、私有化算力項目。

這場雙雄齊發不是一次短期熱點，而是國產 AI 從技術追趕，轉向自主構建產業生態的標誌性拐點。

屬於國產大模型的時代，已經真正到來。
