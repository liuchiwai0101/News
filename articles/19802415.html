修改場景：在安全管控APP的進程白名單模型列表頁查詢接口，排序有問題，希望Claude Code能修改並最終生成MR

步驟

#### 主要步驟

- 使用自然語言描述需求

- Claude Code修改代碼並push到遠端

- 手動生成並獲取gitlab token，並配置到本機，使Claude Code有調用gitlab api權限

- Claude Code生成Merge Request

#### 詳細步驟

1、在Claude Code命令行，輸入需求：查詢進程白名單模型列表”接口，幫忙修改代碼，在當前排序的基礎上，同時按主鍵ID倒序排序。修改完成後，commit代碼的message前綴爲【SC-1108】，並最終push到遠端生成一個MergeRequest給我

2、Claude Code分析代碼並修改代碼，然後Commit & Push代碼

3、由於 Claude Code 沒有調用 gitlab api 的權限，所以需要手動獲取gitlab token

4、可以讓 Claude Code 配置token，也可以自己手動配置

5、配置完成後，就可以讓 Claude Code 將上面的改動生成MergeRequest

6、將MR鏈接地址在瀏覽器打開
