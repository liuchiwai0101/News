Mount Thor 融資 4500 萬美元　建設 Apple Silicon AI 代理數據中心

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

灣區初創公司 Mount Thor 今日宣佈完成種子輪及 A 輪共 4500 萬美元的融資，旨在構建基於 Apple Silicon 的雲端基礎設施。該公司向投資者提出的核心論點是：AI 代理在 Apple Silicon 上表現卓越，但目前市場缺乏以數據中心規模租用這些資源的服務。

提供 macOS 彈性計算實例

CRV 和 Conviction 共同領投 A 輪，Chad Byers 和 Offline Ventures 共同領投種子輪。CSC Leasing、Enea Capital、Long Journey Ventures 和 Upper90 亦參與投資，OpenAI、Meta、Cognition、Together AI 和 Vercel 的天使投資人也提供了支持。此外，公司還為新硬件籌集了額外的非稀釋性資金。

Mount Thor 將 macOS 作為彈性計算實例運行在 Apple Silicon 上，類似於雲端供應商出租 Linux 虛擬機。客户可按需獲得大量 Mac 電腦，用於僅能在 macOS 上執行的工作負載，例如在強化學習環境中訓練電腦使用模型、運行安全的 macOS 沙盒供代理使用、維持讓代理在單一 Apple ID 下跨用户裝置工作的長期實例，以及為 Apple 軟件進行構建和測試的農場。

其解決方案提供兩種使用方式。在「託管計算」模式下，客户選擇機器級別和映像，可透過網頁入口、命令行工具、Kubernetes 或 API 獲取完整的裸機 Mac 或具有管理員權限的隔離 macOS 虛擬機，並按每台 Mac 每日計費。在「客户託管計算」模式下，組織在 Mount Thor 的站點使用自己的 MDM 系統運營自有 Mac，而 Mount Thor 負責設施運作，並提供序列號庫存、問題報告和事件通知服務。

瞄準推理效能與自主代理趨勢

該公司認為，AI 代理正逐漸成為 macOS 的使用者，因此對 Apple 平台的需求將隨代理數量而非人類數量增長。Mount Thor 創辦人兼執行長 Peter Voell 表示：「將 Apple 的操作系統和晶片擴展至數據中心規模，是人工智能基礎設施中一個巨大的未開發機會。」他指出，數十年來在無障礙功能和人機互動方面的投入，使 macOS 成為代理工作和人類監督的最佳場所。隨著 M5 Ultra 等晶片的問世，Apple Silicon 正成為高性能且更節能的生產推理平台。

M5 Ultra Mac Studio 於 8 月出貨，配備高達 512GB 的統一記憶體，使得單台機器即可處理大型開源權重模型，其功耗遠低於傳統 GPU 伺服器。Mount Thor 指出，新資金的一個重點是用於建設其稱之為「Apple Silicon 上最佳開源模型推理實驗室」的項目。

CRV 合夥人 Brittany Walker 表示：「Mount Thor 處於兩個重要轉變的交匯點：自主代理能力的快速擴展，以及支持本地和雲端工作負載的算力需求不斷增加。」她讚賞團隊讓大規模使用 Apple 平台進行代理式人工智能變得更加容易。

該團隊成員來自 Cerebras、CoreWeave、Fluidstack、Nebius、OpenAI 和 xAI。公司成立於今年，並在不到六個月內部署了首個數據中心。雖然 AWS 和 MacStadium 早已提供雲端 Mac 實例，但 Mount Thor 強調其目標客户是需要 Mac 執行任務的大型 AI 代理，這類需求隨代理數量而非開發者數量增長。公司計劃將資金用於擴大計算足跡和建設團隊，以迅速增加容量滿足客户需求。
