Vue 與 Vite：正在連成一條完整的路徑

Vite 曾經的標籤是"快"。但今天的 Vite 生態，已經遠不止於此。

Rolldown、Oxc、Vitest、Vite Task、Vite+、Void——這些工具正在形成一條完整路徑：從創建項目、啓動開發，到檢查、測試、構建、緩存優化，再到雲端部署與 AI Agent 協作。

Void 將數據庫、KV 存儲、AI 推理、身份驗證等能力開箱即用，內置 Skills 與 MCP 支持，讓 Coding Agent 能通過自然語言指令自動搭建並上線完整應用。

Vite+ 則用一個全局命令 vp 加一個 vite.config.ts，覆蓋從創建到部署的完整工具鏈——不只給人用，也給 AI Agent 用。

工具越統一，AI 越容易理解項目。流程越清晰，自動化越不容易失控。
