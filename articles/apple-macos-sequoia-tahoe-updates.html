Apple 推出 macOS Sequoia 15.8.2 與 macOS Tahoe 26.7.2　兩個維護版本以安全修正為主

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

Apple 在推出 macOS 27.2 的同時，亦向用户推送 macOS Sequoia 15.8.2 及 macOS Tahoe 26.7.2。兩個版本的正式版本號分別為 24H232 與 25G332，改動內容以安全修正為主。

兩版以安全修正為主

兩個系統在過去數週先後進入 Release Candidate 階段。在 RC 測試期間，Apple 除提及一貫的「重要安全修正」外，並未詳細説明系統包含哪些改動。

隨著正式版上線，Apple 預計會在安全更新頁面公佈 macOS Sequoia 15.8.2 與 macOS Tahoe 26.7.2 的修正詳情。

macOS 27.2 擴展 Siri 語言支援

同日推出的 macOS 27.2（代號 Golden Gate）把 Siri 的 AI 支援擴展至五種新語言，並包含底層改動，有可能為日後 Mac 支援觸控螢幕鋪路。
