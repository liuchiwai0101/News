上海AI Lab团队推出MemHarness：让Agent记忆像人类一样被重构

檢索過往經驗，已成爲增強 LLM Agent 決策能力的常見方法。在面對新任務時，Agent 往往會直接調用過去的經驗，藉助記憶輔助判斷。

但問題在於，**歷史經驗只有在適配當前****上下文****時****，****才具有****實用****價值**。多數現有記憶增強 Agent 會把檢索到的經驗當作靜態記錄，直接注入上下文，很少判斷這些經驗是否適合當前上下文。如果“舊”經驗與當前狀態不匹配，反而可能干擾決策、導致負面效果（負遷移）。

與人工智能（AI）系統不同，**人類調用記憶則更加靈活**：通常會結合當前上下文，重新判斷以往經驗該如何使用，從而更好地服務於當前決策。

受到這一啓發，**上海 AI Lab 團隊及其合作者提出****了“LLM Agent 經驗重構”框架 MemHarness**，通過在檢索與動作之間插入顯式的記憶重構環節來主動 harness 檢索到的經驗，並通過 GRPO 端到端地學習這一能力，且無需任何額外的人工標註。

結果顯示，MemHarness 的性能顯著**優於純強化學習（RL）和靜態記憶增強基線**方法，且在分佈外（OOD）場景中展現出很強的魯棒性。同時，重構目標不僅減少了負遷移，也在記憶重構過程中進一步訓練了 Agent 的推理能力。

论文链接：https://arxiv.org/abs/2607.28272

**像人類一樣“檢索、評估和重構”**

MemHarness 的設計思路是通過**在“檢索”與“動作”之間顯式插入“批判”與“重構”**這兩個新的環節，主動地 harness 所檢索到的經驗，從而將記憶從靜態的提示片段轉變爲具有上下文敏感性的指導信息。

其中，歷史記憶只保留可遷移的部分，供模型在新狀態下繼續使用。具體流程如下：

檢索：根據最近幾步的觀測和動作，判斷是否需要調用歷史經驗。需要時，模型會查詢經驗記憶庫，獲取相關經驗。

重構：負責將檢索到的經驗改寫成當前可用的指導。模型會結合任務描述、當前上下文、檢索到的記憶和來源狀態，比較過去與現在的差異，再決定保留、改寫還是丟棄。如果沒有合適的記憶，就跳過這一步，直接讓模型繼續推理。

動作生成：模型結合當前歷史信息和重構後的指導生成動作。重構模塊不單獨提供標註，整個流程主要依賴任務獎勵，並通過 GRPO 端到端優化。

圖｜MemHarness 框架概覽。

整個訓練階段，MemHarness 採用 GRPO 進行端到端優化，優化信號來自任務獎勵和格式約束。GRPO 會比較同一任務下多條軌跡的表現，思考、重構和動作生成可以同時訓練，不需要單獨訓練價值網絡。

持續優於純RL基線

研究團隊在兩個具有挑戰性的 agent 決策基準 ALFWorld 和 WebShop 上評估了 MemHarness。

結果顯示，MemHarness 持續優於純 RL 基線以及 SOTA 靜態記憶增強方法。消融實驗進一步表明，**去除重構階段會使模型性能退化到與樸素記憶重放相當的水平**，這證實了自適應重構（而非單純的檢索）纔是實驗中所觀察到的性能提升的主要驅動因素。

詳細實驗結果如下：

1.優於純 RL 和靜態記憶

結果顯示，相比直接疊加外部記憶的做法，MemHarness 通過記憶重構取得了更好的整體表現；即便模型規模只有 7B，其表現也超過了更大規模的 Gemini-2.5-Pro 等閉源模型。

圖｜ALFWorld 和 WebShop 上的主要結果。

2. 直接複用記憶會引入噪聲

消融結果顯示，當去掉記憶重構後，Agent 在 ALFWorld 上的表現會下降。直接將檢索到的經驗放入上下文，並不一定能輔助決策。

圖｜MemHarness 各組件的消融實驗。

在 OOD 評測中，測試環境換成了訓練時沒見過的佈局和物品位置。當 Agent 直接套用舊經驗時，更容易做出錯誤決策；MemHarness 則會先判斷記憶是否適用，並改寫或捨棄不匹配的內容，在 OOD 場景中具有強大的魯棒性。

圖｜ALFWorld 在 OOD 場景中的表現。

3.重構需要端到端訓練

訓練過程中，Agent 會把交互軌跡中的經驗逐步存進記憶庫，每次只取最相關的三條作爲參考。由於沒有現成標註告訴模型記憶該怎麼改寫，整套“檢索-重構-行動”流程只能靠 GRPO 結合任務獎勵端到端訓練。

圖｜RL 訓練過程中記憶使用行爲的演化。

4.當前狀態決定重構是否有效

結果顯示，策略模型是否採納重構內容，取決於來源狀態和當前狀態是否匹配。如果將來源狀態替換爲明顯不匹配的隨機狀態，模型的拒絕率會上升；如果直接刪去原始狀態信息，拒絕率變化不大，任務成功率會下降。

圖｜按記憶決策條件劃分的成功率訓練動態。“SR when Accepted/Rejected”表示包含至少一次被接受或被拒絕的記憶重構的軌跡對應的成功率。

當然，目前的方法也存在一些不足。

例如，MemHarness 目前主要只在 ALFWorld 和 WebShop 兩個交互式基準上進行了驗證，尚未覆蓋更開放、更多樣的真實環境。未來，研究團隊仍需在更大規模的模型和更開放的環境中進一步驗證該方法。

此外，目前冷啓動模型本身的任務表現有限，真正的重建和決策能力仍需要要依賴後續的任務級強化學習。
