OpenAI 正式推出 Images 2.6　ChatGPT 支援直接生成動畫 GIF．API 支援 SVG 輸出

內容機器翻譯自第三方媒體（PCM），僅供參考，以原文為準。

OpenAI 於美國時間 11 月 4 日正式發布新一代圖片生成模型 Images 2.6，加入動畫 GIF 生成功能，讓用户透過文字指令直接製作循環動畫。經筆者實測，毋須提供任何標誌圖片，只需輸入 PCM 的網址和動畫的文字描述，ChatGPT 便能抓取 PCM 標誌直接生成字母跳躍登場的 GIF，展示生成式 AI 在日常設計及內容製作方面的應用潛力。

生成活潑跳躍的 PCM 標誌動畫 GIF，僅花了 1 分 7 秒，容量為 229K。

ChatGPT 首次支援直接生成動畫 GIF

Images 2.6 最受關注的新功能，是讓 ChatGPT 直接生成動畫 GIF。用户只需要以自然語言描述希望呈現的角色、動作及動畫效果，便可以要求系統製作循環動畫，毋須自行使用傳統動畫軟件逐格繪製。

例如，用户可以要求 ChatGPT 製作正在揮手的卡通人物、跳舞的品牌吉祥物，或適合社交平台使用的動態反應圖片。

由 GPT Images 2.6 生成的角色動畫，容量為 688K，適合放在網頁上，但色彩就較淡，雜訊較多。

除了從文字直接建立動畫，用户亦可以提供已有的圖片作為參考，再要求 AI 加入動作或其他視覺效果。

對需要快速製作簡短動畫的用户而言，這種操作方式可以大幅降低製作門檻。

筆者實測：毋須上載圖片　ChatGPT 直接生成 PCM 標誌動畫

為測試 Images 2.6 的動畫生成能力，筆者直接在 ChatGPT 輸入以下指令：

製作一張 https://www.pcmarket.com.hk 的標誌 GIF，描邊標誌每個字母蹦蹦跳的從畫框左邊跳到中央登場，氣氛快樂。

筆者透過 ChatGPT 輸入文字指令，要求 PCM 標誌字母以跳躍形式登場。整個過程毋須上載原始標誌圖片，ChatGPT 約用 1 分 7 秒便完成 GIF 動畫生成，並可在對話介面直接預覽。

整個測試過程中，筆者沒有上載 PCM 標誌圖片，亦沒有事先製作任何動畫畫格，而是直接透過 ChatGPT 本身的上網功能從網站取得 PCM 標誌，以文字描述希望生成的內容。

ChatGPT 隨後成功生成 GIF 動畫，字母以跳躍形式進入畫面，紅色「PC」字樣成為主要視覺元素，並配合星星、彩紙及其他色彩裝飾，呈現歡樂的登場效果。整體效果符合筆者要求的方向，亦證實 ChatGPT 已能直接完成簡單的標誌動態展示。

從測試畫面可見，ChatGPT 約用了 1 分 7 秒完成這次生成工作。完成後，動畫可直接在 ChatGPT 對話介面預覽，畫面亦提供播放速度及分享功能。

完成 GIF 圖可逐格編輯。

這次實測最值得注意的是，用户並不需要自行準備原始圖片檔案、動畫素材或 GIF 製作軟件。即使只有一個網站網址及簡單的文字描述，ChatGPT 仍能嘗試理解創作要求，並生成相應動畫。

生成的 GIF 可以即時分享，但並非直接分享圖像，而是分享連結。想直接分享圖像仍需要下載。

不過，這次結果亦反映 AI 生成品牌標誌仍存在限制。雖然動畫呈現了 PCM 標誌的主要視覺風格，但畫面中的字母及細節未必完全符合官方標誌的精確設計。若用於正式品牌宣傳，仍應由設計人員核對品牌字體、比例、顏色及其他視覺規範。

另一項測試，筆者提供角色設定圖，要求製作角色轉身打招呼的動畫。圖像約在 1 分 45 秒完成，基本上符合設定，只有少量問題可透過修改提示詞解決。不過輸出圖像有很多雜訊。官方示範以草稿來生成 GIF 動畫。

圖片生成速度提升 50%　強化角色與品牌一致性

除了加入動畫功能，OpenAI 亦著重改善圖片生成及反覆編輯的效率。官方表示，Images 2.6 的圖片生成速度較上一代提升約 50%，有助縮短用户在設計過程中等待生成結果的時間。

提升生成速度也是 Images 2.6 的重點。

新模型同時改善圖片細節的一致性，尤其是角色服裝、人物外觀、產品造型及品牌元素等容易在多次修改後出現變化的部分。

例如，用户可以先生成一張角色圖片，再要求修改背景、光線或場景。Images 2.6 的目標是盡量保留原有角色的服裝及外觀特徵，避免每次編輯都出現不必要的改動。

對需要製作系列廣告圖片、產品宣傳圖或故事角色的創作者而言，這項改善尤其重要。OpenAI 亦指出，新模型改善了海報、產品圖片及其他專業視覺設計的排版品質。

新增參考圖片功能　可跨對話重用角色與素材

ChatGPT Images 2.6 亦加入 Saved Reference Images 功能，容許用户將常用照片保存為具名稱的參考圖片，在日後不同對話中再次使用。

例如，用户可以將寵物照片儲存為指定名稱，其後只需在新對話中引用該名稱，便可以要求 ChatGPT 生成相關插畫，而不必每次重新上載原始照片。

直接在對話中要求儲存角色設定。完成後會回覆儲存路徑（雖然將來只會使用名字稱呼）

這項功能亦可應用於固定角色、品牌吉祥物及其他需要長期維持外觀一致的創作素材。對經常製作系列圖片的設計師、內容創作者及市場推廣人員而言，跨對話重用參考圖片可減少重複準備素材的工作。

API 推出 Flare 與 Sunburst 兩款模型

針對開發者及企業用户，OpenAI 同步推出兩款 Images 2.6 API 模型，分別是 GPT-Image-2.6 Flare 及 GPT-Image-2.6 Sunburst。

Flare 主要針對生成速度及快速編輯而設計。OpenAI 表示，在低品質設定下，最快可以約 6 秒生成一張圖片。Sunburst 則著重圖片品質、細節及反覆編輯時的一致性，較適合需要精細畫面或維持特定設計風格的工作。

OpenAI 亦為 API 加入圖片標註編輯、SVG 格式輸出，以及新的 complexity 參數。

圖片標註編輯功能讓開發者指定需要修改的位置，減少以文字描述局部編輯時可能產生的誤差。SVG 輸出則方便將生成結果進一步應用於網站、App 或設計流程。

至於 complexity 參數，開發者可以調整模型處理圖片任務時的規劃程度，在生成速度及複雜任務處理能力之間作出選擇。

這些功能反映 OpenAI 正進一步把圖片生成技術整合至專業設計及企業自動化平台，而不再侷限於一般聊天介面的圖片製作。

每星期生成約 40 億張圖片　OpenAI 加強動畫安全防護

OpenAI 披露，目前 ChatGPT、Codex 及 API 每星期合共生成約 40 億張圖片，平均每日超過 5 億張。

隨着 Images 2.6 加入動畫功能，OpenAI 亦介紹專門針對 GIF 的安全措施。

與一般靜態圖片不同，動畫可能透過多個畫格的連續動作表達內容，因此只分析單一畫格未必足夠。

OpenAI 表示，新系統會結合動畫畫格及生成描述進行安全檢查，並對部分動畫內容採取比靜態圖片更嚴格的限制。

不過，涉及畫格之間動作及語意的問題仍然較難準確辨識，現有防護措施不能保證完全阻止所有不當生成結果。

ChatGPT 圖片生成邁向動畫創作　降低內容製作門檻

Images 2.6 已由 11 月 4 日（當地時間）起向 ChatGPT、Codex 及 API 用户推出，涵蓋不同使用方案。

動畫 GIF 功能採取分階段開放安排，不同用户取得功能的時間可能存在差異。

從這次實測可見，生成式 AI 已不再侷限於製作單張靜態圖片，而是開始讓一般用户透過簡單文字描述，直接完成具有動態效果的視覺內容。
