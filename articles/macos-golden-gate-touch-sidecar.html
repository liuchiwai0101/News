macOS Golden Gate 觸控支援擴至外部螢幕　Sidecar 可透過手指直接操作

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

Apple 在新款 PROLED MacBook Pro 上引入的 macOS Golden Gate 觸控相關改變，不僅適用於這台筆記型電腦，第三方外部螢幕與 Sidecar 功能同樣能受惠於此更新。

觸控介面在多種裝置上的表現

隨著 Apple 決定為新款 OLED MacBook Pro 加入觸控螢幕支援，macOS 系統也必須進行相應調整以配合硬體。這些改動並不只限於最新推出的筆電，任何使用具備觸控功能的外部螢幕使用者，都能體驗到 macOS 27 中的新介面。包括透過 Sidecar 將 iPad 作為延伸螢幕的使用者，亦能受益於此功能。

測試結果與驅動程式影響

目前發現，macOS 的觸控增強功能已在 iOS 27.3 和 macOS 27.3 的開發者 Beta 版本中運作正常。測試人員嘗試了兩款第三方觸控螢幕，其中一款即插即用即可運作，另一款暫時無法使用。經確認，問題出在驅動程式而非螢幕硬體本身。

介面元素針對觸控優化

雖然在一般鍵盤與滑鼠使用情境下，macOS Golden Gate 的外觀維持不變，但當使用者採用觸控方式時，系統會有多項細微調整。例如視窗左上角的「交通燈」按鈕（關閉、最小化、最大化）在被觸碰時會變大，以便手指更精確地點擊。這種設計類似 iPadOS 的互動體驗，單次輕觸即可放大按鈕區域，讓後續點擊能準確命中目標。頂部選單列也能動態放大，以方便觸控操作。此外，長按 Dock 圖示或其他 UI 元素時，會彈出更符合觸控習慣的選單與動畫效果。

應用程式支援與開發者 API

儘管重點在於 macOS 系統本身，部分改變已即時套用於 macOS 應用程式。Apple 表示，開發者可利用手勢 API 擴展其應用的觸控支援能力，超越簡單的模擬滑鼠點擊。

Sidecar 觸控互動改進

過去 Sidecar 雖允許用户將 Mac 工作區延伸至 iPad 螢幕，並支援 Apple Pencil 控制，但缺乏直觀的手指觸控體驗。早期僅能處理多點手勢或將 iPad 當作 Magic Trackpad 使用，無法真正與 macOS 介面進行互動。在 macOS 27 的初期開發者 Beta 版本中，Apple 曾嘗試讓 iPad 螢幕上的觸控動作對應相同位置的滑鼠點擊與拖曳。而在最終版本的 macOS 中，經過介面調整後，使用者僅需透過手指觸控便能更輕鬆地瀏覽 macOS 及其應用程式。
