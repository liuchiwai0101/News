AI+辦公：Agent都有“工位”了，雲電腦既讓它接手業務、也管住權限 ｜ 阿里雲智能集團研發副總裁 張獻濤分享

正文

在 1024 模力工場 · AI社區日 主論壇上，阿里雲智能集團研發副總裁、終端智能計算事業部負責人張獻濤，以《雲電腦的演進：從人的辦公桌面到智能體的工位》為題，分享了雲電腦在 Agent 時代的新角色： 為智能體提供一個能持續運行、權限可控，並能與人協作的工作環境。

張獻濤於 2014 年加入阿里雲，長期負責彈性計算服務 ECS，隨後轉向終端設備與 AI 結合的業務探索。從支撐雲上業務運行，到為 Agent 提供操作軟件的環境，他關注的問題也隨之延伸：當智能體開始進入企業工作流程，怎樣才能讓它順利幹活？

過去，雲電腦是人遠程辦公的工具；如今，Agent 也需要這樣一個“工位”。它要在裏面打開軟件、訪問業務系統、處理任務，遇到無法繼續的步驟，還得有人能接手。

給 Agent 配“工位”，首先是讓它有工具可用。 之前的 Agent 主要通過瀏覽器執行任務；接入雲電腦後，它們可以進一步使用桌面軟件和企業應用，處理跨系統的複雜工作。對於沒有開放 API、仍然依賴圖形界面操作的老舊系統，這種能力尤其重要。

但有一台電腦，並不意味着 Agent 就能在企業裏順利工作。它以什麼身份登錄，能訪問哪些數據、執行哪些操作，操作過程如何記錄和審計，都需要明確。雲電腦的作用，也因此從提供運行環境，延伸到身份、權限和資源的統一管理。

另一個關鍵問題是：Agent 卡住了，人能不能接得上手？

張獻濤以訂單處理為例：Agent 接收新訂單後，需要核對信息、生成報告，再提交主管審批。這條流程看起來順暢，實際執行時卻可能遇到登錄失效、驗證碼，或需要人工判斷的情況。任何一步受阻，都可能讓任務停下來。

這時，雲電腦需要保存當前工作狀態，通知用户並説明阻塞原因，讓人接入處理。問題解決後，Agent 再接着執行。這樣的協作，既需要人看得懂任務進行到了哪一步，也需要系統保留現場，避免每次接管後都從頭重來。

這些能力已經開始用於具體業務。據張獻濤介紹，好未來的一個項目在不到兩週內，通過企業級雲電腦部署了約 1,000 個 Agent，為教師提供教案、課件製作及作業批改等支持。員工也可以進入雲電腦進行調試，並利用數據恢復等能力保障數據安全。

總而言之，在張獻濤看來，雲電腦積累了多年的身份權限管理、資源管理和協作能力，剛好可以成為 Agent 的“工位”： 雲電腦為 Agent 提供運行軟件、訪問業務系統的環境，並管理好身份和權限。當 Agent 遇到問題時，人可以接入同一台雲電腦處理，隨後再由 Agent 繼續執行任務。

以下為張獻濤講演的完整速記，模力工場在不改變原意的前提下進行了訂正和編輯。

Agent 也有“工位”了：雲電腦讓它能接手業務，也管住了權限

各位嘉賓、各位朋友，大家節日好！非常歡迎大家來到雲谷，也感謝 Kevin 的邀請。過去幾年，我和 Kevin 有不少交流。今天也很開心見到許多老朋友，剛才還見到了畢玄。

畢玄見面後的第一句話就是：“你們的雲電腦現在已經變成 Agent 的基礎設施了，應該賣得很好吧？”我説，確實如此。

先向在座的新朋友介紹一下自己。我的履歷比較簡單：畢業後的前 9 年在英特爾工作，主要從事雲計算核心技術相關的研發。2014 年加入阿里雲，到現在已經 12 年了。前 10 年，我主要負責彈性計算服務，也就是 ECS。2024 年初，我開始內部創業，探索終端設備與 AI 結合的新業務。

過去幾年，我們做了無影雲電腦。前段時間的雲棲大會上，我們還發布了千問 Book，這是業界第一台智能體電腦。

今天討論的話題與此密切相關： 無影雲電腦迎來了一個新時代，它正在成為智能體的“工位”。

首先，回顧過去三年多的變化。2023 年初，以大模型為代表的這一輪 AI 浪潮爆發，大致經歷了三個階段。

第一個階段，以 ChatGPT 這樣的 Chatbot 為代表。它帶給大家的震撼是：人工智能的能力確實很強，已經能夠輕鬆處理自然語言，與人類交流。

第二個階段，以 Agent 應用為代表，比如 Coding Agent 和工作類 Agent。它們讓我們發現，AI 可以調用各種工具，代替人類完成非常複雜的工作。

第三個階段，是最近很受關注的 Personal Agent，也就是個人智能體。各家廠商都在發佈相關產品，阿里也發佈了千問 Go（千問在 2026 年推出的 Personal Agent）。

這意味着 Agent 正在進入一個非常重要的場景：個人生活和工作。

關注 Personal Agent 的朋友應該能感受到，一個被反覆強調的重點是： 給每個 Agent 配備一台雲電腦，讓 Agent 可以向雲電腦下達各種複雜任務 。以前，它可能主要調用瀏覽器；有了雲電腦之後，就能完成更加複雜的工作。

背後的道理很簡單。我們接觸的世界，可以分為物理世界和數字世界。物理世界是我們可以觸及的現實世界，數字世界則包括互聯網和移動互聯網，是人類構建起來的。
