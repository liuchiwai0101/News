逐行比對版本掌握修改細節　原價 US $0.99《Orange Cat》限時免費

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

Orange Cat 是一款 Markdown 筆記編輯器，能把零散想法整理成結構清晰、日後易於重讀的文字。無論是隨手記下的短筆記，還是持續修訂的長篇文稿，都可以在同一個介面完成。此工具原價 US $0.99，現正限時免費，適合習慣以 Markdown 寫作的學生、寫作者與上班族。

並排預覽與版本比對

編輯與預覽並排顯示，可切換專注模式只留文字，或以閲讀模式檢視成果。修改時可手動或自動建立版本，瀏覽筆記歷史並逐行比對差異。另備內置搜尋快速找回筆記，按月份整理內容，寫作可匯出為 Markdown，外觀與字體可自行調整，常用功能亦設鍵盤快捷鍵。
