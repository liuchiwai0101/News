📰 本週重要資訊

由 VoidZero 團隊打造的 **Rolldown 1.0** 本週正式發佈，這是一個基於 **Rust** 編寫的高性能 JavaScript 打包器，現已作爲 **Vite 8** 的統一底層引擎。Rolldown 在兼容 Rollup 插件 API 的同時，打包速度比 Rollup 快 **10-30 倍**。早期採用者 Linear 的構建時間從 46 秒降至 6 秒。這意味着前端構建工具鏈正式進入 Rust 時代——Rolldown 與 Rspack、Turbopack 三足鼎立的格局已經形成。

本週前端社區最大的安全事件：5 月 11 日，攻擊者利用 **GitHub Actions 漏洞鏈**（pull_request_target Pwn Request + 緩存投毒 + OIDC Token 竊取），在 **6 分鐘內發佈了 84 個惡意版本**，覆蓋 42 個 @tanstack/* 包。攻擊者並未竊取維護者憑證——惡意代碼是通過 TanStack 自身的合法發佈流水線推送的，擁有有效的 **SLSA Build Level 3 認證**。受影響範圍隨後擴大到 170+ 個 npm 和 PyPI 包，包括 Mistral AI、UiPath 等。

該攻擊被命名爲 **Mini Shai-Hulud**,CVE-2026-45321,CVSS 評分 10.0。

Bun 發佈了 **v1.3.14**，這很可能是最後一個使用 **Zig** 編寫的版本。本次更新帶來了 **Bun. Image**——一個可替代 Sharp 的內置圖像處理 API，支持 JPEG、PNG、WebP、GIF、BMP 等格式；**HTTP/3（QUIC）實驗性支持**；以及 **7 倍更快的熱安裝速度**（通過全局虛擬存儲）。與此同時，Jarred Sumner 宣佈 Bun 的 Rust 重寫已通過 **99.8% 的原有測試套件**，96 萬行 Zig 代碼被遷移至 Rust，整個過程僅用了約 6 天，大量藉助 Claude Code 完成。

Node.js 26（Current）於 5 月 5 日正式發佈，將在 **2026 年 10 月進入 LTS**。核心亮點包括：**Temporal API** 默認可用（無需 flag）、Map upsert 輔助方法、Iterator.concat、V8 14.6 引擎和 Undici 8。隨後發佈的 **Node.js 26.1** 更進一步，新增了實驗性的 **FFI（外部函數接口）支持**，允許直接調用 C 語言庫。Node.js 22.22.3（LTS）也在本週發佈，修復了關鍵加密空指針崩潰問題。
