CSS Container Queries：徹底告別 @media 寫到手軟（附 5 個真實佈局案例）

以前寫響應式組件，總要根據視口寬度寫一堆@media，代碼又臭又長。現在 Container Queries 讓組件根據父容器尺寸響應，代碼直接減半。本文講透語法 + 5 個可直接複用的案例。

一、Container Queries 解決了什麼問題？

@media 媒體查詢基於**視口**寬度。這導致一個組件在不同父容器下無法獨立響應——同樣的卡片，在側邊欄和主內容區需要兩套樣式或者額外類名。

**Container Queries** 允許你定義：當**父容器**達到某個寬度時，子元素改變佈局。

/* 以前：基于视口，无法区分卡片在哪个容器里 */
@media (min-width: 600px) {
  .card { display: flex; }
}
/* 现在：基于父容器宽度 */
@container (min-width: 300px) {
  .card { display: flex; }
}

二、基礎語法（三步搞定）

2.1 定義容器

.sidebar {
  container-type: inline-size;   /* 监听内联方向（宽度）变化 */
  container-name: sidebar;       /* 可选，给容器起名 */
}

- `container-type: inline-size`最常用，表示根据宽度变化。

- 也可以 `size`（寬高都監聽）或`normal`（不監聽）。

2.2 使用 @container

@container (min-width: 300px) {
  .card-title {
    font-size: 1.5rem;
  }
}

如果只有一個容器，可以直接寫條件。如果有多個容器，用 container-name 限定：

@container sidebar (min-width: 300px) {
  /* 只对 sidebar 容器内的元素生效 */
}

2.3 組合與範圍

@container (100px <= width < 300px) {
  /* 容器宽度在 100px 到 300px 之间 */
}

三、與 @media 對比（代碼量減少 50%）

**代碼對比**：

<!-- 以前：需要额外类名 -->
<div class="sidebar">
  <div class="card vertical"></div>
</div>
<div class="main">
  <div class="card horizontal"></div>
</div>
/* 以前：手动控制 */
.card.vertical { flex-direction: column; }
.card.horizontal { flex-direction: row; }
/* Container Queries：一套规则 */
.card {
  container-type: inline-size;
}
@container (min-width: 400px) {
  .card { flex-direction: row; }
}
@container (max-width: 399px) {
  .card { flex-direction: column; }
}

四、5 個實戰案例（可直接複製）

案例 1：卡片組件根據容器寬度切換佈局

<div class="card-container">
  <div class="card">
    <img src="photo.jpg" alt="">
    <div class="card-body">
      <h3>标题</h3>
      <p>描述文字</p>
    </div>
  </div>
</div>
.card-container {
  container-type: inline-size;
}
.card {
  display: flex;
  flex-direction: column;
  gap: 1rem;
}
@container (min-width: 350px) {
  .card {
    flex-direction: row;
    align-items: center;
  }
  .card img {
    width: 40%;
  }
}

案例 2：側邊欄與主內容區共享同一卡片組件

/* 不需要任何额外代码，卡片自己响应父容器宽度 */
.sidebar { container-type: inline-size; width: 280px; }
.main { container-type: inline-size; width: 800px; }
/* 卡片规则如上，当父容器<350px时垂直，>350px时水平 */

案例 3：儀表盤小部件矩陣

<div class="dashboard">
  <div class="widget" style="width: 200px">...</div>
  <div class="widget" style="width: 400px">...</div>
  <div class="widget" style="width: 200px">...</div>
</div>
.widget {
  container-type: inline-size;
}
.widget-content {
  font-size: 12px;
}
@container (min-width: 250px) {
  .widget-content {
    font-size: 16px;
    display: flex;
    gap: 1rem;
  }
}

案例 4：商品列表切換行列（類似 Grid 與 Flex 混合）

.product-list {
  container-type: inline-size;
  display: flex;
  flex-wrap: wrap;
  gap: 1rem;
}
.product-item {
  flex: 1 1 200px;
}
@container (max-width: 500px) {
  .product-item {
    flex-basis: 100%;  /* 小于500px时每行一个 */
  }
}

案例 5：自適應導航欄（摺疊菜單）

<nav class="navbar">
  <div class="logo">Logo</div>
  <ul class="nav-links">
    <li>首页</li>
    <li>产品</li>
    <li>关于</li>
  </ul>
</nav>
.navbar {
  container-type: inline-size;
  display: flex;
  justify-content: space-between;
}
.nav-links {
  display: flex;
  gap: 1rem;
}
@container (max-width: 500px) {
  .navbar {
    flex-direction: column;
  }
  .nav-links {
    flex-direction: column;
    margin-top: 0.5rem;
  }
}

五、瀏覽器兼容性與降級方案

**支持情況**（截至 2026-06）：

- Chrome 105+ ✅

- Firefox 110+ ✅

- Safari 16+ ✅

- Edge 105+ ✅

**如果需要兼容舊瀏覽器**，使用 `@supports` 漸進增強：

/* 降级：默认样式（例如始终垂直） */
.card {
  flex-direction: column;
}
/* 支持 Container Queries 时覆盖 */
@supports (container-type: inline-size) {
  .card-container {
    container-type: inline-size;
  }
  @container (min-width: 350px) {
    .card {
      flex-direction: row;
    }
  }
}

六、總結

- Container Queries 讓組件根據**父容器**而非視口響應，實現真正的組件級響應式。

- 语法简单：`container-type`+`@container`。

- 5 個案例覆蓋卡片、側邊欄、儀表盤、商品列表、導航欄。

- 兼容性已可投入生產，配合 `@supports`安全降級。
