Google Chrome 終於支援 Netflix 4K 僅限 Windows 11 與 Chromebook

Netflix 更新官方支援頁面，確認 Google Chrome 現在支援 4K 播放。這項功能讓用戶終於可以透過 Chrome 觀看 Netflix 的 4K 內容，但並非所有裝置都能使用。

支援平臺有限

目前 Netflix 4K 播放僅適用於 Windows 11 與 Chromebook。Windows 10、macOS 和 Linux 上的 Chrome 暫時不支援 4K 播放。

硬件要求

硬件方面，Windows 電腦需要配備 Intel 第 7 代或更新的 CPU，或 AMD Ryzen CPU；顯示卡則需要 Nvidia GTX 1050 或 AMD Radeon RX 400 系列或更新的型號。此外，系統亦可能需要支援 HEVC 及更新驅動程式。

其他瀏覽器支援

除了 Chrome，Windows 上的 Microsoft Edge 與 macOS 上的 Safari 亦已支援透過網頁瀏覽器播放 Netflix 4K 內容。
