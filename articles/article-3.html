**5****、****微軟推出 MAI-Code-1.1-Flash 編程模型：更好、更快，價格降至 1/4**

8月12日消息，早在今年 6 月，微軟首次公佈了 MAI-Code-1。這是一款針對 GitHub Copilot 工作負載進行優化、強調推理效率的編程模型。此後，MAI-Code-1 的 Flash 版本登陸 GitHub Copilot，成爲用戶可選的模型之一，可與 OpenAI 和 Anthropic 的模型競爭。

MAI-Code-1-Flash 剛發佈時，其價格和效率表現頗具競爭力，但很快就被 GLM-5.2、Kimi K3 等價格更低且性能強大的中國模型，以及 OpenAI 的 GPT-5.6 Luna 搶去了風頭。

今天，微軟宣佈推出升級版 MAI-Code-1.1-Flash，在提升代碼編寫能力的同時，大幅降低成本和 Token 消耗。微軟表示，通過 GitHub Copilot CLI 使用 MAI-Code-1.1-Flash 時，該模型在 Terminal-Bench 2.1 測試中的表現提升了 22%，在.NET 相關任務中的表現則提升了 15%。

微軟還表示，新模型的 Token 生成速度提升了 25%，同時完成相同任務所需的 Token 數量減少了 25%。得益於訓練和服務效率的提升，微軟將 MAI-Code-1.1-Flash 的價格降至初代模型的四分之一。對於年度 Copilot 訂閱用戶，該模型的高級請求倍率爲 0.25 倍。

根據 GitHub Copilot 的價格表，MAI-Code-1.1-Flash 的價格爲每 100 萬輸入 Token 收費 0.20 美元（現匯率約合 1.4 元人民幣），每 100 萬緩存輸入 Token 收費 0.02 美元（現匯率約合 0.14 元人民幣），每 100 萬輸出 Token 收費 1.20 美元（現匯率約合 8.1 元人民幣）。

相比之下，MAI-Code-1-Flash 每 100 萬 Token 的價格分別爲 0.75 美元（現匯率約合 5.1 元人民幣）、0.075 美元（現匯率約合 0.51 元人民幣）和 4.50 美元（現匯率約合 30.4 元人民幣），新模型的價格大幅下降。

除了代碼能力提升之外，MAI-Code-1.1-Flash 還新增原生視覺能力，可以理解和分析圖像內容。

目前，MAI-Code-1.1-Flash 已经开始陆续登陆 GitHub Copilot 的各项服务，包括 VS Code、Visual Studio、JetBrains IDE、Copilot CLI、GitHub Mobile 以及其他受支持的平台。

免費用戶和學生用戶可以通過自動模型選擇功能使用該模型，付費用戶則可以手動選擇 MAI-Code-1.1-Flash。

隨着升級版模型正式上線，GitHub 將於 2026 年 9 月 10 日在所有 Copilot 服務中停止提供 MAI-Code-1-Flash。（IT之家）
