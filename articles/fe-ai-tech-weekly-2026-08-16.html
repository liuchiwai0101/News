構建工具

pnpm 12 RC

8 月 10 日，pnpm 官方博客發佈 pnpm 12（Rust 重寫版）的差異說明，確認其處於 RC 階段併兼容 pnpm 11 的命令、設置與鎖文件格式。三處實質變化：全局命令遵循項目鎖定版本（globalShims）、Git 依賴一律解析爲規範 HTTPS URL（鎖文件不再記錄 SSH 地址）、移除 --resolution-only 標誌（改用 pnpm peers check）。

舊鎖文件中記錄 SSH 地址的 Git 依賴需 pnpm update 重新解析；CI 腳本若使用 --resolution-only 將直接報 unexpected argument 失敗。使用 pnpm 11 的團隊應先 grep 替換該標誌再評估 RC，遷移風險爲中，建議 **verify**。

SWC 1.16.0

参考来源：SWC 1.16.0 changelog

8 月 14 日发布的 SWC 1.16.0 修复 JSX surrogate entity panic、静态字段参数中的 this、minifier 初始化循环与 React Compiler 类型重载丢失；同时调整 Switch.body_ctxt、拆分 TypeScript this 参数，并引入 FunctionBody 等多项 AST 破坏性变更。

直接使用 swc_core AST、visitor 或插件 ABI 的工具需同步修改節點匹配和序列化邏輯；僅通過上層構建工具使用 SWC 的項目仍應迴歸 JSX、壓縮與 React Compiler 產物。AST 集成用戶應先完成適配再升級，兼容性風險爲高，建議 **migrate**。

Rspack 2.1.9 与 2.1.10

8 月 11 日的 Rspack 2.1.9 新增未知 import.meta 属性告警、import.meta.glob 的 caseSensitive 选项、Linux ppc64/s390x 构建与 create-rspack --no-git，并优化 copy 插件缓存与 HMR 增量处理；8 月 13 日的 2.1.10 移除了 2.1.9 中过噪的 import.meta 告警，引入新缓存系统与 ExternalModule 的 chunkCondition 钩子。

2.1.10 還將 rkyv 升至 0.8.18 修復 RUSTSEC-2026-0233/0234/0235。2.1.9 的告警在自定義運行時屬性場景會大量刷屏，已隨 2.1.10 撤銷；新緩存系統可能改變磁盤緩存行爲。使用持久緩存或依賴緩存插件的團隊應直接升級到 2.1.10 並複測緩存命中，緩存風險爲中，建議 **upgrade**。

8 月 12 日發佈的 Rolldown 1.2.4 放寬了已加載合併場景下的 namespace 提取，修復 Android arm64 上的 illegal instruction 崩潰、負向 sideEffects glob 保留模塊，以及 devtools 日誌路徑未按構建目錄解析的問題；同批測試補充了真實瀏覽器與 WebContainer 的 WASI 冒煙驗證。

Android arm64 崩潰影響移動端構建場景，其餘爲邊界修復。採用 Rolldown 原生或 WASI 綁定的工具鏈應升級後複測產物與日誌路徑，兼容性風險爲低，建議 **upgrade**。
