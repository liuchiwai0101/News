開發者以 Claude 在破解版 PS5 原生運行 Xbox Cloud Gaming

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

巴西開發者 RafaelNGP 為已越獄的 PS5 自製 Homebrew 程式 PSBox Cloud Gaming，並已在 GitHub 上發佈供下載。這個改裝部分藉助 Claude 編寫，可讓 Xbox Cloud Gaming 在 PS5 上原生運行，並支援最多四個 DualSense 控制器對應至 Xbox，以確保兼容。

安裝步驟與手機代碼登入

Rafael 表示安裝過程相當簡單：從其 GitHub 下載 .zip 檔案、解壓到指定資料夾，等待 Homebrew 載入器掛載該「遊戲」，然後啟動並照常登入。用户亦可透過電視上顯示的代碼，以手機完成登入。

1080p60 串流可升頻至 4K

程式目前支援 1080p60 串流，並可利用 PS5 的 GPU，配合 AMD FSR 1 或 Anime4K 升頻器把畫面提升至 4K。

測試者反映畫面與震動問題

應用程式仍未完善，測試者報告出現馬賽克區塊、粉紅色異常等畫面問題，DualSense 控制器亦有震動問題；另一方面，也有其他用户表示體驗良好，對成果感到興奮。

數日後補上 Xbox Remote Play

在破解 PS5 上模擬初代 Xbox、以至運行 xCloud 之外，Reddit 帖文下有留言詢問能否使用本機 Xbox Remote Play，把已有的 Xbox 遊戲串流至 PS5。Rafael 表示當時尚未成功，但數日後便迅速推出更新，加入 Xbox Remote Play 功能。

PS5 的獨佔作品陣容或不夠突出，但越獄社群正為這部主機帶來 Sony 原意以外的更多可能。
