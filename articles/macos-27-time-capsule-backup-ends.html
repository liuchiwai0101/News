macOS 27 終止 Time Machine 備份至 Time Capsule　舊有無線備份方式告終

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

macOS 27 將終止 Time Machine 對 Time Capsule 的備份支援。這項提醒意味著，過去以 Time Capsule 作為 Time Machine 備份目標的 Mac 用户，在系統升級之後將無法再沿用同一備份方式。

備份支援正式終止

按現有資訊，macOS 27 不再支援把 Time Machine 備份寫入 Time Capsule。Time Machine 是 macOS 內建的備份功能，Time Capsule 則一直是其中一個可選的備份目標；這個組合在 macOS 27 正式終止，日後無法再於該系統版本下使用。

影響範圍集中單一目標

受影響的是仍然以 Time Capsule 存放 Time Machine 備份的用户。系統升級後，這條備份路徑將不再可用，原有的備份流程亦會中止；至於其他備份目標的支援情況，現有資訊並未交代，用户在升級前宜先確認手上備份的去向。

功能變動並非硬件更新

這項改動屬於 macOS 層面的支援終止，並非 Time Capsule 硬件本身獲得新功能或修復。隨著 macOS 27 結束相關支援，Time Capsule 在 Time Machine 流程中的角色亦告一段落。
