DeepSeek 發佈 V4.1 Flash 1017　代理任務成本遠低於大型對手

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

中國 AI 公司 DeepSeek 發佈更新版 Flash 模型 DeepSeek-V4.1-Flash-1017，已在公司網站、應用程式及 API 上線，並以開放權重模型形式於 Hugging Face 和 ModelScope 公開。公司稱，新版本在代理及編程任務有明顯提升，運作更快、輸出更短，並首次把內部搜尋引擎開放給外部開發者。

新 Flash 模型效能與成本

DeepSeek 表示，DeepSeek-V4.1-Flash-1017 以自我回饋強化學習（RLSF）訓練。這種後訓練方法讓模型把自身的內部信心分數或自行生成的批評作為獎勵信號，因而無需人類評估者或外部獎勵模型。公司稱，這套方法改善了從遊戲編程、3D 建模到設計工作的端到端項目開發，模型亦可製作精簡的解説影片動畫，類似近期發佈的 Opus 5.5。

新模型針對 DeepSeek Harness（建議使用 v0.2.1-rc.1 或更新版本）、騰訊 CodeBuddy 及 WorkBuddy 等開發環境調校。

在 DeepSeek 自家基準測試中，V4.1-Flash-1017 在每項受測類別均勝過前代 V4.1-Flash，並在多個編程及 AI 代理類別擊敗 Claude Opus 5、GPT 5.6-Sol、Kimi K3 和 GLM 5.3 等更大型競爭模型。

DeepSWE 基準測試的成本圖表顯示，更短輸出對效率影響顯著。V4.1-Flash-1017 最高得分為 77.0%，平均每項任務成本略低於 0.20 美元；在低設定下仍取得逾 72% 成績，成本約 0.10 美元。前代得分為 74.2%，但每次執行成本約 0.50 美元。

在代理編程任務的平均成本方面，這款 Flash 模型大幅低於對手。圖表中 GPT-6 Astra、Gemini 3.8 Flash 和 Claude Opus 5 等模型每項任務成本介乎 2 美元至超過 10 美元，且無一能匹敵這款較小型 DeepSeek 模型的準確度。不過，獨立基準測試尚未出爐，而基準測試本身也只能説明部分情況，例如開發者對程式碼質素的觀感可能與測試結果大相逕庭。

內部搜尋 API 向開發者開放

除了語言模型，DeepSeek 亦把網頁搜尋工具 Search & Fetch API 開放給所有開發者。公司稱，這些服務建基於其內部建構的搜尋引擎，該引擎目前每日在全球處理數以億計查詢。設定細節載於 API 文件。

每個端點每 1,000 次呼叫收費 0.75 美元。DeepSeek API 用户可透過 DeepSeek Harness、Claude Code 及 Codex 的伺服器端工具免費使用相關功能，直至 2026 年 10 月 31 日（UTC 下午 4 時）。

中國擬收緊開放權重模型規則

另外，中國政府據報計劃收緊發佈開放權重模型的規則，甚至完全阻止其發佈。其中一項決定因素，是該系統是否位列十大最強模型。
