Apple 準備推出系統安全測試更新 覆蓋 iOS 18、iOS 26 及 macOS 26

Apple 正在加快推出更多安全性更新，目前已針對 iPhone、iPad 和 Mac 釋出多個測試版本，修復系統漏洞。緊接上週公開的 macOS 26.6.1，macOS 26.6.2 Beta 已於週二向開發者推送。同時，多款 iOS 及 iPadOS 的候選版本亦同步發佈。

macOS 26.6.2 Beta 發佈詳情

macOS Tahoe 26.6.2 Beta 內部版本號為 25G82，距離 macOS 26.6.1 正式推出僅相隔四天。Apple 尚未說明此版本具體修復內容，但先前的 macOS 26.6.1 已解決螢幕共享中的一項漏洞，透過改善狀態管理來防止潛在攻擊。

多款系統候選版本推出

同日，Apple 也發佈了以下裝置的候選版本： iOS 18.7.10（22H373）、iPadOS 18.7.10（22H373）、iOS 26.6.1（23G82）及 iPadOS 26.6.1（23G82）。若用戶已安裝相關測試版，現在即可下載更新。候選版本意味著若無重大問題，這些版本將會正式推送。

安全更新節奏與官方建議

Apple 表示，用戶應預期這類小型安全更新會持續推出，公司不再將修補延後至下一次主要更新中。Apple 強烈建議用戶避免在主要裝置或關鍵任務硬件上安裝測試版系統，並在正式版更新推出後盡快安裝。此類更新對於封堵漏洞及維持裝置最佳效能至關重要。
