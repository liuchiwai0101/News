Agent 控制正在向外擴展。

今天最強的一批論文把可靠性工作從模型權重轉移到外環控制：部署就緒性檢查、選擇性升級和基準審計揭示了 agent 能力在實際落地中仍然失效的地方。

核心要點

- Agent 工作正從“更好的提示/工具”轉向**顯式控制層**：越來越多論文在凍結模型之外優化路由、拓撲、harness 配置、記憶和證明狀態，且通常帶來可測量的收益與更好的可審計性。

- 一個反覆出現的強模式是**選擇性升級**：只有當置信度或結構信號表明有必要時，才調用昂貴的搜索、糾錯或人工審覈。這一模式出現在長視頻問答、Text-to-SPARQL 糾錯、保形拒判以及生產就緒性治理中。

- 多篇論文對推理時技巧的“輕鬆收益”提出質疑：用於緩解 MLLM 幻覺的對比解碼，其效果似乎在很大程度上是**基準僞象**；而靜態的 DSPy 風格 harness 優化，在現實樣本預算下可優於在線自適應控制器。

先读这篇：Stop Shipping AI Agents on Faith: Capability Is Not Production Readiness

**爲什麼先讀：** 它提供了一個面向部署的框架，用於在演示效果之外評估 agents，這是今天最清晰的實踐性轉向。

**建議重點質疑：** 在尚未跨領域、跨任務和跨模型棧得到廣泛驗證之前，這樣的就緒性指數看起來可能很有說服力。

主題

**凍結 Agent 的外環控制**當下許多實際收益並非來自修改模型權重，而是來自控制模型看到的上下文、拓撲、記憶和驗證結構。這對黑盒 API 和可審計性都很有吸引力，但多篇論文表明控制問題本身很難，而且樣本效率不高。

**選擇性干預優於統一流水線**多篇論文表明，始終開啓的糾錯、搜索或審覈會浪費算力，甚至可能損害準確率。更好的系統會先判斷是否需要干預，然後只在不確定或高風險樣本上投入預算。

**Grounding、檢索與證據衛生**可靠性失敗中很大一部分來自糟糕的證據處理，而非純粹的推理缺陷。當前更強的系統越來越多地約束檢索什麼證據、如何去重，以及證據是否在時間或視覺上被 grounding。

**信號**

**Agent 的提升來自控制層。**多篇論文不是通過修改基礎模型，而是通過 harness 策略、拓撲自適應、記憶更新和證明狀態編排來提升凍結 agent 的表現。

**張力**

**推理時修補更容易被過度宣稱。**關於對比解碼的可復現性研究認爲，已報告的 MLLM 幻覺緩解收益，可能來自輸出偏置和貪婪塌縮僞象，而不是真正更好的 grounding。

**判斷**

**選擇性升級將優於始終開啓的流水線。**保形拒判、選擇性 SPARQL 糾錯、置信度感知視頻推理和就緒性門控，都只在不確定樣本上投入成本。

- MANTA: Multi-Agent Network Topology Adaptation for Self-Evolving Multi-Agent Systems

- **常見方法**：- 將提示、檢索深度、規劃/驗證輪次或通信拓撲視爲顯式動作空間。

- 保持基礎模型凍結，同時從軌跡、審計或評估器反饋中學習或演化外部策略。

- 將可複用的過程性工件外置存儲：情節記憶、狀態圖、操作手冊或 harness 狀態。

- 基於過程信號的自適應，可能在軌跡表面看似健康時漏掉潛在推理失敗。

3) 技術綜合

- 一個常見的系統模式是**兩階段推理**：先進行廉價的全局遍歷，再進行昂貴的局部化/工具輔助處理。CADER、GGC 和保形拒判都以不同路由信號實例化了這一模式。

- 多篇論文用**信任過程工件**替代“信任模型”：HydroAgent 的顯式技能、Albilich 的證明狀態賬本、Living-Harness 的門控更新，以及 MANTA 的有界拓撲變異，都將推理狀態外置以便審計。

- **GRPO 風格優化**出現在非常不同的任務中：DocRE 一致性遷移、強化 unlearning、多模態摘要，以及研究 Agent 的系統報告。趨勢是轉向可驗證或可分解的獎勵，而不是不透明的偏好模型。

- 多項工作表明**簡單基線依然強大**：在 RepBench 中，diff-mean 贏得 grand-mean LOBO-AUC；DSPy-static 優於在線 harness 控制器；在幻覺基準上，非視覺控制可匹配對比解碼。

- 一個反覆出現的轉向是從**實例局部修補到跨 episode 累積**：Living-Harness、SkillRise、Rehearse 和 MANTA 都試圖在單次運行之外保留有用的過程性知識。

- **校準是核心瓶頸**：在大動作空間中，控制器 softmax 置信度不可用；邊際保形預測對少數類會災難性欠覆蓋；選擇性系統高度依賴閾值質量。

- 多篇論文使用**確定性工具來約束 LLM 行爲**，而不是替代它：水文模擬器、CAS 後端、定理搜索、SPARQL 執行器和專用視覺工具都充當錨點。

- 證據質量正越來越被視爲**一等優化目標**：時間泄漏檢查、片段抽取、分塊去重、視覺對齊加權和語義查詢糾錯，都通過清理輸入或中間工件來提升下游可靠性。

- 基準設計正轉向**工作流現實性優先於孤立任務**：多輪臨牀診斷、從零開始的軟件交付，以及異構 schema 上的個性化記憶，暴露了單輪 QA 所掩蓋的失敗。

- 一個值得注意的負面結果簇警告說，**表面上的基準收益可能並非因果**：對比解碼的收益可能來自是/否偏置和貪婪塌縮；隨着模型生成變化，論文中的發表結論也可能迅速過時。
