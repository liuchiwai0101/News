macOS 27.2 不再強行移除現有 Rosetta 安裝　macOS 28 逐步淘汰相關支援

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

根據 Apple 為 macOS 27.2 提供的企業版發佈説明，用户升級至 macOS 27 後，系統不再移除已安裝的 Rosetta。此前的做法是，升級至 macOS 27 會一併刪除現有的 Rosetta 安裝。

Rosetta 通用支援至 macOS 27

Rosetta 是翻譯工具，讓以 Intel 為基礎的應用程式可以在 Apple 晶片 Mac 上運行。按照原有安排，升級過程會清除這項既有安裝，令依賴該工具的舊有應用程式失去運行途徑；企業版發佈説明所述的改動，正是針對這一點。

macOS 27 仍是最後一個提供完整 Rosetta 支援的版本。Apple 計劃由 macOS 28 開始，逐步淘汰一般用途的支援。
