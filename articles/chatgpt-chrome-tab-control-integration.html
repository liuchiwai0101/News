ChatGPT 深化 Google Chrome 整合　可操控瀏覽器分頁

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

OpenAI 本週宣佈深化 ChatGPT 與 Google Chrome 的整合，用户可將已開啟分頁的控制權交給這個 AI 助理，相關的 ChatGPT 擴充功能現已在 Chrome Web Store 上架。

分頁操控與側邊欄介面

在 Twitter/X 的帖文中，OpenAI 交代了 Chrome 版 ChatGPT 擴充功能的多項改進。這個瀏覽器附加元件與 Chrome 的整合更為深入，ChatGPT 可以查看用户已開啟的分頁，並運用這些上下文完成工作。

OpenAI 表示，用户可直接在 ChatGPT 內提問，由 AI 根據已開啟分頁的內容作答，甚至反過來操控這些分頁，例如傳送訊息、填寫表格或下載檔案。ChatGPT 亦可協助整理及分組大量已開啟的分頁。

ChatGPT 另設側邊欄介面供用户操作，用法與 Chrome 內置的 Gemini 整合相若。OpenAI 同時發佈兩段影片，示範整合的實際運作。

比較產品與整理供應商資料

OpenAI 列出的應用情境涵蓋比較與資料整理。用户可要求 ChatGPT 比較三個已開啟分頁中的梳化，按尺寸、材質、送貨時間及退貨政策列出分別；把已開啟的定價頁與自身需求比對，判斷哪個方案包含所需的一切；以及把分頁內多家供應商的價格、主要功能及來源連結整理到比較表。另一個例子是查看所有已開啟的分頁並比較承辦商服務，再為最適合其家居裝修的一家草擬電郵。

摘要文章與代填表格

用户亦可要求 ChatGPT 以淺白英文解釋一篇文章，説明其主要論點及支持證據；或根據活動簡介的內容代為填寫報名錶，並在提交前停手。另一個例子是代為填妥已開啟的牙醫診所表格，同時把預約加入工作及個人行事曆。
