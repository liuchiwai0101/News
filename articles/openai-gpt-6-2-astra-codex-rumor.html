gpt-6.2-astra 現身 Codex 介面　Tibo 以「地下室充滿奇蹟」回應

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

早前 X 用户 Layton Gott 貼出一張據稱來自 Codex CLI 的截圖，當中出現「gpt-6.2-astra xhigh」字樣。OpenAI 工程師 Tibo 約四分鐘後回覆「地下室充滿奇蹟」。這是社群截圖及玩笑式回應，並非產品正式公佈。

Codex CLI 截圖顯示模型字串

Layton 的貼文截圖顯示，Codex CLI 介面上有「gpt-6.2-astra xhigh」字串，並可見「Ask Codex to do anything」及「? for shortcuts」兩項提示。圖片來自 Layton 的社群貼文，並非 OpenAI 官方新聞稿。

Tibo 回應與地下室玩笑的脈絡

Layton 在貼文中表示，他到地下室探訪 Tibo 時發現這張截圖。Tibo 於中國香港時間 12:53 回覆「Basement is full of wonders」，即「地下室充滿奇蹟」。這是玩笑式個人回應，並非 OpenAI 的產品公佈。

在此之前，@kimmonismus 曾詢問 GPT-6.2 何時推出，Tibo 回答「不知道，我現在住在地下室」。Layton 的貼文引用了這則回覆。該對話出現在 Tibo 宣佈已公佈的 GPT-6 Cyber 經 Daybreak Red 可用的脈絡下，與 gpt-6.2-astra 的截圖傳聞並非同一則公佈。

目前可確認與不可確認的事

上述已核實來源顯示的是介面截圖及個人回應，OpenAI 尚未在這些來源中正式公佈 gpt-6.2-astra、GPT-6.2 Astra 或 GPT-6.2 Sol。截圖亦不足以確認相關模型的功能、推出日期，或是否已向一般用户開放。

資料來源：Layton Gott｜Tibo
