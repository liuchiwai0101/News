【Anthropic】推出兩款Claude AI新模型 速度快30% 收費降20% - 香港經濟日報HKET

正文

SpaceX、Anthropic關鍵合約藏風險！美國AI算力主導地位恐被扭轉？ 鉅亨網編譯莊閔棻 2026年11月9日週一 上午3:40 [EST] 7 分鐘閲讀時間 SPCX +5.79% 美國中期選舉結果恐為人工智慧（AI）產業帶來新的算力危機。隨著多州新任州長揚言暫停核發資料中心建設許可，超大規模雲端業者、新興雲端服務商與AI模型公司可能面臨截然不同的命運。矽谷投資人Chamath Palihapitiya更警告，SpaceX( SPCX-US ) 與Anthropic合約中的「雙向90天退出條款」，可能讓算力價格飆漲至原合約的2至3倍；若美國持續築起建設壁壘，數百億美元資料中心投資恐轉往海外，甚至動搖美國在全球AI算力市場的主導地位。

美國中期選舉結果可能為AI產業帶來意想不到的衝擊。民主黨在多州選舉中取得勝利後，新當選州長紛紛對資料中心建設採取強硬立場，甚至宣佈在新法規出爐前暫停核發新建許可，引發市場對美國AI基礎設施擴張受阻的疑慮。

矽谷投資人、All-In Podcast共同主持人Chamath Palihapitiya在11月8日播出的節目中警告，這場政策轉向可能進一步改變全球AI算力市場的競爭格局。

他特別點出，SpaceX與Anthropic的算力供應合約設有雙方均可提前90天通知終止的條款，一旦市場算力供給緊縮，SpaceX可能藉此重新議價，將價格提高至原合約的2至3倍，對高度仰賴外部算力的AI業者形成重大衝擊。

節目其他共同主持人Jason Calacanis、David Sacks與David Friedberg也警告，若美國各州持續提高資料中心建設門檻，投資金額超過500億美元的吉瓦級大型專案可能轉往加拿大、墨西哥、馬來西亞及中東等地，不僅衝擊美國科技產業競爭力，也可能使美國從算力出口國轉為Token進口國。

地方反彈升高 資料中心許可成政治難題 美國地方政府對資料中心建設的態度正在轉變。選舉結果出爐後，新當選的德州州長Gina Ino Hosa隨即表態，在相關專項法規制定完成前，將暫停核發所有新資料中心許可。

這股反對聲浪與地方居民對AI產業擴張的疑慮有關。Chamath在節目中提到，SpaceX團隊日前前往亞利桑那州科奇斯縣，為一項6GW資料中心計畫舉辦説明會。

兩名員工Riley與Katie當場承諾，專案將降低當地電費、不消耗水資源、減少20%房產税，並協助償還縣政府債券，但現場居民仍以持續喧鬧及對抗表達不滿。

Chamath認為，這類反彈反映出地方社區對經濟利益分配不均的強烈不滿。居民質疑科技巨頭享有地方政府提供的税務優惠，卻可能讓當地承擔更高電價及水資源消耗等成本。

Sacks則指出，資料中心審批已成為跨黨派政治議題，支持核准相關建設的政治人物都可能面臨選舉壓力。他認為，未來4年，政治人物幾乎沒有動機為新專案背書。

他預估，已取得完整許可、正在興建的資料中心，大致仍有機會在2027年完工，但尚未獲批的專案將面臨高度不確定性，到2028年，整體新建專案管線可能大幅萎縮，甚至幾乎停擺。

超大規模雲端業者成贏家 新雲與AI模型公司面臨算力壓力 Chamath將AI算力市場分為兩大陣營：擁有自建資料中心及既有算力資產的超大規模雲端業者（Hyperscalers），以及高度仰賴外部租賃算力的新興雲端服務商（Neoclouds）與尖端AI模型公司。

Google( GOOGL-US ) 、Meta( META-US ) 、微軟( MSFT-US ) 、亞馬遜( AMZN-US ) 及SpaceX等大型業者，因掌握大量既有算力資源，受到新建許可收緊的直接衝擊相對有限。若市場新增供給受限，這些業者還能優先將算力保留給自家產品，進一步拉開與外部競爭者的差距。

Chamath以Google近期收購Crusoe資料中心為例，指出大型雲端業者可能透過收購相關資產，將原本提供外部客户使用的算力納入自身體系。

相較之下，Anthropic、OpenAI及Neoclouds等業者高度依賴外部算力供應，一旦新建資料中心受阻，市場可用GPU資源減少，現貨價格可能大幅上漲，迫使業者支付更高成本，甚至因算力不足而影響模型開發進度。

尤其Anthropic與OpenAI目前的模型更新週期約為60至90天，若算力供應緊縮迫使開發速度放慢，Google Gemini等大型雲端業者旗下模型將有更多時間追趕，進一步改變AI模型市場的競爭態勢。

SpaceX與Anthropic合約藏90天退出條款 算力價格恐飆漲2至3倍 在這場算力供應變局中，Chamath認為，SpaceX與Anthropic之間的合約條款可能成為左右產業格局的關鍵。

他透露，雙方的算力供應協議設有雙向90天退出條款，任何一方都可以提前90天通知對方終止合約。這項安排在市場供需穩定時或許只是一般商業條款，但若資料中心建設受阻、算力供給突然收緊，可能成為影響AI產業的重要變數。

Chamath推演，假如各州凍結新建許可，導致市場可用算力減少，現貨算力價格可能迅速攀升。SpaceX屆時便有經濟誘因終止原有合約，改以當時市場價格重新議價，價格可能達到原合約的2至3倍。

屆時，Anthropic將面臨兩難：接受大幅提高的算力成本，或承受算力供應中斷的風險。

這項變化也可能迫使其他超大規模雲端業者重新評估算力分配策略，在對外出租與供應自家AI模型之間做出取捨；Neoclouds則可能被迫動用融資資金，在高價環境下搶購可用算力，以維持市場競爭力。

Chamath認為，這份合約所涉及的利益博弈，可能成為整個AI產業重新洗牌的縮影。如果SpaceX決定終止協議，影響恐怕不只限於Anthropic，而是整個AI算力市場的供需與競爭關係。

美國資料中心恐外移 算力出口優勢面臨挑戰 除了產業內部的算力分配問題，All-In Podcast主持人也擔憂，美國若持續提高資料中心建設門檻，可能將龐大基礎設施投資推向海外。

Calacanis與Sacks指出，資料中心並非只能設在美國境內。投資規模超過500億美元、電力需求達吉瓦級的大型專案，也可以選擇加拿大、墨西哥、馬來西亞、新加坡，甚至在戰事結束後轉往中東。
