實測騰訊 Hy4 flash：花兩毛錢，就能讓 AI 從零做個 3D 交互網頁

內容機器翻譯自第三方媒體（愛範兒），僅供參考，以原文為準。

正文

11 月初，騰訊 Hy4 發佈，新模型在大模型競技場上一躍升至開源第一。

我們此前在 WorkBuddy 內體驗過 Hy4 的 Agent 長程任務和日常辦公能力。從逐幀分析視頻、復刻遊戲和網頁，到文件整理、Office 文檔處理，Hy4 都交出了不錯的成果。

整體實測表現，也基本符合它在大模型競技場上的成績。

但對於經常使用 WorkBuddy 的用户來説，模型能力只是選擇標準之一。是否免費、需不需要排隊、執行速度夠不夠快，同樣會影響實際體驗。

比如在工作日高峯期打開 WorkBuddy，倍率只有 0.11x 的 DeepSeek V4.1 Flash，繁忙程度卻常常居高不下。

早在 Hy4 發佈時，騰訊就預告過一款主打效率的 Hy4 flash。

就在剛剛，Hy4 flash 正式發佈。騰訊希望將 Hy4 已有的 Agent、長程任務和生產力能力，以更低的成本帶到高頻使用場景。

APPSO 提前拿到了 Hy4 flash 的測試資格。這次我們最關心的是， 它能否在保證任務完成質量的同時，減少 Agent 執行過程中的時間和 Token 消耗。

相較於 Hy4，新的 Hy4 flash 對 Token 效率進行了大量優化，Hy4 flash 總參數量為 224B，激活參數 12B，支持多模態和 1M 上下文長度。模型輸出更加精簡，吞吐量和整體響應速度也有所提升。

更高的 Token 效率也讓 Hy4 flash 的價格要比 Hy4 便宜不少，Hy4 flash 的輸入價格為 0.5 元每百萬 Token 輸入，而輸出則是每百萬 Token 輸出 2 元，幾乎是 Hy4 價格的十分之一。

我們可以直接在 WorkBuddy 內選擇 Hy4 flash 模型，新模型還有為期兩週的限時免費福利，11月16日–11月30日，每日贈送免費額度。

打開執行記錄，看着它讀取文件、拆解任務、編寫代碼、調用工具、檢查結果……一整套流程下來，幾十分鐘過去，模型可能還在反覆檢查同一個文件，甚至把剛修好的問題又改了出來。

這些彎路不會出現在最終的成果截圖裏，卻會實實在在地增加任務耗時和 Token 賬單。

所以，當 Agent 開始承擔真實工作，我們也需要關心一個更實際的問題： 完成同一件事，究竟需要多少時間和成本？

為了測試 Hy4 flash 的實際效率，我們在 WorkBuddy 中準備了相同的任務，分別交給 Hy4 flash 和 DeepSeek V4.1 Flash。測試過程中，提示詞、工具權限和其他設置保持一致，重點觀察兩款模型的執行過程、最終交付，以及背後的時間和 Token 消耗。

我們先用了一些在 WorkBuddy 內重複、瑣碎，但又需要花時間的工作，這些工作雖然不需要模型從零開發一套複雜系統，但也很考驗它對信息的理解、整理和工具調用能力。

例如進行一些深度研究的任務，看看是否能高效地獲得信息可靠、條理清晰、便於進一步使用的結果。

再看看編程，我們讓兩款模型在 WorkBuddy 中構建一艘可以交互的 3D 歷史帆船。

Hy4 flash 很快搭出了帆船的基本結構，網頁也能正常交互，整體是相對完整的原型。
