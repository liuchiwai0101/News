黃仁勳婚外情衝擊AI管制 美保守派智庫台學者：華府正轉化成立法問題

內容機器翻譯自第三方媒體（經濟日報），僅供參考，以原文為準。

正文

輝達 黃仁勳 ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' 00:00 2026/11/15 10:35:47 聯合報 記者陳熙文／台北即時報導 輝達執行長黃仁勳接連爆發婚外情而去職，美國國會議員日前聯名致函，要求他仍必須配合國會調查，前立委、現華府保守派智庫哈德遜研究所資深研究員許毓仁表示，華府正在把黃仁勳事件轉化為立法問題。

黃仁勳爆發婚外情，對象疑似為中共間諜，黃仁勳也在近日離任，不過聯邦眾議院共和黨籍「美國與中國共產黨戰略競爭特別委員會」主席穆勒納爾（John Moolenaar）、眾院外委會主席馬斯特（Brian Mast），以及眾院情報委員會主席克勞福（Rick Crawford）聯名致函，要求黃仁勳仍應該向國會報告。

許毓仁認為，這不只是黃仁勳個人與美國國會之間的衝突，更是美國對中國AI科技競爭政策，正從「管制晶片出口」走向「追究企業戰略責任」的一個重要訊號。

許毓仁指出，美國政府過去幾年對中國半導體的政策，主要圍繞出口管制、先進製程、設備限制及運算能力的封鎖。但隨著AI逐漸成為經濟競爭、軍事現代化與國家安全的核心，美國國會開始提出一個更根本的問題：當一家美國科技企業的商業利益，與美國政府所認定的國家安全利益產生衝突時，誰有權決定這家企業可以把技術賣給誰？

許毓仁表示，華府正在把黃仁勳事件轉化為立法問題，指美國國會正在推動四大法案，包括「AI監管法案」（AI Overwatch Act）、「晶片安全法案」（Chip Security Act）、「硬體技術多邊協調法案」（MATCH Act），以及「遠端存取安全法案」（Remote Access Security Act），都與晶片管制、AI、美中競爭有關。

許毓仁表示，當情報安全疑慮與企業高層的政策遊説同時出現時，支持更嚴格管制的議員就有了新的政治理由，要求行政部門提高透明度、限制出口許可的裁量空間，並將監督措施寫入法律。

許毓仁表示，目前國會正在討論2027財政年度「國防授權法」（NDAA），認為這些法案是否能透過NDAA進入立法程序，成為接下來的重要觀察指標，指黃仁勳事件可能不只影響輝達，更可能改變美國AI晶片出口管制的制度設計。

前國民黨籍立法委員、現任華府智庫哈德遜研究所資深研究員許毓仁。取自許毓仁臉書
