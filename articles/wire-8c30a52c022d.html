Windows 11 26H2 更新雖好　微軟確認已有不同問題有待解決

內容機器翻譯自第三方媒體（Yahoo 新聞），僅供參考，以原文為準。

正文

PC3 Windows 11 26H2 更新雖好 微軟確認已有不同問題有待解決 偽宅男 2026年10月2日週五 下午7:30 昨日提到，微軟現已推出 Windows 11 26H2 更新，讓現有使用版本 24H2 及 25H2 的用家，都可以經 Windows Update 下載並安裝更新。理論上 Windows 11 有更新，還要是版本更新，應該及早安排進行更新。不過微軟亦同時表明，部分 Windows 11 安裝 26H2 更新後，可能會遇上過往未看見的問題……

26H2 更新可能令 USB 音訊裝置無法啟動 微軟已經確認，安裝 Windows 11 26H2 後，部分 USB Audio Class 1.0 裝置可能無法啟動或輸出聲音。微軟在支援文件中指出，有關裝置或不能啟動及發出聲響，即使音量已調至 100% 也沒用，而耳機和麥克風會同時失效。同時，Windows 裝置管理員會顯示「裝置未能啟動」的錯誤警告。

廣告 廣告 若用家嘗試進入音效設定排解問題，設定頁面更可能無法回應或直接當機。即使是選擇暫時停用或移除有問題的驅動程式，因今次出問題的是微軟自家的組件，所以也沒用。目前微軟仍在調查問題，並承諾日後推出更新修正。

另有問題影響企業用家 第二項問題隻影響使用 Active Directory 的企業環境。部分受 Credential Guard 保護的電腦帳户，會失去安全通道，令用家即使輸入有效的網域憑證，仍然無法登入電腦。微軟解釋，26H2 會啟用 Machine Identity Isolation 功能。雖然更新本身不會直接強制執行該功能，但會令 Windows 開始採納任何已存在，或由原則配置的相關強制執行設定，導致出問題。同樣，微軟仍在查找根本原因，預期日後要透過 Windows 更新來處理。

第三項問題是 26H2 會導致電腦黑畫面或桌面載入異常，但只限於 Azure Virtual Desktop（AVD）主機，大部分一般用家不受影響。微軟表示，安裝 26H2 及後續更新後，部分裝置可能遇上桌面載入問題，而這情況在部分既有使用者設定檔上較為常見。微軟同樣仍在調查問題成因。

略過 26H2 未必能避開問題 由於 26H2、25H2 和 24H2 共用相同的 Windows 11 程式碼和維護分支，所以有電腦安裝 26H2 出現上述其中一項問題，25H2 與 24H2 也會有同樣缺陷，只是過往未必有被觸發問題。到了日後微軟查明原因並推出更新解決問題，就會同時修復 25H2 及 24H2。

如果顧慮上述三項問題而略過 26H2，其實不會避得開，只是尚未被觸發而已。當然安排更新與否又或何時更新，一切全憑用家決定。
