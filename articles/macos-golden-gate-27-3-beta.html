Apple 開始測試 macOS Golden Gate 27.3　首個 Beta 供開發者下載

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

Apple 已開始測試 macOS Golden Gate 的下一個更新，首個 macOS Golden Gate 27.3 Beta 現已向註冊開發者開放。該測試版在 macOS Golden Gate 27.2 推出後一週登場。

開發者測試版開放下載

註冊開發者可開啟「系統設定」應用程式，依次點選「一般」及「軟件更新」，並選擇加入 macOS Golden Gate Beta 測試，以下載 macOS Golden Gate 27.3。

Apple Intelligence 或擴至中國

另有傳聞指，Apple 可能隨 .3 版本更新把 Apple Intelligence 擴展至中國；至於新軟件還可能包含哪些其他內容，目前仍不清楚。
