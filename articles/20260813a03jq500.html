IT之家 8 月 13 日消息，Anthropic 今天（8 月 13 日）在 X 平臺發佈推文，宣佈升級適用於谷歌 Chrome 瀏覽器的 Claude 擴展程序，**在側邊欄帶來完整的 Claude Cowork 會話體驗。**

在體驗方面，本次更新主要打破了瀏覽器和 Claude 其它平臺的數據壁壘，瀏覽器內的任務和對話現可跨 Claude 桌面端、網頁端及移動端無縫同步。IT之家附上相關視頻演示如下：

側邊欄中發起的對話將保存至 Claude 歷史記錄，用戶可在其他平臺恢復會話。此外用戶無需二次設置，可以直接在瀏覽器中使用賬戶已配置的 Agent Skills 和 Connectors。

Chrome 版 Claude 能查看當前網頁，並利用用戶現有的瀏覽器登錄狀態執行具體操作，包括點擊鏈接、頁面跳轉、輸入文本及填寫表單等。

安全方面，Anthropic 警告，瀏覽器智能體仍易受。爲提升安全性，啓用自動批准時，系統會通過單獨檢查審查重大操作。

在執行購買或共享個人數據等操作前，Claude 仍會徵詢用戶意見。公司強調，這些保障措施可降低風險，但無法完全消除風險。

推送範圍上，Anthropic 自今天開始已經面向 Max 和 Team 客戶開放，未來幾周內將向 Pro 用戶推出。企業管理員可啓用該功能，並限制 Claude 僅訪問已批准的域名。
