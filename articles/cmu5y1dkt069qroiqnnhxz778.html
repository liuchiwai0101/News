在這篇文章中，我們分享 Claude 如何讓科學家用於預測和設計生物分子的開源模型變得更快、更節省內存。Claude 在不到四周的時間裏優化了 30 多個此類模型，平均提速約 4 倍。它還創建了一種低內存模式，使得在單個 NVIDIA GPU 節點上即可對超過 10,000 tokens（氨基酸、核苷酸，以及來自小分子和離子的原子）的大型生物分子系統進行準確預測。我們將全部優化代碼開源，並宣佈與 Adaptyv Bio 聯合贊助一場蛋白質設計競賽，提供最高 100 萬美元的 Claude 額度支持，併為超過 5,000 個設計提供濕實驗驗證。

最近，我們分享了相關成果，展示了 Claude 通過專家級地編排開源蛋白質設計與結構預測模型，設計de novo蛋白質結合體的能力。De novo結合體是通過計算設計的小型蛋白質，能夠緊密附着於特定靶標分子，從而對其激活、阻斷或遞送某種物質。

儘管這是對 AI 科學能力的一次令人鼓舞的展示，也是推進藥物發現邁出的早期一步，但它所消耗的資源超出了絕大多數蛋白質設計者所能獲得的水平。我們允許 Claude 在 AI 基礎設施平台 Modal 上為每個靶標花費最高 10,000 美元，大致相當於 2,500 個 NVIDIA H100 GPU 小時。

為了讓這類研究更易於開展，我們開始探索推理優化，以便更高效地運行這些模型。作為這些優化的早期成果，Claude Mythos 5.1 加速了七個開源生物學模型，使其運行速度最高提升至 2.5 倍。

在此，我們展示新的結果，説明一個內部的通用研究模型如何能夠優化 30 多個為多種生物學任務訓練的深度學習模型，這些任務包括結構預測和蛋白質設計，以及基因組學和蛋白質語言模型。平均而言，Claude 能夠將此類任務加速約 4 倍，同時僅犧牲極少的精度；在輸出完全相同的情況下則可加速近 2 倍。Claude 還改善了這些模型的內存利用率，使得預測前所未有的規模的生物分子系統成為可能。通過將這些結果與我們對先前智能體蛋白質設計方法的簡化相結合，我們表明 Claude 能夠以少兩個數量級的 GPU 小時數，達到與我們此前報告的成果相當的 in silico 性能。

除了蛋白質設計之外，這些專門的生物學模型還被分子生物學家廣泛使用，包括用於藥物發現與開發。我們今天將所有這些模型的優化代碼開源（在此），以便更廣泛的社區能夠加以利用。你可以在我們的技術報告（在此）中找到更多細節。

為了進一步支持社區，我們還與 Adaptyv Bio 共同贊助了一項蛋白質設計競賽，後者開創了 開放蛋白質設計競賽。我們共同選出了五個處於當今能力前沿的挑戰性問題。與 Adaptyv 一起，並得益於 Modal 和 Twist Bioscience 的慷慨捐助，我們承諾提供最高 $1 million 的 Claude 額度以及 $250,000 的 Modal 算力額度，併為超過 5,000 個設計提供濕實驗驗證。更多信息請見（在此）並（在此申請）。

加速蛋白質結構預測與設計模型

蛋白質結構預測是指僅根據蛋白質的氨基酸序列來確定其三維結構的問題。而蛋白質設計則是創造具有特定結構、功能或一組特性的蛋白質的過程。這兩類計算工具結合起來，使科學家能夠探究關鍵的生物分子過程——例如癌症是如何形成的——並創造出有用的分子，例如能夠靶向這些癌症的藥物。

現代結構預測模型，如 AlphaFold3、OpenFold3 和 Boltz-2，將大部分計算運行時間和內存花在兩個操作上：三角注意力和三角乘法，它們作用於 token 三元組。這些操作使得對生物分子系統的幾何結構進行建模成為可能，但它們的計算代價極其高昂，因為它們在運行時間和內存上都是三次方複雜度：系統規模翻倍會使用 8 倍的時間和內存，而規模變為三倍則會使用 27 倍。

編寫 kernel——面向 GPU 等加速計算硬件的底層軟件轉換層——是降低這些成本的常規方法。鑑於其重要性，三角注意力和三角乘法一直是專門 kernel 開發工作的對象，最初是 NVIDIA 的 cuEquivariance，最近則是 NVIDIA 的 BioNeMo Inference Runtime（BioNeMo-IR）。

為了我們自身針對結構預測模型優化推理的工作，我們與 Claude 合作開發了 FlashPairformer，這是一組自定義 kernel，可加速三角注意力與三角乘法。它達到了新的 SOTA，在三角注意力上平均比該領域標準快 2.7-2.9x，在三角乘法上快 1.7-3.2x，具體取決於模型配置。

我們與 Claude 合作開發了 FlashPairformer，這是一組自定義 kernel，可加速三角注意力與三角乘法，而這兩者是支撐最先進生物分子結構預測模型的 Pairformer 架構的主要組成部分。結果均相對於該領域標準報告。

除了開發可遷移的 kernel 之外，我們還讓 Claude 針對每一個單獨的模型進行優化，目標是產出更具針對性的優化。這些優化包括緩存重複計算的工作，以及將死分支簡化為其常量輸出等改動。這些改進的組合使結構預測模型平均加速了 4x，並且對於每個模型，我們都確認了 Claude 的加速版本沒有影響下游任務（例如結構預測）的性能。

通常，一個經驗豐富的工程師團隊需要數週時間才能為每個模型完成此類優化，而且這些工作往往無法在不同模型之間遷移。Claude 在 Anthropic 兩位技術人員的監督下——他們具備生物分子建模經驗，但此前沒有任何推理優化或內核工程方面的經驗——在不到四周的時間裏，完成了對 30 多個開源模型的加速，涵蓋生物分子結構預測、蛋白質設計、蛋白質語言建模和基因組學。

我們的結果表明，前沿 AI 模型將幫助該領域的其他人以更快的速度和更簡便的方式構建科學工具。

Claude 的優化加速了十多個生物分子結構預測模型，平均實現了約 4 倍的加速且精度下降極小，以及在輸出完全相同的情況下約 1.6 倍的加速。注意：ColabFold 1.6.3 同期發佈的可選快速內核尚未在此進行基準測試。Claude 的優化還加速了多個蛋白質設計模型，涵蓋幻覺、結構生成和逆折疊。這些模型依賴於多種架構，包括 AlphaFold 級別的結構 Transformer、擴散模型、流匹配和圖神經網絡。我們為結構預測開發的快速模式，在一組彙總的生物分子界面上與默認設置在統計上無法區分。如果預測界面的 DockQ 分數大於 0.23，我們認為該界面是可接受的。

實現大規模生物分子系統的建模

除了讓這些蛋白質結構預測與設計模型運行得更快之外，我們還讓 Claude 承擔了降低大型分子機器建模所涉及的內存佔用的任務。細胞中的許多工作都是由這類系統完成的，包括構建蛋白質的核糖體、為細胞供能的呼吸鏈複合物，以及幫助其他蛋白質摺疊的分子伴侶。每一個都由數十個組件構成，其功能取決於這些組件如何組合在一起並相互作用。預測如此龐大系統的結構，通常需要大量計算資源，而大多數分子生物學家無法獲得這些資源，例如跨多個 GPU 節點分佈的推理。

Claude 創建了一種低內存的“Big”模式，使得對超過 10,000 tokens 的系統進行精確建模成為可能，並且僅使用一個 NVIDIA GPU 節點就能對超過 70,000 tokens 的系統成功完成推理——這在以前是無法企及的任務。使用 Big 模式成功摺疊的分子機器包括人類線粒體複合物 I、TRiC 分子伴侶複合物、一個蛋白酶體以及一個細菌核糖體，每一個都與其通過實驗測定的結構高度吻合。據我們所知，這些是迄今使用結構預測模型準確摺疊出的最大結構之一，其中複合物 I 和 70S 核糖體各自包含超過 10,000 tokens，相比之下，AlphaFold3準確預測的 40S 核糖體包含 7,663 tokens。

Claude 創建的低內存“Big”模式使開源結構預測模型能夠在單個 NVIDIA GPU 節點上準確預測由超過 10,000 個 token 組成的生物分子系統，這表明這些專用模型能夠在其訓練上下文之外泛化近 1.5 個數量級。前三行展示的是準確預測的系統；底行展示的是預測不準確的系統。如果界面的 DockQ 分數至少為 0.23，則認為其是準確的。

為了測試 Claude 優化的極限，我們讓 Claude 預測比此前所實現的任何規模都更大的結構。使用單個 8-GPU B300 節點，Claude 生成了對整個病毒衣殼和蛋白質區室的預測，規模從超過 31,000 個 token 到超過 70,000 個 token 不等。

這些系統比這些結構預測模型的訓練上下文大了近兩個數量級，而且或許並不令人意外的是，它們並未被正確預測。然而，在這一規模上進行推理的門檻如今已顯著降低，因為現在只需要一個 NVIDIA B300 節點，這表明隨着工具的改進，研究人員很快將能夠對日益複雜的生物系統進行計算建模。

“Big”模式使開源結構預測模型能夠使用單個 NVIDIA B300 節點以前所未有的規模成功運行推理。能力測試運行以單次主幹前向傳播（無循環）執行，作為概念驗證。預測的結構崩潰，表明在訓練上下文之外近兩個數量級的範圍內缺乏泛化能力。

Claude 高效設計 de novo 蛋白質結合體

在我們早先的蛋白質設計工作中，我們為 Claude 提供了一段約 16,000 詞的提示詞，鼓勵它調用子智能體，並在 24 小時內為每個靶點最多花費 $10,000 使用 Modal（約 2,500 NVIDIA H100 GPU 小時）。

而在這裏，我們只給單個 Claude 模型提供了一塊 NVIDIA H200 和 24 小時的掛鐘時間、一段約 1,100 詞的提示詞，以及一份預裝工具的參考表，沒有子智能體，也沒有人類對設計過程進行引導。

我們使用本文所述的加速生物分子模型，讓三個 Claude 模型（Mythos 5.1、Mythos 5 和 Opus 5）針對 16 個靶點進行了測試。我們通過 ipSAE 對設計進行評分，這是一種 in silico 評分，已被證明能夠預測濕實驗室中的結合情況。在 16 個靶點上取平均，所有三個 Claude 模型評估所得的中位評分設計和最高評分設計，所達到的 ipSAE 值與我們早先的 Mythos 5.1 系列大致相同，儘管使用的 GPU 小時數少了約兩個數量級。我們還考慮了 Claude 的 token 成本，發現 GPU 與 token 合計花費約 $150，我們就能實現與先前系列相當的 in silico 性能。

單個 Claude 模型僅使用一塊 NVIDIA H200 和 24 小時掛鐘時間，就設計出了 從頭（de novo）蛋白質結合體，其 計算機模擬（in silico）結合分數與我們早先 Mythos 5.1 項目（虛線）相當，而後者可以使用子智能體，並消耗約 100 倍的 GPU 小時。每條曲線代表一個 Claude 模型在編排加速生物分子模型時所得 ipSAE 分數（計算機模擬結合分數）的中位數（上圖）或最大值（下圖）。我們展示了分數與估計 GPU 花費（左）、token 花費（中）以及二者組合（右）的關係。結果在 16 個靶標上取平均，每個靶標最多進行五次獨立運行。
