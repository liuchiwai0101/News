出差遇法國暴動！街頭狂爆炸「路被大火堵死」 名導崩潰：該往哪走

葡萄牙 比利時 ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' 00:00 2026/10/19 01:45:43 經濟日報 國際中心／綜合外電 歐洲社會再陷動盪，法國17日爆發大規模示威，估計55萬人走上街頭，演變為暴力抗爭，抗議浪潮也蔓延到義大利、比利時、葡萄牙及阿爾巴尼亞等歐洲多國，且多地發生警民暴力衝突，可能加劇歐洲公債殖利率上漲的壓力。同時，德國極右派興起將威脅政府想推動投資的努力，讓19日登場的「投資德國」峯會蒙上陰影。

法國各地工會與公民團體17日發起大規模示威，號召群眾走上巴黎與里昂等各大城市街頭，抗議生活成本升高與燃料價格持續上揚，與要求改革教育體系、充實教學經費和設備等問題的學生示威者，匯聚成龐大的遊行隊伍。

法國總工會（CGT）指出，約80萬人走上街頭，全國各地舉行1,750場集會。法國當局則表示，估約55萬人參與示威。

然而，這場示威活動卻演變為暴力抗爭，多地群眾開始在街頭縱火、焚燒汽車，商店遭洗劫，就連市政廳與警察局建築都遭攻擊，成為多年來最嚴重的暴亂事件，官員形容暴力與洗劫程度為「前所未見」，企業界估算造成上億歐元的損失。

法國當局迄今已逮捕至少1,800人，光是巴黎就有至少855人，為該市最高紀錄。總統馬克宏強調，所有破壞建築、攻擊政府機關及商家、洗劫市政廳的人，都將面臨起訴及懲罰，政府也將幫助遭逢損失的商家。

義大利、比利時、葡萄牙及阿爾巴尼亞等國的民眾17日也舉行示威，抗議生活成本高漲或教育問題，多地發生警民暴力衝突，抗爭者攻擊警方，促使警方發射催淚瓦斯與橡膠子彈驅散人群。

這些動盪正值歐洲未來12個月將進入「前所未見的全國投票超級循環」，除了法國明年4月將舉行總統大選，西班牙、義大利及波蘭也都將舉行全國選舉。

在德國，極右派的另類選擇黨（AfD）近來在邦選舉接連告捷，已加劇對德國政局穩定的憂慮，也讓投資人憂心柏林原先要縮減官僚、提高勞動法規彈性、改革退休金體系、擴大投資等承諾，將遭遇阻礙。

德國19日將在柏林舉行首場「投資德國」峯會，迎接多達200名投資人，包括高盛執行長蘇德巍與貝萊德執行長芬克，會場勢將瀰漫焦慮情緒。
