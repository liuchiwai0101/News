美國勞工統計局（BLS）週五公佈的10月非農就業報告顯示，美國新增16.5萬個工作機會，遠高於市場預期的7萬個，也超過華爾街所有機構的最高預估。

其中，民間部門新增15.9萬個工作機會，遠高於預期的6.5萬個，政府部門則增加6,000個職位。

其他就業數據也同步優於預期。8月新增就業人數上修5.3萬人至18.6萬人，9月則上修3.1萬人至6萬人，兩個月合計上修8.4萬人。

以家庭調查口徑計算，10月就業人數增加46.3萬人，連續第三個月增加超過40萬人；全職就業人數增加71.4萬人，創2026年第二大增幅，兼職就業人數則減少24.2萬人。

薪資與失業率同樣呈現強勁表現。10月失業率從4.2%降至4.1%，優於市場預期持平；平均時薪月增0.4%，高於預期的0.3%，年增率則達3.1%，也扭轉市場原先預期薪資年增率將首度跌破3%的看法。

非農數據公佈後，美國公債殖利率迅速走高，2年期公債殖利率一度上升7個基點至4.54%，10年期殖利率則升至4.87%。市場對聯準會12月升息25個基點的預期機率一度升至85%。

非農數據全面優於預期 聯準會升息選項重新浮現

這份就業報告公佈的時機，正值市場對AI基礎建設投資能否持續產生足夠回報產生疑慮，美股科技股近期遭遇大幅賣壓。

先前市場一度認為，金融環境收緊可能促使聯準會放緩緊縮步調，但強勁的就業與薪資數據，重新為鷹派官員提供支持升息的理由。

根據《彭博》統計，市場對聯準會截至2027年9月前累計至少再升息40個基點的預期並未改變，但12月升息25個基點的機率在非農數據公佈後一度升至85%。

華爾街人士普遍認為，這份報告讓聯準會12月會議再次升息成為實際選項。不過，也有部分市場人士認為，股市持續震盪，加上AI投資前景仍存在不確定性，可能促使聯準會暫時維持利率不變。

《華爾街日報》記者、有Fed 傳聲筒之稱的Nick Timiraos指出，這份報告尚未從根本上改變聯準會對經濟成長與通膨的基本判斷，但AI相關資產遭到拋售後，是否進一步收緊金融環境，可能成為12月利率決策的新變數。

此外，聯準會主席華許（Kevin Warsh）如何權衡落後反映經濟狀況的就業數據，以及能夠提前反映市場變化的金融市場訊號，也將影響12月會議的政策走向。

半導體股領漲美股 市場漲勢集中、反彈力道存疑

美股週五收盤漲跌互見，科技股反彈帶動 那斯達克 100指數上漲1.35%， 費城半導體 指數上漲約3%；標普500指數僅小漲0.3%， 道瓊工業指數 則下跌0.5%，顯示市場漲勢集中在少數科技權值股，多數個股仍收黑。

半導體股成為反彈主力，超微半導體( AMD-US ) 大漲11%，英特爾( INTC-US ) 上漲7.71%，高通( QCOM-US ) 上漲5.52%，美光科技( MU-US ) 上漲5.12%，輝達( NVDA-US ) 也上漲2.78%。

值得注意的是，週五漲幅居前的半導體股，正是本週跌勢最重的個股。這種跌幅越深、反彈越強的走勢，更接近超跌後的技術性修復，尚不足以證明市場投資情緒已經反轉。

市場廣度疲弱也反映出投資人信心尚未恢復。標普500指數僅小幅收高， 道瓊指數 甚至收黑，代表少數大型科技股的漲勢，並未擴散至整體市場。

此外，非農數據公佈後， 美元指數 單日上漲0.74%，創6月以來最大單日漲幅，美債殖利率也同步走高，進一步增加股票等風險性資產的壓力。

在資金部位方面，CTA基金已持續系統性減碼，偏多操作的基金也再度轉趨觀望。市場分析人士認為，強勁非農數據帶來的升息壓力，加上AI產業投資疑慮尚未解除，目前的市場環境仍不足以支撐美股出現持續性反彈。

整體而言，週五科技股回升雖暫時緩解本週賣壓，但在升息預期升温、市場漲勢集中及AI投資疑慮交織下，這波反彈究竟是市場止跌訊號，還是跌深後的短暫回升，仍有待觀察。
