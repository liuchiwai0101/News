Claude Code v2.1.208 發佈

內容機器翻譯自第三方媒體（Claude Code：GitHub Releases（RSS）），僅供參考，以原文為準。

重點內容

Claude Code v2.1.208 發佈。新增屏幕閲讀器模式，可通過 `claude --ax-screen-reader` 等啓用。新增 `vimInsertModeRemaps` 設置，支持映射雙鍵序列為 Escape。新增 `CLAUDE_CODE_PROCESS_WRAPPER`，允許通過包裝可執行文件啓動所有自生成進程。修復了快速模式未自動恢復、後台會話因二進制替換導致附加失敗、上下文窗口重置為 200k 等問題。優化了多 MCP 工具場景下的工具輪次性能，並將會話轉錄體積大幅縮減。
