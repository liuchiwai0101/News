AI 編程工具 Amp 推出 Spaces：你的 AI 項目經理上線，自主編排 / 協調 Agent 幹活

內容機器翻譯自第三方媒體（IT之家），僅供參考，以原文為準。

正文

IT之家 11 月 7 日消息，AI 編程協作工具 Amp 昨日（11 月 6 日）宣佈推出 Spaces， 希望構建面向 AI 智能體（Agent）和團隊協作的全新工作方式。

對於用户而言，不再需要手動創建、命名和管理多個 Agent 線程，只需對話一個主 Agent，由它理解需求、拆解任務，並讓其自動生成和協調其他 Agent 線程。IT之家附上相關截圖如下：

Amp 指出在傳統多 Agent 工作流中，用户往往要自己決定拆分、分派以及追蹤任務，Spaces 將這一層組織工作交給 Agent：每個 Space 是用户與單個 Agent 的對話，該 Agent 會為用户啓動並協調多個並行線程。

例如，團隊可以在一個 Space 中提出“推進某項功能上線”或“開展一次安全審查”。主 Agent 會將目標轉化為多個具體任務，分別創建線程執行，並將進展以實時卡片形式呈現在聊天中。

Spaces 不只是單人自動化工具，它被設計為團隊共同規劃和指揮工作的場所：成員可在同一聊天中提出需求、反饋問題或補充想法；每項被拆出的工作會顯示當前狀態，以及是否需要人工介入。

用户點擊任務卡片即可進入對應線程，查看 Agent 的產出、繼續迭代或直接推進交付。團隊成員還能在消息下評論討論；只有當有人通過 @amp 提及時，Amp 才會讀取相關評論，以減少不必要的干擾。

Amp 將 Spaces 定位為一種“更高層級”的多 Agent 協作方式，用户從逐條安排 Agent，轉向一個具備協調能力的 Agent 描述目標，再由後者負責任務分解、線程創建、進度組織和結果彙總。

官方示例顯示，一名成員曾通過單個 Space 完成服務賬號功能的發佈；另一個場景則是定期安全審查。用户只需在側邊欄的 Spaces 區域點擊“+”，設置標題和項目，並向 Agent 説明要處理的工作即可開始。

這一功能反映出 AI 編程工具正從“單人問答”走向“團隊化、任務編排化”。當 Agent 能夠自主拆解和並行執行任務時，開發者的角色可能更多轉向定義目標、審查結果、處理關鍵決策，而非手動調度每一個子任務。

Amp 是一款面向軟件開發的 AI 編程 Agent 與開發環境，核心目標是讓開發者把“做什麼”交給 Agent，而由 Agent 負責讀代碼、改代碼、跑測試、迭代，並在雲端或本機持續執行任務。

Amp 可以在用户的工作區中運行工具和 Shell 命令，用於檢查代碼、執行測試並快速迭代；它還能通過 Task 工具把特定子任務交給子 Agent 處理。
