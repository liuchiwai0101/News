Claude Fable 5.2 及 Mythos 5.2 登場　多項能力顯著提升

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

Anthropic 於 2026 年 11 月 9 日推出 Claude Fable 5.2 及 Claude Mythos 5.2。官方表示，兩者在幾乎所有受測能力上超越 Opus 5.5，輸出速度較上一代快最多 30%，API 收費亦下調兩成。

兩個版本、同一模型

Fable 5.2 與 Mythos 5.2 採用同一底層模型，面向開放式的高難度技術工作。Fable 內建較強的網絡安全及生物安全防護，向所有用户開放；Mythos 則供網絡安全及生物醫學研究機構使用，須透過生命科學或網絡安全驗證計劃申請。

速度提升三成　API 減價兩成

新模型的輸出速度較 Fable 5.1 及 Mythos 5.1 快最多 30%。API 每百萬輸入 token 的價格由 10 美元降至 8 美元，每百萬輸出 token 則由 50 美元降至 40 美元。

選用 fast mode 可令輸出快最多 2.5 倍，價格則倍增至每百萬 token 16 美元及 80 美元。ClaudeDevs 指出，Claude Code 用户可在模型選單切換並以額外用量計費，API 用户則把 speed 設為 fast；Mythos 的 fast mode 只限驗證計劃機構。

基準測試與實際案例

官方基準測試顯示，Fable 5.2 在 FrontierSWE v2 取得 69.9%（Opus 5.5 為 62.3%）；FrontierCode 2.0 以 High 強度得 45.3%，與 Opus 5.5 用 Max 的 45.5% 相近而每項任務成本約一半，Xhigh 強度下升至 49.1%。AutomationBench 得 51.4%，高於 Opus 5.5 但低於 Gemini 4 Carbon 的 53.9%。

實際案例方面，官方表示，1,000 個 Fable 5.2 代理在極少人手介入下，用 30 小時將費馬最後定理完整形式化，使證明可由 Lean 逐步檢查。同一設定下，Opus 5.5 在 18 小時內完成 26%，其後進展甚少。

其他測試顯示，Mythos 5.2 用開源折疊模型配合衣殼對稱性，成功預測 34 個腺相關病毒衣殼中 28 個的完整結構，可加快基因治療載體設計。在模擬雙臂機械人的 RoboDojo Sim，Fable 5.2 成功率 64.9%，是 GPT-6 Astra（29.8%）與 Fable 5.1（27.6%）兩倍以上，並在未經專門訓練下完成扭開瓶蓋、解拼圖等實體任務；它亦以一段提示設計出三件可運作的電子裝置，自行佈線及建模外殼。

安全防護與防蒸餾

模型推出前曾交由外部機構測試。Anthropic 稱，高風險失準的風險仍低，多數對齊指標與近期模型相若或更好；Fable 的網絡及生物安全防護與 5.1 同樣穩健，誤擋則有所減少。

官方亦加入歷來最強的防蒸餾保護，在所有 Fable 5.2 API 帳户啟用 preserved thinking；開發者如改動先前上下文可能收到 400 錯誤，需改用上下文壓縮或編輯。

供應情況與官方建議

Claude 官方 X 帳户公佈，Fable 5.2 即日起在所有付費方案、Claude Platform、Claude Code 及各大雲端平台提供。首週推廣按訂閲年資提供一至三次 Fable 用量重設；Pro 及 Team Standard 可試用一星期，上限為每週額度一半。

官方仍建議，大多數日常編碼及知識工作先使用 Opus 5.5，再按複雜程度選擇更強或較小的模型。Claude 應用程式及 Claude Code 預設 Medium 推理強度，Claude Platform 預設 High；Max 不宜日常使用。
