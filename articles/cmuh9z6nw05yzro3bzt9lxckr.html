正文

每天，數百萬人將 Claude 連接到他們的應用、工作工具和數據。今天，我們讓開發者更容易觸達這些用户。

插件可以打包 MCP 連接器、Agent Skills，或兩者兼有，是為 Claude 構建第三方擴展的主要方式。構建一個插件，通過新的目錄提交門户提交，一旦獲批，它就會出現在 Claude 目錄中。

在目錄提交門户中提交併跟蹤插件

目錄提交門户面向付費 Claude 套餐的開發者開放。有兩種方式可以提交併讓你的插件發佈到 Claude 目錄中：

  • 單個 MCP 連接器：指向你的遠程 MCP 服務器。
  • 插件包：將 MCP 服務器和技能組合起來，託管在 GitHub 上，然後提交該倉庫。在 Claude Code 中，插件還可以包含 LSP、命令、鈎子和智能體。

無論你選擇哪條路徑，門户都會引導你從提交到發佈的全過程。你可以：

  • 自動驗證你的插件。每次提交都會在你提交後立即接受檢查和安全掃描，讓你儘早發現問題。
  • 查看審核狀態和反饋。查看你的插件在審核流程中的進展、安全掃描結果以及建議的修改。
  • 準備好後再發布。一旦獲批，由你決定何時在 Claude 中發佈你的插件。

插件發佈後進行監控和優化

插件上線後，使用分析會按產品界面和版本展示安裝量，讓你能夠為用户優先安排修復和功能。在發現方面，你可以看到你的列表被查看的頻率，以及哪些搜索將用户引導至此，從而優化它以觸達新用户。

藉助 MCP 2.0 及其擴展為用户帶來豐富體驗

Claude 支持最新的 MCP 規範，通常被稱為 MCP 2.0，其中包含無狀態核心。你可以通過兩個 MCP 擴展來提升插件的使用體驗：MCP Apps，用於在聊天中提供交互式 UI；以及 Enterprise Managed Auth，為企業用户提供零接觸 OAuth。對更多 MCP 功能和擴展的支持即將推出。

開始為 Claude 構建插件

插件是第三方開發者為 Claude 創建擴展的主要方式。在接下來的幾周內，一個統一的發現體驗將陸續在 Claude 和 Claude Code 中推出。

技能和 MCP 連接器仍作為構建模塊保留，Claude 目錄也將繼續列出它們。未來，開發者將能夠把自己的連接器列表轉化為插件。如果你在 Claude 目錄中已有技能、連接器或插件，則無需做任何更改。

要開始構建插件，請閲讀我們的文檔，瞭解如何構建插件，並在此處提交你的插件。
