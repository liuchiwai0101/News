沙烏地阿拉伯首都金融區遭襲 石油巨頭Saudi Aramco大樓受損

正文

沙國 ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' 00:00 2026/11/08 15:45:23 中央社 利雅德8日綜合外電報導 在葉門叛軍「青年運動」稱沙烏地阿拉伯的空襲造成33死後，沙國首都利雅德今天傳出巨響。由沙國主導對抗青年運動的聯軍表示，聯軍攔截並摧毀了青年運動發射的2枚彈道飛彈。

路透社報導，巨響傳出前不久，沙國民防部門曾對利雅德（Riyadh）地區發布警報。當局隨後宣佈危險已解除。

這起最新事件發生的前一天，葉門受青年運動（Houthi）掌控的衞生部表示，沙烏地空襲葉門首都沙那（Sanaa）附近地區，造成至少33人死亡。沙國當局表示，正就此展開調查。

自南、北葉門於1990年統一後，青年運動就頻頻叛亂，並於2014年發動內戰攻下沙那，內戰至今仍未結束。沙烏地於2015年率領阿拉伯國家組成的聯軍進軍葉門，以協助獲國際承認的政府恢復執政。

自今年7月戰事再起以來，青年運動以飛彈和無人機攻擊沙烏地的機場、港口及石油設施，沙國則空襲葉門境內的青年運動目標。
