OpenAI 推出 ChatGPT Work 與 Codex 的 Admin 外掛程式 管理員可在對話中管理用戶與權限

OpenAI 今日宣佈推出 ChatGPT Work 與 Codex 的 Admin 外掛程式，讓工作區管理員可以直接在對話中管理用戶與權限、分析用量，以及建立報告。

帳戶權限內運作

Admin 外掛程式在帳戶權限範圍內運作。管理員可以更新設定、提出問題，並根據工作區用量與活動資料生成報告。OpenAI 表示，管理員可以瞭解採用情況、查看 ChatGPT Work 與 Codex 的活動和額度用量，找出需要進一步協助的地方，以及哪些成員或羣組接近額度上限；亦可新增或移除成員、更新羣組、完成例行的加入與退出程序、審視有效權限、診斷存取問題，按角色或羣組控制功能與模型存取權，並管理用量限制與開支申請。

示範實際操作

OpenAI 的 GTM 團隊成員 Aarti Bagul 在示範中展示了實際用法。她準備每月 AI 導入檢討時，向 ChatGPT Work 查詢過去 30 日各團隊的採用與額度用量變化，再要求生成圖表；隨後分析趨勢、追問細節、批准用量申請，最後由 ChatGPT 製作簡報並分享到 Slack 頻道。

發佈與應用

OpenAI 指出，Admin 外掛程式的應用包括自動化重複管理流程、以現有控制措施擴展管理工作，以及支援內部 IT 營運。目前該外掛程式已可從 ChatGPT Work 的外掛程式目錄取得。
