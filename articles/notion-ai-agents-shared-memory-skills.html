Notion 宣佈可讓 ChatGPT、Claude 等 AI 代理共用同一份記憶與 Skills

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

Notion 宣佈 ChatGPT、Claude、Muse 及 Bot 等 AI 代理可把學到的內容存入 Notion 的同一份記憶，並共用同一批 Skills。換句話説，你在一個代理交代過的專案脈絡和偏好，換到另一個代理時也能直接沿用。

共用記憶與 Skill

Notion 表示，當代理使用相同的記憶與 Skills，便可以在其他代理已學到的內容上繼續工作。你轉用其他代理時毋須從頭交代，也不會被綁定在單一代理。

官方示範中的 Memories 頁面按 Work 及 Preference 分類，每項記憶均標示寫入代理及日期。示範亦展示終端機中的 Claude Code 和手機上的 Notion AI 讀寫同一份 Memories。

如何設定 Notion 共用脈絡

官方為 ChatGPT 及 Claude 分別提供設定入口；其他代理則可使用官方設定指南，把以下提示交給代理：

Help me set up Notion as my context system using this guide: developers.notion.com/prompts/setup

設定前需要授權 Notion MCP。指南提供兩個選項：建議使用的 Shared context layer 會把記憶、工作成果及 Skills 存於 Notion，供不同代理及工作階段沿用；Basic setup 則只連接 Notion，並加入代理優先閲讀的 Agent Operating Guide，不另外儲存內容。

設定會建立私人的 Agent Operating Guide 頁面，並提示你把自訂指示貼到 ChatGPT 或 Claude 的設定，讓日後的對話先查閲 Notion。

Clay 使用例子與私隱控制

Notion 以 Clay 為例，指該團隊已把 OpenAI、Claude、Cursor 及 Town 等工具連接至 Notion，讓團隊使用不同代理時仍可保留工作脈絡。

設定指南列明，記憶歸你擁有，你可以閲讀、編輯、整理、分享或匯出；指南不會儲存密碼、機密資料或完整對話紀錄。
