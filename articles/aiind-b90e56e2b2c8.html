GPU-Z 2.72.0 發佈：可識別英偉達 RTX Spark、RTX 4090 Ti ES，新增 AMD 多顯卡熱點温度監控

內容機器翻譯自第三方媒體（IT之家），僅供參考，以原文為準。

正文

IT之家 11 月 20 日消息，TechPowerUp 今日發佈了 GPU-Z 2.72.0 版本更新，此次新增對 NVIDIA RTX Spark 處理器、GB203 版本 GeForce RTX 5070 以及尚未發佈的 GeForce RTX 4090 Ti 工程樣品的支持，同時擴展了對 AMD 和 Intel 多款圖形產品的識別能力。

在 NVIDIA 產品方面，GPU-Z 2.72.0 新增對 RTX Spark 的支持，但部分顯存信息暫時仍無法讀取。此外，軟件還加入了對 GB203 核心 GeForce RTX 5070 以及 GeForce RTX 4090 Ti 工程樣品（ES）的支持。

AMD 方面，新版本增加了對 BC-250 礦卡的支持，併為部分 AMD 集成 GPU 加入時鐘頻率和温度監控功能。同時，軟件現在能夠讀取 AMD R9 200/300、Fury 和 RX 400/500 系列顯卡的 GPU 熱點温度，涉及 Polaris、Lexa、Hawaii、Fiji、Bonaire 和 Tonga 等 GPU 架構。

傳感器功能也是此次更新的重點之一。用户將鼠標懸停在傳感器數值上時，可以通過新增的工具提示查看相關統計信息。此外，傳感器頁面中的最小值、最大值和平均值計算現在會自動排除無效讀數，避免異常數據影響統計結果。

對於配備集成顯卡的設備，新版本調整了顯存顯示方式，不再顯示“N/A”，而是以 iGPU 標註共享系統內存的容量，例如“iGPU (64 GB)”。在高級信息頁面中，軟件還增加了對未知 NVIDIA 供電線路的顯示支持，相關數據將以“Rail ### power draw”的形式呈現，該功能默認關閉。

針對無法識別 GPU 型號的顯卡（IT之家注：包括部分假冒顯卡），GPU-Z 現在可以直接從當前系統讀取 DirectX API 版本及功能級別支持情況，而不再統一顯示“Unknown”。

其他改進還包括：在高級信息頁面中增加 CUDA 能力信息，新增 CUDA 6.2、 7.x 、 8.x 、9.0、 10.x 和 12.x 等版本的能力識別及多項 CUDA 屬性；擴充 AMD 和 NVIDIA 顯卡的 DXVA GUID 名稱，並修復 8K 視頻支持檢測問題。

此外，新版本修復了部分情況下 OpenGL 檢測失效的問題，調整了 AMD 和 NVIDIA 顯卡熱點温度傳感器的名稱，統一顯示為“Hot Spot”；如果 NVIDIA BIOS 完全無法讀取，高級信息頁面也不再顯示損壞的 BIOS 信息區塊。GPU-Z 2.72.0 還修復了高級 CUDA 信息頁面中的多處拼寫及細節錯誤，並進行了其他小幅改進。
