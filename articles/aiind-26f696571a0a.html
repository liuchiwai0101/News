騰訊新 AI 模型 將擴大規模 也會推出小模型

騰訊 ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' 00:00 2026/11/22 01:08:25 經濟日報 記者林宸誼／綜合報導 騰訊首席AI科學家、混元大模型負責人姚順雨與混元團隊研究員昨（21）日凌晨在Reddit開發者社群進行了一場AMA（Ask Me Anything，線上問答），這次交流是在混元連續發布Hy4和Hy4 flash之後。混元團隊明確表示，下一代Hy模型的規模將「進一步顯著擴大」，並將繼續投入大規模強化學習，也會推出小模型。

姚順雨指出，如果要問AI是短期遊戲還是長期遊戲？他的判斷是長期遊戲：「下半場才剛開始，我不認為ChatGPT和Anthropic永遠都是第一位，今天就像70年代PC剛出現時的階段一樣。」

界面新聞報導，姚順雨説，在當前AI的發展中，所有人都在做一樣的事情：AI coding（AI程式設計），但未來會變得更多元，程式設計智慧體會更重要，但多模態、具身智慧等很多路線也在繼續探索，因此在下半場的長跑中，更重要的事情是誠實面對自己，保持耐心，stay real（保持真實）。

每日經濟新聞報導，在提問的全球開發者眼中，大陸開源模型已經自成一張對照表；混元被拿來比較的對象是千問和Kimi。

因此有人問到，字節跳動和Kimi等（參數量）似乎都在往3T甚至5T推，混元為什麼停在700B？混元團隊回應：「Hy3和Hy4已經證明，較小的模型也能超越較大的模型，而且更便宜。」

不過，混元團隊也表示，Hy4仍有很大的進步空間，尤其是通過後訓練。 「我們正投入大量精力進行大規模強化學習，同時繼續改善用户體驗和模型安全。我們還計劃訓練更大規模的模型。」

根據騰訊提供的信息，11月4日發布的Hy4在第三方評測機構Artificial Analysis的智能指數榜單上位列大陸模型第二，在Agent Arena榜單上居開源模型首位；隨後推出的Hy4 flash則側重使用成本，單任務成本為Hy4的二十分之一。兩款產品分別指向更強的模型能力和更低的使用門檻。

在問答中，混元團隊明確表示，下一代Hy模型的規模將「進一步顯著擴大」，並將繼續投入大規模強化學習。不過，面對用户關於參數量擴大至1.5兆至2兆的追問，團隊並未確認具體數字。

同時，Hy4-mini已進入路線圖，團隊也預告了Flash-Lite模型，並表示正在考慮24B至31B的稠密模型，以及尺寸較小的圖像模型。
