會員卡條碼集中收納　原價 US $0.99《Code Cards》限時免費

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

Code Cards 是一款把會員卡、圖書證及各類條碼卡集中收納的錢包 App，適合不想隨身攜帶一堆實體卡片的用户。卡片資料儲存在裝置本機，無需註冊帳户，亦不會自動上傳到任何地方。原價 US $0.99，現正限時免費。

掃描匯入條碼一目瞭然

以相機掃描條碼或 QR 碼，也可從相片、截圖匯入或手動輸入卡號，並保留開頭的零，避免號碼出錯。錢包支援按卡名搜尋、標記常用卡片，配合資料夾分類整理，結帳時以全螢幕顯示條碼，方便店員掃讀。免費版可加入 3 張卡片，足以應付日常所需。
