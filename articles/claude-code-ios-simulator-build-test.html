Claude Code 桌面版支援 iOS 模擬器 可建置測試應用程式

Anthropic 今天宣佈，Claude Code 桌面版已更新並加入 iOS 模擬器支援，這項整合現已開放公開測試。開發者可以透過 Claude Code 直接在 iOS 模擬器中執行、建置及測試應用程式，全程無需手動操作。

即時互動與反覆迭代

當 Claude Code 收到建置、執行或檢查應用程式的指令時，它會在 iOS 模擬器視窗中開啟正在開發的應用程式。Claude 能夠即時觀看模擬器畫面，與之互動，並反覆調整直至項目完成。開發者可在 Claude 工作的同時繼續使用 iOS 模擬器。不同於需要 macOS 輔助功能及螢幕錄影權限的電腦操作方式，Claude Code 直接驅動模擬器，無需這些權限。

隱私與系統要求

Claude 在 iOS 模擬器中擷取的螢幕截圖會傳送至 Anthropic，並按照標準對話保留政策處理。Anthropic 建議使用者不要在 Claude 使用的裝置上登入真實帳戶。iOS 模擬器整合功能僅在 macOS 上的 Claude Code Desktop 中可用，且需要安裝 Xcode 及 iOS 平臺。此模擬器面板僅支援本地工作階段。詳細使用說明可在 Anthropic 網站上找到。
