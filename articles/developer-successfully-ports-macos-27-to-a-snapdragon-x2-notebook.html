「黑蘋果」再次偉大？macOS 27 成功移植 Snapdragon X2 Notebook

內容機器翻譯自第三方媒體（PCM），僅供參考，以原文為準。

早年 Apple Mac 全線採用 Intel x86 處理器時，坊間不少高手各顯神通，以「黑蘋果」（Hackintosh）之名將 macOS 移植到 PC 平台，一度盛極一時。不過隨著 Apple 徹底轉向自家 Apple Silicon 陣營，「黑蘋果」社群近年幾近沉寂。然而，近日有獨立開發者公開名為「Snapintosh」的開源專案，成功將 macOS 27 Golden Gate 移植至搭載 Qualcomm Snapdragon X2 晶片的 Notebook 上，難道真的可以「讓黑蘋果再次偉大」？

Apple 最新 macOS 27 Golden Gate 已被移植至 Qualcomm Snapdragon X2 晶片的 Notebook 上，震驚科技圈。

這個名為 Snapintosh 的專案由獨立開發者 Miguel C 一手打造，目前他已將原始碼、驅動及相關工具放上 GitHub 供公眾下載，象徵著第三方開發者在 ARM 架構下逆向工程運行 macOS 的重大突破。有別於以往 Intel 時代依賴 Clover 或 OpenCore 修改 x86 ACPI 描述檔的傳統做法，這次的「Snapintosh」是一套建基於 ARM64 架構、以 EL2 虛擬化底層（Hypervisor）為核心的相容層系統。

獨立開發者 Miguel C 發布了真實相片，可見在 ASUS Zenbook A16 UX3607OA 成功運行 macOS 27。

雖然 Qualcomm Oryon 核心與 Apple M 系列晶片同屬 ARM64 架構，但兩者的自研微架構與指令集擴展存在顯著差異。為此，「Snapintosh」在保留 Apple 原生 macOS 核心的前提下，於底層動態攔截並轉譯記憶體管理單元（MMU）及各類硬體暫存器指令。目前系統分配了六顆虛擬 CPU 核心供 macOS 運行，雖然已能成功載入桌面，但由於底層轉譯損耗以及排程優化尚處於初期階段，整體介面的反應速度與流暢度仍然飄忽。

ASUS Zenbook A16 UX3607OA 搭載了 Qualcomm Snapdragon X2 Elite Extreme 處理器，屬旗艦級機種。

按以往玩「黑蘋果」的經驗，GPU 加速向來是移植過程最大難題。若未能成功驅動 GPU 硬件加速，單靠 CPU 進行軟件加速，操作介面或將「窒到完全無法使用」。「Snapintosh」最大的技術突破，正在於作者為 Qualcomm Adreno X2-90 GPU 編寫了專屬客製化 Metal 驅動程式，令 macOS 得以直接調用硬件繪圖加速，順利繪畫桌面及各類毛玻璃半透明視覺特效。受限於驅動完整度與面板控制通訊協定，目前螢幕只能鎖定於 2880 x 1800 解析度以 60Hz 輸出，暫時未支援螢幕原生的 120Hz 高更新率，但單是實現基本的 GPU 硬件繪圖加速，已是整個專案含金量最高一環。

Qualcomm Snapdragon X2 Elite Extreme 規格及效能強勁，但由於它是 Windows on ARM 機種，普及仍然需時。

不過從現況來看，「Snapintosh」的硬體相容性依然極為挑剔，現階段僅支援搭載 Snapdragon X2 Elite Extreme（X2E-96-100）處理器的 ASUS Zenbook A16 UX3607OA 單一機型，距離「日常可用」還有非常漫長的道路要走。雖然 Notebook 的實體鍵盤、多點觸控板手勢以及內部 NVMe 固態硬碟已能正常識別與讀寫，但最大的物理限制是系統完全無法獨立開機。每次重新開機，都必須以 USB-C 線接駁另一部運行 macOS 27「母機」Mac 電腦，由「母機」推送引導程式與初始化記憶體 Image 才能啟動。此外，藍牙、音效、Webcam、睡眠喚醒（Sleep Mode）以及外接屏幕輸出都尚未成功運作，連 Wi-Fi 亦只能依靠「母機」進行連線除錯，無法在系統內直接搜尋及連線。

然而，隨著現時越來越多開發者藉助 AI 工具輔助進行逆向破解工程，破解進度或許會大幅躍進。未來「Snapintosh」甚至有望拓展至更多 ARM Notebook 之上，對於一眾技術玩家而言，可玩性勢必進一步提升。
