Lenovo 平價掌機 Legion Go Beam 曝光！取消觸控板 改 16:9 屏 核心規格會否大縮水？

內容機器翻譯自第三方媒體（PCM），僅供參考，以原文為準。

近年 PC 遊戲掌機市場競爭激烈，但動輒五、六千元甚至過萬港元的定價，令不少想入手的玩家都為之卻步。就在連定位相對親民的 Lenovo Legion Go S 中國香港售價亦要 HK$5,298（美洲地區售價更達 829 美元）之際，外媒 Windows Latest 近日曝光了 Lenovo 全新入門級掌機 Legion Go Beam 的高解析產品圖，顯示廠方正透過大刀闊斧的「減法設計」進一步壓低門檻，預計最快於 2027 年 1 月的 CES 大展正式亮相。

拔走標誌性設計 改用 16:9 寬邊框螢幕

從流出的產品渲染圖可見，Legion Go Beam 採用白色機身配襯螢光綠點綴，機身線條比以往更圓潤，並重新調整了兩支類比搖桿的位置以改善握感。不過，為了將售價壓至更具競爭力的入門水平（外界預期將低於 Lenovo Legion Go S  的 HK$5,298 ），Lenovo 在外部硬件上作出了多項明顯妥協：

捨棄觸控板： 不僅拿掉了初代標誌性的可拆式手把設計，甚至連 Lenovo Legion Go S 右搖桿下方的小型觸控板亦一併取消。雖然正面保留立體聲喇叭、背面設有散熱孔，並具備圓形十字鍵、ABXY、四肩鍵及兩顆背鍵，但少了觸控板在操作 Windows 桌面介面時難免會較為不便。

螢幕改為 16:9 比例： 螢幕比例由過去的 16:10 縮減為傳統的 16:9，且上下邊框明顯變寬，顯示面板採購上明顯以成本控制為優先考量。

連接埠精簡： 機身頂部僅配備單一 USB-C 連接埠（Lenovo Legion Go S 具備雙 USB-C 埠），幸好仍保留實用的 3.5mm 耳機孔及 microSD 記憶卡槽。

外部減配壓低成本 核心效能會否「縮水」？

目前這波爆料僅限於外觀產品圖，官方及外媒均尚未取得處理器（SoC）、記憶體容量及電池等內部核心規格。然而，結合產品定位與供應鏈現況分析，Legion Go Beam 的效能規格確實存在下調空間：

拉開產品線階級差距： 目前旗艦級 Legion Go 2 售價高昂，而搭載 AMD Ryzen Z2 Go 與 16GB RAM 的 Lenovo Legion Go S 亦站穩 HK$5,298 價位。Legion Go Beam 若要主攻三、四千元級別的入門市場，除了精簡外殼模具與螢幕，在內部硬件選用較入門的掌機晶片也是理所當然的市場區隔。

DRAM 漲價與短缺壓力： 報導特別指出當前正面臨 DRAM 價格上漲與供應緊張的環境。廠商為了保住平價門檻與利潤，極有可能在記憶體配置（例如維持 16GB 甚至更低）上作出妥協。

系統成關鍵變數 搭載 SteamOS 或成救星

現階段仍未確定 Legion Go Beam 會預載 Windows 11 還是 SteamOS。從用家體驗角度出發，在機身已經拿掉觸控板、且核心效能可能有所保留的前提下，若最終能採用系統資源佔用較少、且專為手把操作優化的 SteamOS，其遊戲流暢度與操作直覺度，無疑會比運行 Windows 11 更具優勢。外媒 Notebookcheck 推測，按目前的爆料時間點推算，Lenovo最快有望在 2027 年 1 月的 CES 展會 正式發表這款平價新機。對於預算有限、覺得現時 HK$5,298 的 Legion Go S 仍未夠「貼地」的玩家來説，不妨密切留意其最終定價與系統配置。
