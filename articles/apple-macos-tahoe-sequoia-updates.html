Apple 發佈 macOS Tahoe 26.7　同步推出 macOS Sequoia 15.8

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

Apple 於 2026 年 9 月 14 日發佈 macOS Tahoe 26.7 與 macOS Sequoia 15.8，兩者與 macOS Golden Gate 同日推出。新版本面向仍在使用較舊 Mac 的用户，以及暫時無意升級至 macOS Golden Gate 的用户。

舊款電腦仍可更新

macOS Tahoe 26.7 與 macOS Sequoia 15.8 為使用較舊 Mac 的用户，以及尚未打算改用 macOS Golden Gate 的用户提供更新途徑。Apple 同日亦發佈 macOS Golden Gate，作為最新一代系統版本。

經系統設定下載

兩個更新可透過系統設定應用程式內的軟件更新部分下載。在符合安裝 macOS Golden Gate 資格的 Mac 上，用户會同時看到 macOS Tahoe 26.7 更新與新的 macOS Golden Gate 更新，可按需要選擇其一。

兩版同含安全修正

macOS Tahoe 26.7 與 macOS Sequoia 15.8 均包含安全修正，有關修正內容很可能與 macOS Golden Gate 所包含的相同。
