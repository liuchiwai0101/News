中美人工智慧對話 登場

人工智慧 國務院 ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' 00:00 2026/11/22 00:49:56 經濟日報 記者林茂仁／綜合報導 中美雙方近日正式確認，將於27日舉行下一次人工智慧領域雙邊對話，相關籌備工作目前已在兩國經貿磋商機制框架下推進，標誌著兩國在人工智慧治理領域的務實溝通進入常態化推進階段。

中美雙方今年9月已在美國完成首次人工智慧對話，由中方牽頭人、中國大陸國務院副總理何立峯與美方牽頭人、美國財政部長貝森特共同主持。首次對話中，兩國團隊圍繞人工智慧技術發展的潛在風險與公共利益展開坦誠交流，雙方一致同意建立人工智慧重大突發事件專項溝通管道，並約定在今年第4季內舉行下一輪對話，進一步細化相關治理協作路徑。

美國財政部長貝森特10日公開對外確認，美方已正式啟動新一輪對話的籌備工作，雙方團隊近期通過線下與線上結合的方式，就對話的議程設置、參與人員、討論議題等細節進行多輪對接。
