IT之家 7 月 28 日消息，今日，火山引擎宣佈上線豆包搜索服務，提供跨語言、多模態、多垂類聯網信息查詢，融合全域互聯網信息、行業專業知識以及字節跳動獨家內容資源，爲企業和開發者構建 AI Agent，提供更加智能、高效的信息引擎。

IT之家附官方詳細介紹如下：

Agent 可信搜索：權威信息高效調用

圍繞 Agent 在真實任務中的信息獲取需求，豆包搜索針對搜索效率、信息可信度以及複雜任務處理能力進行了全面升級。

**// Agent 直接使用，提升信息獲取效率**

豆包搜索可**直接輸出 Agent 能直接使用的信息格式**，支持原文 markdown 和各類結構化數據返回；同時支持精準定向查詢、寬搜語義改寫、多輪檢索增強等搜索模式。它能理解自然語言任務意圖，跟隨 Agent 任務推進自動調整檢索策略，識別信息缺口併發起補充檢索，無需開發者手動拆解查詢指令。

**// 權威分級治理，提供可信信息來源**

針對互聯網低質內容和 SEO 灌水信息干擾檢索結果的問題，豆包搜索從網站站點和創作者兩個維度對信源建立權威分級體系，按行業分類做垂直治理；同時，融合全域互聯網信息、行業知識與字節跳動獨家內容資源，**從檢索源頭爲 Agent 過濾無效低質信息，提升結果可信度**。

**// 多項公開評測表現優異，複雜檢索能力突出**

豆包搜索持續**強化事實問答、時效信息獲取與複雜檢索能力**，在 SimpleQA、FreshQA、BrowseComp-ZH 等多項行業公開評測中均表現優異，通過提供穩定、高質量的聯網搜索支撐，滿足 Agent 信息獲取需求。

覆蓋多元場景：深入企業業務一線

目前，豆包搜索已經服務知識問答、辦公協同、金融服務等多個行業場景，幫助企業將實時、可信的搜索能力融入 AI 應用。

**AI 問答和搜索**

豆包搜索已成爲**國內 9 成 TOP 手機廠商**智能助手背後的信息引擎，滿足用戶知識問答和信息檢索的需求。

**辦公協同**

爲**辦公生產類 Agent** 提供信息檢索、多輪搜索與上下文構建能力，支撐事實獲取、證據組織與結果生成，強化 AI 辦公信息底座。

**金融投研**

爲**證券投資類 Agent** 提供權威新聞、高時效資訊以及金融垂類數據庫查詢，爲投資分析、投教陪伴、研報生成等場景提供可靠信息支撐。

**商業分析**

爲**洞察分析 Agent** 提供行業洞察和企業動態查詢能力，助力企業內部運營和戰略分析場景，構建商業洞察分析能力。

**內容生產**

爲**電商類 Agent **應用提供品類信息、消費趨勢、熱點素材等內容查詢，爲內容創作提供更加豐富、實時的信息來源，有效提升電商社區的信息價值和生態豐富度。

適配不同開發需求：支持獨立接入和 Agent Plan 配置

豆包搜索支持獨立產品接入與 Agent Plan 內置配置兩種路徑，適配不同開發場景需求。

企業和開發者**可直接登錄火山引擎豆包搜索控制檯開通服務**，支持 API、Skill、MCP 等多種接入形態；也**可基於火山引擎 Agent Plan 在 harness 工具裏一鍵配置**啓用豆包搜索，無需額外聯調，快速爲 Agent 補齊聯網檢索能力。

豆包搜索面向企業和開發者提供每月 500 次免費搜索額度，超出額度後支持按量後付費，按需調用、靈活可控；也可選擇月卡低折扣套餐，適配穩定的規模化使用需求。
