Anthropic 推出 Claude Ship　Claude 可審核並批准程式碼 PR

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

Anthropic 於 2026 年 11 月 23 日推出 beta 版 Claude Ship，讓 Claude 審核及修正程式碼合併請求（PR），並根據團隊自訂政策判斷哪些改動可以合併。隨著更多開發者用代理程式寫程式碼，PR 的審核、修正及批准成為瓶頸；Anthropic 希望加快這些步驟，同時讓團隊決定哪些變更仍需人手處理。

三層分工：審核、修正、批准

Claude Ship 由三部分組成：Code Review（已正式推出）及兩個 beta 代理程式 PR Steward、Claude Approvals。Code Review 對照整個程式碼庫審核 PR，並將發現分類；各程式碼庫可選 Quick、Standard 或 Deep 深度。官方稱其 Claude Code 團隊 6 月至 9 月合併 PR 增加逾一倍，回滾比例降逾 40%。

PR Steward 負責處理失敗的持續整合（CI）檢查、合併衝突及審核意見，令 PR 保持通過檢查，但不會批准或合併。每次推送後，它會留言交代改動及撤銷方法；開發者可用 @claude 下指示，或用 @claude stop 叫它停止。Claude Approvals 則依程式碼庫內的政策檔案決定批准例行改動或要求人手簽核，官方建議多數客户先使用只觀察模式。

兩種用法：/ship 與逐個程式碼庫設定

開發者可在 Claude Code 執行 /ship，讓 Claude 推送改動、開啟 PR、審核及處理意見和失敗的檢查；可合併與否取決於開發者權限及分支規則。管理員亦可逐個程式碼庫開啟 Code Review 和 PR Steward，選擇審核深度、執行時機及消費上限，並兼容現有分支保護和必要檢查。

Team 與 Enterprise 限定　按 token 計費

Claude Ship 適用於 Team、Enterprise 的 GitHub 程式碼庫，按 token 計費。Approvals 無基本收費，惟分類器及政策觸發的審核按 token 計費，觀察模式亦然。啟用 Zero Data Retention、HIPAA 配置或客户自管加密金鑰的組織不可使用。/ship 自 11 月 23 日起在 Claude Code 及桌面程式推出。
