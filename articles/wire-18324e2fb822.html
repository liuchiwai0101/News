開發者以 Claude 在破解版 PS5 原生運行 Xbox Cloud Gaming - Yahoo

內容機器翻譯自第三方媒體（Yahoo 新聞 · GameApps.hk · 蕃新聞 · MTGamer 等5家），僅供參考，以原文為準。

正文

一位名為Sword的自製軟體開發者剛剛完成了索尼從未正式提供的功能：讓PlayStation 5能夠讀取真正的PS2光碟，並以高達原生解析度六倍的解析度進行渲染。該專案名為PS5SX2，是開源PCSX2模擬器的移植版，旨在直接在破解後的PS5硬體上運行，而非Windows PC。根據Hardware Busters報道，2026年10月10日發布的2.01版本增加了從主機內建藍光光碟機直接啟動PS2 DVD光碟的測試版功能，幾天後發布的2.02版本則增加了一個實驗性的USB光碟機選項。

這則消息發佈於PS5主機發布六年之際，索尼從未在PS5硬體上提供原生的PS2向下相容功能，這一空白只能由PC上的第三方模擬器填補。 PS5SX2 透過將已知的 PS5 破解漏洞與經過大幅修改的 PCSX2 版本相結合，以非官方的方式關閉了 PS5 的向下相容功能。 PCSX2 是 PC 用户二十多年來一直依賴的 PS2 遊戲模擬器。安裝 PS5SX2 的用户將面臨真正的法律風險。

PS5SX2 並非索尼產品，也並非獲得授權的模擬器或官方認可的向下相容層。其 GitHub 程式碼庫由 Swordpdf 維護，其中明確指出該專案是將 PCSX2 移植到 PS5 平台。 PCSX2 本身就是一款長期運行的開源 PlayStation 2 模擬器，自 2000 年代中期以來一直為 PC 上的 PS2 遊戲提供支援。 PS5SX2 的獨特之處在於其目標硬體：它並非運行在 Windows 或 Linux PC 上，而是原生運行在已破解的 PS5 主機上，利用主機本身的 CPU、GPU，以及從本次發布開始，其內建光碟機。

該項目進展迅速。其 GitHub 程式碼庫和 README 文件於 2026 年 9 月 25 日左右被索引，當時已經記錄了一個可運行的模擬器核心。 10 月 9 日，Sword 發布了一段視頻，展示了將 PS2 遊戲光碟直接插入 PS5 的過程，以預告了實體光碟功能。第二天，2.01 版本發布，並加入了測試版光碟支援；不久之後，2.02 版本也發布，其中包含一個早期但預設為停用的選項，允許用户透過外接 USB 光碟支援而不是主機內建光碟機讀取光碟。根據 TechPowerUp 報告，對於那些沒有內建光碟機的 PS5 數位版用户來説，這是一個重要的細節。

以上功能在未經任何修改的 PS5 主機上都無法運作。運行 PS5SX2 需要一台已破解且能夠執行未簽署、非官方代碼的主機，而該專案的 README 文件也明確列出了這項要求。與此發布相關的報告指出，目前的破解窗口期歸因於 Relapse 漏洞，據稱該漏洞適用於 PS5 系統軟體版本 7.00 至 13.60。 Insider Gaming 在其對該發布的報告中指出，任何韌體版本高於 13.60 的主機都超出了該視窗期，目前無法運行 PS5SX2 所依賴的自製軟體鏈。

根據 The Gamer 報導，Sword 的開發工作據稱是在一台運行韌體版本 11.40 的 PS5 Pro 上進行的，該版本完全處於可破解的韌體版本範圍內。這一細節提供了有用的背景信息，但並不能證明該模擬器在所有 PS5 機型以及 7.00 至 13.60 範圍內的每個固件版本上都能表現完全相同。 PS5 Pro 的效能比標準版 PS5 更強，而且即使是同一代主機，模擬器在不同型號上的效能也歷來存在差異，這也是該專案文件沒有保證結果完全一致的原因之一。

光碟讀取功能的原理遠比插入光碟並按下播放鍵複雜得多。根據 Hardware Busters 報告，PS5SX2 會在首次使用時將插入的光碟複製到主機內部存儲，然後在後續使用中啟動儲存的副本，而不是直接從旋轉的光碟讀取模擬內容。這種設計避免了在為完全不同的光碟世代設計的硬體上即時模擬 2000 年代光碟機格式時可能出現的讀取速度和尋道延遲問題。

此外，還有一個值得了解的物理限制。 PS5 的內建光碟機可以讀取藍光和 DVD 光碟，這涵蓋了絕大多數 PS2 遊戲，因為當時大多數 PS2 遊戲都是以 DVD 光碟形式發售的。但它無法讀取普通 CD，這意味著對於少數最初以 CD 光碟形式發售的 PS2 遊戲來説，內建光碟機就無法播放了。除了實體光碟之外，報導 PS5 發售的媒體也指出，PS5SX2 支援常見的 PS2 光碟鏡像格式，包括 ISO、CHD、CSO 和 ZSO，並且據説任何區域的光碟都能正常播放。這意味著，即使實體光碟無法播放，PS5SX2 也能播放 CD 遊戲和進口遊戲。

PS5SX2 的主要規格是其解析度倍增器，最高可達 PS2 原生輸出解析度的 6 倍。 PS2 通常以 480i 或 480p 解析度渲染遊戲，因此 6 倍的內部渲染縮放會將垂直解析度提升至約 2880 像素，有報導稱這一範圍已接近 4K 解析度。該版本的發布報導還指出，PS5SX2 包含後期處理選項，包括 AMD 的 FidelityFX 超解析度技術，該技術疊加在原始的內部解析度提升之上。

關於 6 倍的縮放比例，需要注意一個容易被標題忽略的注意事項：它指的是最高可用設置，而不是保證在所有遊戲中都能穩定運行。據報道，該專案的 README 文件警告説，某些 PS2 遊戲對硬體要求過高，無法在標準 PS5 上以 6 倍縮放流暢運行，這與 PC 模擬器的運行規律一致。具有複雜粒子特效或密集幾何圖形的 PS2 大型遊戲一直以來都比簡單的 2D 或早期 3D 遊戲更耗費 PCSX2 的性能，這種差異也同樣存在於 PS5 移植版中。玩家應該預期在PS2遊戲庫中相當一部分遊戲中可以達到6倍效能，而不是指望在所有約3800款PS2遊戲中都能獲得全面的效能提升。

自2020年PS5主機發布以來，索尼一直銷售不帶光碟機的數位版PS5，這顯然與一個圍繞讀取PS2實體光碟而開發的專案存在相容性問題。 2.02版本嘗試透過一個實驗性的、預設為停用的選項來解決這個問題，該選項允許玩家透過外接USB DVD或藍光光碟機讀取光碟，而不是使用內建光碟機。報道稱，該功能尚處於早期階段，未經充分驗證，而非已完成。此外，一個名為5S2CD的相關社區專案（託管在GitHub上）也正在為同一生態系統開發USB光碟讀取功能，顯示外接光碟機方案目前仍是開發者積極探索的方向，而非已解決的問題。

目前，最流暢的遊戲體驗仍僅限於內建光碟機的 PS5 機型，其他使用者則需要使用 ISO 或 CHD 等光碟鏡像檔。這種差異反映了主機改裝領域的一個常見模式：新功能的首個可用版本幾乎總是優先支援開發者手頭用於測試的硬體配置，更廣泛的兼容性會在後續版本中逐步實現。

對於任何 PS5 上的 PS2 項目，自然而然會有人問：PS3 模擬是否也能遵循同樣的路徑？而開發者已經給出了肯定的答案。根據 Hardware Busters 報導，當被問及成熟的 PC 平台 PS3 模擬器 RPCS3 的 PS5 移植版是否最終會像 PS5SX2 支援 PS2 光碟一樣支援 PS3 光碟時，Sword 簡單地回答：「是的，它會隨之而來 :))」。這只是開發者的展望性評論，並非已發布的功能，目前也沒有任何公開的 PS3 光碟支援實作。讀者應該將 PS3 支援視為計劃中的支持，而不是可用的支持，這與 2.01 版本正式發布前幾週 PS2 光碟支援的情況相同。
