經典 Windows 遊戲可以重生？ 微軟高層稱《立體彈珠台- 太空軍校生》會被列入內部考慮事項 - Yahoo

正文

PC3 經典 Windows 遊戲可以重生？ 微軟高層稱《立體彈珠台- 太空軍校生》會被列入內部考慮事項 偽宅男 2026年10月7日週三 下午7:30 如果大家使用 Windows 多年，也許會記得昔日在 Windows XP 年代，有一款預載的彈珠台遊戲名為《立體彈珠台- 太空軍校生》。但是由 Windows Vista 開始至今，《立體彈珠台- 太空軍校生》就已再沒蹤影。過往不時有意見認為，微軟應該嘗試令《立體彈珠台- 太空軍校生》「翻生」，而有微軟高層已表明，會把此意見列為內部考慮事項……

微軟高層將《立體彈珠台- 太空軍校生》列入考慮清單 較早時候在微軟自家名為《Inside Windows》的 Podcast 節目中，Windows 及裝置執行副總裁 Pavan Davuluri 及設計及研究企業副總裁 Marcus Ash 一同登場，解答大眾有關 Windows 的提問、意見。當他們回應有網民提出應該讓 Windows 昔日經典遊戲《立體彈珠台- 太空軍校生》「翻生」，Davuluri 沒有當場否決這建議，只表示這是「很好的提醒」，並會加入至內部考慮事項當中。

廣告 廣告 如果《立體彈珠台- 太空軍校生》完全翻生無望，Davuluri 大可以斬釘截鐵叫大家「死心」，但因《立體彈珠台》的確深受眾多資深 Windows 玩家歡迎，連他自己都指出 Windows 過去一直有內置遊戲的傳統，所以到了未來，Windows 11 是否再沒可能預載《立體彈珠台- 太空軍校生》，目前仍未可蓋棺定論。

《立體彈珠台- 太空軍校生》在 Windows XP 後消失的原因 如果大家還記得，昔日的《立體彈珠台- 太空軍校生》自從 Windows Vista 開始，就再沒出現過，一直到現在。有關背後的原因，微軟資深工程師 Raymond Chen 曾解釋指，工程團隊嘗試將 Windows XP 移植到 64 位元時，發現遊戲中的彈珠會在開球後，直接穿過發射器與枱面掉出畫面外。雖然團隊曾嘗試修復問題，惟《立體彈珠台- 太空軍校生》的程式碼是當年微軟找外判公司多年前設計，微軟內部根本無人完全理解其運作邏輯，程式碼亦幾乎沒有註解，令團隊難以補救。加上當年微軟關注的是數以百萬行計的 Windows 程式碼移植問題，令微軟最終選擇放棄《立體彈珠台- 太空軍校生》。

Raymond Chen 也曾提到，有關《立體彈珠台- 太空軍校生》微軟曾有權向原設計公司 Cinematronics 取得授權，將遊戲與 Windows 一併發行，但就沒有獨立發行同一遊戲的權利。而 Cinematronics 其後已被 Electronic Arts 收購，令重新取得授權更是無從談起。因此微軟若要再度推出《立體彈珠台- 太空軍校生》，恐怕是要全新製作，而且無法「原汁原味」地還原。
