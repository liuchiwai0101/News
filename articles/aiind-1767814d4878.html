Google Cloud 擴大模型選擇與彈性：正式為企業客户帶來 OpenAI 模型

我們正式將 OpenAI 模型加入 model garden 中，企業現可於 Google Cloud 統一的企業級 AI 平台，依照不同需求選擇最適合的 GPT 模型。不僅能享有單一帳單，同時在嚴格的企業級資料治理下，賦予企業高度彈性，讓各項 AI 工作負載的成本與效能達到最佳平衡。

提供多元選擇、企業級治理與領先業界的性價比，一直是 Google Cloud 的核心價值。為了落實開放與選擇的承諾，我們致力於賦予企業客户高度的彈性，讓企業能自由選擇模型與基礎架構，來執行 AI 代理工作負載（agentic workloads），以達到成本、承載力與效能的最佳平衡。今天，我們將進一步擴展這項基礎，正式在 Google Cloud 的 model garden 中推出 OpenAI 模型。

Google Cloud 現在是唯一一家能在統一的企業級 AI 平台上，同時提供三大領先閉源大型語言模型（LLM），以及超過 200 個第一方、第三方與開放模型（open models）的超大規模雲端服務供應商。

為每項工作負載提供最合適的模型 現代企業 AI 需要為不同的工作負載搭配最適合的模型，而非仰賴單一模型來處理所有任務。透過將 OpenAI 的最新模型加入 model garden 中，我們為團隊提供了能滿足所有企業工作負載的多樣選擇。本次加入的 OpenAI 模型，包含如下：

GPT Astra ：專為程式設計、電腦操作（computer use）、專業任務與科學研究等高難度工作而設計。 GPT 6.1 Sol ：以較低的成本提供 Astra 等級的智慧能力，能夠處理代理式程式設計（agentic coding）、電腦操作與各項專業任務。 GPT 6.0 Luna ：一款快速且具成本效益的模型，適合大規模處理日常工作。 透過我們的平台，客户能根據效能、延遲與成本效益，針對任何應用情境動態選擇與切換最佳模型，不再受限於單一架構或簽署分散的供應商合約。對於開發者而言，他們將能在 model garden 中自由運用數百種選項進行開發。此外，由於 OpenAI 模型是直接透過 Google Cloud Marketplace 進行交易，所有用量皆會顯示於單一的 Google Cloud 帳單上，可抵扣現有的雲端承諾額度（cloud commitments），並計入跨模型供應商的 彈性節省方案（Flexible Savings Plans，FSPs） 。

內建的資料治理與企業級安全 擴展生成式 AI 的規模，絕不該以在法規遵循或安全性上妥協為代價。為企業治理而打造的 Gemini 平台 ，如今已深獲全球頂尖企業的信賴。我們也會確保執行任何第三方或 OpenAI 工作負載，皆能符合最嚴格的企業標準：

嚴格的資料邊界（Strict Data Perimeters） ：客户的提示詞、情境脈絡與生成結果，皆完全保留在指定的資料邊界內，絕不用於訓練基礎模型；我們也將於近期推出零資料保留（Zero Data Retention，ZDR）選項。 隔離的存取邊界（Isolated Access Boundaries） ：OpenAI 模型運行於專屬的 Google Cloud 基礎架構上，且即將支援機密運算（Confidential Compute）。所有查詢皆會透過經安全強化的隔離閘道進行路由，確保資料傳輸嚴格限制在 Google Cloud 的安全環境內，第三方模型供應商無法未經授權存取你的雲端環境。 統一稽核與身分驗證（Unified Auditing & Identity） ：每個 AI 代理與模型的互動皆在經過驗證的身分下運作，賦予 IT 管理員端到端的可視性、VPC Service Controls 保護，以及橫跨整個企業環境的統一稽核紀錄（logging）。

開始體驗 OpenAI 的 GPT Astra、GPT 6.1 Sol 與 GPT 6.0 Luna 模型目前已在 Google Cloud 的 model garden 針對特定企業客户推出私人預覽，未來也將提供更多選擇。即日起，企業客户不僅能透過我們的 API 運用這些模型進行開發，還能將本機端的 Codex CLI 與桌面工作流程直接串接至我們的 Gemini 平台進行推論。歡迎填寫此 表單 ，讓我們知道您有興趣瞭解更多。

OpenAI 模型近期也將在 Google Cloud 的 Gemini for business 與 Google Antigravity 中推出，為企業客户與開發者提供模型選擇的彈性，以及應對每項任務的最佳模型。
