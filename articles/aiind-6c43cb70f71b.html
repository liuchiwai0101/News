小摩：AI 業明年發債4,500億美元

美元 摩根大通 債券 ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' 00:00 2026/11/27 02:56:53 經濟日報 編譯陳律安／綜合外電 摩根大通（小摩）策略師指出，儘管蓬勃發展的人工智慧（AI）產業將來的成長可能趨於平緩，但企業明年仍將透過公開投資級債券市場籌資4,500億美元，來為AI相關資本支出籌集資金，規模遠高於今年的3,680億美元。

彭博資訊報導，以哈密德與羅森鮑姆為首的小摩策略師表示，整體而言，2027年AI支出將近乎翻倍至1.4兆美元，2028年將趨於平緩。

策略師指出，「由於整體產業成長率放緩，預料在2027年底或2028年初的某季，對次一季資本支出的預估將基本持平」，「市場屆時會做出正面或負面反應，誰也説不準」。策略師表示，這項轉變將使信用市場的債券供給更容易預測，但支出成長陷入停滯，也可能動搖投資人信心。

除了投資等級債券，摩根大通預期，企業2027年還將透過槓桿融資籌措650億美元，並透過證券化商品籌資250億–350億美元。

由於如此龐大的籌資需求，將使債市的承接能力逼近極限，預料現金充裕的超大規模雲端業者將投入更多自有資金。
