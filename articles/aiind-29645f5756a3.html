Mac Studio 加推 512GB RAM 版可選購 本機行大模型沒難度盛惠逾 17 萬 - Yahoo

內容機器翻譯自第三方媒體（Yahoo 新聞），僅供參考，以原文為準。

正文

PC3 Mac Studio 加推 512GB RAM 版可選購 本機行大模型沒難度盛惠逾 17 萬 偽宅男 2026年10月29日週四 下午7:30 今年 8 月，蘋果推出新一代可選配 M5 Max 或 M5 Ultra 的 Mac Studio，令它成為部署、運行大型 AI 模型，以及執行不同類型複雜工作的強勁桌上電腦。但若要在本機運行大模型，單是核心晶片效能強勁是不足夠的，重要的是同時備有足夠的記憶體。如今，Mac Studio 已添加了新的記憶體選項，讓大家需要選購時，可以有更多的選擇。

Mac Studio 現已開放 512GB 統一記憶體升級選項 廣告 廣告 當蘋果這三數天的焦點，放在新一代的 iPad mini、M6 版 14 吋 MacBook Pro 及設有 PROLED XDR 顯示器的 MacBook Pro 時，他們也悄悄為現有的 Mac Studio 進行小升級，可以選配多達 512GB 統一記憶體，比原有 256GB RAM 再多一倍。

蘋果指出，512GB RAM 最適合對記憶體要求較高的專業應用程式進行多工處理，或者是要日常處理大量的複雜內容或數據，以至在裝置上運行龐大 AI 模型。機內配置的記憶體越多，可同時運行的程式就越多，能使用的 AI 模型也越大，效能表現越見出色。

由於 Mac Studio 本身不具備後續自行升級的設計，所以現時蘋果開放選配 512GB RAM 的選項，對有需要的用家來説就不用勉強選配 256GB 而要左算右算。

要價逾 17 萬 雖然現時 Mac Studio 可以選配 512GB RAM，但前提是用家必須搭配現時最高階的 36 核心 CPU、80 核心 GPU 版 M5 Ultra，並且選用最少 1TB SSD 才行。當然，在現今 RAM 價仍高居不下的時代，512GB RAM 版 Mac Studio 當然售價不菲。即使其他選項都不升級，刻意選用 512GB RAM 就已要價 $170999，再加增 SSD 空間至 2TB 至 16TB 不等，當然要再加價。如果有意瞭解這種頂級配置究竟是甚麼的一回事，或者本身對 Mac Studio 有點興趣，希望多加認識，都可先瀏覽 Mac Studio 的產品頁。（ 連結 ）
