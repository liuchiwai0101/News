砸億元投資 AI Agent 旅遊巨頭推信箱整合工具搶客 - Yahoo股市

內容機器翻譯自第三方媒體（Yahoo 股市），僅供參考，以原文為準。

正文

11 月中旬，蘋果官網出現了兩則與自主式 AI Agent 有關的招聘信息。

其中一則描述了一個能夠像人類一樣操作電腦的智能體，另一則甚至直接點名 Claude Code 和 Codex，要求應聘者平時就使用這些工具。

據彭博社報道，蘋果正在開發自己的自主式 AI Agent，希望讓人工智能能夠跨應用執行任務，甚至自主規劃工作流程。

Meta、OpenAI、Anthropic，以及騰訊、字節跳動，都在把 AI Agent 推向真實的工作和生活場景。部分產品已經積累了千萬級用户，並開始創造實際收入。

對於依靠 iPhone、Mac 和 App Store 建立起龐大生態的蘋果來説，這場競爭恐怕很難繼續慢慢來。

蘋果終於要讓 AI 自己幹活了 蘋果究竟想讓 AI 做到什麼程度？招聘信息裏有一段描述，幾乎可以直接拿來當作產品介紹。

蘋果正在尋找一名高級工程經理，負責開發具備主動服務能力的 AI 助手。在崗位介紹中，蘋果描繪了一個讓 AI 像人一樣操作電腦的願景：

想象一個能夠像熟練的人類一樣使用電腦的 AI Agent。它可以瀏覽網頁、跨應用工作、運行命令、編寫和調試代碼、調用服務，併為每一步選擇合適的工具。

招聘信息顯示，蘋果正在開發一套通用計算機操作智能體系統。它能夠在應用、瀏覽器、命令行、代碼環境和 API 之間切換，獨立規劃並執行多步驟任務，還可以協調多個專門的子智能體共同工作。

拿出差來説，用户只需要交代「幫我安排下週去東京的出差」，AI 就可以查詢航班、篩選酒店、查看日曆、整理會議安排，最後給出一份行程方案。至於先查機票還是先看日曆、需要調用哪些工具，都交給它自己判斷。

蘋果正在尋找一名高級應用 AI 工程師，負責建立個人智能評測基準、完善評測基礎設施，並利用反饋機制不斷優化 Agent 的表現。

更有意思的是，蘋果在任職要求中指名道姓提到了 Claude Code 和 Codex，甚至要求候選人日常使用這類智能編程工具。

從這些要求來看，蘋果已經不滿足於讓 AI 回答問題、執行簡單指令。它希望智能體能自己找到完成任務的方法，並且在不斷使用中變得更可靠。

不過，電腦裏的文件、賬户和應用一旦交給 AI 操作，麻煩也可能隨之而來。

假如用户讓 Agent 整理電腦裏的舊文件，它可能誤刪重要資料；如果它能讀取郵件、運行代碼，權限範圍又該如何限制？這也是蘋果在招聘信息中反覆強調隱私、安全、沙盒隔離和權限管理的原因。

在 macOS 27.3 Beta 2 中，蘋果調整了設備控制和完全磁盤訪問權限的授權機制，將不同類型的系統權限拆分管理，並允許用户針對具體應用、文件夾進行授權。系統還會在 AI 應用控制其他應用時提供明顯的狀態提示。

用户可以更清楚地知道 AI 獲得了哪些權限、正在操作什麼，第三方 Agent 在 Mac 上的運行方式也會受到影響。

一邊調整第三方 Agent 的權限規則，一邊招人開發自己的智能體，蘋果顯然正在為 AI 深度介入操作系統做準備。

既要讓它有足夠的能力完成任務，又不能讓它隨意訪問用户的數據和設備，這兩件事必須一起解決。

據彭博社報道，蘋果曾考慮最早在 2027 年底推出相關產品，目前開發仍處於早期階段。
