OpenAI 三個神秘模型曝光 10 月 18 日，有開發者發現，OpenAI 的 API 模型列表中突然出現了三個陌生名字：

aurora-red-alpha、aurora-green-alpha、aurora-blue-alpha。三個模型都以 Aurora（極光）命名，分別對應紅、綠、藍三種顏色。但相關條目很快便從模型列表中消失。

此次發現來自第三方維護的 OpenAI 模型列表鏡像，並非官方公告。因此，這些模型究竟是什麼、是否會正式發佈，目前都還是未知數。

有網友推測，這些模型極有可能是 GPT-6 Astra 後續版本的內部檢查點，專門對標 Fable 5.5 的強項，創意編碼、長程 agent、視覺 / 3D。也有網友推測：三個模型對應 OpenAI 三個圖像模型。（消息來源：機器之心）

Anthropic 與法律專家討論 AI Agent 談判規則，未來可替用户砍價、處理糾紛 據《金融時報》最新報道，Anthropic 正在與律師事務所及法律專家合作，研究 AI Agent 代表用户進行談判時應遵循的行為規範。

隨着 Agent 逐漸能夠獨立執行任務，未來可能出現大量 AI 與 AI 之間的商業交互。

例如，消費者讓自己的 AI 助手與商家的 AI Agent 討價還價，員工讓 AI 代理參與薪資談判，或者用户委託 AI 處理服務糾紛。

Anthropic 希望明確幾個問題：AI 應該在多大程度上爭取用户利益？什麼時候需要徵求用户確認？面對其他 AI Agent 時，是否應該默認對方存在欺騙或操縱意圖？

公司還討論過一種授權方式：讓用户通過簽署文件，明確 AI 的代理權限、目標和行為邊界。

目前，這仍屬於規則研究和產品探索，尚未推出面向公眾的自動談判服務。（消息來源：金融時報）

DeepSeek 正式開放搜索與網頁抓取 API，每千次調用收費 5 元 DeepSeek 正式開放 Search 和 Fetch 兩項 API，向開發者提供基於自研搜索引擎的網頁搜索及內容抓取能力。

其中，Search API 可以根據關鍵詞返回結構化搜索結果，包括網頁標題、鏈接、摘要、發佈日期等信息；Fetch API 則可以抓取指定網頁，將正文轉換為 Markdown 文本。

兩項 API 均採用按成功請求次數計費的方式，價格為每千次 5 元。失敗、超時或未返回有效結果的請求不收費。

DeepSeek 表示，其自研搜索引擎目前每天在全球範圍內處理數億次請求。（消息來源：DeepSeek 官方公告）

Anthropic 擬設立「公共利益」基金，初始注入 5% 股份 當地時間 10 月 18 日，Anthropic 宣佈，在獲得股東批准的前提下， 公司計劃將 5% 的股份劃入新設立的公共利益基金 （Public Benefit Fund）；且隨着這家人工智能巨頭的估值增長，該基金持有的股份比例未來還可能進一步提升。

該擬議的基金將作為一家全資擁有的有限責任公司設立，經董事會裁量，公司估值每較尚未披露的基準上漲 50%，基金就會獲得 Anthropic 額外 2% 的股份。

Anthropic 公共利益基金所支持的項目將涵蓋非營利捐贈、向特定群體發放直接資助，以及應對人工智能對就業人員衝擊等舉措。

該公司表示，該基金所持有的任何股權均不會用於美國國內或海外的政治遊説與政治捐贈。

Anthropic 表示，將於未來數月內公佈有關該基金治理機制、組織結構以及可能擴大其持股比例的估值門檻的更多細節；此外，公司還計劃發佈一份公共利益報告，詳細披露其實現使命的進展。（消息來源：IT 之家）

蘋果首次公佈摺疊屏 iPhone Duo 電池容量：4883mAh 由兩塊電池組成 蘋果公司近日公佈的歐盟產品信息文件揭示了首款摺疊屏手機 iPhone Duo 的電池容量。這款設備配備總容量為 4883mAh 的電池，由兩塊電芯組合而成，容量分別為 2962mAh 和 1921mAh。相關信息此前已在網絡上出現，此次歐盟產品信息文件的發佈進一步證實了這一數據。

對於一款採用書本式摺疊設計的手機而言，4883mAh 的容量反映了蘋果在機身厚度、鉸鏈結構、屏幕尺寸和電池空間之間所作的取捨。摺疊屏手機需要將內部空間分配給兩塊顯示屏、鉸鏈、主板、攝像頭及其他組件，同時還必須在展開和摺疊狀態下維持合理的機身厚度。與傳統直板手機相比，這種結構設計會給電池佈局帶來更多限制。

iPhone Duo 採用雙電池系統，兩塊電芯分別位於機身的兩個部分。蘋果此前表示，iOS 會將這兩塊電池作為一個整體進行管理，而不是讓用户分別操作。採用兩塊電池有助於適應摺疊機身的內部空間佈局，但這並不意味着兩塊電池的容量相同，也不能僅憑電芯數量判斷整機的續航表現。

蘋果公佈的續航數據也顯示，使用哪塊屏幕會顯著影響電池表現。根據蘋果此前公佈的規格，iPhone Duo 在展開狀態下使用 7.6 英寸內屏播放視頻，最長續航時間為 31 小時；僅使用 5.4 英寸外屏播放視頻時，最長可達 44 小時。按照蘋果定義的典型使用場景，設備的續航時間最長為 24 小時。該典型使用場景假設用户均衡使用內外兩塊屏幕，同時進行消息收發、拍照、音樂播放、社交應用、視頻流媒體、遊戲、網頁瀏覽和導航等操作。( 消息來源：cnBeta)
