OpenAI總裁預告明年上市 挖角Claude Code產品負責人

內容機器翻譯自第三方媒體（橙新聞 · Yahoo 財經 · 華爾街日報中文網 · TechNews 科技新報 等6家），僅供參考，以原文為準。

正文

人工智能公司 Anthropic 在籌備大規模首次公開募股（IPO）之際，遭遇一項重要人事變動。長期負責 Claude Code 產品工作的高級產品負責人 Cat Wu 已正式離開公司。消息公佈後，引發業界對於這家 AI 獨角獸未來產品戰略和管理穩定性的關注。

Cat Wu 於當地時間11月3日在社交平台 X 上宣佈離職消息。她在發文中感謝了 Claude Code 團隊和廣大用户，並回顧了產品的發展歷程，不過並未透露離開的具體原因。Anthropic 隨後證實了這一消息。

作為 Claude Code 的產品負責人，Cat Wu 與該產品原創作者 Boris Cherny 一同被視為項目最重要的兩位核心人物。在兩人的帶領下，Claude Code 從內部實驗項目迅速成長為 AI 編程領域最具影響力的產品之一，也成為 Anthropic 挑戰 OpenAI 競爭地位的重要武器。

報道指出，Claude Code 的成功不僅幫助 Anthropic 獲得了廣泛關注，也為公司帶來了持續增長的收入和更充足的算力資金支持。隨着越來越多開發者將其用於軟件開發工作，大型科技企業對 Claude 模型服務的使用量持續上升，相關支出也快速增長。

Cat Wu 於2024年夏季加入 Anthropic，最初接觸到的是 Claude Code 的早期原型版本。她後來回憶稱，在首次體驗該產品後便被其能力所吸引，並決定加入團隊參與開發工作。

2025年2月，Anthropic 以研究預覽形式正式發佈 Claude Code。當時公司通過一段簡短演示視頻向外界展示產品，視頻主角正是 Cat Wu 和 Boris Cherny。

同年夏天，兩人曾短暫離開 Anthropic 並加入 AI 編程初創公司 Cursor，但數週後又重新回到 Anthropic，繼續主導 Claude Code 的發展。此後，該產品迎來爆發式增長，並在2025年底開始迅速流行。

最初，軟件工程師群體成為 Claude Code 最主要的用户。藉助生成式 AI 能力，該工具能夠自動完成大量編碼任務，大幅提升開發效率。隨着企業客户規模不斷擴大，Claude Code 逐漸成為 Anthropic 最重要的商業化產品之一。

除 Claude Code 外，Cat Wu 還負責 Cowork 項目。這是一款面向非軟件工程師的 AI 工作助手，同樣基於 Anthropic 的核心模型能力，主要服務於知識型工作場景。

在今年4月接受播客節目採訪時，Cat Wu 曾談到自己的工作目標是推動 Claude Code 向 Boris Cherny 所設想的“AGI 化版本”邁進。這裏的 AGI 指的是“通用人工智能”，即能夠在廣泛任務中展現接近人類水平能力的人工智能系統。

她表示，自己的工作不僅涉及產品規劃，還需要與市場、銷售、財務等多個部門協同合作，同時負責招聘部分產品經理。過去一段時間裏，她也經常通過社交媒體直接回應用户對 Claude Code 的反饋和建議。

值得注意的是，這並非近期 Claude Code 團隊唯一的重要人員流動。另一位參與項目開發的成員 Thariq Shihipar 已於上個月宣佈離職，使得外界更加關注團隊未來的穩定性。

Cat Wu 的離開發生在 Anthropic 即將啓動 IPO 的關鍵階段。市場普遍認為，Claude Code 是推動公司成長的重要引擎之一，而核心管理層變動能否被順利消化，將成為投資者觀察公司的重要指標。

對於未來計劃，Cat Wu 尚未作出詳細説明。不過在離職聲明下方，有網友調侃她是否終於可以開始長時間休假。對此，她以一句“等 AGI 實現之後吧”作為回應，為自己的 Anthropic 生涯畫上了一個頗具行業特色的句號。
