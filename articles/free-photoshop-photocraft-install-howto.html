免費 Photoshop 替代新星　PhotoCraft 安裝與使用全攻略

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

在開源影像處理軟體的世界裡，許多人習慣使用 GIMP 或 Photopea，但 GIMP 獨特的介面邏輯對 Photoshop 老用户來説學習成本高，而 Photopea 則是基於瀏覽器的 Web 應用。

近日在 GitHub 上備受矚目的開源專案 PhotoCraft（隸屬於 ArtCraft 社群），主打以 100% 純 Rust 語言 進行「無污染淨室重製（Clean-room reimplementation）」的 Adobe Photoshop 開源替代品。它不僅介面、快捷鍵高度復刻 Photoshop，更採用原生 GPU 算圖架構，擺脱了 Electron 等框架的笨重感。本文將帶你全面瞭解 PhotoCraft 的核心亮點、環境安裝步驟與日常上手教學！

PhotoCraft 的核心亮點

PhotoCraft 之所以一推出就引發熱烈討論，關鍵在於它在「效能」、「相容性」與「現代技術」上的突破：

極致原生效能

底層採用 wgpu（支援 Metal、Vulkan、DirectX 12、WebGPU），搭配寫入時複製（Copy-on-write）與多執行緒渲染，濾鏡與筆刷運算極快，啟動迅速且不依賴 Electron 或 Chromium 核心。

無縫接軌的熟悉體驗

無論是工具列配置、圖層面板，還是鍵盤快捷鍵（如 Ctrl/Cmd + J 複製圖層、Shift + Ctrl/Cmd + D 重新選取等），完全按照 Photoshop 慣用邏輯設計，無痛轉移零學習成本。

    高保真 PSD 檔案相容性

    原生支援讀取與匯出分層的 Photoshop .psd 格式。專案通過了數百個官方 PSD 測試集，完整保留文字圖層、圖層樣式與遮罩結構。

      非破壞性編輯體系

      提供多達 16 種調整圖層（曲線、色階、色相/飽和度、黑白、漸層對應、LUT .cube 載入等），搭配圖層樣式（陰影、外發光、筆畫等）與智慧型物件（Smart Objects），隨時修改不傷原圖。

        完整的專業工具箱

        • 包含 34 種核心工具：仿製印章、修復筆刷、污點修復、歷史紀錄筆刷、貝茲曲線（鋼筆）、向量形狀等。
        • 內建支援壓感、傾斜度、旋轉與筆擦的完整筆刷引擎。
        • 整合本地運算的智慧選取（快速選取、主體選取、物件選取），無須聯網、不上傳雲端，保障隱私。

        Agent-Ready（支援 AI 與自動化）

        軟體內部每個操作皆為指令驅動，支援透過 CLI、JSON 通訊通道以及 MCP（Model Context Protocol）伺服器進行程式化或 AI 代理控制。

            支援平台與安裝方式

            PhotoCraft 目前處於 Early Alpha（早期公開預覽） 階段，官方提供預編譯檔案與原始碼編譯兩種方式。支援平台包括 Windows、macOS、Linux、FreeBSD。

            下載預編譯版本

            前往官方 GitHub 發布頁面，根據你的作業系統下載對應檔案，注意，下載位置放在 Release Notes 下方 Assets（即 Contributors 下方）：

            • Windows：下載 Portable 便攜版 .zip 或完整安裝檔，解壓縮後直接執行 photocraft.exe（便攜版會將設定檔保存在執行檔同級目錄，不寫入登錄檔）。
            • macOS：下載 .dmg或打包檔案，拖曳至「應用程式」資料夾即可。
            • Linux / FreeBSD：提供 AppImage 或 Tarball 壓縮包。
