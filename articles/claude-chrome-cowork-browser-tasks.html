Claude 的 Chrome 側邊面板變成完整 Cowork 工作階段 瀏覽器任務可跨應用程式延續

Anthropic 今日宣佈，Claude 的 Chrome 側邊面板已變成完整的 Cowork 工作階段。瀏覽器內的任務與對話可隨用戶在 Claude 其他應用程式之間延續；此功能今日向 Max 和 Team 客戶提供，Pro 用戶會在未來數週內陸續使用。企業管理員可自行啟用並限制只容許指定網域存取，目前仍不支援其他 Chromium 瀏覽器或流動裝置。

跨應用程式延續

側邊面板內開始的對話會存入 Claude 歷史記錄，用戶可從 Claude 桌面版、網頁版及流動應用程式繼續同一工作階段。Anthropic 舉例，用戶可要求 Claude 從多個供應商入口網站收集發票資料並建立試算表，之後在桌面版繼續同一工作階段，加入本機檔案或與過往預算比較。

瀏覽器操作能力

用戶帳戶已配置的技能及連接器，無需額外設定即可在瀏覽器使用。Claude 的 Chrome 擴充程式能查看目前頁面，並利用用戶現有的瀏覽器登入資料操作網站，包括點擊連結、切換頁面、輸入文字及填寫表格。這項安排填補了以往側邊面板工作階段與 Claude 其他應用程式分離的缺口；這些工作階段原本不會把對話與上下文帶到其他應用程式。

安全警告

Anthropic 警告，瀏覽器代理程式仍容易受到 prompt injection 攻擊。啟用自動批准時，系統會另設檢查審視影響重大的操作；而在購買或分享個人資料前，Claude 仍會先詢問用戶。Anthropic 表示，這些保護措施能降低風險，但無法完全消除。
