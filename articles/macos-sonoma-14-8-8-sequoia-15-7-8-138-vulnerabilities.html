macOS Sonoma 14.8.8 與 macOS Sequoia 15.7.8 正式推出 修補超過 138 項漏洞

Apple 今日正式發佈 macOS Sonoma 14.8.8 與 macOS Sequoia 15.7.8，兩個版本均專注於錯誤修復與安全性更新。根據官方說明，這兩項更新為仍在使用 macOS Sonoma 或 macOS Sequoia 的用戶提供「重要安全性修正」，建議盡快安裝。

更新版本與 RC 相同

本次發佈的正式版本與上週推出的 Release Candidate 完全相同：macOS Sonoma 14.8.8 的組建編號為 23J620，macOS Sequoia 15.7.8 則為 24G824。Apple 在過去數週已向多個舊版系統推送安全修補，其中不少是針對 WebKit 漏洞，這些漏洞可能導致用戶資料外洩。

安全修復超過 138 項

Apple 隨後公開了 macOS Sonoma 14.8.8 與 macOS Sequoia 15.7.8 的完整安全內容，顯示兩個系統總共修補了超過 138 個不同漏洞。對於仍停留在 macOS Sonoma 或 macOS Sequoia 的用戶而言，安裝這些更新是保障裝置安全的重要步驟。
