賴清德 ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' 00:00 2026/10/11 15:33:43 經濟日報 記者邱琮皓／台北即時報導 賴清德總統11日上午陪同史瓦帝尼王國國王恩史瓦帝三世（King MswatiⅢ）前往台南參訪陸軍航空飛行訓練指揮部。並表示，台史建交58年，兩國邦誼深厚，飛訓部過去曾協助訓練史瓦帝尼飛行官及保修幹部，為兩國合作做出貢獻。期盼透過此次參訪，讓國王對台灣有更進一步瞭解，未來持續深化合作，促進兩國邦誼更加穩固。

賴總統與恩史瓦帝三世國王抵達後，首先一同聽取模擬機系統介紹，並操作體驗模擬機，接著至展示區聽取各項直升機型及突擊車簡介。

隨後，賴總統致詞時表示，台史建交已經58年，有非常深厚的情誼。很榮幸在一年一度的國慶日，歡迎恩史瓦帝三世國王暨祖瑪（Inkhosikati Make Zuma）王妃訪團參加我國國慶典禮。這也是恩史瓦帝三世國王第20次訪台，可見國王對台灣的支持與兩國邦誼的深厚。

賴總統指出，在昨天國慶慶典結束後，今天特別邀請恩史瓦帝三世國王來到台南參訪。飛訓部肩負陸、海、空軍直升機飛行官及航保人員的教育訓練，是國軍航空人才的重要搖籃，而這份培育人才的經驗，也運用在台灣與史瓦帝尼王國的合作上。
