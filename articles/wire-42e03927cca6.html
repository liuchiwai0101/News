Google 公佈推出 Nano Banana 2.1　多次生成人物圖像可保原貌並支援局部修改

內容機器翻譯自第三方媒體（Yahoo 新聞），僅供參考，以原文為準。

正文

PC3 無需再預先轉換格式 Google 文件開始原生支援讀取及修改 Markdown 檔 偽宅男 2026年10月7日週三 下午7:30 平日我們有需要利用 AI 處理不同工作，常會接觸到 Markdown 檔。雖然 Markdown 檔可利用純文字編輯程式開啟使用，但遇上需要跨裝置、跨平台協作的工作，若有方法可以隨時隨地檢視以至修改 Markdown 檔，始終會是好事。好消息是，現時開始 Google 文件已能原生支援 Markdown 檔，有能力讀取並讓我們進行檢視或編輯，而且不會因而令內容走位變樣。

Google 文件原生支援 Markdown 檔 廣告 廣告 Google 透過 Google Workspace 的官方網誌公佈，Google 文件現可直接檢視、編輯及協作處理副檔名為 .md 或 .markdown 的 Markdown 檔案，無需先轉換格式才開啟，同時 Google Drive 同步支援 Markdown 的渲染預覽。

過去用户要在 Google 文件開啟 Markdown 檔，必須先匯入並轉換成 Doc 格式。不過這有一大問題是，Google 文件會在過程中，改動原有檔案內容的排版、移除註解，並令同一份內容散落成多個檔案，令事情變得更糟糕。新功能就能保留原本的檔案類型，用家可以放心利用 Google 文件開啟檢視，以至編輯 Markdown 檔。在 Google 雲端硬碟方面，現時 Markdown 檔會以完整排版顯示，包括可點擊的連結和結構化表格，連 Google 文件都不用便能閲讀。

人與 AI 可共用同一份 Markdown 檔 Google 解釋，Markdown 是大型語言模型（LLM）常用的標準文字格式，可以用輕量的檔案保存表格、標題和項目清單等結構化內容。當 Google 文件原生支援 Markdown 檔，人與 AI 就可以在同一份 Markdown 檔上協作，用家亦無需自行撰寫原始語法或先行尋找方法手動轉換檔案，也不用放棄 Google 文件已有的即時協作工具。如果本身用家日常已有使用 Gemini，並且已連結各項 Google 服務，新功能就會更見方便。

由即日起，Google 文件已開始原生支援 Markdown 檔，並適用於所有 Google 用家，包括本身沒有訂閲任何 AI 計劃的 Google 用家。即使暫時看不見，預計最遲到了本月中下旬，都將可以應用。
