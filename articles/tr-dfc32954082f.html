Agent Plugins 1.0.0 發佈：谷歌、亞馬遜、微軟等支持的統一智能體插件規範

內容機器翻譯自第三方媒體（Google Developers Blog（RSS）），僅供參考，以原文為準。

重點內容

Agent Plugins 1.0.0 是一項由谷歌、亞馬遜、微軟等支持的中立目錄規範，將 Agent Skills 和 MCP 服務器打包為單一可移植單元。通過標準化 plugin.json 清單和固定目錄佈局，開發者無需為不同 AI 編碼智能體和 IDE 維護單獨封裝。谷歌已作為核心維護者加入，並在 Agents CLI 和 Data Agent Kit 中提供支持。
