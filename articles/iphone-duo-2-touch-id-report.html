傳 iPhone Duo 2 維持 Touch ID　Face ID 加入仍存變數

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

據爆料者「數碼閒聊站」透露，Apple 第二代摺疊手機 iPhone Duo 2 預計將沿用第一代的外螢幕尺寸及側邊指紋識別功能，目前尚無明確跡象顯示該型號會配備 Face ID。

工程樣機保留現有設計

「數碼閒聊站」在微博發文指出，雖然關於 iPhone Duo 2 的細節消息仍然有限，但目前的工程樣機繼續配備 7.6 吋內螢幕、5.4 吋外螢幕以及位於機身側面的指紋感應器。這意味著新一代產品在螢幕規格與生物辨識配置上，將直接繼承第一代 iPhone Duo 的設計。

Face ID 應用面臨空間挑戰

該爆料者對在外螢幕上使用 Face ID 的空間需求及實用性提出質疑。由於摺疊狀態下面向外螢幕的是使用者背部而非面部，若僅依靠外螢幕進行 Face ID 驗證，用户在使用內螢幕時可能需要切換至 Touch ID，或者必須轉動裝置才能完成認證，這種操作方式可能造成體驗上的割裂感。

原型測試受阻或延至第三代

《彭博》記者 Mark Gurman 早前報導稱，Apple 曾開發過在外螢幕配備 Face ID 的 iPhone Duo 2 原型機，但因時間緊迫無法最終完善該功能，相關技術可能會延遲至第三代產品才推出。這與業界對第二代產品僅作小幅改進的預期相符，而 Apple 更重大的設計變化預計將集中在 2027 年發佈的 iPhone 20 週年紀念版機型上。

現有型號新增基礎解鎖選項

Apple 近期已在 iOS 27.3 beta 2 中為現有的 iPhone Duo 引入一個名為「使用前鏡頭解鎖」（Unlock with Front Camera）的較受限功能。此功能利用標準外鏡頭在裝置合上時進行解鎖，但它不具備 Face ID 的深度感知身份驗證能力，因此無法用於授權 Apple Pay 交易或自動填充密碼。當裝置展開使用內螢幕時，用户仍需依賴 Touch ID 或密碼進行解鎖。iPhone Duo 2 預計將於 2027 年秋季發佈。
