Apple 推出訂閲挽留功能　開發者可設訊息阻止用户取消

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

Apple 今日為開發者新增了一項訂閲挽留功能，允許開發者在訂閲者嘗試取消服務時顯示挽留訊息。此舉旨在協助應用程序供應商在用户流失前提供誘因或解釋，以維持訂閲數量。

App Store Connect 設定與 API 選項

據 Apple 表示，這些挽留訊息將出現在訂閲取消流程中，內容可包含文字、圖片或特別優惠。開發者可以在 App Store Connect 中為自動續費訂閲添加相關訊息，並設定subscriber 資格條件以及兩條訊息之間的等待時間。

此外，透過獨立的「Retention Messaging API」，開發者可以根據訂閲者的具體資料選擇顯示哪一條訊息。需要注意的是，存取該 API 需經過申請批准。

對於終端用户而言，這意味著當他們準備在 App Store 上取消訂閲時，可能會先看到折扣優惠或建議保留訂閲的理由，然後才能完成取消動作。
