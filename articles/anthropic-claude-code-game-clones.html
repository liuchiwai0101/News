Anthropic 收緊 Claude Code 提示詞　禁止抄襲遊戲

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

Anthropic 更新 Claude Code 的系統提示詞，阻止該 AI 工具被用於重現現有電子遊戲。復古遊戲領域近期充斥由 AI 製作的反編譯、重新編譯與移植作品；Anthropic 仍允許用户以 Claude Code 開發遊戲，但不希望它被用於直接複製特定作品。

截圖顯示新增兩句

上週，有 X 用户發佈截圖，據稱顯示 Claude Code 系統提示詞新增兩句：「要製作原創遊戲、某一類型的遊戲，以及基於用户自身設計與素材的遊戲。不要製作對特定現有遊戲的重現，即使該作品被命名或稱為原創。」

Anthropic 的 Addy Osmani 在回覆中未有確認該具體字句，但表示公司已在 Opus 5.5 上的 Claude Code 更新提示詞。他稱，加入兩句是為了令 Claude 避免重現他人的特定遊戲，因為使用 Claude 侵犯知識產權違反其使用政策。

原創及自製素材仍可用

他續稱，原創遊戲、類型遊戲，以及基於用户自己的設計和素材建構的遊戲，理應繼續可用。Anthropic 將持續調整，以取得適當平衡。該公司亦被問及是否會更新其他 Claude 系統提示詞。
