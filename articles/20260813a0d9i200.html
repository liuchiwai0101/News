DeepSeek-V4-Pro正式版上线，调价方案公布_腾讯新闻

新京報貝殼財經訊（記者羅亦丹）8月13日，深度求索在官方公衆號發文稱，發佈 DeepSeek- 正式版。

當前，DeepSeek-V4-Pro 正式版已同步在App、網頁端和API更新上線。用戶可以通過App或網頁端選擇“專家模式”使用全新的 V4 Pro 正式版模型，API模型名不變，其他更新細節詳見DeepSeek API官方接口文檔。

正式版 DeepSeek-V4-Pro增強了Agent（智能體）能力，在生產環境中的性能表現提升尤爲顯著。

DeepSeek API 現已原生支持 OpenAI Responses API 格式，並針對性適配Codex。用戶可以參考官方 API 文檔：快速開始-接入Agent工具-Codex，通過一鍵配置腳本完成Codex的配置。

V4-Pro和V4-Flash思考模式現支持low / high / max三檔思考強度，用戶在實際使用中可以根據任務複雜度靈活選擇：簡單任務使用low，日常Agent任務使用high，高度複雜的任務場景使用max。

深度求索方面表示，“隨着DeepSeek V4全系列模型正式版上線，我們將對API價格進行更新調整。爲了更加合理地調配資源，我們將採用，閒時價格爲高峯時段價格的一半，鼓勵用戶根據實際使用情況調整任務時間。新價格將於北京時間2026年8月17日0時開始生效。”

具體來看，高峯時段DeepSeek-V4-Pro的價格爲輸入（緩存命中）0.3元/百萬Tokens，輸入（緩存未命中）9元/百萬Tokens，輸出27元/百萬Tokens。高峯時段爲北京時間9:00-12:00、14:00-18:00(其餘爲空閒時段)。
