4.4 遇到 Bug？系統性調試

你：登錄後 token 沒存到 localStorage，系統性排查

Hermes 加载 systematic-debugging 技能：

Phase 1: 根因调查
  1. 读错误：Chrome 控制台无报错，token 默默丢失
  2. 构建复现循环：curl POST /api/auth/login → 200 OK 有 token
                     前端 fetch → Network 有 token → localStorage 空
  3. 检查最近改动：git diff，发现 auth.ts 中 setToken 用了异步写法
  4. 溯源数据流：
     login() → setToken(token) → localStorage.setItem() → 此处 token 为 undefined
     原因：API 响应中字段名是 access_token，但代码读的是 token
  根因：字段名不匹配
Phase 2: 模式分析
  后端返回：{ access_token: "xxx" }
  前端读取：data.token  → undefined
Phase 3: 修正
  将 data.token 改为 data.access_token → 问题解决
Phase 4: 回归测试
  写测试 test('登录后 token 应存入 localStorage') → PASS

6.2 遇到線上 Bug

你：用戶反饋發佈文章後看不到，對這個問題做系統性排查
Phase 1: 根因調查
  curl POST /api/articles → 201 Created（數據庫有記錄）
  前端 GET /api/articles → 200 OK（返回空數組）
  問題孤立到後端：文章查詢 API 返回空
  讀代碼：articleController.getAll() → Prisma article.findMany()
  檢查 Prisma 查詢：where published = true（但新建文章 published 默認 false）
  根因：默認未發佈
Phase 2: 模式分析
  設計文檔中寫的是"創建後自動發佈"
  代碼與設計文檔不一致
Phase 3: 修復
  Prisma schema: published Boolean @default(true)
  運行測試 → 已有測試通過 + 新增迴歸測試通過
Phase 4: 審計
  加載 docs-audit 技能：檢查是否還有其他設計與代碼不一致的地方
