iPhone Duo 2 擬外螢幕加入 Face ID　時間緊迫未必趕上

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

據《彭博》Mark Gurman 報道，Apple 計劃於明年秋季推出第二代 iPhone Duo，除了慣常的晶片升級與相機改進外，目前未清楚新機還會帶來哪些實質升級。Gurman 稱，工程師正積極嘗試把 Face ID 整合到機身外螢幕，但相關時間緊迫，這項功能未必能趕及隨新機登場。

Face ID 列為首要目標

Gurman 指出，Apple 對 iPhone Duo 有兩個優先事項，分別是 Face ID 與動作按鈕，其中 Face ID 屬首要目標。Apple 已開發配備 Face ID 的 iPhone Duo 2 原型機，工程師仍在積極把臉部識別系統整合到第二代型號的外螢幕。不過，Gurman 表示時間表緊湊，技術尚未完全準備就緒，因此他未能確定 Face ID 會否隨 iPhone Duo 2 推出；若這代未能實現，功能很可能留待 2028 年的 iPhone Duo 3。

動作按鈕或屬軟件改動

至於動作按鈕，Gurman 稱它可能只是相機控制的一項新軟件功能，讓用户把在相機介面長按呼叫 Siri 的動作，重新對應至自選應用程式。

長焦與輕薄屬後續方向

Face ID 之外，Gurman 報道 Apple 計劃在未來幾代為 iPhone Duo 加入長焦相機，並令裝置整體更薄更輕。9to5Mac 的評論認為，Duo 確實需要變得更輕，但進一步縮薄機身將會是一項有趣的挑戰。

外螢幕 Face ID 效用存疑

9to5Mac 的評論認為，Face ID 出現在 iPhone Duo 固然值得歡迎，但僅限於外螢幕便未必有太大意義。文章作者指出，自己接受 Touch ID，但不便之處通常發生在內螢幕，視乎握持方式，用户可能難以觸及按鈕；若只能讓一個螢幕配備 Face ID，他寧願選擇內螢幕。內螢幕的 Touch ID 使用體驗受裝置方向影響較大，而外螢幕一般只有左手或右手直立握持兩種方式。
