AI 持續帶動台灣經濟高速成長 今年經濟成長挑戰 13%

外銷訂單 主計總處 出口 ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' 00:00 2026/11/22 00:58:51 經濟日報 記者洪安怡／台北報導 AI持續帶動台灣經濟高速成長，今年經濟成長率可望再上修。主計總處預計27日公佈最新經濟預測，由於第3季經濟成長率概估達14.36%，大幅優於預期，加上10月出口、外銷訂單雙雙改寫新高，市場普遍看好今年經濟成長率將由原估11.05%上修至12%以上，甚至有機會挑戰13%。

另一值得注意的是，明年能否在高基期下維持6%以上成長，也將是焦點。

主計總處8月預測，今年經濟成長率達11.05%，寫下1988年以來、39年新高；明年則預估成長6.04%。當時預測今年第3、4季分別成長11.42%、5.37%，顯示出下半年經濟成長步調將逐漸放緩。

不過，最新經濟數據再度超乎預期。主計總處10月底公佈第3季經濟成長率概估達14.36%，較原預測大幅增加2.94個百分點，寫48年來同季新高，且已連續四季維持雙位數成長，帶動前三季經濟成長率達14.22%。

出口及外銷訂單同樣表現強勁。財政部統計，10月出口達967.6億美元，首度突破900億美元大關，年增58.9%，連續36個月正成長；前10月出口7,582.9億美元，年增47.7%，同樣刷新歷年同期新高。

經濟部公佈10月外銷訂單達1,238.2億美元，連續第五個月改寫歷年單月新高，年增78.3%；前10月訂單達9,430.2億美元，年增58.6%，經濟部更預期全年訂單有望達1.1兆美元。

隨出口與投資動能持續擴張，國內主要預測機構也陸續調高經濟展望。中經院10月將今年經濟成長率上修至12.16%，台經院11月進一步上調至12.34%，顯示今年經濟成長率突破12%已成為市場普遍預期。

展望明年，儘管今年高速成長墊高比較基期，但全球雲端服務業者持續擴大資本支出，帶動半導體、先進封裝及AI伺服器需求，加上國內高科技業者持續擴產，出口及民間投資仍將扮演成長引擎。

主計總處原估明年經濟成長率為6.04%，略低於台經院預估的6.45%。不過，近期全球AI類股波動加劇，市場對AI投資效益及後續成長動能的疑慮升温，加上美國關税政策及地緣政治風險仍存，明年經濟能否維持6%以上成長，仍有待觀察。

除經濟成長率，主計總處此次也將同步更新物價預測。8月原估今年消費者物價指數（CPI）年增2.07%，明年回落至1.9%。但隨國際能源及電子零組件價格波動，全年CPI預測是否調整，以及明年通膨能否降至2%以下，同樣值得關注。
