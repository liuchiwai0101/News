Anthropic 推出 Claude Opus 5 號稱接近 Fable 5 一半價格

Anthropic 今日正式發佈最新的大型 AI 模型 Claude Opus 5，距離上一代 Opus 4.8 約兩個月。該公司指出，Opus 5 在性能上接近其最強模型 Fable 5，但價格僅為一半，旨在成為日常使用的預設模型。

價格與可用性

Claude Opus 5 即日起在所有平臺上線，定價與 Opus 4.8 相同：每百萬輸入 Token 收費 5 美元，每百萬輸出 Token 收費 25 美元。Anthropic 表示，Opus 5 將成為 Claude Max 的預設模型，同時也是 Claude Pro 上最強大的選項。

新增功能與改進

除了模型升級，Anthropic 同步推出兩項平臺更新：對話中工具變更（允許開發者在對話期間切換 Claude 使用的工具而不影響提示快取），以及 API 自動回退功能（當請求被安全分類器攔截時，可自動轉至其他可用模型，避免請求被阻擋）。

Anthropic 形容 Opus 5 是一款「深思熟慮且主動」的模型，其智能水平接近先前因安全考慮而延後發佈的 Fable 5。Fable 5 仍是 Anthropic 目前能力最全面的模型，而 Opus 5 則以更實惠的價格提供接近的表現。
