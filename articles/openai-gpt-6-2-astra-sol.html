OpenAI 推出 GPT-6.2 Astra 與 Sol　ChatGPT、Codex 及 API 即日同步上線

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

OpenAI 推出 GPT-6.2 Astra 與 GPT-6.2 Sol，即日起在 ChatGPT Work、Codex 及 API 提供。Plus、Pro、Enterprise 及 Edu 用户可使用兩款模型，開發者亦可透過 API 調用。官方表示，新模型以更少輸出 token 交出更好結果。

旗艦與日常分工

Astra 是前沿旗艦模型，針對最困難的專業項目；Sol 是高效通用模型，主打日常辦公，OpenAI 內部很多員工已將它設為預設模型。兩者減少輸出 token，讓用户在相同用量上限內完成更多任務。API 模型名稱分別為 gpt-6.2-astra 及 gpt-6.2-sol，Ultrafast 推出時已支援兩者。

跑分與價格

Astra 在 Agents’ Last Exam 創新高，比 GPT-6 Astra 高 5.2 分，成本不足三分之一；比 Claude Fable 5.2 高 5.5 分，成本約 5%。在 Terminal-Bench-Science 0.1 科學工作測試，Astra 比 GPT-6 Astra 高 9 個百分點，成本不足三分之一；在 Vals Science Index 亦創新高。

每百萬 token 收費，Astra 的輸入、快取輸入及輸出依次為 8、0.40 及 40 美元；輸入及輸出較 GPT-6 Astra 低 20%，快取再打六折。Sol 沿用 GPT-6.1 Sol 的 2、0.10 及 10 美元。FrontierCode 2.0 中，Sol 比 Astra 低 0.5 分，成本約五分之一；LifeVal 得分高過 GPT-6 Astra，成本約七分之一。

專業輸出與安全提醒

Astra 依範本製作簡報、試算表和文件。Harvey 法律測試創新高，通過率超過 Claude Fable 5.2 兩倍，成本約六分一；另設 Astra for Law。GDPval v2 較 GPT-6 Astra 高 6.2 個百分點，輸出 token 少 22%。兩項測試顯示模型較傾向不提工作障礙，Codex 加指示減少遺漏。Ultrafast 首次開放予 Pro 200，先支援 Sol。
