美股 《大賣空》貝瑞預言9個月內市場見頂！調整AI放空策略：鎖定那斯達克100、半導體ETF 鉅亨網編譯莊閔棻 2026-10-14 23:10

AI新聞摘要 1 . 貝瑞持續看空AI熱潮股市，稱未來9個月內市場某個時點將出現「重大頂部」。 2 . 他將多數選擇權部位轉為放空NASDAQ100與VanEck半導體ETF，2027年6月到期。 3 . 仍持有ORCL、PLTR、MET、CAT看跌選擇權，並指PLTR上漲但量縮、漲勢恐耗盡動能。 《大賣空》原型、以預測2008年美國房市崩盤聞名的投資人貝瑞（Michael Burry），持續看空人工智慧（AI）熱潮帶動的股市漲勢，並表示自己已經進一步調整做空策略。

《大賣空》貝瑞預言9個月內市場見頂！調整AI放空策略：鎖定那斯達克100、半導體ETF（圖：Shutterstock）

根據《Business Insider》報導，貝瑞近日在Substack發文，以「鞏固大賣空」（Consolidating the Big Short）為題詳細闡述了自己看空押注近期的變化。今年稍早，他曾揭露對輝達( NVDA-US ) 與Palantir( PLTR-US ) 等股價表現強勢的個股建立空頭部位，並隨後將放空部位轉為選擇權部位。

不過，貝瑞表示，自己現已將大部分選擇權部位轉為兩項指數型放空部位，包括買進 NASDAQ 100( NDX ) 的看跌選擇權，以及VanEck Vectors 半導體 ETF( SMH-US ) 的看跌選擇權。

對於後市，貝瑞表示，他預期未來9個月內，市場某個時點將出現一個「重大頂部」。他也認為，多頭行情的最後階段可能會相當「瘋狂」，在他預期的回檔到來之前，股價可能先快速飆升。

貝瑞寫道，VanEck半導體ETF「集中押注於市場上最熱門、股價漲幅也最為過度的半導體股票」。

他指出：「輝達佔該基金19.6%，台積電ADR( TSM-US ) 佔9.3%，超微半導體( AMD-US ) 佔5.6%。博通( AVGO-US ) 、美光科技( MU-US ) 、邁威爾科技( MRVL-US ) 及應用材料( AMAT-US ) 的持股比重則都接近5%。」

他也表示，自己買進的看跌選擇權將於2027年6月到期，這代表其看空論點大約還有8個月的時間接受市場驗證。

除了指數型部位，貝瑞仍直接押注部分個股下跌。他表示，目前仍持有熱門AI概念股甲骨文( ORCL-US ) 與Palantir的看跌選擇權，另外也持有大都會人壽( MET-US ) 及卡特彼勒( CAT-US ) 的看跌選擇權。

貝瑞表示：「Palantir股價持續上漲，但成交量卻不斷萎縮，這顯示該股的漲勢可能正逐漸耗盡動能。」
