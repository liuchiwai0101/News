1. 將獨立的異步操作並行

請求瀑布流是 React 應用性能的頭號殺手。

每次順序執行 await 都會增加網絡延遲，消除它們可以帶來最大的性能提升。

❌ 錯誤：

async function Page() {
  const user = await fetchUser();
  const posts = await fetchPosts();
  return <Dashboard user={user} posts={posts} />;
}

✅ 正確：

async function Page() {
  const [user, posts] = await Promise.all([fetchUser(), fetchPosts()]);
  return <Dashboard user={user} posts={posts} />;
}

當處理多個數據源時，這個簡單的改變可以將頁面加載時間減少數百毫秒。

2. 避免桶文件導入

從桶文件導入會強制打包程序解析整個庫，即使你只需要其中一個組件。

這就像把整個衣櫃都搬走，只爲了穿一件衣服。

❌ 錯誤：

import { Check, X, Menu } from "lucide-react";✅ 正确：

import Check from "lucide-react/dist/esm/icons/check";
import X from "lucide-react/dist/esm/icons/x";
import Menu from "lucide-react/dist/esm/icons/menu";

**更好的方式（使用 Next.js 配置）：**

// next.config.js
module.exports = {
  experimental: {
    optimizePackageImports: ["lucide-react", "@mui/material"],
  },
};
// 然后保持简洁的导入方式
import { Check, X, Menu } from "lucide-react";

直接導入可將啓動速度提高 15-70%，構建難度降低 28%，冷啓動速度提高 40%，HMR 速度顯著提高。

3. 使用延遲狀態初始化

當初始化狀態需要進行耗時的計算時，將初始化程序包裝在一個函數中，確保它只運行一次。

❌ 錯誤：

function Component() {
  const [config, setConfig] = useState(JSON.parse(localStorage.getItem("config")));
  return <div>{config.theme}</div>;
}

✅ 正確：

function Component() {
  const [config, setConfig] = useState(() => JSON.parse(localStorage.getItem("config")));
  return <div>{config.theme}</div>;
}

組件每次渲染都會從 localStorage 解析 JSON 配置，但其實它只需要在初始化的時候讀取一次，將其封裝在回調函數中可以消除這種浪費。

4. 最小化 RSC 邊界的數據傳遞

React **服務端/客戶端**邊界會將所有對象屬性序列化爲字符串並嵌入到 HTML 響應中，這會直接影響頁面大小和加載時間。

❌ 錯誤：

async function Page() {
  const user = await fetchUser(); // 50 fields
  return <Profile user={user} />;
}
("use client");
function Profile({ user }) {
  return <div>{user.name}</div>; // uses 1 field
}

✅ 正確：

async function Page() {
  const user = await fetchUser();
  return <Profile name={user.name} />;
}
("use client");
function Profile({ name }) {
  return <div>{name}</div>;
}

只傳遞客戶端組件實際需要的數據。

5. 動態導入大型組件

僅在功能激活時加載大型庫，減少初始包體積。

❌ 錯誤：

import { AnimationPlayer } from "./heavy-animation-lib";
function Component() {
  const [enabled, setEnabled] = useState(false);
  return enabled ? <AnimationPlayer /> : null;
}

✅ 正確：

function AnimationPlayer({ enabled, setEnabled }) {
  const [frames, setFrames] = useState(null);
  useEffect(() => {
    if (enabled && !frames && typeof window !== "undefined") {
      import("./animation-frames.js").then((mod) => setFrames(mod.frames)).catch(() => setEnabled(false));
    }
  }, [enabled, frames, setEnabled]);
  if (!frames) return <Skeleton />;
  return <Canvas frames={frames} />;
}

typeof window 可以防止將此模塊打包用於 **SSR，優化**服務端包體積和構建速度。

6. 延遲加載第三方腳本

分析和跟蹤腳本不要阻塞用戶交互。

❌ 錯誤：

export default function RootLayout({ children }) {
  useEffect(() => {
    initAnalytics();
  }, []);
  return (
    <html>
      <body>{children}</body>
    </html>
  );
}

✅ 正確：

import { Analytics } from "@vercel/analytics/react";
export default function RootLayout({ children }) {
  return (
    <html>
      <body>
        {children}
        <Analytics />
      </body>
    </html>
  );
}

在水合後加載分析腳本，優先處理交互內容。

7. 使用 React.cache() 進行請求去重

防止服務端在同一渲染週期內重複請求。

❌ 錯誤：

async function Sidebar() {
  const user = await fetchUser();
  return <div>{user.name}</div>;
}
async function Header() {
  const user = await fetchUser(); // 重复请求
  return <nav>{user.email}</nav>;
}

✅ 正確：

import { cache } from "react";
const getUser = cache(async () => {
  return await fetchUser();
});
async function Sidebar() {
  const user = await getUser();
  return <div>{user.name}</div>;
}
async function Header() {
  const user = await getUser(); // 已缓存，无重复请求
  return <nav>{user.email}</nav>;
}

8. 實現跨請求數據的 LRU 緩存

React.cache() 僅在單個請求內有效，因此對於跨連續請求共享的數據，使用 LRU 緩存。

❌ 錯誤：

import { LRUCache } from "lru-cache";
const cache = new LRUCache({
  max: 1000,
  ttl: 5 * 60 * 1000, // 5 分钟
});
export async function getUser(id) {
  const cached = cache.get(id);
  if (cached) return cached;
  const user = await db.user.findUnique({ where: { id } });
  cache.set(id, user);
  return user;
}

這在 Vercel 的 Fluid Compute 中特別有效，多個併發請求共享同一個函數實例。

9. 通過組件組合實現並行化

React 服務端組件在樹狀結構中按順序執行，因此需要使用組合對組件樹進行重構以實現並行化數據獲取：

❌ 錯誤：

async function Page() {
  const data = await fetchPageData();
  return (
    <>
      <Header />
      <Sidebar data={data} />
    </>
  );
}

✅ 正確：

async function Page() {
  return (
    <>
      <Header />
      <Sidebar />
    </>
  );
}
async function Sidebar() {
  const data = await fetchPageData();
  return <div>{data.content}</div>;
}

這樣一來，頁眉和側邊欄就可以並行獲取數據了。

10. 使用 SWR 進行客戶端請求去重

當客戶端上的多個組件請求相同的數據時，SWR 會自動對請求進行去重。

❌ 錯誤：

function UserProfile() {
  const [user, setUser] = useState(null);
  useEffect(() => {
    fetch("/api/user")
      .then((r) => r.json())
      .then(setUser);
  }, []);
  return <div>{user?.name}</div>;
}
function UserAvatar() {
  const [user, setUser] = useState(null);
  useEffect(() => {
    fetch("/api/user")
      .then((r) => r.json())
      .then(setUser);
  }, []);
  return <img src={user?.avatar} />;
}

✅ 正確：

import useSWR from "swr";
const fetcher = (url) => fetch(url).then((r) => r.json());
function UserProfile() {
  const { data: user } = useSWR("/api/user", fetcher);
  return <div>{user?.name}</div>;
}
function UserAvatar() {
  const { data: user } = useSWR("/api/user", fetcher);
  return <img src={user?.avatar} />;
}

SWR 只發出一個請求，並將結果在兩個組件之間共享。
