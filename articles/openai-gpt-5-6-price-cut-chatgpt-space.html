OpenAI 大幅調降 GPT-5.6 模型價格 Luna 減價達八成

OpenAI 近日宣佈調降兩個 GPT-5.6 模型的 API 價格，其中 Terra 模型降價 20%，Luna 模型更大幅降價 80%。這項調整不僅影響 API 客戶，亦為 ChatGPT Work 與 Codex 用戶帶來更多可用 Token 配額。此舉被視為應對中國低價 AI 供應商競爭的直接回應。

兩款模型降價幅度

OpenAI 目前共提供三個 GPT-5.6 模型：旗艦型 Sol、平衡型 Terra 以及快速經濟型 Luna。本月稍早公佈的初始價格之後，Terra 的輸入 Token 成本從每百萬個 2.5 美元降至 2 美元，輸出 Token 則從 15 美元降至 12 美元；Luna 的輸入 Token 成本更從 1 美元降至 0.2 美元，輸出 Token 從 6 美元降至 1.2 美元。

ChatGPT 用戶也受惠

對於使用 ChatGPT Work 或 Codex 的訂閱用戶，雖然月費不變，但 OpenAI 同步調整了 Terra 與 Luna 模型的 Token 計算方式。官方表示，較低的價格同樣反映在付費訂閱的用量計算上，讓用戶在達到上限前能執行更多任務，變相擴大了使用空間。

AI 市場價格戰壓力

市場上來自低成本中國供應商的價格壓力日益增加，Microsoft 亦公開推廣自家 MAI 模型作為 OpenAI 的更便宜替代方案。分析認為，若降價持續拖慢前沿實驗室的收入增長，而這些實驗室的資產負債表與鉅額基建投資緊密相連，則可能損害整體市場發展。
