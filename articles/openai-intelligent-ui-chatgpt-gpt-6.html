OpenAI 推出 Intelligent UI　ChatGPT 回應加入互動圖表與按鈕

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

OpenAI 今日推出 Intelligent UI，這項新功能讓 ChatGPT 以「完全互動的使用者介面」回答問題。OpenAI 表示，日常回答將更具視覺效果，新功能亦令用户更容易理解複雜議題。

回應加入圖表與互動元件

ChatGPT 的回應會包含圖像、可點按按鈕、表單、圖表、示意圖及其他互動體驗。OpenAI 網站上 GPT-5.6 與 GPT-6 的示例比較顯示，回應中的視覺元素明顯增加，並加入可互動的食譜小工具、清單、整合地圖，以及以選擇題形式追問以收窄結果；其中食譜小工具可按客人數自動調整份量。

可按需求即時生成小工具

ChatGPT 能快速建立工具完成任務，例如分帳工具、小遊戲和計算機。GPT-6 亦可在仍在思考時就開始作答，以加快回應。

原生串流元件與編譯器

OpenAI 指出，Intelligent UI 採用一組原生、可串流的元件，並配合編譯器，在模型生成介面的同時處理該介面。

GPT-6 擴大開放範圍

除推出 Intelligent UI，OpenAI 亦把 GPT-6 模型開放給更多用户。配備 Intelligent UI 的 GPT-6 今日向 ChatGPT Plus、Pro、Business 及 Enterprise 用户推送，明日擴展至 Free 及 Go 級別。Plus、Pro、Business 及 Enterprise 用户可使用 GPT-6 Sol，Free 及 Go 級別用户則可使用 GPT-6 Luna。GPT-6 僅限於 Chat 分頁，Work 及 Codex 的模型維持不變。
