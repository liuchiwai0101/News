Claude 嚴查 IP 杜絕跨區使用 香港用家翻牆遭「大屠殺」 帳號突被封存數據難救

內容機器翻譯自第三方媒體（PCM），僅供參考，以原文為準。

生成式 AI 開發商 Anthropic 近日針對旗下著名 AI 助手 Claude 實施更嚴格的地緣限制政策。據本地科技圈及社群反應，大量中國香港用户在無事前通知的情況下，因使用虛擬私人網路（VPN）連線至新加坡或美歐等支援地區存取 Claude，遭到系統全面「封鎖（Block）」，甚至直接終止帳號。由於事出突然，不少依賴 Claude 進行日常工作或寫程式的本地用家頓時失去工具，存放在平台內的對話紀錄與專案數據亦面臨無法拯救的困境。

嚴查多重訊號 杜絕非服務地區翻牆

根據 Anthropic 最新更新的服務條款及支援地區名單（Supported Regions Policy），中國香港至今仍未被列入 Claude.ai 及商業 API 的 官方支援範圍。過去不少中國香港用户透過 VPN 轉跳至美、日、新等地區進行註冊與付費訂閲，以繞過區域限制。

然而，Anthropic 官方近期悄悄升級了地緣偵測機制。官方團隊指出，系統現時會結合 IP 位址、連線特徵及其他多重訊號（signals），精準辨識用户的實際地理位置。若發現帳號來自非支援地區或長期透過 VPN 存取，系統將採取強制措施，甚至直接將涉嫌違規的帳號封禁。

事出突然未予警告 用家崩潰：對話紀錄全滅

這次收緊政策在中國香港科技界引發不少震盪。多名本地工程師、數據分析師及創作人於討論區及社交平台反應，指在登入 Claude 時突遭系統退回，並顯示帳號被封鎖的警告。

不少用家指責 Anthropic 未有預先發出警告郵件或給予寬限期，導致用户完全沒有時間備份保存在 Claude 中的數據與 Prompt 庫。儘管 Anthropic 官方聲稱被封用户仍可登入提交申訴或嘗試申請資料匯出，但多數中國香港用户表示申訴成功率極低，且系統極難完成數據匯出程序，累積的對話紀錄恐怕已成泡影。

近年全球對 AI 模型的數據合規及跨境傳輸監管日益嚴格，Anthropic 此次大規模封殺 VPN 用户，被視為矽谷 AI 巨頭進一步收緊營運風險管理的動作。隨著 Claude 對 VPN 的容忍度降至零，中國香港開發者與企業轉向研究其他替代方案，包括利用微軟 Azure OpenAI 服務、AWS Bedrock 等企業級雲端 API，或部署本地化（On-Premise）開源模型，以降低對單一外地服務的依賴。
