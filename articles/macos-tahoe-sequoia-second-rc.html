Apple 推出 macOS Tahoe 26.7 與 macOS Sequoia 15.8 的第二個候選版本，距離 macOS 26.7 的首個候選版本一星期。

開發者更新

開發者現可安裝 macOS Tahoe 26.7 與 macOS Sequoia 15.8 的 RC 2。macOS 26.7 的首個候選版本日前流出多項即將推出產品的細節，包括一段 AirPods 配備相機並使用視覺智能的實際操作影片，以及多項技術資料。

同場測試版

今日的發佈亦伴隨 macOS 27 Golden Gate 開發者 beta 7，公開測試版很可能短期內推出。

版本現況

macOS 26.7 預料不會加入大量新功能；Apple 正結束 macOS 26 的主要開發流程，準備迎接數週內推出的 macOS 27 Golden Gate。macOS Sequoia 15.8 則很可能包含重要保安修正，部分亦會納入 macOS Tahoe 26.7。RC 2 的 build 編號分別為 25G224 與 24H20，團隊正檢視新代碼，如有值得注意的發現會再報告。
