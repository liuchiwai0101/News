Adobe 將 Acrobat 整合至 WhatsApp Web 用戶可直接檢閱 PDF 文件

今日起，WhatsApp Web 用戶無需離開對話，即可直接在聊天介面中檢閱、審核及註釋 PDF 文件，無需額外下載。Adobe 將 Acrobat 的 PDF 工具直接整合至 WhatsApp Web 及 Windows 版 WhatsApp，讓工作流程更為順暢。

無需下載即可註釋

過去在 WhatsApp 收到 PDF 檔案時，用戶必須先下載才能開啟，且缺乏內建檢閱或註釋功能。Adobe 今日宣佈的整合改變了這一狀況，用戶現在可以開啟、審閱和註釋文件，而無需離開對話或下載檔案。

支援加密與密碼保護

這項整合同時支援受密碼保護的 PDF 文件，且所有在聊天中分享的檔案仍受 WhatsApp 的端到端加密保護。Adobe 強調，「只有聊天中的參與者才能閱讀這些文件」。

反映跨平臺策略

Adobe 表示，此舉反映 WhatsApp 在大螢幕裝置上使用的增長趨勢——合約、發票、表格及作業等文件處理需求增加；同時也是 Acrobat 工具整合至人們日常工作平臺（如 Chrome、Microsoft 360、Copilot、ChatGPT、Workday 等）的整體策略一部分。
