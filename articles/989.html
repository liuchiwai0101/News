IT之家 8 月 13 日消息，阿里雲“魔搭 ModelScope 社區”公衆號昨天（12 日）深夜宣佈，阿里 Qwen 團隊正式開放 **Qwen3.8-2.4T-A95B **模型權重。

此次是 Qwen-Max 級別的模型首次開源權重：模型總參數爲 2.4T，每個 Token 激活 95B 參數，**原生支持 262,144 Token 上下文，並可擴展至 1,010,000 Token**。

Qwen3.8 延續 Qwen3.5 的混合架構，重點提升**編程、辦公、科研和長週期 Agent 任務**的端到端完成能力。官方雲端版 Qwen3.8-Max 基於該開放權重模型，並加入更多生產環境能力。

官方公佈的評測覆蓋編程 Agent、通用 Agent、專業工作和長上下文等方向；與 Opus 4.8、Fable 5、GPT 5.6 Sol 等模型相比，各項結果**互有高低**，並在 PaperBench、IFBench 等 Benchmark 中取得所列模型中的較高成績。

Qwen3.8-2.4T-A95B 是一個因果語言模型，總參數爲 2.4T，每個 Token 激活 95B。模型每個 MoE 層包含 512 個專家，每個 Token 選擇 10 個路由專家，並同時激活 1 個共享專家。

模型還進行了多步 MTP（Multi-Token Prediction）訓練，爲支持相應機制的推理引擎提供預測多個後續 Token 的能力。

根據介紹，Qwen3.8-Max 的辦公與 Agent 後訓練概括爲三個環節：

- 持續擴展真實環境，並在這些獨立維度上解耦合：任務（Task）（單任務 → 多任務 → 跨天任務）、工作空間（Workspace）（多文件 → 層級目錄 → 複雜異構目錄）、Harness （不同的類別、版本、技能）。這使得環境數能夠以組合方式自然增長，而非依賴逐一定製化集成。

- 構建一個統一的獎勵系統，將真實任務中異構的驗證方式內化其中。該系統涵蓋基於執行的校驗、對文本及渲染後的視覺輸出的 rubric 評估、以及 agentic 檢查。我們將多種形式與模態統一在一個獎勵系統內，爲所有環境提供了一致而可靠的獎勵信號，消除維護任務專用的 verifier 所固有的不一致性。

- 構建一個在線數據均衡器，對每個 batch 進行重構，使其在任務、難度、工作區與 harness 上的分佈高度均衡，降低 batch 間梯度方差，從而支撐強化學習的訓練算力穩定、持續地擴展。
