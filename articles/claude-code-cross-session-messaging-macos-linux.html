Claude Code 新增跨工作階段通訊 macOS 與 Linux 用戶可互傳訊息

Anthropic 在 2026 年 8 月 7 日宣佈推出 Claude Code 跨工作階段訊息功能。在 macOS 及 Linux 上運行最新版 Claude Code 的用戶，可讓不同工作階段互相傳送訊息，分享結果、提出問題及協調工作。此功能自 Claude Code v2.1.224 起提供。

跨工作階段互傳訊息

新功能讓 Claude 可以將一個 Claude Code 工作階段的訊息傳遞到另一個工作階段，包括更新及其他相關資訊。當某一階段的改動破壞另一個階段正在依賴的內容時，Claude 會在用戶察覺前向該階段發出警告；當某一階段解決了另一個階段受阻的問題，Claude 也會把答案傳送過去。用戶不需要自行組織訊息內容，只要在提示中寫出想傳達的事項，Claude 便會代為撰寫實際訊息。

官方建議使用情境

Anthropic 表示，此功能最適合用於交接調查結果、協調平行 worktree、取得長時間執行工作的狀態，以及跨機器回覆。對於同時運行多個 Claude Code 工作階段、並在同一項目的不同部分協作的用戶，這項功能尤其實用。用戶不必在另一個工作階段重新說明，可直接指示 Claude 發送摘要；摘要不會包含完整歷史或檔案，另一個工作階段會在任務進行中接收。

權限與指令限制

跨工作階段訊息不適用於批准權限請求或更改配置。諸如 /compact 等指令會以純文字形式送達，不會作為實際指令執行；如果接收方需要權限才能處理訊息內容，接收工作階段仍會要求用戶批准。詳情可參閱 Anthropic 的官方文件。
