Apple 推進 Siri AI agent 功能　銀行相繼封鎖及警告客户

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

AI agent 能代用户操作 iPhone 和 Mac 應用程式以完成任務，相關能力正在迅速發展。Apple 正計劃為 Siri 加入同類功能，但銀行已率先封鎖 AI agent 或警告客户，顯示金融機構對這項技術的疑慮。

Apple 擬明年為 Siri 加入 agent 能力

Claude、ChatGPT、Grok 和 Muse 等第三方聊天機械人已具備 agent 能力，Apple 預計明年某個時候將相關能力帶到 Siri AI。《彭博》的 Mark Gurman 本月較早時表示，Apple 最終希望朝這個方向發展，並可能明年加入這些能力。據報 CEO John Ternus 一直催促 Craig Federighi 加快軟件開發，具體提到「超越 Siri 的必要改進」，似乎很可能是指 agent 能力。上週一份已刪除的 Apple 招聘啟事亦詳細説明瞭自主 AI agent 的計劃。

銀行封鎖 AI agent 並警告客户

Wired 報道，銀行正透過封鎖 AI agent 或警告客户使用相關工具可能帶來危險來回應。JPMorgan Chase 修改條款，禁止使用客户憑證登入的第三方 agent。同日，Bank of America 警告客户不要與 agent 分享登入資料。Wells Fargo 宣佈相關變更之餘，Citibank 和 PNC 亦已修改條款，加入有關 agent 的警告。Wells Fargo 更在最新條款中以大寫字母表明，不會對後果負責：「Your use of any AI Agent is AT YOUR OWN RISK」。

預料網購等行業亦可能出現類似阻力，因為企業擔心 AI agent 出錯導致高退貨成本及其他後果。有評論認為，讓 AI agent 存取銀行或其他金融服務的風險過高，短期內不會改變此立場。
