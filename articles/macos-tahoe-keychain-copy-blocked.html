macOS Tahoe 26.4 更新　收緊登入鑰匙圈複製功能

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

Apple 在 macOS Tahoe 26.4 更新中收緊登入鑰匙圈的存取方式。以往用户可以把存放在個人檔案夾的登入鑰匙圈檔案複製到另一部 Mac 直接使用，這個做法在配備 Secure Enclave 的 Mac 上已經失效。

鑰匙圈改由安全隔離區把關

登入鑰匙圈本身是一個 SQLite 資料庫檔案，儲存在用户的個人檔案夾內。在較早版本的 macOS，用户把檔案複製到第二部 Mac 後可以立即使用，但 macOS Tahoe 的更新令這個做法在配備安全隔離區（Secure Enclave）的 Mac 上不再可行。Secure Enclave 負責保管一把中介資料密鑰，這把密鑰保護解密鑰匙圈所需的屬性；更新之後，每次存取登入鑰匙圈檔案都必須經由 Secure Enclave。中介資料密鑰可以快取在應用處理器內，以加快鑰匙圈項目的讀取速度，但前提是 Secure Enclave 必須先被存取，快取才能夠存在。

檔案搬到另一部電腦即失效

如果把鑰匙圈檔案搬到另一部 Mac，該機無法存取原有的 Secure Enclave，因此檔案不會開啟。其他非登入類別的鑰匙圈檔案不受影響，仍然可以在其他 Mac 上解鎖。Johnson 指出，在緊急情況下，例如一部 Mac 突然損壞，用户只會在最糟糕的時刻才發現登入鑰匙圈無法使用，並總結指 Apple 的做法極不負責任。

部分遷移情境不受影響

直接把登入鑰匙圈複製到別處再開啟，顯然已經行不通，收緊保安正是為了阻止惡意人士這樣做。不過問題只出現在以這種方式搬移憑證的用户身上。把備份還原到同一部 Mac 的用户不受影響，使用 Migration Assistant 的用户同樣不受影響；但在企業環境中負責大量遷移的管理員就會遇到麻煩。遷移前先匯出項目，或者改用自訂鑰匙圈及其他密碼管理工具，都是繞過問題的方法。
