Anthropic 推出 Claude 桌面應用安裝功能　用户可建立個人化 Mac 及 Windows 程式

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

Anthropic 宣佈為使用 Claude 的 Mac 及 Windows 用户提供新方法，利用人工智能工具創建個人化桌面應用程式。這項名為「Install as app」的功能即日起在 Claude for Mac 和 Windows 的測試版中逐步推出。

獨立視窗與權限控制

當工件（artifact）被安裝為 Mac 或 Windows 應用程式時，它會擁有自己的圖示並在其專屬視窗中開啟，不再內嵌於 Claude 介面之內。用户可以將這些應用程式分享給他人，但該應用在與電腦互動前必須徵得用户許可，用户可自行選擇授權範圍。此外，透過此方法建立的應用程式具備發送通知、在選單欄添加項目以及管理自身權限的能力。

整合連接器與開發者支援

Anthropic 表示，使用此方法建立的應用程式可受益於 Claude 連接器（connectors），且 Claude 的使用情況會與透過工件建立的桌面應用程式綁定。這是 Anthropic 本週針對開發者推出的第二項 Claude 更新。
