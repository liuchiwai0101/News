Grok Bot 推出常駐 AI 代理 macOS 及 iOS 開始測試

Elon Musk 旗下的 SpaceXAI 今日宣佈推出 Grok Bot，一個由「常駐智能代理」組成的團隊，能夠利用工具、網站和應用程式完成任務。Grok Bot 可在雲端運作，即使用戶關上筆記型電腦，工作仍會繼續進行。該功能與 AI 編碼公司 Cursor 緊密結合，而 SpaceX 現正以 600 億美元收購該公司。

以對話指揮代理工作

Grok 訂戶可透過手機或桌面應用程式，以自然語言向代理發送訊息。SpaceXAI 表示，其他工具可能需要先建立工作流程與例行程序，但 Grok Bot 只需對話就能完成任務。代理甚至能登入網站（包括沒有提供 API 的網站），不過 SpaceXAI 尚未說明身份驗證的具體運作方式。

多代理並行與羣組協調

用戶可同時使用多個代理，其中一個負責管理其他代理，並為不同任務指派專門的代理。代理能夠加入羣組聊天，自行協調工作、分配任務、確立負責人，只有當需要判斷時才會尋求用戶介入。

教導代理自動執行流程

用戶可以教導 Grok Bot 執行特定工作流程。代理會觀察用戶完成任務的過程，儲存步驟，之後便能獨立按照相同步驟執行。SpaceXAI 指出，這些代理會隨時間學習，最終能在用戶開口前就主動開始工作。

實際應用與訂閱資格

SpaceXAI 網站上展示多個 Grok Bot 的應用例子，包括銷售代理將通話記錄更新至 CRM、營運代理處理新入職員工及 Gmail 中的發票、工程代理重現產品介面錯誤、提交工單，並將修復任務轉交除錯代理。Grok Bot 現處於測試階段，macOS 及 iOS 上的 SuperGrok Heavy、Cursor Ultra 及 Cursor Teams Premium 訂戶可率先使用。企業用戶則可加入候補名單，等待日後存取。
