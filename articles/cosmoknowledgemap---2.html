將散亂筆記化為 3D 知識星圖　原價 US $0.99《CosmoKnowledgeMap》限時免費

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

CosmoKnowledgeMap 是一款將 Safari 網頁與筆記轉化為 3D 知識星圖的個人知識管理工具，適合經常蒐集資料、整理研究或建立學習筆記的人士。原價 US $0.99，現正限時免費。

知識星圖與全文搜尋

可從 Safari 擴展、分享表單或手動收集網頁與筆記，以全文搜尋定位後跳至星圖節點，沿連線探索關聯。提供四種視圖切換；選取主題可生成文字，讓使用者自行貼到 ChatGPT、Claude 或 Gemini 再匯回，新增 30、100 或 200 個項目，無需 API key 或額外付款。每個筆記本可設獨立數字密碼，支援 Face ID 或 Touch ID；內建日本星圖樣本與宇宙坍縮模式，資料儲存於裝置。
