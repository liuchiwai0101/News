大陸兩大AI模型 開放海外授權

DeepSeek 科技部 人工智慧 ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' 00:00 2026/10/24 23:24:48 經濟日報 記者賴錦宏／綜合報導 大陸官媒透露，大陸人工智慧（AI）新創深度求索（DeepSeek）和MiniMax已履行相關登記手續，並完成模型開源和海外授權。

在經歷數月震盪走低後，上週五MiniMax和智譜股價罕見大漲。其中MiniMax漲近17%、智譜漲逾8%。

大陸商務部、科技部日前就修訂「中國禁止出口限制出口技術目錄」公開徵求意見，其中涉及23項人工智慧（AI）相關技術。自那以來，海外輿論就開始熱議，這是否意味著中國大陸即將限制AI模型出口。

央視旗下新媒體「玉淵譚天」23日發文稱，據其瞭解，政策公佈以來，DeepSeek及MiniMax兩家AI新創企業已順利履行登記手續，並完成開源和海外授權使用。玉淵譚天並強調，目錄修訂並非旨在單純限制AI技術對外出口，而是透過建立清晰的邊界，對具有戰略意義的技術出口進行規範管理。

事實上，大陸商務部亦就相關問題給出明確答案，指出判斷AI產品出海是否屬於技術出口管理範圍，核心在於是否涉及限制類技術從中國大陸境內向境外轉移，且擬議的措施存在相當大範圍的豁免。

商務部指出，即使相關API、網頁應用或軟體即服務（SaaS）功能背後的底層模型屬於受管制範圍，只要企業以API調用、網頁應用或SaaS等形式向海外提供服務，都不會受到出口限制。

商務部提到，對於人工智慧類技術開源、中國大陸企業在境外自建自營算力中心、赴境外展開晶片流片製造、利用境外資源聯合研發、參與國際標準制定等情形的技術出口，基本實現「隨報隨出」；對於已經通過開源、發表學術論文等方式進入公共領域的相關技術，也不計劃納入出口管理範圍。
