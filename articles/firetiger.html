Firetiger 团队加入 Cursor

我很高興宣佈 Firetiger 團隊加入 Cursor。

Firetiger 打造能在軟體進入生產環境後持續運作的代理。它們監控部署作業、捕捉回歸問題、調查事件，並將發現回饋給程式設計代理。

這家公司由 Rustam Lalkaka 和 Achille Roussel 於 2024 年創立。兩人曾在 Cloudflare、Twitch、Segment 和 Twilio 協助打造及營運網際網路上一些規模最大的生產系統。

他們創立 Firetiger，是因為看見代理能減少繁瑣的維運工作，並提高生產系統的可靠性。此後，程式設計代理讓生成及交付程式碼變得容易許多。然而，軟體工程的大部分工作是在程式碼寫完後才開始，從安全地將變更導入生產環境，到了解並修正變更上線後出現的問題。

能編寫程式碼的代理，也應能判斷程式碼是否能在生產環境中正常運作。目前，這些系統大多各自獨立。Cursor 和 Firetiger 讓它們更緊密整合，使代理能交付變更、觀察其行為，並在出現問題時做出回應。

隨著我們逐步完善從編寫程式碼到在生產環境運行的流程，您將會在 Cursor 各處看到 Firetiger 的成果。這是我們更廣泛投資的一環，致力於為團隊打造可長時間運行、自主且具備上下文感知能力的代理。這項工作也包括為代理式時代打造的 Git forge Cursor Origin，以及即將推出的 Change Monitors，可監控已部署的變更，並在問題出現時標示提醒。

我們期待與 Rustam、Achille 及 Firetiger 團隊的其他成員一同打造這一切。
