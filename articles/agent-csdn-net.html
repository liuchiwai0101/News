目標：創建一個「小紅書爆款文案生成器」智能體，輸入主題，輸出3種不同風格的爆款文案。

- 登錄釦子 → 點擊「創建」→「創建智能體」

- 填寫名稱：「小紅書爆款文案助手」

- 填寫描述：「輸入主題，自動生成3種風格的小紅書爆款文案」

- 圖標可用AI自動生成，點擊「確認」

這是智能體的**靈魂**。一個好提示詞 = 角色設定 + 輸出結構 + 風格要求 + 示例。

進入編輯頁面後，在「人設與回覆邏輯」框中填入以下內容：

# 角色
你是小紅書爆款文案創作專家，擁有5年新媒體運營經驗，精通小紅書平臺的爆款公式和流量密碼。
# 技能
- 根據用戶輸入的主題，創作3種不同風格的爆款文案
- 風格1：種草推薦型（真誠分享口吻 + 使用體驗 + 種草理由）
- 風格2：乾貨教程型（價值感標題 + 步驟拆解 + 收藏引導）
- 風格3：情感共鳴型（情緒鉤子 + 故事感 + 互動引導）
- 每種風格附帶標籤建議和使用場景說明
# 輸出格式

【標題】
【正文】（包含使用體驗+種草理由）
【推薦標籤】
【適用場景】
## 風格2：乾貨教程型
……（同上）
## 風格3：情感共鳴型
……（同上）
# 限制
- 不編造虛假信息
- 不推薦未經驗證的產品
- 每個文案控制在300字以內

寫完提示詞後，可以點擊右上角的「優化」按鈕，讓釦子幫你潤色一下。

在「編排」區域 → 「技能」→ 添加以下技能：

- **開場白**：設置歡迎語，例如「嗨～告訴我你想寫什麼主題，我幫你生成3種爆款文案！」

如果說智能體是「一個AI員工」，那工作流就是「一條AI生產線」。

工作流 = 多個節點串聯的自動化流水線。每個節點完成一個任務，數據在節點之間流轉。

釦子提供兩種工作流類型：

- **工作流（Workflow）**：處理功能類任務，如數據採集、內容生成

- **對話流（Chatflow）**：處理對話類任務，如智能客服

這個工作流的功能：自動抓取科技新聞 → AI篩選精華 → 生成摘要 → 輸出給用戶。

釦子首頁 → 資源庫 → 工作流 → 新建工作流，命名爲「科技新聞精選」。

- 在畫布中點擊「添加節點」→「插件」

- 搜索「科技新聞」→ 添加 `Science_news`插件

- 將開始節點連接到 Science_news 節點

- 添加節點 → 「大模型」

- 連接在 Science_news 節點之後

- 重命名爲「新聞精選」

- 設置輸入參數，引用上一個節點的輸出

將結束節點連接到「新聞精選」節點後，設置輸出爲精選後的新聞內容。

點擊「試運行」，如果結果滿意，點擊「發佈」。

回到你的智能體編輯頁 → 編排 → 技能 → 添加工作流 → 選擇剛發佈的「科技新聞精選」。然後在人設中描述這個技能：

當用戶需要科技新聞時，調用「科技新聞精選」工作流獲取最新資訊並整理輸出。

大模型最大的問題是：**容易胡說八道**。要解決這個問題，就給它喂「靠譜的資料」—— 知識庫。

通俗理解：**知識庫 = AI員工的培訓手冊**。你把公司文檔、產品手冊、FAQ傳上去，智能體回答問題時先查知識庫，有了依據再回答。

釦子知識庫支持：

- 網頁鏈接（自動抓取內容）

- PDF / Word / Excel / Markdown 文件

- 飛書表格

- 手動錄入文本

上傳後系統自動將長文本「切片」，檢索到的片段作爲上下文送給大模型生成回答。

- 準備資料：產品使用手冊（PDF）、常見問題（Excel Q&A表格）

- 釦子 → 資源庫 → 知識庫 → 新建知識庫

- 上傳文件，等待系統自動切片（通常1-3分鐘）

- 在智能體中關聯該知識庫

- 設置檢索優先級

**舉個例子你就懂了**：

你說「幫我查一下明天北京的天氣」，大模型本身不知道天氣，但它知道應該調用天氣查詢工具，然後告訴你結果。

這個過程就是 Function Calling：**大模型不直接執行函數，而是返回「應該調用哪個函數 + 什麼參數」**，由釦子平臺實際去調用。

當官方插件無法滿足需求時，比如：

- 需要對接公司內部的API

- 需要調用特定數據源

- 需要實現獨有的業務邏輯

創建自定義插件的步驟：

- 資源庫 → 插件 → 新建插件

- 填寫 API 地址、認證方式

- 定義輸入輸出參數

- 測試通過後發佈

- 智能體編輯頁 → 右上角「發佈」

- 填寫發佈記錄

- 勾選「釦子智能體商店」

- 點擊「發佈」

- 發佈時勾選「微信」

- 按指引完成微信公衆號授權

- 配置自動回覆規則

- 發佈時勾選「飛書」

- 在飛書開放平臺創建應用，獲取 App ID 和 App Secret

- 回到釦子完成綁定

- **直接對話大模型**：問一位「無所不知但沒記憶」的萬能博士

- **智能體**：你親手打造的、有特定技能和長期記憶的「專屬專家員工」

按這個順序排查：

- 檢查每個節點的輸入輸出是否正確引用

- 檢查變量名是否拼寫正確

- 用「試運行」逐節點排查

- 檢查插件是否需要額外配置

- 新手先用免費額度學習

- 熟練後再升級專業版

- 知識庫可以減少不必要的 Token 消耗（有據可依，不用每次都長篇推理）

**AI機器人（Bot）是智能體（Agent）的子集**。Bot 通常是簡單的對話機器人；Agent 能自主規劃、調用多種工具、完成複雜多步驟任務。
