DeepSeek-V4-Flash-Vision-Exp 发布

今天，全新的多模態視覺理解模型 DeepSeek-V4-Flash-Vision-Exp 上線 DeepSeek API 平臺，這是一個實驗性質的模型，用戶可以通過設置 model='deepseek-v4-flash-vision-exp' 訪問該模型。

- Terminal Bench 2.1: 83.9

- NL2Repo: 57.7

- DeepSWE: 59.3

- DSBench-Hard: 63.6

- AutomationBench (Public): 25.7

- ApexBench (Pass@1): 36.5

- Agents' Last Exam: 27.3

- Chartography: 64.3

- ZeroBench (Pass@5): 35.0

* 對於公開基準測試集中的 Code Agent 文本任務，DeepSeek 系列模型使用 DeepSeek Harness 極簡模式作爲框架進行測試，並使用 max 檔位，topp=0.95，temperature=1.0；在 ApexBench 與 Agents' Last Exam 測評中，文本模型 DeepSeek-V4-Flash 會忽略其中的多模態元素

在純文本能力（Agent、推理、世界知識等）方面，DeepSeek-V4-Flash-Vision-Exp 與 DeepSeek-V4-Flash 正式版持平。

在需要视觉理解的 Agent Benchmark 上，DeepSeek-V4-Flash-Vision-Exp 相比 DeepSeek-V4-Flash 实现了大幅跃升，多模态 Agent 能力已接近 Opus-4.8。

詳細調用方法請參閱文檔。

时间: 2026-08-13

DeepSeek-V4-Pro 更新

DeepSeek-V4-Pro 正式版已同步在 APP、網頁端和 API 更新上線。API 調用方式不變，模型名設置爲 deepseek-v4-pro，即可使用最新版本。

**Agent 能力大幅提升**

正式版 DeepSeek V4 Pro 極大增強了 Agent 能力，在生產環境中的性能表現提升尤爲顯著。

- HLE (wo / w tools): 42.7/60.0

- Terminal Bench 2.1: 87.9

- NL2Repo: 61.5

- Cybergym: 83.3

- DeepSWE: 62.7

- Toolathlon-Verified: 74.1

- Agents' Last Exam: 25.7

- AutomationBench (Public): 31.8

- DSBench-FullStack: 71.1

- DSBench-Hard: 67.2

**原生支持 Responses API**

DeepSeek API 現已原生支持 OpenAI Responses API 格式，並針對性適配 Codex。用戶可以參考官方文檔，通過一鍵配置腳本完成 Codex 的配置。

**更靈活的思考強度控制**

V4-Pro 和 V4-Flash 思考模式現支持 low / high / max 三檔思考強度，用戶在實際使用中可以根據任務複雜度靈活選擇：簡單任務使用 low，日常 Agent 任務使用 high，更復雜的任務場景使用 max。設置方法請參考官方 API 文檔：思考模式。

**API 定價調整**

隨着 DeepSeek V4 全系列模型正式版上線，我們將對 API 價格進行更新調整。爲了更加合理地調配資源，我們將採用峯谷定價，閒時價格爲高峯時段價格的一半，鼓勵用戶根據實際使用情況調整任務時間。新價格將於北京時間 2026 年 8 月 17 日 0 時開始生效。
