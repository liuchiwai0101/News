大陸、澳洲共建 AI 對話機制 將針對安全、治理和應用交換意見

內容機器翻譯自第三方媒體（經濟日報），僅供參考，以原文為準。

澳洲 國務院 釣魚台 ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' 00:00 2026/11/22 01:12:37 經濟日報 記者陳宥菘／綜合報導 大陸國務院總理李強在北京釣魚台國賓館與澳洲總理艾班尼斯（Anthony Albanese）舉行第11輪中澳總理年度會晤，會後聯合聲明指出，雙方同意建立中澳人工智慧（AI）對話機制，就AI安全、治理和應用交換意見。兩人還討論了貿易、氣候變遷等問題，並同意2027年舉行下一輪中澳總理年度會晤。

艾班尼斯赴深圳出席APEC峯會，並與大陸國家主席習近平20日在深圳會見後，隨即轉往北京與李強舉行中澳總理年度會晤。新華社報導，雙方會後共同發表「中澳總理年度會晤聯合成果聲明」。

據報導，李強在會晤中表示，當前中澳關係保持積極發展勢頭，各層級交往日益密切，各領域合作走深走實。明年是中澳建交55週年，中方願同澳方一道以此為契機，聚焦共同利益，妥善管控分歧，推動中澳全面戰略夥伴關係取得更多積極成效。

李強指出，中澳在產業、市場、技術等方面各有優勢、互補性強，兩國深化合作有內生需求，能夠相互賦能。

中方願同澳方推動雙邊貿易擴大規模、優化結構，打造綠色低碳、新能源汽車、人工智慧等新興領域合作亮點，進一步提升貿易投資自由化便利化水平，爭取更多實際成果。雙方要辦好明年的「中澳旅遊年」，深化文化、青年等交流合作。

李強表示，當前單邊主義、保護主義還在大行其道，中澳同為多邊主義的支持者、受益者，中方願同澳方加強在聯合國、亞太經合會等框架下溝通協調，共同維護多邊體系和自由貿易，捍衞國際公平正義。

據中方引述，艾班尼斯表示在當前動盪的國際形勢下，澳中更應放眼長遠，「不能讓分歧幹擾雙邊關係，而是要積極推進合作」。澳中經濟具有互補性，願同中方深化經貿、農業、能源等領域合作，加快清潔能源、人工智慧、電動汽車、數字經濟等新興領域合作，密切旅遊等人文交流。

艾班尼斯還説，澳方堅持多邊主義和自由、開放的貿易，願同中方攜手維護以規則為基礎的多邊貿易體制。澳洲廣播公司（ABC）報導，艾班尼斯説，人工智慧有潛力改變生產力和生活水平，「這就是為什麼澳洲要制定人工智慧標準，因為我們認真地想要塑造人工智慧的未來，而不是被人工智慧塑造。」
