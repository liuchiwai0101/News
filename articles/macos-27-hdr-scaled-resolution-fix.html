macOS 27 修復第三方 HDR 顯示器限制　縮放解像度可同時啟用 HDR

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

macOS 27（代號 Golden Gate）修復了第三方 HDR 顯示器用户長期面對的一項限制：在 macOS 26 Tahoe 上，系統無法在常用的 2560 x 1440 縮放解像度下啟用高動態範圍（HDR），如今兩者可同時開啟。有評測者正在測試 Dell 32 吋 UltraSharp U3226Q，並指這款 OLED 面板在 macOS 開啟 HDR 後畫質令人印象深刻。

Tahoe 下 HDR 無法配合縮放

在 macOS Tahoe 上使用支援 HDR10 的第三方顯示器時，「系統設定」→「顯示器」會提供高動態範圍開關，開啟後即可觀看 HDR 內容。此時若把 4K UHD 顯示器設為 1920 x 1080，即原生 3840 x 2160 的 2 倍像素，HDR 可正常運作。

不過 1920 x 1080 對多數用户並不實用：在 4K 顯示器上內容會顯得過大，32 吋的 Dell UltraSharp U3226Q 可用畫面空間亦大幅縮減。一旦改用縮放解像度，例如 Apple 5K Studio Display 預設的 2560 x 1440，高動態範圍開關便不再提供，系統自動退回標準動態範圍，用户只能在 HDR 與慣用縮放解像度之間二選一。

macOS 27 支援同時啟用

macOS 27 Golden Gate 已修復上述問題。在該版本下，用户可同時選用縮放解像度並啟用 HDR，屬系統原生選項，不涉及第三方軟件。

這項改動似乎仍有硬件要求。在 M4 MacBook Pro 上可同時選取兩項設定，但在同樣運行 macOS 27 的 M1 Max MacBook Pro 上，系統已更新仍無法同時選取。有評測者認為，單是這項修正，已足以令第三方 HDR 顯示器用户由 macOS Tahoe 升級至 Golden Gate。

系統整體 HDR 支援加強

macOS 27 亦在多個層面加強原生 HDR 支援。整體外觀較 macOS Tahoe 更具對比，並出現特別明亮的高光及遊標；對 Apple Studio Display XDR、Pro Display XDR 以及第三方 OLED 顯示器的用户而言，效果均相當明顯。
