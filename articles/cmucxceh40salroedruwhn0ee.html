Claude Code v2.1.280 發佈，新增 Claude Opus 5.5 為默認 Opus 模型

內容機器翻譯自第三方媒體（Claude Code），僅供參考，以原文為準。

AI 導讀

Claude Code 發佈 v2.1.280，新增 Claude Opus 5.5（claude-opus-5-5）為默認 Opus 模型，支持 1M 上下文，價格為 $4/$20 per Mtok、緩存讀取 $0.20/Mtok；同時將 Pro 和 Team Standard 計劃的默認模型從 Sonnet 改為 Opus。

推薦理由

官方更新日誌詳列了新增 Opus 5.5 默認模型、價格與大量修復，開發者可據此判斷是否升級及對現有工作流的影響。

正文

變更內容
