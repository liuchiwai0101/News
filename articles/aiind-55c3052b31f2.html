兩代間隔 44 個月？消息稱英偉達 RTX 6060 可能推遲至 2029 年發佈，遊戲性能不及 PS6

內容機器翻譯自第三方媒體（IT之家），僅供參考，以原文為準。

正文

剛剛，首批搭載英偉達 RTX Spark 超級芯片的 Windows 筆記本電腦開售了。

APPSO 也提前拿到華碩 ProArt 創16 RTX Spark，這款筆記本 16 寸的 64GB 統一內存版本價格為 28999 人民幣，128GB 統一內存版本則是 37999 人民幣。

這是英偉達第一次以這樣的方式進入 Windows PC 的核心硬件平台。以前的 Windows 電腦，大多數是使用 Intel 或者 AMD 的處理器，英偉達只是向電腦廠商提供顯卡。

現在， 英偉達開始把自己的 ARM CPU、Blackwell RTX GPU 和統一內存結合起來，推出一套能夠運行 Windows 的完整計算平台 。

在體驗了一段時間後 APPSO 給大家挖出了更多細節，作為 AI PC 跟 Mac 對比如何，是不是可以當「理財產品」來等着它增值……

把大模型裝進一台最薄 12.9 mm 的電腦 我們拿到的是 64GB 統一內存版本，由於是統一內存的形式，實際可用的 GPU 顯存大約在 46.7 GB 左右，LPDDR5X 的內存類型，讓它的內存帶寬速度峯值理論在 300GB/s，但這也能讓它運行像 Qwen 3.8 270 億參數這樣的模型。

另一方面，過去的 Windows ARM 架構的筆記本電腦，主要想回答的是「能不能像 MacBook Air 一樣輕薄、省電、續航長」。

而 RTX Spark 的 ARM64 架構則讓這台電腦能獲得類似 Apple Silicon Mac 的高能效和統一內存優勢， 又保留了 Windows 的應用生態和 NVIDIA 的 CUDA 能力 。

圖｜華碩 ProArt 創16 H7607BA，處理器為英偉達 RTX Spark N1X 在續航上，這台華碩 ProArt 創16 RTX Spark 的電池是 99.9Wh，我們找了一個本地 270 億參數模型持續生成文本和推理，拔掉電源，能看到電池的放電功率大約在 86.5W 左右，而剩餘的電量幾乎是在 2 分鐘的時間裏，就從 98.5Wh 掉到了 96.1Wh。

圖｜十分鐘左右的時間，跑一個 27B 的本地推理大模型，電量從 100% 掉到 85%；DischargeRate 通常以毫瓦（mW）表示，88493 表示大約 88.4W 的電池放電功率。 88108 表示電池剩餘大約 88Wh 的能量。

圖｜顯卡功率大約是 30W，位於 P4，根據英偉達 RTX Spark 技術文檔，P0 為最高性能，P4 平衡性能與功耗，P8 則是更側重省電。插上充電器之後，顯卡性能會更新為 P0。 假設整機平均功耗是 80W，99.9Wh 理論續航也能達到約 1 小時 15 分鐘。也就是説，如果你正在持續運行一個 27B 或更大的模型，能夠在不插電的情況下堅持約一個小時。

對於一台能在本地運行大型 AI 模型的筆記本，一台最薄 12.9mm ， 重約 1.77kg 的筆記本 ，這意味着即使離開電源，它還能繼續承擔一段時間的高負載計算任務。

圖｜GPU 利用率達到了將近 100% 續航之外，這台華碩 ProArt 創16 RTX Spark 筆記本電腦配備了豐富的外部接口，3 個 USB4 Type-C，每個最高 40Gbps，支持視頻輸出和 USB PD 供電。

1 個 USB-A 接口，使用 USB 3.2 Gen 2，最高 10Gbps；1 個 HDMI 2.1 FRL 接口用來連接外部顯示器，以及 1 個 SD Express 7.0，用於高速存儲卡和 1 個 3.5mm 音頻接口。

這些接口最大的意義，也是讓它可以成為一台移動工作站：外接高速硬盤、4K 顯示器、相機存儲卡，以及各種創作設備。

64GB 統一內存，能讓 AI 幹多少活 前幾天，在微軟的特別活動上，他們把 Windows PC 分成了開箱即用的迷你台式電腦、具備混合智能，本地和雲端 AI 的 Copilot + PC，以及能利用雲端和本地 AI 進行創作的 Builder PC。

這台華碩 ProArt 創16 RTX Spark筆記本電腦正是位於 Builder PC，即創作者個人電腦的類別下，而眼下最熱門的創作，自然是用 AI 來進行，生成遊戲、3D 建模，還有簡單的網頁應用等，AI 都必須參與其中。

對華碩 ProArt 創16 RTX Spark來説，引入 AI 的方式之一就是本地部署，因為這樣才能充分利用英偉達 RTX Spark 的能力。

我們下載了 LM Studio，並安裝了 Qwen 3.8 27B 的模型。將思考深度調整為極高，問一句「你好」，這枱筆記本總共花了 18 秒，能看到模型讀取、處理輸入內容的速度 Prompt Speed 是 615.7 token/s，生成 token 速度在 14.3 token/s，首 token 的時間是 2.83s。

而當我們嘗試要求它做一些網頁項目時，例如為一個 AI PC 的活動設計網頁。

可以看到生成 Token 的速度還是穩定在 14 token/s 左右，首 token 的時間是 12.05s，總的用時為 609.67s。

Qwen3 32B（NVFP4）的推理速度在每秒 55–60 tokens 上下，日常對話、文案寫作、代碼輔助完全流暢；喂入長文檔做總結時，十萬 token 級的上下文也沒有明顯衰減。

WorkBuddy，我的智能體現在 0 元/月 除了單獨的本地部署，這台 Windows 電腦最有意思的地方是和 WorkBuddy 的配合。
