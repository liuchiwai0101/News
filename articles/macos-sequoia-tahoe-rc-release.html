Apple 釋出 macOS Sequoia 15.8.4 與 macOS Tahoe 26.7.4 RC　更新説明僅提安全修正

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

Apple 釋出 macOS Sequoia 15.8.4 與 macOS Tahoe 26.7.4 的首個 Release Candidate（RC），同時向開發者提供 macOS 27.3 第二個測試版。兩個 RC 的更新説明目前僅提到為 Mac 提供安全修正。

RC 建置編號與更新説明

macOS Sequoia 15.8.4 RC 1 的建置編號為 24H319，macOS Tahoe 26.7.4 RC 1 則為 25G422。Apple 在直接推送至 RC 的更新中通常只註明提供「為你的 Mac 提供安全修正」；實際發佈説明可能在 Apple 於未來數週正式發佈兩個版本後不久公佈。

此次 RC 推出前，Apple 於兩週前發佈 macOS Tahoe 26.7.3 與 Sequoia 15.8.3，以及 macOS 27.2.1 Golden Gate，相關更新包含 AirPlay、藍牙及 Messages 等安全修正。
