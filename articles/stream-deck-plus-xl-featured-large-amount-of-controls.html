按鈕、旋鈕、觸控條多到用唔晒　Stream Deck + XL 大場面一手包辦

內容機器翻譯自第三方媒體（PCM），僅供參考，以原文為準。

面對今時今日各軟件都有一大堆快捷鍵操作的情況，Elgato 的 Stream Deck 系列快捷鍵中樞為各類型電腦用家提供就手的操作介面，繁瑣的操作可以一鍵搞定。2022 年推出的 Stream Deck + 更引入創新的可按壓旋鈕和觸控橫幅屏幕，將「調節系」操作也一併納入其中。不過面對日益繁重和多樣化的操作，單純多按鈕的 Stream Deck XL 和只有簡單控制面的 Stream Deck + 顯然無法應對大場面的需要。如今，Elgato 就為需要面對眾多輸入項目、希望將整個操作環境集中於單一介面中的用户，帶來品牌史上最大尺寸的 Stream Deck + XL。36 個 LCD 按鈕、6 個可按壓旋鈕和加大碼動態觸控屏幕，足以應付各種大場面！

與標準 Stream Deck + 相比，Stream Deck + XL 無論 LCD 按鈕、可按壓旋鈕以至觸控橫幅屏幕都大幅增加，足以將整個工作環境放在一個頁面裡。

滿足大型場景應用需要

讓我們想像一下一場有多名玩家在不同地點參與的 Twitch 遊戲直播場景會有甚麼需要操作的元素吧：除了遊戲畫面之外，其他參加者的影像和語音、開場卡和完場卡、多條 Lower Third 標題條、在不同參加者之間切換場景、瀏覽器、燈光、音量調節、觀眾即時回應和打賞的動畫和音效⋯⋯如果還同時做直度串流情況就更複雜，打開 OBS 的 Source Tree 簡直就是「水蛇春咁長」。單靠滑鼠操作一定會亂作一團，大大影響直播節目質素。

以上這些事情其實都可以利用 Stream Deck 一鍵搞定，但面對這種「全包宴」大場面，過去會在 Stream Deck 設定多個分頁和資料夾，分門別類組織來源，有空間可以加插一些如回應數字、倒數計時、電腦狀況的訊息等。不過切換分頁、開關資料夾仍會對直播的進行帶來一些影響，沒有旋鈕要控制音量、燈光也不夠直觀。而後來的 Stream Deck + 雖然控制面種類全面，但按鈕數量只得 8 個就顯得捉襟見肘。

Stream Deck + XL 的優勢就是「給你吃個飽」！

海量控制面給你用個飽

Stream Deck + XL 正是為了應付大型密集場景而設計。與原本的 Stream Deck + 相比，Stream Deck + XL 的功能鍵足足擴展了 3.5 倍！動態 LCD 按鈕由 8 個大增至 36 個，比只有按鈕的 Stream Deck XL 還要多；可按壓旋鈕增至 6 個，而動態觸控橫幅屏幕也相應擴闊 50%。只要你有足夠想像力，大量捷徑鍵、開關、調節、系統資訊都能塞進一個介面，不用頻繁地在分頁、資料夾之間切換，減少直播時因為進行操作所產生的停頓冷場。

相比起要將 Source 開關、場景切換、音量調整、Lower Third 標題條開關等功能以分頁、資料夾來分散收藏，Stream Deck + XL 的大量按鈕和旋鈕讓用家可以直接將所有功能放在同一頁面上，不用在分頁、資料夾間來回切換。

Stream Deck + XL 三種控制面各有所長：經典的 LCD 按鈕除了最基本的開／關／觸發功能外，還支援單按、雙按、長按以觸發不同自訂功能；Multi Action 按一下就能執行連串工作，還有 Multi Action Switch、資料夾和 Hotkey Switch 等不同類型的操作方式。

按鈕除了提供單按、雙按、長按等操控方式，與及 Multi Action 等組合控制方式，本身的 LCD 小屏幕亦是顯示即時資訊的好地方，例如用來顯示現時 CPU 和記憶體負荷。

可按壓旋鈕除了可 360 度無限轉亦可按壓，旋轉適合用來調校音量、亮度等，按壓就如一般按鈕一樣，與旋鈕放在一起就提供更直觀的操作，如旋鈕調校音量按下就開關靜音。用户亦可利用 Dial Stack 將幾個需調校的項目如一組燈光放在一個旋鈕上一同控制亮度。

旋鈕配合上方的觸控橫幅屏幕，可以將多個調節項目整合在一組旋鈕＋觸控屏幕裡，同時提供控制和資訊。

此外，Steam Deck + XL 的旋鈕亦是與觸控橫幅屏幕結合一起工作的，旋鈕調節的數值可以即時顯示在橫幅屏幕上。而 Action Wheel 就可將多種按鈕堆在一個旋鈕和觸控屏幕中，用户轉動旋鈕或在觸控屏幕上左右撥，就可以選擇要操控的項目，再壓下旋鈕或在觸控屏幕點擊就可以像按鈕一樣觸發。這可大幅減少同類型指令佔用大量 LCD 按鈕的問題。

安裝簡單，只要插一條 USB-C，安裝 Stream Deck 軟件就能開始按照自己的工作流程來設定各種按鈕和旋鈕。

龐大插件商城

擁有龐大插件商城 Elgato Marketplace 也是 Stream Deck 系列的強項之一，提供各種插件、預先設定好的 Profile、圖示等，而且已分門別類，包括各種直播時有用的功能、控制 Photoshop、Davinci Resolve 等創作工具、Windows 的就手快捷鍵、支援 Zoom、Teams、筆記簿等文書辦公室應用，當然還有一系列遊戲快捷鍵包，付費免費都有，用户可按平日工作流程選用。

龐大的插件商城是 Stream Deck 系列的強項，裡麪包含各種軟件的捷徑鍵和插件，即使不是做直播也能找到常用軟件的插件和遊戲的捷徑鍵。有這麼多按鈕、旋鈕，即使是 A320Neo 空中巴士的錶板也可以完整收納。遊戲 profile 可以在 Elgato Marketplace 下載／購買得到。

硬件擴充全面

作為操控中樞，Stream Deck + XL 可以透過 Stream Deck 軟件來控制 Elgato 品牌一系列影音製作直播產品，靈活性最高是咪高風系列，除了 Elgato 本身的 Wave 系列咪高風之外，其他品牌的咪高風也可以透過 Wave Link 軟件控制。其他產品如透過 Camera Hub 插件控制 Facecam 系列鏡頭、Prompter 提詞器，和透過 Control Center 插件控制 Key Light 系列燈具。

Elgato 品牌下多款咪高風、燈具以至提詞器和鏡頭都可以透過插件在 Stream Deck 上控制。

Stream Deck + XL 亦同時兼容部分同系的硬件擴充，例如 Network Dock 就可解除 Stream Deck + XL 一定要跟電腦放在一起的枷鎖，透過網絡通訊、PoE 或 USB 供電，Stream Deck + XL 放置在遠離直播電腦的佈景位置，直播主依然可以控制直播流程。

Network Dock 可以令 Stream Deck + XL 脱離 USB 的枷鎖，例如放到主持人手邊讓他即時控制直播流程。

而需要大量 USB 接口又不想佔用電腦 USB 接口的話，USB HUB FOR STREAM DECK + 就讓 STREAM DECK + XL 充當 USB 集線器和 SD 讀咭器，可以節省一些桌面空間。

USB Hub for Stream Deck + 配件將 USB 集線噐與 Stream Deck + XL 結合。
