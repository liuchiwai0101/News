香港爆發 Claude 大規模「封號潮」　VPN 用户集體被禁用

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

踏入十月，Anthropic Claude 疑似再度收緊存取限制！大量中國香港用户在 10 月 1 日登入服務時遭遇阻截，畫面顯示帳號已被停用（Account Suspended）或存取被拒（Access Denied）。本地科技社群、Threads 及討論區湧現大批求助個案，不少已付費訂閲 Claude Pro 的使用者亦未能倖免，引發業界對跨境 AI 服務穩定性與資料風險的關注。

非支援地區＋機房 IP 清理

Anthropic 自推出 Claude 以來，服務涵蓋地區清單中一直未包含中國香港。過去多數本地用户多依賴虛擬私人網絡（VPN）及海外帳單地址進行註冊與使用。然而，業內分析指出，Anthropic 近期正進行大規模的安全合規與反濫用審查。

綜合網絡工程師與受影響用户的分析，本次封禁主要針對三大特徵：

  • 商業數據中心 IP 批量封鎖： 許多常見商業 VPN 所使用的數據中心（Data Center）IP 節點被集中標記為高風險連線，系統針對共用節點進行了整批攔截。
  • 支付與地區資訊審查： 部份使用中國香港本地銀行信用卡配合海外虛擬地址，或使用第三方虛擬信用卡（Virtual Card）支付 Pro 訂閲費用的帳户，因觸發反欺詐與屬地合規風控而被直接封停。
  • 帳號行為標記： 頻繁切換不同國家節點登入的帳户，被安全系統列為異常存取。

轉向雲端 API

由於 Claude 近年在長文分析、邏輯推理與程式碼生成方面廣受業界好評，本次封禁行動對本地從事軟體開發的專業人士造成顯著衝擊，要用最先進的 AI 模型看來就要用 API 方式才行，然而價格遠比月費計劃高。截至目前，Anthropic 官方尚未就本次針對特定地區或節點的封鎖行動發表正式聲明。
