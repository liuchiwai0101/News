Microsoft 送 Windows Insider 12 週年桌布 網民查 EXIF 驚見「用 Mac 製作」

內容機器翻譯自第三方媒體（PCM），僅供參考，以原文為準。

為了慶祝 Windows Insider 測試計劃推出 12 週年，Microsoft 日前特意向社群用户發送電郵，免費送出一套以 Windows 11 標誌性「Bloom」花卉意象及 Surface 設計美學為靈感的全新桌面桌布。然而，這份本應温馨的感謝禮物，卻因為網友的一個無意發現，演變成一場尷尬笑話。

EXIF 檔案資料露餡：出自 macOS 版 Photoshop

獨立軟體開發者 Rafael Rivera 在收到 Microsoft 的紀念郵件後，好奇檢查了該批桌布圖檔（EXIF）的詳細資訊。結果發現，這些主打「展現 Windows 11 與 Surface 設計美學」的官方桌布，其元數據（Metadata）竟顯示圖檔是由 macOS 版的 Adobe Photoshop 建立並匯出。

Rafael Rivera 在社交平台 X 上記錄了這個發現，隨即引來大量網民轉發與調侃。有網民打趣表示：「原來連 Microsoft 的設計師都覺得 Mac 比較好用」、「自家 Surface Laptop Ultra 辦不到嗎？」。

內部設計團隊 排除外判責任

針對有人質疑「是否外判設計公司使用 Mac 所致」，Rivera 後續補充指出，該批圖檔的詳細資訊顯示，創作團隊確實是 Microsoft 內部的設計部門（Microsoft In-House Design Team）。這意味著並非外部廠商的個人習慣，而是 Microsoft 自家員工在日常設計工作流程中，直接使用了 Apple 的 Mac 電腦進行繪圖。

科技界觀點：尷尬但情有可原

對於這起公關小意外，外媒與科技圈普遍認為不算重大失誤，但時間點確實相當微妙。目前 Microsoft 正大力推廣搭載 Windows 11 的 Copilot+ PC 以及各類新世代 Surface 硬體，並不斷向創作者喊話 Windows 平台具備強大的生產力與效能。
雖然 Adobe Photoshop 在 Windows 11 及 Windows on Arm 平台上早已能順暢運行，Microsoft 員工使用何種工具純屬個人或團隊選擇，但作為宣傳 Windows 12 週年與自家生態系的紀唸作品，卻由敵對陣營的 macOS 設備一手打造，難免讓微軟落入被網民嘲諷的尷尬境地。
