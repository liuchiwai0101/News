Meta 推出 Muse Voice Transcribe　支援 Mac 即時語音轉錄

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

Meta 正式發佈 Muse Voice Transcribe，這是其首個即時音頻感知模型。該技術將多語言串流轉錄功能整合至 Meta AI for Mac、Muse Code 以及供開發者使用的 Meta Model API，為用戶帶來更高效的語音處理體驗。

系統級別語音聽寫功能

Meta Superintelligence Labs 指出，Muse Voice Transcribe 結合了串流自動語音識別、說話人分離及端點檢測技術。在實際應用中，它能在語音發生的同時進行轉錄，並可從包含超過 20 位說話人的錄音中區分不同說話者，同時判斷何時結束對話，整个过程無需獨立的後處理步驟。

支持七十種以上語言

該模型訓練涵蓋超過 70 種語言，並在發佈時驗證了其中 25 種。它支持長度超過一小時的音頻，並具備句子內或句子間的原生語碼轉換能力。此外，透過語言、關鍵字及上下文偏差調整，進一步提升識別準確度。Meta 表示，截至 9 月 1 日，該模型在 Artificial Analysis 串流語音轉文字排行榜上位居第一。

自適應延遲與定價策略

Muse Voice Transcribe 採用「自適應延遲」機制，動態決定在確定每個單詞前需聆聽多久，以便在簡單語音中快速推進，而在困難詞彙中利用更多音頻上下文，從而平衡速度與準確率。該模型已於 Meta Model API 提供，收費為每 1,000 分鐘音頻 3 美元，相當於每小時 0.18 美元。目前，用戶可在 Mac 上按住 Fn 鍵，在任何應用程式中使用此功能進行語音聽寫。
