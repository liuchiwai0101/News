正文

使用 Codex harness 構建並運行雲端智能體，由 OpenAI 全託管。

隨着我們將 Codex 和 ChatGPT for Work 擴展到全球數百萬用户，我們瞭解到要讓長時間運行的智能體在實踐中良好運作需要什麼。有用的智能體需要一個強大的 harness，能夠管理上下文、高效使用工具並協調子智能體。它們還需要能夠讓其可靠運行數天的基礎設施，以及可以處理文件、運行代碼並保存中間結果的環境。

今天，我們推出 Agents API⁠ 公測版，通過一個簡單、靈活的 API，將驅動 Codex 的同一套 harness 和基礎設施帶給開發者。

OpenAI 負責託管和維護 harness。你可以選擇智能體的計算環境：在 OpenAI 託管的沙箱中、在你自己的基礎設施上，或使用我們的沙箱合作伙伴之一。Agents API 為你提供了堅實的基礎，讓你能夠在我們優化的智能體 harness 和基礎設施之上構建智能體，這樣你就可以專注於讓你的智能體獨一無二的工具、知識和工作流。

選擇你的智能體環境

不同的工作負載需要不同的計算、存儲和部署選項。Agents API 讓你可以選擇適合你應用的沙箱。

我們正在與生態合作伙伴攜手⁠，包括 Blaxel、Cloudflare、Daytona、DigitalOcean、E2B、Modal、Oracle、Runloop 和 Vercel，為一系列需求提供一流的集成：

  • 完全託管的環境，或部署在你自己的 VPC 中
  • 特定的文件和密鑰存儲機制
  • 不同的 CPU、GPU 和內存配置，具備與貴公司工作流相匹配的性能、冷啓動和成本特徵。

Agents API 提供與主流生態服務商的一流集成。

OpenAI 託管沙箱

對於希望快速上手並高效擴展的開發者，我們還推出了 OpenAI 託管沙箱。它複用了驅動 Codex 和 ChatGPT 的同一套沙箱基礎設施。

OpenAI 負責沙箱的配置與管理，為你的智能體提供一個安全且高性能的環境，用於運行代碼、處理文件並生成產物。這些沙箱可以靈活地配置你的文件、軟件包、技能和插件，為智能體提供完成任務所需的一切。

基於持續演進的 Codex harness 進行構建

讓智能體在長時間會話中持續工作

為了支持模型連續工作數小時，我們構建了上下文管理機制，幫助智能體在更長的會話中攜帶相關信息。當會話接近上下文窗口上限時，Agents API 會自動壓縮較早的上下文，保留智能體繼續工作所需的信息。開發者可以構建跨越多個上下文窗口的工作流，而無需自行實現壓縮邏輯。

幫助智能體高效使用更多工具

Agents API 幫助智能體找到合適的工具並高效使用它們。工具搜索會按需加載相關的工具定義，有助於減少 token 用量和成本，同時保留模型的緩存。工具可用後，程序化工具調用讓智能體可以並行執行調用、串聯相關操作，並在代碼中過濾或合併結果，從而能夠處理海量數據，同時只將相關結果帶回上下文中。Agents API 支持 MCP、自定義函數以及網頁搜索等內置工具。

讓智能體通過子智能體並行處理工作

藉助多智能體支持，Agents API 可以將複雜任務拆解為相互獨立的部分，並委派給並行工作的子智能體。每個子智能體都維護自己的上下文，從而幫助它專注於自己的任務，而主智能體則協調它們的工作並彙總結果。這可以加速那些受益於並行處理的研究、分析和編碼任務，而無需你自己構建編排邏輯。

構建於開源基礎之上

Agents API 由開源的 Codex harness 驅動，讓開發者能夠瞭解協調模型調用、工具和上下文的核心邏輯。藉助 Agents API，OpenAI 負責運營和維護該 harness，而開發者則可以查看其公開代碼庫並從中學習。

開始構建

Agents API 今日面向所有開發者開放公開測試版。使用 Agents API 無需額外費用——你只需為智能體所使用的 token 和工具付費，具體如我們的定價頁面所述。

瀏覽Agents API 概覽以瞭解更多，或按照快速入門開始使用，將 Codex 背後的 harness 引入你自己的智能體。

在公開測試期間，我們將根據你們的反饋快速迭代，朝着正式可用版本推進。請告訴我們哪些地方好用、在哪裏遇到了阻礙，以及你們在生產環境中構建和運行智能體需要什麼。
