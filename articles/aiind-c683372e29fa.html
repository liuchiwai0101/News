開發者使用AI寫開源驅動遭到廠商威脅：Synaptics要求下架項目 甚至要索賠2.5萬美元

內容機器翻譯自第三方媒體（cnBeta.COM），僅供參考，以原文為準。

正文

芯片公司 Synaptics 日前向開源開發者邁克洛錫安發出停止侵權函，要求這名開發者停止開發和發佈 Linux 驅動程序 Vino。該驅動旨在為 DisplayLink 設備提供開源支持，在開發過程中開發者使用 Claude AI 輔助開發。

DisplayLink 技術常用於 USB 擴展塢和顯示適配器，可以通過 USB 等連接方式為電腦增加外接顯示器。Synaptics 提供 Linux 版 DisplayLink 支持，但其方案需要使用閉源的專有組件。

Vino 項目通過獨立的逆向工程開發，開發過程使用 Claude AI 輔助，該驅動程序在戴爾 D6000 擴展塢上測試過，開發者還希望推動相關工作成果進入 Linux 內核。

Synaptics 公司也關注到這個項目，該公司向開發者發送停止侵權函。根據停止侵權函説明，Synaptics 指控 Vino 項目侵犯英國 GB2484736 和 2485613 專利。Synaptics 要求洛錫安停止相關開發、測試和分發，同時要求刪除代碼、文檔和其他實現，也要撤回提交給 Linux 內核維護者和其他平台的相關材料。

在後續函件中，Synaptics 還表示如果開發者未在指定期限前滿足要求，該公司將尋求 2.5 萬美元的賠償，用於補償準備侵權説明材料的成本和工作。此後每週至少增加 2.5 萬美元，即超過指定日期後每 7 天增加 2.5 萬美元索賠。

Synaptics 法律負責人安德魯貝特曼表示，公開 DisplayLink 的實現方式可能會幫助該公司的競爭對手瞭解 Synaptics 的專有技術，這會影響 Synaptics 公司的競爭優勢。

開發者洛錫安在公開回復中表示，自己是個人愛好者開發者，自己的行為並未侵犯相關專利。洛錫安還對 Synaptics 的兩項專利有效性提出質疑，洛錫安稱其中的部分技術在專利申請前就已經有相關公開材料。

不過即便如此現在 Vino 倉庫也已經被轉為私密狀態，不知道倉庫是被 GitHub 刪了還是開發者按要求不再公開倉庫。不過 Synaptics 的法律函件、專利材料以及開發者的回覆，都已經發送到 Linux 內核郵件列表。
