Yahoo! 輸入法無法在 macOS 27 使用？救星「Yahoo! KeyKey 2」完美替代方案！

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

如果你是經典「Yahoo! 奇摩輸入法」的忠實用户，並且正打算升級到最新的 macOS 27，那麼在按下更新鍵之前，請務必留意這個重要資訊：升級 macOS 27 後，你熟悉的 Yahoo! 輸入法將會無法正常運作。

告別舊時代：macOS 27 正式停止支援 x86 應用

這其實是有跡可循的。蘋果早在 macOS 26 Tahoe 時就已經預告，系統未來將會停止支援 Rosetta 2（即用來執行舊版 x86 架構應用程式的轉譯工具）。隨著 macOS 27 的到來，這項改變正式生效，這也意味著多年未更新的舊版 Yahoo! 輸入法正式功成身退。

雖然在 macOS 27 Beta 測試期間，曾有社群討論指出可以透過終端機（Terminal）輸入以下指令來嘗試喚醒 Rosetta 2 支援：

/usr/sbin/softwareupdate --install-rosetta

不過經筆者實際測試，這個方法在目前的 macOS 27 正式版中，只能安裝但似乎無法正常使用 Yahoo! 輸入法（不知，其他人能否正常使用）

完美救星登場：Yahoo! KeyKey 2

雖然舊版無法使用，但先別灰心！對於依賴倉頡與速成的用户來説，筆者近期發現了一套完美的替代方案——Yahoo! KeyKey 2。

簡而言之，這是一款將經典「Yahoo!奇摩輸入法」中大受歡迎的「倉頡」及「速成」輸入法，以 Native macOS App（蘋果原生晶片架構）方式重新打造的應用程式！它不但能完美適應最新的 macOS 系統，不再有相容性問題，更讚的是它採用開源（Open-source）的形式釋出。

找回熟悉的打字手感

換一套輸入法最怕的就是「手感不對」或是「選字習慣不同」。但別擔心，針對廣大的 Yahoo! 輸入法老用家，這套 Yahoo! KeyKey 2 在細節上作出了非常多的貼心微調。

安裝後，你只需進入 Options（設定選項） 中，就可以根據自己過去的習慣進行自訂化。只要稍加設定，就能立刻重拾當年那份行雲流水的打字感覺，幾乎可以做到無縫接軌。特別一提，它能夠讓用户自訂候選字大小！

如果你也正面臨升級後的輸入法陣痛期，強烈建議試試看這個專案：Yahoo! KeyKey 2 網址

安裝方法：

方法 1：你可到 Github 下載打包版本進行安裝，當前最新版是 YahooKeyKey2-2.13.4.zip ，解壓後即可安裝。


方法 2. 也可用 Homebrew 進行安裝在 Terminal 輸入：

brew install –cask teddychan/tap/yahoo-keykey-2

    完成後，進入鍵盤 -> 文字輸入，在輸入方法選編輯，在所有輸入方式中選 + ，找到倉頡(Yahoo KeyKey2)即可。
