ReviewBench源自真實的PR評論

ReviewBench是LangChain公司爲評估AI代碼審查（code review）智能體而開發的基準測試，基於LangSmith代碼庫中真實的pull request（PR）評論構建而成。它包含59項任務，涵蓋64個核心問題，並通過Harbor框架——一個用於指令、環境和任務驗證的標準化框架——進行格式化處理。

評估方法分爲三個階段：首先，通過LLM門控（LLM gate）對已合併（merged）PR中可信審查員留下的評論進行初步過濾，篩掉弱候選項；隨後，對剩餘評論進行人工審查；最後，將確認的發現轉化爲Harbor任務。

兩項指標合併爲F1分數

作者衡量了兩個維度。Coverage（覆蓋率）衡量智能體是否在與人類審查員相同的代碼路徑上識別出了相同的核心問題。Precision（精確率）衡量智能體報告的發現中，實際正確的比例有多少。兩項指標結合爲F1分數，既懲罰遺漏的問題，也懲罰誤報。

最好的模型發現了約30%的問題

在59項任務的基線評估中，每項任務嘗試三次，表現最好的模型發現了64個核心問題中約30%的問題。這意味着，使用基礎harness的智能體遺漏了人類審查員最初發現的約70%的實際問題——絕大部分工作仍然要靠人來完成。

爲什麼結構化提示詞能把F1提升到0.32？

因爲要求智能體在得出結論之前先梳理變更內容、檢查可能出錯的地方，這一指令改變了模型的行爲，而不是依靠更強的基礎模型。在由20項任務組成的更小子集上，每項任務嘗試三次，經過微調、採用結構化提示詞的配置「Luna」取得了0.32的F1分數，明顯優於同一子集上的基礎提示詞。

LangChain這項研究的核心結論是：改進來自於提示策略——即在得出結論之前明確引導智能體分析變更內容——而不是來自基礎模型本身的實力。
