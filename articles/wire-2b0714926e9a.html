iPhone 18 Pro Max 1TB 換用 QLC NAND 高強度寫入極限慢過硬碟？

內容機器翻譯自第三方媒體（電腦廣場 · 電腦領域HKEPC Hardware · DCFever.com · 電腦王阿達 等6家），僅供參考，以原文為準。

重點內容

隨著 iPhone 18 Pro 及 18 Pro Max 已經正式開售，部分首批訂購新機的用家，已經開始使用手機，體驗新 iPhone 帶來的好處。18 Pro / Pro Max 與上代一樣，都是以 Face ID 作為生物認證的方式。不過部分用家發現，使用 18 Pro / Pro Max 期間，遇上 Face ID 運作異常的問題，影響日常使用……

部分外國 18 Pro 及 18 Pro Max 的用家發現，需要使用 Face ID 執行部分身分驗證操作，例如解鎖已鎖定的應用程式時，Face ID 未能順利完成驗證程序，甚至不知何故會隨即當機，然後強制重新啟動並返回裝置鎖定的畫面，令人不明所以，亦打亂多工作業的流程。除了突然當機重啟的情況外，亦有用家發現 Face ID 於設定期間，收到「Face ID 目前無法使用」的訊息。

本身 Face ID 設有螢幕注視的機制，並引伸出可以開啟使用 Face ID 必須注視螢幕及螢幕注視感知功能。不過有用家發現即使已開啟「使用 Face ID 需要注視螢幕」的選項，有時手機卻未有遵從該設定，未有直視 Face ID 鏡頭仍可如常解鎖，造成安全隱患。

對於上述的錯誤，目前未清楚問題影響範圍有多廣，而即使不幸成為受影響的用家，都有機會昨天遇上問題，今天卻完全正常。媒體 MacRumors 猜測，蘋果改動過 18 Pro 系列的靈動島設計，將 Face ID 紅外線鏡頭移至螢幕左上角下方，不排除 18 Pro 系列的 Face ID 問題與此有關。但是無論如何，這些都是蘋果需要透過系統更新解決的問題，甚至未必可以等到正式版的 iOS 27.2，而是會於短期內，安排推出 iOS 27.0.1，專門為各 18 Pro 系列用家排難解憂。
