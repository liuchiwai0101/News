OpenAI 宣佈開源 Codex Security CLI，支持代碼掃描、漏洞追蹤和自動化安全檢查

IT之家 7 月 29 日消息，OpenAI 今日宣佈推出開源命令行安全工具 Codex Security CLI，用於幫助開發者掃描代碼倉庫、發現和驗證安全漏洞，並將安全檢查流程集成到持續集成與持續交付（CI / CD）環境中。

OpenAI 表示，該工具實際上在正式公開前就已被人發現。目前，Codex Security CLI 仍處於早期版本階段，官方表示將根據開發者反饋持續改進工具功能。

Codex Security CLI 是一款基於命令行界面的安全工具，同時提供 TypeScript SDK 接口。開發者可以使用它掃描代碼倉庫，查看代碼變更，跟蹤不同運行週期中的安全問題，並驗證漏洞修復效果。

OpenAI 介紹，該工具支持將安全檢查加入 CI / CD 流程，幫助開發團隊在軟件開發過程中自動執行安全檢測。對於持續開發的軟件項目，這類工具可以用於提前發現代碼中的潛在安全風險。

在 CI 環境中，開發者無需交互式登錄，可通過設置 OPENAI_API_KEY 環境變量完成身份驗證。工具同時支持 ChatGPT 賬號登錄和 API 密鑰兩種認證方式，用戶可以通過參數指定使用哪一種認證方式。

此外，OpenAI 還提供了 TypeScript SDK，開發者可以直接在 TypeScript 項目中調用 Codex Security 功能。例如，通過 SDK 運行代碼安全掃描，並獲取掃描報告路徑。

OpenAI 表示，Codex Security CLI 的掃描歷史會保存在 Codex Security 工作目錄中。如果默認目錄無法寫入，用戶可以通過設置 CODEX_SECURITY_STATE_DIR 變量指定其他可寫目錄。
