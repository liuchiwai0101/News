HKGAI 開放「Agent Workshop」API：AI 智能體數十小時無間斷運作　企業一鍵整合複雜任務能力

內容機器翻譯自第三方媒體（PCM），僅供參考，以原文為準。

中國香港生成式人工智能研發中心（HKGAI）於 10 月 16 日宣佈，旗下核心平台「HKGAI Agent Workshop」的應用程式介面（API）正式開放。該平台將 AI 智能體（AI Agent）技術封裝成標準化的「能力平台（AI Capability Platform）」，並針對企業級部署需求進行深度架構設計；開發者只需透過極簡的 API 串接，即可為自家產品一鍵引入能自主執行複雜長程任務的 AI 智能體，實現企業級的大規模安全部署與穩定運行。

針對長程任務痛點：內核級沙盒隔離

新聞稿指出，現時市面上的 AI 智能體在處理長任務時，經常出現中途斷線、丟失上下文以及高昂運算成本等痛點，Agent Workshop 從底層架構全面強化企業級部署與穩定防護機制。安全方面，平台採用內核級沙盒隔離技術，支援 gVisor 核心級隔離與 runsc 出站管控，並實施嚴格的權限控管與數據隔離，確保企業機密數據的安全，滿足本地機構及大企業對資訊安全與合規的嚴謹要求。按官方説明，每個對話皆配備獨立的雲端電腦與安全的隔離環境，讓開發者將能獨立完成複雜任務的 Agent 方便快捷地接入產品中。

支援數十小時連續運作、單輪過百次工具調用

在穩定性方面，平台作出以下設計：

  • 高穩定持續運行：支援 Agent 在獨立的「雲端沙盒」內連續運作數十小時，並可單輪執行過百次工具調用，涵蓋資料檢索、程式碼撰寫及文件處理等任務。
  • 自動容災：AI 運算過程中如遇網絡不穩定或伺服器故障，系統會即時自動切換至備用接口。
  • 斷線續傳：此前 AI 已處理好的文件和進度均會保留，遇到故障時系統自動接棒，確保任務能連續數十小時穩定完成，實現自動化業務處理。

10 路並行與智能上下文壓縮

為協助企業在規模化部署時精準控制 AI 營運成本，平台在底層架構上進行了多項優化：

  • 即開即用、進度自動無縫接軌：系統能在秒級內為 AI 建構專屬且安全的虛擬工作間；即使任務暫停或系統閒置，所有工作進度都會自動儲存，下次重新啟動時即可瞬間無縫接軌，毋須從頭再來。
  • 邊思考邊執行：流式智能調度令系統能夠「邊想邊做」，讀取任務時最高支援「10 路並行」，寫入操作則按次序逐一處理，確保資料絕對一致。
  • 智能上下文壓縮：採用多級漸進式壓縮技術，自動清理冗餘數據並生成摘要，大幅降低 Token 使用成本；同時精準保留 URL、檔案路徑及 ID 等關鍵資料，確保訊息不會丟失。

原生支援 MCP 與 Agent Skills，每個對話可掛載 10 個 MCP 伺服器

生態擴展方面，Agent Workshop 原生支援 MCP（Model Context Protocol）與 Agent Skills 擴展協議，每個對話可掛載多達 10 個 MCP 伺服器，單一伺服器最多提供 256 個工具，可按需要加載各類專業技能，而不佔用模型的記憶空間。平台並透過內核級沙盒隔離與嚴格權限控管，為本地機構及企業提供「銀行級」的數據安全保障。

官方：從技術研發邁向能力賦能與生態構建

中國香港科技大學首席副校長、HKGAI 主任郭毅可教授表示：「『HKGAI Agent Workshop』的開放，標誌著中心從『技術研發』進一步邁向『能力賦能與生態構建』。HKGAI 未來將持續推動中國香港人工智能技術的商業化發展，將本地研發項目真正落地、賦能各行各業。」

開發者與企業即日起可瀏覽官方文件瞭解詳情。
