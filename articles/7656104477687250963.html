📰 技術資訊

-

**Vite 8.1**：新增實驗性「打包開發模式」支持，與未打包的開發服務器相比，打包開發模式實現了約 15 倍的啓動速度提升和約 10 倍的全頁面重載速度提升；同時提供 WASM 與 ES 模塊集成能力。

-

**Rspack 2.1**：Rspack 2.1 版本現已發佈，新版本內置基於 Rust 重構的 React 編譯器、支持 TypeScript 7，同時新增 TanStack Start 適配支持。

-

**Babel 8.0**：Babel 8.0 正式發佈，距離 Babel 7.0 問世已有八年。儘管 SWC、Oxc 等同類工具不斷興起，但`@babel`系列包的周下載量在此期間暴漲 380 倍。8.0 版本是一次現代化升級，僅支持 ES 模塊，且默認編譯目標爲 ES2023（舊版默認目標爲 ES5）。

-

**Astro 7**：Astro 剛剛推出 7.0.0 版本，本次更新升級至 Vite 8、搭載全新高性能 Rust 編譯器，同時開放完整請求處理鏈路權限。

-

**Deno 2.9**：Deno 2.9 版本可將 JavaScript 項目打包爲 macOS、Windows、Linux 三平臺獨立桌面程序。與 Electron 不同，開發者可選擇調用系統自帶網頁視圖組件，或是內置 Chromium 內核；同時工具原生支持跨平臺編譯，還能直接適配基於 Next.js、SvelteKit 等框架開發的應用。

🔧 開發工具

- **FullCalendar 7.0**：爲自有應用打造媲美谷歌日曆的使用體驗。兼容 React、Vue、Angular（7.0 版本新增 Angular 22 支持），也可直接在原生 JavaScript 項目中使用。項目採用 MIT 開源協議，同時提供商業增值擴展。

- **Kage**：網站離線鏡像工具，和瀏覽器“另存爲”功能的區別在於：它藉助無頭瀏覽器捕獲頁面 DOM，完美支持 JS 動態渲染的網站。
