Anthropic 威脅報告披露 Claude 被用於間諜軟件、導彈與無人機研發，中國實驗室大規模蒸餾提取數據

內容機器翻譯自第三方媒體（The Decoder），僅供參考，以原文為準。

AI 導讀

Anthropic 發佈威脅情報報告，記錄 2025 年 12 月至 2026 年 8 月間 Claude 被濫用的七類行為。俄語間諜組織用 AI 代理自動改寫惡意軟件繞過殺軟，也門一組織用 Claude Code 開發射程超 2000 公里的導彈軟件，另有團隊構建無人在環的自主 FPV 無人機蜂群。

推薦理由

這份報告把八個月的濫用案例按領域拆開呈現，讀者可以瞭解當前模型安全防線在哪些場景下暴露了邊界。

正文

要點

  • Anthropic 的一份報告顯示，其 Claude AI 模型被濫用於間諜活動、監控和武器研發。黑客利用該 AI 自動改寫惡意軟件，而其他組織則編寫導彈和自主無人機的軟件。
  • 阿里巴巴和 DeepSeek 等中國 AI 公司運營隱蔽網絡，大規模提取 Claude 的訓練數據，或秘密改道其自身客户的請求。政府監控數據等敏感信息也在其中被處理。
  • 在生物學研究中，安全過濾器觸及了極限，因為合法意圖與有害意圖幾乎無法區分。Anthropic 正以新模型中更嚴格的防護措施予以應對，並呼籲將訪問權限限制在已驗證用户範圍內。

Anthropic 的新威脅報告記錄了八個月間 Claude 被濫用的情況：間諜活動、全國性監控、武器軟件，以及中國 AI 實驗室的知識蒸餾。

Anthropic 的威脅情報報告涵蓋 2025 年 12 月至 2026 年 8 月，將濫用行為分為七類：網絡行動、影響力行動、監控、欺詐、生物濫用、常規武器，以及未經授權的模型蒸餾。

受影響最大的模型是 Haiku、Sonnet 和 Opus，而較新的 Fable 和 Mythos 模型僅出現在一例蒸餾案例中。Anthropic 表示，其記錄的是新型濫用行為，而非典型濫用。

網絡章節的核心發現是，高級攻擊不再需要高級攻擊者，而高級程度也不再是歸因的可靠信號。這些技術本身並不新鮮，包括竊取憑證、未修補設備、SQL 注入和釣魚。變化在於經濟性，因為偵察、利用和工具構建如今被交給以機器速度並行運行的模型。

Anthropic 表示，自主性降低了攻擊者算計中的成本一側，並使此前無利可圖的目標變得值得追求。

當殺毒工具捕獲時能自我重建的惡意軟件

Anthropic 追蹤了一個講俄語的間諜行為體，代號 GTG-20006，其使用了一個反饋循環。AI 智能體不斷檢查正在使用的惡意軟件是否被常見安全產品標記，當殺毒工具捕獲它時，這些智能體自行重寫並重新編譯惡意代碼，直到它再次躲過檢測。

Anthropic 表示，這把負擔轉回給防禦方，因為如果攻擊者變更的速度快於新簽名能夠推出的速度，那麼編寫新的檢測簽名就不再能拖慢攻擊者。

超過 20 家機構成為攻擊目標，包括政府部門、情報機構、大使館和國防承包商，重點集中在烏克蘭和歐洲。無人機供應鏈被反覆提及，該行為體竊取了一套完整的專有 SDK，用於無人機視覺系統，此外還有其他目標。訪問有時通過第三方進行，例如被攻陷的酒店住客 Wi-Fi 提供商，其住客設備隨後被植入惡意軟件，微軟在 2026 年 7 月將這一手法稱為 CaptiveCrunch。

對於 Anthropic 歸因於 ShinyHunters 團夥（GTG-50014）的集群，重點是大規模憑據挖掘。一名黑客下載了 180 萬個 Android 應用，將其反編譯，並搜索硬編碼的密鑰。Anthropic 將這一手法描述為“氛圍黑客”（vibe hacking），即由人類設定一個粗略目標，模型評估環境並反覆迭代，直到任務完成。其中一名黑客表示，除了勒索兩家公司外，他還通過 HackerOne 漏洞賞金獲利。

中國實驗室將自身客户的請求路由至 Claude

在知識蒸餾方面，Anthropic 自 2 月首次披露以來，又識別出來自另外七家中國實驗室的攻擊。知識蒸餾作為一種訓練方法是合法的，但 Anthropic 將非法版本定義為工業規模、隱蔽的行動，在未經授權的情況下提取模型能力，通常藉助使用被盜信用卡和 API 密鑰的虛假賬號網絡，並通過其所謂的“中轉站”進行路由。

迄今為止被測量到的最大規模行動被歸因於阿里巴巴的 Qwen 實驗室（GTG-16005）。一個固定提示詞讓 Claude 在回答前寫出其推理軌跡，這些記錄隨後被處理成用於 Qwen 3.5、3.6 和 3.7 模型的微調數據。峯值時每天來自 3,500 多個欺詐賬户的交互量接近三百萬次，2026 年 5 月至 7 月期間總計超過 1.51 億次交互，主要集中在智能體任務和軟件開發上。

更奇怪的是那些實驗室將自家客户的請求轉發給 Claude 的案例。Moonshot AI（GTG-16002）在十天內通過 5,380 個欺詐賬户向 Anthropic 轉發了近 30 萬條客户請求，而用户以為自己使用的是 Kimi 模型。DeepSeek（GTG-16001）利用字符串檢測請求是否來自 Claude Code 等工具框架，標記這些用户，並將選定用户路由至 Claude Opus，14 天內交互量超過 1,210 萬次。

在被轉發的請求中，Anthropic 發現一名可能與中國人民解放軍有關的用户，其將央視檔案影像用於對單一目標的分析，涉及成都數百個攝像頭的視頻，包括解放軍設施外的攝像頭。通過 DeepSeek，Claude 還收到了一名操作員的請求，該操作員持有與俄羅斯國防部相關數據庫的實時憑證，此外還涉及為中國某公安局開發案件管理系統的工作，該系統將人員活動畫像與警方記錄進行比對。

小米（GTG-16008）對 Claude 的用法有所不同，它存儲了自家 MiMo 模型用户的請求和編碼會話，並通過 Claude 重放這些對話以生成訓練數據。Anthropic 未發現證據表明 Claude 的回覆被直接提供給小米的用户。然而，這些轉發的請求包含至少十幾種語言、數百人的個人數據，如姓名、聯繫方式和公司信息。

智譜（在中國以外稱為 Z.ai）輪換了 273 個賬號，並在十天內通過一個 CoT 清洗器推送了超過 77 萬次交互，該工具可自動將捕獲的推理軌跡轉化為可用的訓練數據。為了在網絡安全任務上訓練 GLM-5.3，該實驗室首先針對 Anthropic 的 Fable 模型，但在網絡安全防護措施削弱其性能後放棄，隨後刻意轉向其判定防護較弱的模型。

據該報告稱，商湯從第三方購買轉錄文本，因此它並非自行獲取捕獲的 Claude 數據，而是通過中間市場獲得。MiniMax 通過一家空殼公司運營自己的代理網絡，該網絡僅提供 Anthropic 和 OpenAI 的模型，沒有中國模型，甚至沒有它自己的。

監控作為主要工程勞動力

在監控這一章中，Mali 尤為突出。一名顧問將 Claude 用作“Lakana 360”的主要工程勞動力，該平台用於監控全國三大移動運營商約 2500 萬張 SIM 卡。它通過語音在 SIM 卡更換過程中識別人員，標記加密和 VPN 用户，並將個人與國家生物識別民事登記系統關聯起來。

暫停該賬號只中斷了開發工作，而未影響其運營，因為該平台在本地以本地模型運行。Anthropic 記錄了伊朗相關單位的類似模式，這些單位聲稱在一年內對 6,388 名伊朗人進行了監視和畫像。

關於常規武器的第一章

在武器方面，Anthropic 首次記錄了自己的案例。也門北部的一個小組（GTG-87001）讓 Claude Code 取代人類軟件工程師，為三個導彈項目開發制導、導航與控制軟件，其中包括一枚目標射程超過 2,000 公里的多級導彈。

這些行為體並行運行了多個 Claude 實例，並將工作分散到不同會話中，使任何單個實例都無法暴露其意圖。一次試射顯然失敗了，幾小時內這些行為體就回到 Claude 上排查原因。

第二起案例（GTG-27005）很可能涉及俄羅斯自由職業行為體，他們構建了一套自主 FPV 自殺式無人機蜂群，機上搭載一個小型語言模型，並由攝像頭進行末段目標瞄準。該平台被設計用於自主致命打擊，機上模型能夠選擇“人”類目標並在無人在環的情況下觸發引爆。據 Anthropic 稱，該圖像分類器是用繳獲的烏克蘭作戰影像訓練的。

一起中國案例（GTG-17002）涉及一套約 16 個模塊的電子戰與壓制敵方防空系統套件。項目進行到中途時，模擬的默認場景切換為中國台灣的十二個目標。

生物學：Anthropic 描述了自身過濾器的侷限

生物學章節是最具自我批判性的部分。Anthropic 記錄了五個匿名案例，涉及在職科研人員，其中 Claude 為可能具有危險性的兩用項目提供了協助。在其中一個案例中，生物安全分類器阻止了一份關於基孔肯雅病毒功能獲得性研究的經費申請，該研究計劃在一家軍事研究機構開展。

據報告稱，所使用平台的運營方構建了一個回退機制，將 Claude 拒絕的請求路由至競爭對手的模型，而 Claude 本身為該機制編寫了大部分代碼。其他項目則基本未受阻礙，例如起草一份關於正痘病毒免疫逃逸基因的申請。

結論是，分類器無法既支持有用的工作又防止危害，因為兩用領域中用户的意圖無法被可靠地檢測出來。作為回應，Anthropic 推出了 Claude Fable 5，對兩用生物學請求施加了更嚴格的防護措施；而針對知識蒸餾，隨 Fable 5.1 引入的“保留思考”旨在防止新的 API 賬户操縱上下文。Anthropic 表示，在生物學領域通往前沿能力的唯一安全路徑，是通過面向經過驗證的用户的計劃。
