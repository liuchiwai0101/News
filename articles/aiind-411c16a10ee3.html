高盛收窄 Claude Code 權限只限工程師 交易員 AI 建模製圖被叫停

內容機器翻譯自第三方媒體（unwire PRO · InfoQ · cnBeta.COM），僅供參考，以原文為準。

正文

今早， 前 Claude Code 產品負責人 Cat Wu 在 X 上宣佈加入 OpenAI，出任核心產品組的產品負責人。 一天前，她剛告別了 Anthropic ，堪稱“無縫銜接”。OpenAI 總裁 Greg Brockman 立刻轉帖歡迎。

這已經是十天內，Claude Code團隊離開的第三位核心成員。前段時間，離開的分別是Claude Code的桌面版之父Anthony Morris 和 Agent 核心工程師 Thariq Shihipar。而這個時間點，Anthropic 正好站在了上市的緊要關口。

Cat Wu 的離職之所以震動硅谷，不只是因為她換了陣營，更因為她帶走了這條最賺錢產品線的完整方法論

Cat Wu，真名是Catherine Wu，她是硅谷 AI 圈炙手可熱的華裔明星產品經理。

作為 Anthropic 旗下王牌 AI 編程工具 Claude Code 和辦公智能體 Cowork 的產品總負責人 ，她與“Claude Code 之父” Boris Cherny 並稱為 Anthropic 團隊的“蝙蝠俠與羅賓”，是親手將 Claude Code 從一個內部小工具打造成全球爆款的靈魂人物之一。

她還曾是普林斯頓女學霸，大四就在校內孵化器合夥開發了協作白板軟件Scratchwork；在大廠與獨角獸歷練過，寫過代碼，研究過數據；還當過三年風險投資人，專注開發者工具和AI基礎設施。 豐富的跨界經歷，讓她成了那種少見的既看得懂代碼，也算得清商業賬，還摸得準開發者想要什麼的人。

那時，Claude Code 還只是 Anthropic 內部一個不起眼的實驗性項目。Cat Wu 想試試這東西到底能做什麼，就讓它幫自己從零搭建一個強化學習環境。她花了幾十個小時，反覆描述需求、調整方向，從頭到尾沒有寫一行代碼。當環境最後真的跑通了，她被這次體驗震住，轉頭申請轉進了這個剛起步的小團隊。

在那個團隊裏，她和技術負責人 Boris Cherny 組成了黃金搭檔。Boris 負責寫下最初的原型代碼，盯下一步能做到什麼；而 Cat Wu 負責把想法變成產品，並調動各方資源推向市場。她執行力極強，開創了極快的產品迭代模式，直接把研發週期從數月壓縮到了幾周、甚至按天來計算。

後來，她的職責進一步延伸到了 Claude Cowork，探索 AI 在團隊的工作場景。

如今，Claude Code 是全球最火的 AI 編程 Agent 之一，大量開發者使用。2026 年 2 月，Anthropic 在 Series G 融資公告裏披露，Claude Code 的年化收入運行率（ARR）已經超過 25 億美元，較年初直接翻倍。

放眼整個科技發展史，這都是增長最快的企業級軟件（SaaS）產品之一，而它在 2025 年 5 月才剛剛向公眾開放。 Cat Wu 執掌的產品線，就是這條收入曲線最核心的增長驅動力。

Cat Wu 是個反傳統的人，在 Anthropic， 她重新定義了"AI時代產品經理該怎麼幹活" 。 她在播客裏公開講過幾條方法論，至今被同行奉為圭臬：

比如，長 PRD 已死，在模型能力幾個月一變的今天，PM有想法就自己或者讓AI快速搓一個能跑的原型，直接在運行和評測中迭代產品；還有“三個月報廢原則”，任何半年以上的產品規劃都會失效，只要今天能改善體驗就立刻上線。她甚至在升級新模型時，乾脆利落地砍掉了團隊辛辛苦苦攢下的 20% 舊提示詞補丁；她鼓勵工程師做主線之外的“支線任務”。在這種鼓勵自由探索的氛圍裏，工程師們在日常閒聊、下午茶交流裏自發撞出了很多經典功能：現在風靡全球的 Claude Code 桌面端、極具靈性的“反問用户（AskUserQuestion）”功能，都是這麼來的。

在離職貼中，Cat Wu表達了對 Claude Code 的自豪，這個產品從早期需要用户逐條手動審批權限，到如今可以信任模型自身判斷，自動完成權限審批，已經完成了關鍵的跨越。而她在這一旅程中收穫的感悟，正如她此前在播客分享的，打造 AI 原生產品最重要的一件事，就是學會放手。

有網友指出，她在 Anthropic 待了大約 26 個月。按硅谷常見的四年期權規則，她已經拿到了大約一半的股份。儘管在公司上市前，這些期權只是“紙面財富”，但只要公司完成敲鐘，她手裏已經兑現的那部分依然可以套現。

事實上，選擇在此時退場的並非只有她。就在 10 月 24 日，團隊另外兩位核心骨幹 Thariq 和 Anthony 也搶先一步宣佈離職。緊接着的兩天後，Anthropic 正式向 SEC 遞交了 S-1 招股書，計劃 11 月 9 日啓動路演。招股書上的數據極其亮眼：2026 年上半年營收超 162 億美元，估值直指萬億美元量級。

Cat Wu 離開的時機，正值這家公司從“創業神話”蜕變為“上市公司”的前夜。對於留下來的員工，上市意味着財富狂歡； 但對於 Cat Wu 這個剛把產品從零帶到 25 億美元 ARR（年度經常性收入）的“一號位”來説，此時正是她職業聲望的最高點。帶着這份耀眼的戰績，她剛好順理成章地開啓下一段冒險。

資本市場並不關心她個人少拿了多少錢，投資者更在意這種“集體離職”傳遞出的危險信號：

Claude Code是Anthropic商業化的主引擎，是這家公司對抗OpenAI代碼產品最重要的一張牌。在短短十天內，這條核心業務線的產品一把手、桌面版負責人、Agent 核心工程師接連出走，一號位甚至直接跳槽到了最大的競爭對手那裏。這在任何一家衝刺IPO的公司身上，都是投資者會反覆掂量的治理問題。

Tibo 可不是一般人，他之前在 Google DeepMind，進入 OpenAI 後，一路主導了早期大語言模型、ChatGPT 到 Codex 這條核心產品線。把Claude Code 的產品一號位放到他手下，説明 Cat Wu 接手的不是什麼邊緣項目，而是OpenAI整個智能體產品線的產品中樞。

她曾在 Anthropic 跑完了完整閉環，懂得如何把實驗室裏的模型能力，打磨成開發者離不開的產品。而這，恰恰是 OpenAI 當下最缺的。
