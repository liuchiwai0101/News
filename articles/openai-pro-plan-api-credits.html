OpenAI 重開 200 美元 Pro 訂閲　API 額度減半改推按量付費

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

OpenAI 重新開放每月 200 美元的 Pro 訂閲供新用户登記，但同時把每美元可得的 API 額度削減一半。

Pro 訂閲重開 API 額度減半

OpenAI 員工 Thibault Sottiaux 表示，訂閲用户實際可完成的工作仍應多於一個月前，並指向本週推出的 GPT-6 Sol 與 GPT-6 Luna，兩款新模型的 API 價格為前代的一半。他亦指出，原本的 5 小時用量上限已永久取消，訂閲用户可以自行分配每週的額度。

轉向按量付費定價

這次調整顯示 OpenAI 正由大幅補貼的訂閲模式，轉向按量付費的定價方式。Microsoft 已在部分範疇透過 Copilot 採取類似做法。

Sottiaux 稱，長遠而言 API 價格應會下降到足以令大部分人按需要購買用量，而訂閲與 API 之間每美元所得不會出現明顯差距。他認為，這樣可讓 AI 實驗室把收入與企業實際從 AI 取得的價值更緊密連繫。
