自動遮蓋敏感資料　原價 US $0.99《ShadowClip》限時免費

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

ShadowClip 是一款專為保護隱私設計的圖片編輯工具，適合經常與同事或朋友分享截圖的用户。它能自動偵測並移除畫面中的個人數據、API 金鑰及金融資訊，確保你在發送前已清除所有敏感內容。目前該應用正提供限時免費下載。

智能識別多重敏感資訊

ShadowClip 能自動偵測超過 20 種格式的 API 金鑰、信用卡號、國民身分證字號、電郵地址、電話號碼、IP 位址、人臉、QR Code 及條碼等。它支援 30 種語言的文字檢查，包括中文、日文及阿拉伯文，並在本地端進行不可逆的像素級別遮罩處理，確保原始資料徹底消失且無網路傳輸風險。
