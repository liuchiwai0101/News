亞股 美股 升息 ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' 00:00 2026/11/23 01:35:27 經濟日報 國際中心、謝守真／綜合報導 美股上週五（20日）崩跌，亞洲金融市場嚴密戒備今（23）日行情走勢，股市高度仰賴AI供應的台灣與南韓，週末都召開緊急會議商討市場情勢，並且推出穩市措施；大陸監管機構昨（22）日更是射出「穩市三箭」。

儘管策略師認為，美股賣壓可能暫時告一段落，但Anthropic股價下跌、及本週出爐的通膨指標強化12月升息預期等發展，都暗示最糟情況可能還沒結束。

台股上週慘跌17.5%，跌幅為亞股最大，首爾Kospi指數也跌近8%，之後美股也遭「血洗」，且各類股全跌，投資人無處可躲，各大指數周線全面皆墨，科技與晶片股災情慘重，那斯達克綜合指數單周重挫10%，費城半導體指數暴跌逾17%，輝達股價周線跌幅將近23%。

Anthropic掛盤第二天就重挫，未能上演市場期待的提振AI類股表現；同時，輝達風暴仍未平息，除了證管會（SEC）正在調查其會計作法，加州也傳出正在調查是否涉嫌刑事犯罪，共同創辦人黃仁勳的相關報導更是每天都有，在在使投資人憂心亞股23日開盤時可能陷入動盪。

台灣主管機關週末連續出招，包括平盤下一律禁空、研擬放寬融資擔保維持率由130%調降至120%等。

為緩和市場憂慮，南韓當局22日召開緊急會議，並宣佈分階段的穩定市場措施，包括立即籌備股市穩定基金，確保能在必要時啟動，同時鬆綁上市公司的每日回購股票上限，為期三個月。另外加強監測非法放空活動三個月，矢言若偵測到相關活動，將「強力回應」。

大陸監管機構昨日也緊急射出「穩市三箭」，包括自11月30日起將融資保證金比率由100%降至80%、創業板引入造市商、滬深交易所集體降費等，業內估算，將釋放近人民幣4,000億元（約新台幣2兆元）增量資金，有助活絡A股市場。

策略師認為，美股「恐慌指數」VIX已升至逼近40，暗示拋售潮可能即將告一段落，因為歷史經驗顯示，在VIX衝上40後，標普500指數在之後六個月都會上漲約20%。分析師也認為，在11月26日的感恩節前後，股市通常會有一些樂觀氛圍，可望帶來支撐。

但反彈期能持續多久仍是問號，因為在AI大將黃仁勳下台後，市場對AI支出前景、以及投資報酬的憂慮日益加深，並且憂心美國加強管制海外資料中心運算資源，將對AI支出大踩煞車。

利率也未捎來好消息。美國預定25日公佈的通膨指標10月個人消費支出（PCE）平減指數，年升率預估將比9月提高0.2個百分點到3.8%，核心PCE平減指數年升率也將加速升抵3.2%，都將強化聯準會（Fed）12月升息的預期，甚至提高明年第1季升息的機率。
