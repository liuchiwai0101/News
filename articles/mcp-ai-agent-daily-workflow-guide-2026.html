🤔 什麼是 MCP？一句話講清楚

如果把 AI 大模型比作一臺超級電腦，那 **MCP（Model Context Protocol，模型上下文協議）** 就是它的「USB-C 接口」——讓 AI 能直接連接你的筆記、郵箱、數據庫、項目管理工具，而不再只是聊天窗口裏的文字遊戲。

2025 年 MCP 還是開發者的專屬玩具，但到了 2026 年，隨着 Claude Desktop、Cherry Studio、ChatGPT Desktop 等客戶端的成熟，**普通人也能在 5 分鐘內配好 MCP，讓 AI 真正幫你幹活**。

🛠️ 準備工作：5 分鐘搭建你的 MCP 環境

第一步：選擇你的 AI 客戶端

🎯

推薦：國內用戶首選 Cherry Studio，開箱即用支持 MCP，且可接入通義千問、DeepSeek 等國產模型，無需科學上網。

第二步：安裝第一個 MCP Server

以 Cherry Studio 为例：

- 打开 Cherry Studio → 设置 → MCP Servers

- 点击「添加 Server」→ 选择内置模板（如 Notion、Filesystem）

- 填入 API Key（如 Notion Integration Token）

- 點擊「啓用」→ 狀態變爲綠色即成功

Claude Desktop 用户需编辑配置文件 claude_desktop_config.json：

{
  "mcpServers": {
    "notion": {
      "command": "npx",
      "args": ["-y", "@notionhq/notion-mcp-server"],
      "env": {
        "OPENAPI_MCP_HEADERS": "{\"Authorization\":\"Bearer ntnl_你的token\",\"Notion-Version\":\"2022-06-28\"}"
      }
    }
  }
}

第三步：驗證連接

在對話框輸入：「幫我列出 Notion 中最近的 3 個頁面」。如果 AI 能直接返回結果，說明 MCP 已連通。

解決方案

**MCP Server 组合**：PostgreSQL MCP / SQLite MCP + Supabase MCP

**工作流**：

- 配置數據庫 MCP Server 連接到你的業務數據庫（只讀權限）

- 用自然語言提問：「上個月各渠道的新增用戶數是多少？按渠道排序」

- AI 自動生成 SQL → 執行查詢 → 返回結果

- 進階：讓 AI 生成圖表描述或導出 CSV

配置要點

⚠️ **安全提醒**：務必使用**只讀數據庫賬號**，且限制只能訪問需要的表。MCP Server 的數據庫連接配置中不要使用管理員權限。

{
  "mcpServers": {
    "postgres": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres", "postgresql://readonly_user:password@localhost/mydb"]
    }
  }
}

實際效果

運營同事現在可以直接用自然語言查數據，不再依賴數據分析師。日常數據查詢從「提需求 → 等排期 → 2 天后拿結果」變成「問一句話 → 5 秒出結果」。

❓ 常見問題

**Q1：MCP 需要編程基礎嗎？**

不需要。2026 年的主流客戶端（Cherry Studio、Claude Desktop）都提供圖形化配置界面，大部分 MCP Server 支持一鍵安裝。本文的 5 個場景都提供了完整配置，複製粘貼即可。

**Q2：國內用戶必須用翻牆工具嗎？**

不需要。Cherry Studio 支持接入通義千問、DeepSeek 等國產模型，配合國內可用的 MCP Server（如 Filesystem、SQLite），完全可以在國內網絡環境下使用。

**Q3：MCP 安全嗎？會不會泄露數據？**

MCP 運行在本地，數據不會經過第三方服務器。但需注意：①使用只讀權限連接數據庫；②API Key 妥善保管；③優先選擇開源、社區驗證過的 MCP Server。

**Q4：這些工作流需要付費嗎？**

MCP 協議本身免費開源。費用主要來自：①AI 客戶端訂閱（如 Claude Pro $20/月）；②部分 MCP Server 調用的第三方 API 費用（如 Notion API 免費，Bright Data 按量計費）。

**Q5：和 Zapier/Make 有什么区别？**

Zapier/Make 是傳統的「if-then」自動化，需要預設觸發條件。MCP + AI Agent 是「理解意圖」的智能自動化——你用自然語言描述需求，AI 自主決定調用哪些工具完成任務。
