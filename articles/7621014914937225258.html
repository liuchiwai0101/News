🛠️ 第一關：依賴管理的“愛恨情仇”

在 package.json 的世界裏，存在着兩個平行宇宙：dependencies 和 devDependencies。分不清楚？小心你的生產包體積爆炸！

#### 📦 生产依赖 (dependencies)

這是你項目的**靈魂**。沒有它們，你的應用跑不起來。

- **react (19.2.0)**: 2026 年的王者。現在的 React 不僅僅是 UI 庫，它是- **響應式、組件化、數據綁定**的集大成者。React 19.2 更是引入了穩定的- **Compiler**，自動幫你做- `useMemo`和- `useCallback`的優化，你只管寫代碼，性能它來扛！

- **react-dom**: 如果把 React 比作大腦（Core），那- `react-dom`就是手腳。它負責把虛擬 DOM 真正渲染到瀏覽器的 DOM 樹上。- *冷知識*：Vue 3.5+ 其實也借鑑了 React 的很多思想，可以說- `Vue = React(Core) + 更貼心的語法糖`。但在生態廣度上，React 依然是那個“第一的現代前端開發框架”。

#### 🔧 开发依赖 (devDependencies)

這是你項目的**工具箱**。只在開發、測試、構建時使用，上線時不需要帶走。

- **vite**: 開發服務器和構建工具。

- **stylus/sass**: 預處理器。你寫代碼時需要它編譯 CSS，但瀏覽器只需要最終的 CSS 文件。

- **typescript/eslint**: 代码检查员。

# 安装开发依赖 (记得加 -D 或 --save-dev)

#### 2. 配置路由：搭建你的“立交橋”

別再寫一堆 if (path === '/home') 了。讓我們用聲明式的方式配置路由。

// src/main.jsx
import { StrictMode } from 'react'
import { createRoot } from 'react-dom/client'
import { BrowserRouter, Routes, Route } from 'react-router-dom'
import App from './App'
import Home from './pages/Home'
import About from './pages/About'
import UserProfile from './pages/UserProfile'
createRoot(document.getElementById('root')).render(
  <StrictMode>
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<App />}>
          <Route index element={<Home />} /> {/* 首页 */}
          <Route path="about" element={<About />} /> {/* 关于页 */}
          <Route path="user/:id" element={<UserProfile />} /> {/* 动态路由：/user/123 */}
        </Route>
      </Routes>
    </BrowserRouter>
  </StrictMode>,
)

🔄 第三關：生命週期——Dev -> Test -> Prod 的輪迴

前端開發就是一場無盡的輪迴：

- **Dev (開發)**:- `npm run dev`。Vite 開啓 HMR (熱模塊替換)。你改一行代碼，瀏覽器瞬間刷新，狀態都不丟。這是- **創造**的階段。

- **Test (測試)**:- `npm run test`。Jest/Vitest 上場，確保你的組件不會在奇怪的地方崩潰。這是- **找茬**的階段。

- **Production (上線)**:- `npm run build`。Vite 使用 Rollup 進行生產打包，Tree-shaking 搖掉無用代碼，壓縮、混淆、哈希命名。這是- **交付**的階段。

**循環往復，永無止境：**

Dev ➡️ Test ➡️ Prod ➡️ (发现 Bug) ➡️ Dev ...

在這個循環中，**Vite** 是你的加速器，**React 19** 是你的穩定器。

- **開發時**：ESM 極速加載。

- **生產時**：Rollup 極致優化。

- **運行時**：Compiler 自動優化渲染。
