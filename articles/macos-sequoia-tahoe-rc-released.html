macOS Sequoia 15.8.2 與 Tahoe 26.7.2 首個 RC 推出　發佈説明僅提安全修正

內容機器翻譯自第三方媒體（NewMobileLife 流動日報），僅供參考，以原文為準。

Apple 除了推出 macOS 27.2 Golden Gate 公測版 2，亦向開發者推送 macOS Sequoia 15.8.2 與 macOS Tahoe 26.7.2 的首個 Release Candidate（RC）。這兩個更新以安全修正為主。

Sequoia 與 Tahoe 首個 RC 推出

Apple 在未有先推出常規 Beta 版本的情況下，直接向開發者發佈 macOS Sequoia 15.8.2 與 macOS Tahoe 26.7.2 的首個 RC。這種做法在舊版 macOS 的點更新中屬常見安排。

對上一個版本 macOS Sequoia 15.8.1 與 macOS Tahoe 26.7.1 於上月底推出，兩者都經過兩個 RC 才正式發佈。macOS Sequoia 15.8.2 RC 1 的版本編號為 24H219，macOS Tahoe 26.7.2 RC 1 則為 25G320。

發佈説明僅提安全修正

Apple 的發佈説明只提到這兩個 RC「提供重要安全修正，建議所有用户使用」。上月的 macOS Sequoia 15.8.1 與 macOS Tahoe 26.7.1 更新亦只包含一項 CoreGraphics 安全修正，其説明為「處理惡意製作的檔案可能導致任意程式碼執行。Apple 得悉有報告指，此問題可能已在針對 iOS 27 之前版本的特定目標用户所發動的極精密攻擊中被利用」。

修正詳情待正式版公佈

Apple 可能在 macOS Sequoia 15.8.2 與 macOS Tahoe 26.7.2 正式發佈後才披露修正詳情。這兩個版本料與 macOS 27.2 Golden Gate 一同推出，時間可能在未來數週內。
