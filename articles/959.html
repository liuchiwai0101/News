OpenAI 将在 ChatGPT 应用中集成 Codex 功能

IT之家 6 月 3 日消息，OpenAI 持續拓展 Codex 的應用邊界，不再侷限於一款智能編碼桌面應用，而是朝着面向全用戶的通用生產力工具演進。圍繞這一目標，該公司於今日發佈三項面向企業端的 Codex 功能更新。此外，OpenAI 表示，不久後將在全平臺版 ChatGPT 應用中集成 Codex 功能。

OpenAI 今日圍繞 Codex 商用落地發佈三項更新：上線六款全新智能體插件、新增批註功能與站點生成功能，相關發佈內容來自 OpenAI 主題直播《職場智能》。

發佈會上官方透露，未來數週內將在所有版本 ChatGPT 應用中嵌入 Codex 能力，並非兩款產品合併，而是在 ChatGPT 裏新增更多 Codex 相關功能。

官方的產品邏輯是：多數企業用戶熟知並在用 ChatGPT，但不清楚何時、何種場景需要 Codex。將 Codex 智能體功能接入 ChatGPT，能夠直觀體現兩款工具的協同關係。

OpenAI 同步推出六款聚焦企業業務場景的 Codex 插件，覆蓋六大領域：銷售、數據分析、創意內容製作、產品設計、公募股權投資、投行業務。

OpenAI 對六款插件功能彙總如下：

1. 數據分析插件：賦能分析師與業務團隊依託數據答疑，可深挖產品及經營數據、定位關鍵指標異動原因，對接雪花數據、Databricks Genie、Hex、Tableau 等工具生成報表與數據看板，後續還將接入更多平臺。

2. 創意製作插件：助力營銷與創意團隊把需求簡報落地爲可審校素材，依託 Figma、稿定設計、Shutterstock、Picsart、Fal 等工具製作營銷版面、迭代多版廣告素材、產出產品實景圖及電商專用配圖。

3. 銷售插件：幫助銷售團隊結合客戶信息推進成單，對接 Salesforce、HubSpot、Slack、Outreach 等多款工具，篩選高價值客戶、籌備面談、跟進售後、更新客戶檔案、制定簽約方案、排查高危待跟進訂單。

4. 產品設計插件：快速把初步構想轉化爲可評審原型，支持產品方向調研、用戶流程覈查、基於網頁鏈接生成原型、靜態截圖交互式改造，設計成果可無縫導入 Figma、Canva 繼續優化。

5. 公募股權投資插件：輔助投資人梳理市場與標的企業信息，整合穆迪、Daloopa、Datasite、FactSet、倫交所集團、標普、PitchBook、Hebbia 數據源，查閱財報、橫向對標企業、捕捉行業信號、研判投資邏輯的強弱變化。

6. 投行插件：方便投行從業者把調研與盡調內容整理成交付客戶的正式材料，依託權威數據製作推介方案、對標同類企業與交易案例、從盡調信息提煉投資建議。

除此之外，Codex 正式開放批註、站點兩項面向職場的實用功能。

該功能此前已面向開發者落地，如今全行業企業均可使用：

開發者原本就能借助批註功能優化 Codex 生成的代碼、Markdown 文檔和網頁，使用時選中需要修改的內容，即可定向告知 Codex 調整需求。如今該用法拓展至文檔、表格、幻燈片等各類自研內容。

例如：選中網頁導航欄，指令 Codex 修改字體；圈出投資論點裏的關鍵表述，一鍵溯源信息出處；標註圖表，優化圖表標題。Codex 僅針對選中區域修改，無需推翻重做已成型內容。初稿完成後的打磨、改稿、迭代環節，批註功能能大幅提升 Codex 實用性。

站點生成功能：

企業及大客戶現已開啓該功能預覽，用戶可通過 Codex 快速生成、分享可在線部署的交互式網站與應用。

站點是承載創意的全新畫布，Codex 可將思路、數據分析、項目方案轉化爲數據看板、日程表、協作評審空間、項目看板、素材圖庫以及輕量化工具。當前支持通過鏈接分享至團隊全員，打造統一協作空間，方便成員查閱內容、補充意見、跟進項目進度、協同決策。

IT之家注意到，早在今年 5 月，OpenAI 就已在 iPhone、iPad 及安卓端 ChatGPT 中上線 Codex 遠程操控 Mac、Windows 電腦的功能。
