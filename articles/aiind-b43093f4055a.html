中國 人工智慧 SpaceX ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' ', ' 00:00 2026/11/20 23:36:34 中央社 華盛頓20日綜合外電報導 美國財經媒體CNBC今天報導，SpaceX旗下人工智慧（AI）程式編碼平台Cursor正考慮逐步停止使用中國開發的開放權重AI模型，理由是「地緣政治風險」。

路透社報導，CNBC報導引述美國聯邦眾議院國土安全委員會（House Committee on Homeland Security）及美國聯邦眾議院美中戰略競爭特別委員會（HouseSelect Committee on China）報告。

--> 這份報告歷經數月調查，探討中國AI模型在美國科技產業的應用情況。報告指出，Cursor已「告知委員會」相關計畫。

CNBC報導，度假租屋業者Airbnb及外送公司DoorDash也就使用中國AI模型一事參與這項調查。

SpaceX、Cursor、Airbnb、DoorDash及美國國會相關委員會未立即回應路透社的置評要求。

路透社本週稍早曾獨家報導，川普政府正考慮要求美國企業公開揭露使用中國AI模型的情況，希望藉此降低企業對中國AI模型的依賴，同時避免祭出可能引起產業界或中方反彈的新限制措施。

根據路透社報導，美國財政部及白宮科技政策辦公室（OSTP）已討論這項計畫，適用對象將包括Airbnb等企業。

SpaceX正與Cursor合作開發Grok系列AI模型，Cursor參與這些模型的訓練工作。
